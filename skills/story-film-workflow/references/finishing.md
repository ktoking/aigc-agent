# 配乐、淡入淡出与封面

用于完整制作的最后阶段，或给已通过的静帧成片补配乐与封面。先读取当前story、manifest、主视频、独立最终旁白和时间线，不重生成图片或TTS，不重排字幕。另存新版本，保留旧视频及原始音乐。

## 找到并验证指定音乐

- 优先用户提供路径或项目已有选曲。只有歌名时，先在本地Music、QQ音乐下载目录搜文件名，再用ffprobe核对TITLE、ARTIST、实测时长与可解码性；文件名略写时以元数据确认，不凭相似名字换曲。
- macOS QQ Music可从`~/Music/QQ音乐/`开始查找；必要时只读`~/Library/Containers/com.tencent.QQMusicMac/Data/Library/Application Support/QQMusicMac/qqmusic.sqlite`解析下载路径。`iMusic`可能只是播放缓存，不能称为已下载文件。
- 加密/损坏文件不能直接改扩展名冒充可用音频；先查现有可播放副本或当前应用支持的导出，不把鉴权信息、登录材料写进项目。
- 复制本次选曲到story的production版本内，记录原路径、标题、作者、时长和SHA256。具体曲名和本机用户路径属于story，不写进通用默认。

## 混音与时间

1. 用最终主视频的帧数/帧率确定D；旁白实测时长应与D一致，偏差超过一帧先处理排时。已有视频含配乐时，优先独立旁白stem，防止两层音乐相加。
2. 分别测旁白和音乐的LUFS及真峰值。可用ffmpeg `loudnorm=I=-16:TP=-1.5:LRA=11:print_format=json`作测量，忽略其输出归一化建议；TP参数仅支持-9至0，不用它直接设极低音乐峰值。
3. 音乐起始参考目标为旁白综合响度低14dB，且音乐真峰值不高于-22dBTP；实际增益取两个约束的较小者。不是把线性volume固定成某百分比就认为不会盖过旁白。默认采用固定增益，音乐原有动态保留；不使用旁白触发的侧链压低、自动音量或逐句增益，避免一阵一阵的抽吸起伏。保留旁白原增益、音高、语速与时间位置。只有用户明确要求时才启用自动压低。
4. 连续循环原音乐，裁到D；短片截断，长片循环，最后一遍未播放完也只留到D。只对整条音乐首尾各做一次0.5秒淡入淡出，不给每次循环另添停顿；原曲本身首尾的安静段与循环衔接需实际抽听检查，不能声称已无缝听审。
5. 只淡音乐，不能为了音乐0.5秒淡出吞掉旁白最后一句。画面首尾各0.3秒淡黑，30fps下9帧；在已有镜头时间内完成，不插黑场等待、不改变0.1秒cue间隔或0.1秒镜间叠化。首末实际编码帧需检查淡黑生效。
6. 混合时不自动归一化压低所有人声；检测合成峰值/削波，必要时重调音乐或使用有记录的峰值保护。对每条配音cue或有效语音窗口比较音乐stem和旁白RMS；BGM应明显更低，异常窗口调整后再验收。音频数字指标不能替代人工听感。

## 封面

- 原图保存为独立封面，记录hash。保留构图、文字和长宽比；竖版封面配横版视频时可用播放器`poster`配`object-fit:contain`完整展示。
- MP4可额外嵌入JPEG/PNG为`attached_pic`，它是封面附件，不是主视频帧。不同播放器支持不一，同时交付独立封面与带poster的页面，不承诺所有平台自动读到。
- 封面不等于片头卡。未明确要求时，不把封面插进正片而推迟台词/字幕。需要实际封面片头时，记录其明确时长并同时更新音画时序。

## 可复用执行器

```bash
python3 <skill>/scripts/finish_video.py \
  --video <原成片.mp4> --narration <最终独立旁白.wav> \
  --bgm <指定音乐.ogg> --cover <指定封面.jpg> \
  --output <新版本/video.mp4> --work-dir <新版本生产目录>
```

默认音乐响度差14dB、音乐峰值上限-22dBTP、固定增益不自动压低、音乐首尾0.5秒、画面首尾0.3秒。已完成测量时可用`--bgm-gain-db`显式传入计算后的增益，测量报告另外保存；其余参数可按用户要求覆盖。`--duck-music`仅在用户明确要求时才使用。此脚本保留`bgm-loop.wav`、`bgm-bed.wav`、`mix.wav`供核对，不需要再次请求TTS。拒绝覆盖已有输出。

输出`video.manifest.json`先标记`RENDERED_QA_PENDING`。不使用全局`-frames:v`意外截断音频或封面；`-t D`限制时长，完成后核对实际帧数。

## 交付验收

- 核对主视频分辨率、帧率、帧数、音轨时长；识别`attached_pic`，不能把封面算成第二路正片。完整解码实际输出。
- 核对音乐循环次数、尾段截断、0.5秒音乐包络、0.3秒画面首尾；检查主片段未移动、字幕时序未变。
- 测旁白/音乐相对响度、有效语音窗差值、合成真峰值/削波；编码音轨与最终mix相关性，防止映射错音轨或配乐未进入。
- 查看真实编码首中尾、循环衔接及封面，正常速度播放样段。完整顺序播放、完整人工连续观看和人工听审分别记录PASS或NOT_RUN。
- 交付新MP4、原图封面、播放器poster、实际参数和QA；按原合同保留内嵌字幕或无字，不无故新增独立字幕或公开上传。
