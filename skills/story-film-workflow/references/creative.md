# 叙事与生图

## 新故事

先区分题材、叙事视角和画风。当前默认小说式故事、第一人称叙事、真人写实、干净干燥的画面；题材可以是悬疑、奇幻、爱情、历史等，不把题材自动等同于脏乱灾难风。用户明确要其他视角或画风时覆盖。不能将上一部的衣服、人脸或场景写进通用提示词。

先建立可复用的故事文档：一句话卖点、世界规则、角色欲望/限制、关系、时间线、场景及关键道具状态。按用户授权写剧本；已通过的正文制作成片时逐句保留。每集聚焦一个实际变化，开头提供异常/冲突，结尾用具体未解决问题续接，不用长段世界观解释填时长。

## 从小说正文到第一人称旁白

1. 新故事先写可独立阅读的小说式正文：人物要什么、遇到什么阻碍、如何选择、选择导致什么变化。用动作、物件和对话承载情绪，不把故事写成镜头清单或设定介绍。已有小说先核对原文与授权改编范围，不重写已确认事实。
2. 将正文改为适合朗读的“我”的叙事稿，保留必要角色对白，标清说话人。信息限于“我”所见、所闻、回忆或后来得知的内容；推测写成推测，不能突然知道他人的内心或未见事件。第一人称不要求每句都出现“我”。
3. 用口语可懂的短句与句群推进因果，重要动作或揭示留下表演空间。文本初稿可估时，最终以指定TTS音色、情绪、语速生成后的真实时长为准，不用固定字数保证5秒，也不为图片节奏截断台词。
4. 正文、旁白稿、TTS朗读文本分开保存；后者只增加已说明的发音展开、停顿和合法语气标签。纯重制时保留已通过正文，若必须改写则明确展示变更。

第一人称是**叙述者身份**，不是画面机位要求。可以使用主角正面、侧面、过肩、环境和道具镜头；只有标为POV的图才采用主角眼睛位置。画面信息仍需符合该时刻的叙事与故事连续性。

小说正文、旁白和必要对白完成后，执行[剧本文案检查](script-language-checklist.md)，六项通过后再交用户试读或进入配音。需要反复修改的是稿件本身，不能只在生图负面提示词里补“不要AI味”。

## 约5秒一张、不重复的镜头规划

- 配音分段和图片分镜分别规划：一段10秒旁白可配两张独立图；一张5秒图可承载两句短话。图片不必按字幕或每句话机械切换。
- 以5秒为目标，主要范围4–6秒，沿语义/事件转折调整；短揭示、片尾余量或长句可例外，在shot表写明理由。每分钟约12张、6分钟约72张是预算估算，不是精确图片数量或必须凑满的规格。
- 每个镜头只表现一个可读事件/状态，并比上镜提供新的动作、关系、线索、结果或情绪落点。长旁白提前规划合理细节图，不能全程停在同一张脸上，也不能为凑数量随机换无关场景。
- 每个shot_id使用独立成片图片。演员脸/服装/场景参考可以复用；最终选图不可在后面再次出现。回忆也生成新的相关镜头，不回放原图。缩放、镜像、裁切、调色同一图都不算新图；同地点换图还要有事件或状态上的区别。
- 建立shot表：shot_id、音轨/旁白范围、起止帧、展示时长、事件新增信息、人物/场景/道具ID及状态、画面视角/景别、image_path、完整prompt、参考职责、选图hash、时长例外理由。时间只取一份统一时间线，转换成帧后确保总时长覆盖完整音轨。
- 实际镜头长度包含其分配到的外部空档/转场时段，不能每换图额外累加0.1秒。原有“叠化放空档内”仍适用；同一画面持续期间构图固定，不逐句重置位置。

制作顺序是：旁白实测 → 按事件拆约5秒镜头 → 写逐镜prompt → 生成每镜新图 → 检查 → 合成。先做演员/画风基准可以，但不要先随意生成一批图再用无关旁白拼满。

画面时长由台词驱动。密集叙述和画面事件一起推进；句内自然停连不能一律删掉。实际配音用于取时长时，保护声母、尾字和轻声；无声交付仍可沿用这些测量时长，但未来配音是否吻合须另验。

## 角色与参考职责

为每个人物建立独立ID、演员脸、年龄范围、发型服装、性格/表演和禁止变化项。场景卡记录布局、入口及光源，道具卡记录数量和形状，连续性表记录每镜头前后状态。

参考图按职责传入：人物参考只锁身份；场景参考只锁空间；风格参考只锁影调与材质。不要把全部演员描述或参考图传到每一张图。画面只有一个人，就只要求一个实体演员；屏幕内人物写清“仅存在于二维监视器图像内”，不应站进房间。

一句完整的镜头prompt应明确：

- 本镜头唯一事件、人数、人物所在空间与边界。
- 选用演员ID及各输入图负责什么。
- 时段、光源和已经发生的状态变化。
- 构图/景别及需要看清的手、门、证据或道具。
- 同一画风下的清楚大形、自然比例和适度材质。
- 与当前镜头相关的限制；不要用巨大通用负面词表挤掉核心画面。

写实风默认是自然可信的人脸、衣服、空间尺度与光线，不是脏乱、积水、过锐、塑料皮肤或满屏颗粒。默认背景有秩序、少量必要道具、干燥哑光地面/墙面/衣物，不加无关垃圾、重污渍、霉斑、渗水、雨雾、满地水和油亮湿反光。紧张/悬疑通过人物表演、空间距离、光线与构图表现，不依赖潮湿废墟。正常真实材质可以保留，不要磨皮成塑料或把场景做成无物件的样板间。确实需要偏离时以用户明确的场景要求为准，不能自行用题材推断授权。

可复用的逐镜生图模板（填写具体事件，不把占位符直接送模型）：

```text
真人写实电影静帧，画幅/分辨率按项目设置。
角色：[角色ID、参考图职责、当时服装表情]；仅出现[实际人数]。
地点与时刻：[场景ID、光源、布局、与前镜连续状态]。
本镜唯一事件：[可见动作或结果]；新增叙事信息：[与前镜区别]。
机位与构图：[非默认POV；景别、主体位置、需要看清的物件]。
自然皮肤与衣物质感，主体轮廓清楚，背景简洁有秩序，必要物件数量明确。
环境、墙面、地面及衣物保持干燥，以哑光材质为主，画面干净但保留真实生活细节。
不加无关杂物、垃圾、重污渍、霉斑、潮湿水迹、积水、雨雾或大面积湿反光；
避免过锐、鱼鳞网格、密集微纹理、过量颗粒和字幕水印。
```

## 检查和返工

优先检查身份、关键空间边界、时间、光线、道具数量、主客观视角、环境干燥整洁和新信息。左右肢体要求用人物自身左右说明，不能凭镜像照片猜。生成联系表检查重复构图/近重复情节；hash只能发现文件级重复，不能代替视觉检查。出现偏差时只重绘相关镜头，缩短至一个明确事件，并移除引入错误人物或背景的参考。

拒绝图不进入选用manifest，修正版单独留来源和选择记录。没有用户要求时不覆盖已接受原图。将生成图片归档到story内部，再让时间线引用它；不要只依赖临时会话目录。图片变成视频时如只有固定帧和叠化，交付说明也应如此，不宣称已生成连续肢体表演或口型。
