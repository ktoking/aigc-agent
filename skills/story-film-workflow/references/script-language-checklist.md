# 剧本文案检查：交稿前必须通过

适用于新写、续写、改编的故事正文、旁白与角色对白，包括短段试读。检查整段的语境与使用密度；检索触发词只能定位疑点，不能代替逐句审读。用户明确要求的特殊口吻以当次要求为准。纯重制已确认正文时不擅改旧稿。

## 六项必查

| ID | 检查项 | 不通过情形与定位线索 | 修改方向 |
| --- | --- | --- | --- |
| L01 | 无反复顿悟报幕 | 用“第一次发现／突然明白／这才知道／忽然觉得／终于意识到”反复宣布认识变化；已经演出的信息又用感悟解释一遍。 | 直接写看到了什么、怎样处理、处理后的变化。真正的推理要给出线索和判断，不先宣布顿悟。 |
| L02 | 无对照式说教 | 用“不等于／不代表／不是……是……／真正的……是……”讲原则、替观众归纳道理；反驳剧情中没人提出的极端选项。 | 交代眼前事实、具体条件、决定或后果。具体动作辨认、证据排除可以保留，但须说明其信息用途。 |
| L03 | 无刻意金句和抽象升华 | 动作、冲突或温情片段后补人生道理；强行对仗、排比、拟人；用“学会接受／真正的成长／接住情绪”等抽象评价代替事件。 | 保留人物当时会说的话和会做的事。段落可直接停在动作、回应或具体变化上，不必凑一句漂亮结论。 |
| L04 | 无创作约束或反套路说明混入正文 | 否定无人提出、角色没打算实施的行为；旁白主动声明没有外挂、没有背叛、没有犯某种常识错误；解释模型或制作限制。 | 约束留在生产文档、连续性表与提示词中。正文只写实际发生的事；必要的风险提醒应有眼前动作或对话作为起因。 |
| L05 | 无硬拗幽默和牵强比喻 | 为抖包袱打断危险或感情；每段结尾都吐槽；比喻两端缺少明确的共同感受；不同人物都说同一种段子。 | 可保留符合人物经历、关系与当时处境的自然幽默。其余删掉，或换成角色对具体东西的直接反应，不为完成笑点增加台词。 |
| L06 | 无公文口吻、空泛总结或悬念占位 | “真正落地／明确边界／该处理的处理／都有去处”等汇报式泛指；用“一些食物”等回避关键细节；“事情没结束／也许是也许不是／难道真正的……”没有新证据就宣布悬念。 | 写清吃什么、修哪里、谁提了什么条件、损失了什么。用新动作、物证、声音、信息或未完成的选择留下具体问题。 |

这些问题按表达功能判定，不把所有否定句、第一次、比喻或幽默一律删除。允许的具体信息也不能靠换同义词保留原来的说教结构；“我懂了”“原来如此”等同样需要审读。

## 叙事吸引力：另行六项检查

去除文风问题后，还须检查以下六项；语句通顺或文案六项PASS不能代替剧情有效。新写、续写与专项整改应在交稿前逐项记录结果。

| ID | 检查项 | 必须写出的具体证据 |
| --- | --- | --- |
| S01 | 开场冲突立即发生 | 第一动作或第一句就有利益、关系或安全上的变化；以约前三秒可表达的冲突为目标，尚无音频时不能宣称实测秒数达标。 |
| S02 | 人物有当场目标和代价 | 说明本场争夺什么、失败会损失什么。反派的手段服务其实际利益，不能只为显坏而犯蠢。 |
| S03 | 主角有主动选择 | 主角利用已建立的能力、资源或信息改变局面；选择产生可见结果或成本，不能全程等对手出题、靠搭档或巧合解题。 |
| S04 | 升级与反转有因果 | 每段的新压力、发现或反击有前面的物件、行为、空间或信息作支撑；不能临时增加万能设备、隐藏能力或让反派主动交代全部计划。 |
| S05 | 兑现题材回报 | 本段落实所选题材承诺，例如物资取得、基地改善、关系变化或案件推进。避免用另一轮争吵代替变化；短片段至少有一个已发生的小回报。 |
| S06 | 段落有推进、结尾有具体选择 | 各段承担不同功能并改变局面，不能都是质问与回答；结尾延伸当前冲突或回报，不靠凭空追加敌人、秘密、物资或未读消息凑钩子。 |

借鉴用户提供的爆款参考时，先区分“创作方法”与“参考剧本正文”。有正文才按爽感机制、人设权力差、信息差、视觉冲突、节拍、结尾六项拆解其实际结构；只有方法时，说明按方法应用，不编造参考剧情、播放数据或成功结论。四段作为冲突、加压、反击、后果的组织方法，不固定每段时长或对称长度。

专项整改先给原稿定位、问题和保留项，再定点修改；已确认人设、主线、伏笔继续保留。评审表缺项或评分尺度冲突时，明确采用的实际条目与统一尺度，不补造未给出的项。字数阈值用于定位长句，优先拆成可自然朗读的意群，不把全文切成机械碎句。主观文风评分不能当成AI来源鉴定、人工质感或平台审核通过的证明。

## 审读顺序与放行

1. 先核对上集末尾、人物身份、资源与空间状态；不为消除套话而丢失必要信息、杜撰事实或让叙述者知道未见的幕后事件。
2. 完成初稿后检查正文与旁白两个层次，覆盖旁白、对白、转场句、段尾和结尾。逐句问：新增了什么动作、信息、选择、具体感受或人物关系？只有复述、评价、作者解释的句子删除或重写。
3. 按L01—L06登记疑点的原句、问题、处理及结果；再朗读整段，检查是否仍反复下结论、解释动机、抖包袱。不得用“没有触发词”证明文风合格。
4. 文案L01—L06与叙事S01—S06分别检查，全部PASS且无未处理项，才向用户展示后续剧本，并在已授权范围内进入分镜、TTS和生图；FAIL或待定必须先改再复查，不要求用户接手清理。若客观缺少连续性材料，说明缺口，不伪造PASS。主观通过不代表已证明吸引力或爆款表现。
5. 每份稿件保存对应的文案检查记录，可写入该集`qa-checklist.md`，试读稿可放`reviews/`。记录核对的稿件版本、六项结果、修改证据、保留疑点的具体用途及连续性结果。稿件改动后重查，不复用旧版PASS。
