## 修改记录（初稿写作中已处理的问题句）

- "事情要从那支疏散车队说起。" → 删除（报幕腔，直接切入闪回）。
- "全城最后一台发电机，烧的是我签过字的柴油。" → 删除（宣言式爽点预告），改为具体的拉柴油机动作与油量数字。
- "全城的人拿金子换不着的东西，我拿体温焐化。" → 删除（金句 + 对照式说教）。
- "我睡在零下十八度。" → "我睡在冷库门口，裹着两床被子。"（物理可信：睡在库门口吃冷气，不是睡进 -18°C 库内）。
- "冷气顺着门缝往外爬。" → 删除（拟人弱化），并入"后半夜冻醒了，我起来添油"的体感写法。
- "只要这三个数字不动，我就还活着。" → "油表往下走一格，温度计就不能动。"（从生存宣言改为资源运算，保留信息、去掉宣言）。
- 西瓜"冻透再挪去冷藏库"与前段"只带得动一间冷冻库"矛盾 → 改为"切一块西瓜，带着冰碴吃"， logistics 归入带电冷冻库。
- "柴油一小时耗五升……撑到月底" → 与 1200 升油量数学不符 → 调整为"省着烧，够撑半个月"，作为倒计时口径固定。
