# 长线规划：热浪吞城后，我拥有全城最后的冷库

总主线：夜班理货员在电网崩溃后独守全城最后的冷库，以柴油和温度计为倒计时，把"冷"经营成末世里的硬通货；药厂业务员姜宁持提货单到来后，两人按规程合伙，把一座正在衰变的冷库守成幸存者圈的枢纽。

## 长线限制

- 不用"每集门外新敌人"取代冷库经营；保留吃饭、巡检、添油、改造这类生活篇幅。
- 温度危机只允许缓慢恶化或局部修复，不允许一次归零；油表只减不增，除非剧情明确换来燃料。
- 女主承担冷链规程与账目能力，不承担所有解题功能；主角懂设备与库房，不是只负责开饭的人。
- 外部幸存者可合作、可拒绝、可敌对，按实际行为判断；不写成全员劫匪。
- 不加异能、系统、无限补货；不写重生回灾变前。
- 不锁定总集数与终局；不轻易放弃已建立的仓库据点。
