# 故事记忆：热浪吞城后，我拥有全城最后的冷库

## 项目定位

- Story ID：`heatwave-coldstore`
- 类型：第一人称末世封闭空间求生（极热灾变）。
- 目标平台：抖音 / 视频号，竖屏优先。
- 单集规格：60 秒，4 段，每段 15 秒以内。
- 一句话卖点：全城 51°C，只有他守着 -18°C；冷气就是命，柴油就是倒计时。

## 世界观

- 时间：热浪第九天起。连续极端高温，白天城区 50°C 上下，夜间也在 38°C 以上；无人再谈天气，只谈温度计。
- 市电于热浪第五天深夜全网过载崩溃，一条街一条街熄灭，至今未恢复；自来水随后停供。
- 政府组织过疏散车队，向郊县转运市民；路上发生了什么，主角不知道，不写。
- 舞台：城西生鲜冷链配送中心。外围是铁栅栏和空旷园区，建筑内有月台卷帘门、收货缓冲间、办公区、机房，最里面是三温区冷库：-18°C 冷冻库、0~4°C 冷藏库、2~8°C 药品库。两道门不同时开。
- 电力：一台备用柴油发电机，只带得动冷库和监控，一小时耗油约五升，油罐存量决定一切。
- 核心限制：没有救援承诺、没有系统、没有异能。冷库的冷是消耗品，柴油烧一升少一升；白天出门会中暑热射病，外出只能夜里短窗口进行。

## 核心故事

主角是冷链仓库夜班理货员，灾变时值班在岗。疏散车队来的那天，同事老周拉他上车，他因为一板胰岛素还没送进冷藏库、医院接药车迟迟未到而留下。当晚全市电网崩溃，他拉起备用柴油机，保住了库内的两万盒胰岛素和八百吨冻货。

之后的每一天都是同一道算术题：油表往下走一格，温度计就不能动。他以冷库为家，用军大衣、冻西瓜和添油巡检把日子过出秩序。热浪第九天夜里，月台卷帘门被敲响——监控里一个自称药厂业务员的女人举着市儿童医院的提货单，要求开门发货；她身后，月台阴影里还站着五个人。开门，是把药送出去、把陌生人放进来；不开，是守着规矩等死。

观众继续追的理由：封闭空间里"冷"这一资源的经营管理，每一集都能兑现感官级爽点（冰、凉、冻梨、冷气澡）；温度计与油表构成的倒计时让所有日常都带着滴答声；门外的人带来合作、交易与威胁的持续变数。

- 禁止：不写他廉价牺牲或突兀反派化

### 阻力（非人物型阻力优先）

- 一级阻力：柴油消耗、库温衰变、设备老化（外机过热跳闸、冷凝器脏堵）。
- 二级阻力：高温下的外出窗口（取油、取药、修设备），夜间也 38°C。
- 三级阻力：人——发现"这里凉快"的幸存者，有求合作的，也有想抢的；按行为区分，不写成全员匪徒。
- 升级方式：阻力始终从已建立的资源、设备和人来路里生长，不凭空追加。

## 剧情阶段

- 第一阶段（EP001—EP003）：独守冷库，建立倒计时规则；提货单上门，第一次开门选择。
- 第二阶段（EP004—EP006）：夜间外出找油，与姜宁建立分工信任；冷库从个人据点变成两人据点。
- 第三阶段（EP007—EP010）：设备衰变危机（外机烧毁、保温层损伤），库温爬升倒计时；以"冷"和"药"为筹码的外部交易与冲突。
- 最终阶段（EP011 起）：冷库成为幸存者圈子的枢纽；主角要回答的不是"能不能活"，而是"这座冷库为谁而冷"。终局不提前锁定。
