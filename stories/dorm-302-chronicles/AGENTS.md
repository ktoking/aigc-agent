# 《302 寝事 / Room 302 Diaries》Story 说明

## 一句话

日系 3D CG 泡面番，每集 2 分钟（8 段 × 15 秒）。同一间女生宿舍 302 里的三个成年女大学生——傲娇的粉发、鬼点子的紫发、高冷的白发——靠日常斗嘴、互相拆台和偷偷组 CP，把最普通的宿舍生活过成连续剧。

## 风格锚点

- **画风**：日系 3D CG 角色（Galgame / 游戏宣传 CG 质感），**不是 2D 平涂、不是真人实拍、不是美式 3D**。皮肤有次表面散射，发丝单根可辨，眼球有虹膜层次和高光点，布料有真实纤维与褶皱。
- **光影**：全系列统一"暖绿逆光"。两种配方：① **双色温（室内夜景/黎明，EP001 S01–S05）**——窗外青绿冷光 7000K 从背后勾发丝边缘，室内暖橙台灯 2700K 打亮半张脸；② **晨光逆光（户外/日间，EP001 S06–S08 及后续集）**——暖金 4300K 逆光 + 绿植冷绿反射补光。共同点：轮廓光轻微过曝、空气中有丁达尔体积光与浮尘、背景压成暖绿/金绿 bokeh。
- **镜头**：电影感浅景深（f/1.8–f/2.8 观感），横屏 16:9，以中景与近景为主，少量特写切情绪；每段至少一个运动镜头（推轨 / 手持 / 横移 / 跟拍）。
- **节奏**：泡面番式密集小反转，每 3–5 秒一个反应镜头，台词短、口语、带口癖，不煽情，糖点靠动作和眼神。
- **干净大形**：清晰轮廓、不堆细节、避免过度锐化/鱼鳞网格/满屏微纹理。8K 级质感但画面要"干净"。

## 角色一致性锁（所有 segment 必带）

### C01 桃柒（粉发·傲娇）

- 20 岁，大三，视觉传达。身高 160cm，纤细，肩窄。
- 樱花粉中长发至锁骨，发尾内扣微卷，齐空气刘海，两侧各一缕鬓发到下颌；逆光下发顶呈蜜桃金高光。
- 圆眼微上挑，玫瑰棕瞳，睫毛分明，眼尾浅粉眼影；**常备表情是嘴角下抿的臭脸萌**，被戳中会鼓腮，不轻易脸红。
- 服装（常服锁定）：浅樱花粉短款针织开衫（短到腰线、扣三颗、领口滑下一侧露出白色吊带肩带）+ 白色棉质短背心 + 深炭灰细格纹百褶短裙（膝上 12cm）+ 黑色过膝薄袜 + 白色厚底运动鞋。
- 配饰：左耳白色猫耳降噪耳机（猫耳轮廓清晰，常挂脖、生气时戴上）、右手腕细银链、透明手机壳带贴纸。
- 动作库：抱臂别脸、噘嘴、翻白眼、抢东西、被摸头时僵住、偷瞄后飞快移开视线。
- 声音：偏软的中高音带鼻音；生气时语速变快，句尾上扬。

### C02 星籁（紫发·鬼点子）

- 21 岁，大三，编导。身高 168cm，腰细腿长，肩线直。
- 深紫罗兰长直发到腰，微侧分，发尾挑染浅紫，总有几缕碎发翘起；逆光下发缘呈霓虹紫。
- 狐狸眼上挑，紫褐瞳，细眼线，微卧蚕；笑起来眯成月牙。表情库：坏笑、挑眉、咬下唇、眯眼打量、憋笑抖肩。
- 服装（常服锁定）：黑色短款机车风 PU 夹克（拉链开一半）+ 深紫缎面吊带短上衣（露腰 2cm）+ 黑色高腰皮短裤 + 白色蕾丝边长筒袜（到大腿中部）+ 黑色短靴。
- 配饰：银色 choker、银色耳环、手机几乎不离手（爱偷拍）。
- 动作库：搭肩、偷拍、起哄、用手指戳人、凑到耳边说话、被抓包时吹口哨装无辜。
- 声音：中低音带笑，爱拖腔；起哄时尾音上扬。

### C03 白砚（白发·高冷）

- 21 岁，大四，建筑。身高 172cm，修长，冷白皮。
- 象牙白/银白长直发到蝴蝶骨，中分，发丝极细，逆光下几乎透光，几缕垂在胸前。
- 细长眼，浅灰蓝瞳，眼神冷静；低头抬眼时压迫感强。
- 服装（常服锁定）：象牙白斜肩短针织（露右肩与锁骨、下摆短到露一段腰）+ 高腰微喇黑色皮裤（裤脚开衩）+ 银色几何扣细腰带 + 黑色尖头短靴。
- 配饰：左手食指素银戒指、黑色细框眼镜（看书时戴）。
- 表情梯度（重要，禁止全程面瘫）：平视无表情 → 一眼识破的挑眉 → 鼻息叹气 → 极浅的无奈微笑（嘴角 0.5cm）→ 抬手替人整理时的低垂眼。
- 动作库：抱臂旁观、抬手拆发圈/顺毛、递东西、蹲下系鞋带、抬眼制止。
- 声音：偏低、轻、慢，句尾降；说短句。

## 文件约定

- 每 segment 目录：`segment_NN_MM-MMs/`，内含 `storyboard.md` / `first-frame.md` / `last-frame.md` / `director-promt.txt` / `frames/` / `output/`。
- `director-promt.txt` 密度：整体质感 → 运动规则 → 一致性锁 → 首帧/尾帧 → 秒级子节拍（景别/焦距/运镜/内容/台词）→ 声音 → 负面。
- 时长：每段严格 15 秒（8 段 = 120 秒 / 2 分钟），镜头 3–4 个，每镜 3–5 秒。
- 视频模型：seedance 2.5 优先（相邻两段合并 30 秒），不可用回退 seedance 2.0 15 秒逐段。
