# C01 桃柒 · 锁档（Taoqi）

## 基础

20 岁 / 大三 / 视觉传达 / 身高 160cm / 纤细肩窄 / 冷白微暖皮

## 脸

- 圆眼微上挑，玫瑰棕瞳，双眼皮窄，睫毛分明，眼尾浅粉眼影。
- 齐空气刘海，两侧鬓发到下颌，鬓发比刘海长 2cm。
- 唇形偏小，下唇略厚，自然唇色偏豆沙粉。
- 常备表情：嘴角下抿的"臭脸萌"；无笑意时眼神平。

## 发

樱花粉中长直发至锁骨，发尾内扣微卷；逆光发顶呈蜜桃金；3–5 根碎发常翘在耳侧。

## 服装（常服锁）

1. 浅樱花粉短款针织开衫：短到腰线、扣三颗、领口滑下一侧、露出白色吊带肩带。
2. 白色棉质短背心（下摆塞进裙腰）。
3. 深炭灰细格纹百褶短裙，膝上 12cm。
4. 黑色过膝薄袜（哑光，不反光）。
5. 白色厚底运动鞋（鞋侧有一道浅粉）。

## 配饰

左耳白色猫耳降噪耳机（猫耳轮廓清晰；挂脖/戴上/摘下三种状态要区分），右手腕细银链，透明手机壳贴三张贴纸。

## 表情表（禁止循环使用同一档）

| 档 | 描述 | 使用段 |
|---|---|---|
| A 臭脸 | 嘴角下抿、half-lidded 视线偏开 | S01 起床、S04 前段 |
| B 炸毛 | 眉上挑、腮帮鼓起、眼睛瞪圆 | S02 追人 |
| C 别扭 | 别过脸、下颌抬起、余光偷瞄 | S02 被顺毛、S05 还纸条 |
| D 憋笑 | 嘴角压不住、下唇内收、眼睛弯一点 | S08 看纸条 |
| E 僵住 | 眼睁大、呼吸停半拍、手指不动 | S04 镜中靠近、S06 被系鞋带 |

## 声音

偏软中高音带鼻音；生气语速快、句尾上扬；别扭时声音变小、拖长"嗯——"。

## 口癖

"谁要你管""才没有""……随便吧""再五分钟"
