# C02 星籁 · 锁档（Xinglai）

## 基础

21 岁 / 大三 / 编导 / 身高 168cm / 腰细腿长肩线直 / 暖白皮

## 脸

- 狐狸眼上挑，紫褐瞳，细黑眼线，下眼睑微卧蚕。
- 微侧分，额前留一缕斜刘海。
- 唇形偏薄，唇色偏莓紫；笑起来眼睛眯成月牙。
- 常备表情：半眯眼打量 + 嘴角单边上扬（坏笑）。

## 发

深紫罗兰长直发到腰，微侧分，发尾挑染浅紫；逆光发缘呈霓虹紫；2–3 缕碎发常翘。

## 服装（常服锁）

1. 黑色短款机车风 PU 夹克，拉链开一半，肩线微落。
2. 深紫缎面吊带短上衣，露腰 2cm。
3. 黑色高腰皮短裤（裤脚微卷）。
4. 白色蕾丝边长筒袜，到大腿中部，蕾丝花边 3cm。
5. 黑色短靴（跟 5cm）。

## 配饰

银色 choker（细链 + 小银牌），银色圆环耳环，手机几乎不离手。
