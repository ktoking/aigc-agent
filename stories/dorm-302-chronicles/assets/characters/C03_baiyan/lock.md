# C03 白砚 · 锁档（Baiyan）

## 基础

21 岁 / 大四 / 建筑 / 身高 172cm / 修长 / 冷白皮

## 脸

- 细长眼，浅灰蓝瞳，眼尾平；低头抬眼时压迫感强。
- 中分，无刘海，额线干净。
- 唇形薄，唇色淡；下颌线清晰。
- **表情必须给梯度**：平视无表情 → 挑眉（识破）→ 鼻息叹气 → 嘴角 0.5cm 的无奈笑 → 低头（整理时的专注）。

## 发

象牙白长直发到蝴蝶骨，中分，发丝极细；逆光下发丝几乎透光成金色；垂在胸前 2–3 缕。

## 服装（常服锁）

1. 象牙白斜肩短针织：露右肩与锁骨，下摆短到露一段腰，袖长过手背一半。
2. 高腰微喇黑色皮裤，裤脚外侧开衩 8cm。
3. 银色几何扣细腰带（宽 2cm）。
4. 黑色尖头短靴（跟 6cm）。

## 配饰

左手食指素银戒指，黑色细框眼镜（仅看书/看屏幕时戴）。

## 表情表

| 档 | 描述 | 使用段 |
|---|---|---|
| A 无表情平视 | 眼神冷静、唇线平 | S01 起床、S03 前段 |
| B 挑眉识破 | 单侧眉抬 2mm、眼睛微眯 | S02 拆发圈前、S06 抬眼抓偷拍 |
| C 叹气 | 鼻息、肩微落、视线下移 | S04 两人挤镜子时 |
| D 浅笑 | 嘴角上扬 0.5cm、眼睛略弯 | S07 校门口、S08 教室 |
| E 低头专注 | 垂眼、睫毛投阴影 | S02 拆发圈、S06 系鞋带 |

## 声音

偏低、轻、慢，句尾降；句子极短："嗯""过来""别闹""知道"。

## 动作习惯

- 替人整理时一定低头，不看对方眼睛。
- 抱臂时重心落在一条腿上（略歪）。
- 递东西用手背朝上，动作很稳。
