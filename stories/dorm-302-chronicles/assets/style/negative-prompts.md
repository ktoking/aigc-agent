# 通用负面词库 · 302 寝事

## 必带（每条提示词末尾）

```
不要 2D 平涂、不要赛璐璐动画、不要真人实拍、不要美式 3D、不要 Q 版、不要塑料皮肤、
不要油腻磨皮、不要过度锐化、不要鱼鳞网格、不要满屏微纹理、不要脏噪点、不要过饱和、
不要奇怪手指、不要肢体错误、不要多手多脚、不要人物换脸、不要发型变化、不要服装变化、
不要画面内文字、不要字幕、不要水印、不要 UI、不要定格超过 1 秒。
```

## 分场景附加

- 宿舍室内：`不要过曝的窗（保留窗外爬藤层次）、不要廉价宿舍陈设、不要凌乱杂物堆叠`
- 楼梯间：`不要地下车库感、不要荧光灯死白`
- 校园林荫道：`不要樱花（本片是梧桐/绿荫）、不要过度虚化到没有空间`
- 教室：`不要黑板文字清晰可读（保持虚化）、不要过道拥挤`

## 角色附加

- 桃柒：`不要把表情做成卖萌笑脸、不要兔牙、不要双马尾（除 EP001 恶作剧那一镜）、不要换发色`
