# 镜头语言 · 302 寝事

## 焦段

- **35mm**：交代环境与三人关系（宿舍全景、走廊、楼梯）。
- **50mm**：双人对话、过肩。
- **85mm**：情绪特写（眼睛、手指、发丝、嘴角）。

## 运镜

| 类型 | 用法 | 参数 |
|---|---|---|
| 缓推 | 情绪升温、逼近真相 | 每秒推 2% 画面宽 |
| 手持跟拍 | 追逐、赶时间、笑闹 | 上下起伏 3–5cm，频率每秒 2 次 |
| 横移 | 展示宿舍空间、三人并排 | 每秒移 8% 画面宽 |
| 摇 | 从景物摇到人（起床第一镜） | 3 秒内完成 |
| 固定 | 反应镜头、笑点 | 不超过 2 秒 |

## 剪辑节奏（15 秒段结构）

- 0–4s：环境建立（谁会出场、在哪、光从哪来）
- 4–8s：事件触发（有人动手/说话）
- 8–11s：反应镜头（被打断的人给出表情）
- 11–15s：落点（台词收尾 + 一个糖点或笑点小动作）

## 泡面番镜头习惯

- 每段末尾留 0.5 秒"表情定格"给观众反应时间（画面内仍有微动，不允许完全静止）。
- 反应镜头优先给桃柒（傲娇），其次白砚（无奈），星籁负责起哄侧脸。
- 三人同处一室的镜头，必须有前景遮挡（椅背、绿植、水杯）增加空间层次。

## 禁止

- 不允许"PPT 式"的纯静态画面。
- 不允许频繁变焦（每段最多一次推拉）。
- 不允许低机位仰拍人物脸（会变形），最多略微仰 10°。
