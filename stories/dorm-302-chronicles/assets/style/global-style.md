# 全局视觉风格 · 302 寝事

## 一句话风格

**日系 3D CG 的"暖绿逆光"**——像游戏宣传 CG 里那一帧被窗光打透的少女：背景是压暗的暖绿，人物被一层金色轮廓光包住，发丝一根根亮起来，脸上只留柔和的暖光，眼睛里有一到两个高光点。

## 质感配方

| 维度 | 标准 |
|---|---|
| 渲染 | 3D CG 半写实，PBR 材质 + 次表面散射（SSS）；不是 2D 平涂、不是真人摄影 |
| 皮肤 | 通透、微透光，鼻尖与耳廓有逆光透红；毛孔不可见，但要有柔和高光过渡，不塑料 |
| 头发 | 单根发丝可辨，发梢半透，逆光时呈金色/紫色描边，有 5–8 根不听话的碎发 |
| 眼睛 | 虹膜有层次（外圈深、内圈亮），1–2 个清晰高光点，下眼睑有湿润反光 |
| 布料 | 针织有线圈纹理，皮裤有柔和镜面高光与褶皱，蕾丝有细密镂空阴影 |
| 环境 | 暖绿主调（墨绿/橄榄绿/苔绿），木质暖棕，米白墙；背景压暗并糊成 bokeh |
| 颗粒 | 极轻胶片颗粒，画面干净，不脏 |

## 光照配方（三段式，不可乱）

**A 双色温（室内夜晚 / 黎明，EP001 S01–S05）**
1. 主光：窗外青绿冷光 7000K，从人物背后或侧后 45° 打进来，勾出发丝边缘、窗框与肩线。
2. 补光：室内暖橙台灯 / 灯串 2700K，从侧前方低位打亮半张脸、下颌与锁骨，眼睛留 1–2 个暖橙眼神光。
3. 环境：房间暗部压成青绿，桌面与地板有一层暖橙反光；窗外是城市灯火与雾。

**B 晨光逆光（户外 / 日间，EP001 S06–S08 及后续）**
1. 主光：暖金 4300K 逆光，轮廓光过曝 0.5–1 档。
2. 环境光：绿植与地面反射的冷绿 5200K，占面部照度约 30%。
3. 补光：暖白反光板 3200K，低位补下颌与锁骨。

## 体积光与空气

- 日间：窗光穿过窗帘缝形成斜切光柱，光柱内浮尘 15–30 颗缓慢横飘。
- 夜间：街灯/台灯为点光源，暖橙光晕 + 霓虹绿紫边缘光，空气中轻微雾气。
- 每镜至少一处"会动的光"：窗帘晃、树影摇、光斑移动。

## 构图规则

- 三人同框时按身高排布：白砚最高（172）居中偏后，星籁（168）在侧，桃柒（160）最前最低，形成阶梯。
- 对话镜头用"过肩 + 焦点在听者"制造情绪。
- 特写只给三个时机：情绪转折、糖点、笑点收尾。
- 画面留白偏上，泡面番后期会在下方留字幕安全区（生成时不放任何文字）。
