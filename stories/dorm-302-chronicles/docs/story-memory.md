# 故事记忆 · 302 寝事

## 世界设定

某综合性大学，女生宿舍 3 号楼 302，三人间（靠窗三张单人床 + 中部矮桌 + 小厨房吧台 + 独立卫浴）。三人大三/大四在读，认识一年多，属于"吵得最凶、也最能兜住对方"的关系。

## 关系事实（截至 EP001）

- 桃柒 ↔ 白砚：双向在意但都不说破。桃柒用"谁要你管"掩饰，白砚用"嗯""过来""别闹"表达。星籁看得最明白，负责推。
- 星籁 ↔ 桃柒：表面互怼、实为最铁的搭子。星籁的捉弄都停在"桃柒真的会炸"之前一点点。
- 星籁 ↔ 白砚：互相懂，星籁唯一敢当面吐槽白砚的人；白砚一个抬眼看她就能让她收手。
- 三人共同目标：周五海边（EP001 纸条埋线），后续 EP005/EP006 兑现。

## 连续性约束

- 桃柒被摸头会僵住，不会立刻躲开（EP001-S02 建立，后续可复用反差）。
- 白砚替人整理时一定低头、不看对方眼睛。
- 星籁偷拍必开静音，被抓包就吹口哨。
- 每集结尾必须落在"三人在同一个空间里"的画面，形成系列感。
