# 镜头语言规范 v2 · 302 寝事

> 针对"画面像慢镜头图片"的问题重写。旧版是**一段 15 秒塞 4 个镜头**，只给一张首帧，模型只能把静帧慢慢推近，人物不敢动、机位不敢换。v2 改成**一镜一生成 + 双帧驱动 + 每镜写死运动参数**。

## 一、病根（先认账）

| 现象 | 原因 |
|---|---|
| 画面像会呼吸的图片 | 15 秒生成里塞了 4 个不同构图，模型只能插值，无法真正换机位 |
| 人物只有姿势没有表演 | prompt 只写"她站着/她坐着"，没写眨眼、呼吸、重心转移、手部小动作 |
| 没有运镜 | 只写"全景 35mm"，没写推多少米、每秒多少画幅、往哪个方向 |
| 没有焦点变化 | 全程一个焦点，浅景深等于没有 |
| 没有前景遮挡 | 三层空间只剩中景，画面"空" |

## 二、五条铁律

1. **一镜一生成**：一个视频只做一个镜头、一次运镜，时长 3–5 秒。段与段之间靠剪辑拼，不靠模型自己切。
2. **双帧驱动**：每镜必须给**首帧 + 尾帧**两张图，尾帧的机位/构图要真的变了（推近、转角度、换焦段）。模型有了插值目标，才会真的"运"起来。
3. **运动量下限**：本镜画面位移 ≥ 5% 画幅/秒，或主体位移 ≥ 体高的 10%/秒；低于这个数就是图片。开拍前先给每镜标 `动态强度：低/中/高`。
4. **每镜必须写全六项**：焦段、光圈、焦点对象、运镜（类型＋方向＋速度＋幅度）、三层运动（前景/中景/背景）、人物表演节拍（秒级）。
5. **每 6–8 秒换一次机位或焦段**：泡面番的节奏靠"切"和"推"堆出来，不靠单镜硬撑。

## 三、焦段与景别对照

| 焦段 | 景别 | 用途 | 景深（全画幅等效） |
|---|---|---|---|
| 24mm | 大全景 / 环境 | 交代宿舍空间、三人位置、追跑 | f/2.8，前后都留信息 |
| 35mm | 全景 / 中景 | 三人同框、走廊跟拍 | f/2.0–2.2 |
| 50mm | 中景 / 双人 | 对话、过肩、动作 | f/1.8 |
| 85mm | 近景 / 特写 | 情绪、眼神、手部 | f/1.4–1.8 |
| 100mm | 微距特写 | 睫毛、纸角、鞋带、棉签 | f/1.4，背景全糊 |

## 四、运镜词库（直接抄进 prompt）

| 运镜 | 写法 | 速度 / 幅度 |
|---|---|---|
| 推轨 dolly in | 机位沿光轴向前推 | 0→1.2m，每秒 2–4% 画幅 |
| 拉轨 dolly out | 向后拉，露出环境 | 每秒 3% 画幅 |
| 横移 truck | 平行侧移 | 每秒 6–8% 画幅 |
| 跟拍 follow | 与人物同速，手持 | 起伏 3–5cm，2Hz |
| 弧形环绕 arc | 绕主体转 30–45° | 2.5 秒完成 |
| 摇 pan | 原地转头 | 15°/秒 |
| 升降 crane | 垂直升降 | 0.4m/秒 |
| 手持呼吸 | 极轻微不规则晃 | ±1.5°，0.8Hz |
| 变焦 zoom | 只用于压缩空间 | 每秒 3% |
| 焦点转移 rack focus | 从 A 拉到 B | 0.4–0.6 秒完成，中间 8 帧全虚 |

## 五、三层运动（画面"满"的关键）

- **前景**（虚化 30–50%）：椅背、绿植、水杯、门框、飘过的发丝、被角。每镜必须有一样在动。
- **中景**：主体表演（呼吸起伏 1cm、眨眼 0.15s、手指、重心移动）。
- **背景**：窗帘摆动、城市车灯流动、树影摇、光斑漂移、走廊行人虚影。背景不许静止。

## 六、光与焦点

- 焦点永远在"这一镜的情绪主体"：说话人的眼睛、被看的手、被推的纸条。
- 浅景深只在 50mm 以上用；24/35mm 保留环境信息（泡面番需要看清"谁在哪"）。
- 逆光镜必须给轮廓光：发丝边缘 1–2px 亮线。
- 焦点转移是本片最重要的"说话方式"：从道具 → 人的眼睛，等于替观众完成"她注意到了"。

## 七、表演节拍（每镜至少 2 个）

- 眨眼：0.15s，每 3–4 秒一次，不能全程不眨。
- 呼吸：胸腔起伏 1cm，2.5 秒一个周期。
- 发丝：耳侧 3–5 根随头部动作滞后 0.2 秒摆动。
- 手：抓、推、收、悬停，每个动作给 0.3s 的预备。
- 嘴：说话时下颌开合 0.5–1cm，句尾闭合。

## 八、每镜 prompt 模板

```
【镜头】S01-1A｜0.0–4.0s｜35mm f/2.0｜动态强度：中
【运镜】dolly in：机位从门口向床推 1.5m，每秒 3% 画幅，全程不切
【焦点】起始在床头暖灯（虚），1.2s 时 rack focus 到白砚的手，0.5s 完成
【首帧】(图1) 全景，三张床，白砚坐床沿
【尾帧】(图2) 中景偏右，白砚已起身半步，桃柒抬头
【前景】床头灯暖橙光斑虚化，随推轨逐渐出画
【中景】白砚起身（重心前移 20cm）、手指扣扣子、呼吸起伏
【背景】窗帘被风掀起 8cm、窗外车灯横向流动、浮尘 20 颗
【表演】0.5s 白砚眨眼；1.5s 桃柒翻身；3.0s 被子滑落一角
【声音】布料摩擦、远处车流、极轻的呼吸
【风格】双色温（窗外青绿 7000K / 室内暖橙 2700K），电影级动漫 CG
【负面】不要静止、不要定格、不要多手多脚、不要换脸、不要文字
```

## 九、验收标准（自查表）

- [ ] 每镜有明确运镜词与速度
- [ ] 每镜有首帧 + 尾帧，且两帧构图差 ≥ 10%
- [ ] 每镜有 1 次焦点变化或焦点跟随
- [ ] 前景 / 中景 / 背景三层都有运动
- [ ] 人物每 3–4 秒有眨眼，每镜至少 2 个表演节拍
- [ ] 整段 15 秒内至少 3 次机位或焦段变化
- [ ] 没有一帧定格超过 0.5 秒
