# Production Rules · 302 寝事

## 硬规则

1. **画风锁死**：日系 3D CG（Galgame / 游戏宣传 CG），不是 2D 平涂、不是真人、不是美式 3D。所有提示词首行必带通用视觉总控前缀，末行必带通用负面。
2. **暖绿逆光不可换**：日间场景用窗光暖金逆光 + 绿植冷绿反射；夜景用街灯暖橙 + 霓虹绿紫边缘光，但仍是"逆光勾边"逻辑。
3. **时长**：每段严格 15 秒，8 段/集 = 2 分钟。镜头 3–4 个，单镜不得低于 3 秒、不得超过 5.5 秒。
4. **人物不换**：三人脸型、发型、发色、瞳色、身高差（160 / 168 / 172）、服装在全季 EP001–EP006 内锁定，只有特殊场景（泳池 EP003）允许换泳装，且泳装单独出三视图变体后才可拍。
5. **表情不重复**：桃柒禁止连续两镜同一表情，禁止全程面无表情；白砚禁止全程面瘫，必须给出"识破→叹气→浅笑"的情绪梯度；星籁禁止全程大笑，笑要分"坏笑/憋笑/真笑"。
6. **CP 表达克制**：糖点靠动作、停顿、视线，不靠告白台词。桃柒和白砚不主动说喜欢，星籁负责推波助澜但不点破。
7. **台词**：中文口语短句，每镜不超过两句，总字数≤ 40 字/15 秒。口癖锁定：桃柒"谁要你管""才没有""……随便吧"；星籁"家人们""哎哟""我有个想法"；白砚"嗯""过来""别闹"。
8. **禁止画面文字**：不出字幕、不出对话框、不出漫画字效、不出 UI、不出水印。字幕与片名一律后期加。
9. **每段帧数**：每个 segment 的 `frames/` 不少于 3 张——`first-frame.png`（首帧）、`last-frame.png`（尾帧）、`key-01.png`（关键帧）；三人同框或动作复杂的段落加到 4 张（`key-02.png`）。所有帧 2048×1152、16:9，人物必须与三视图一致。
10. **每镜三层运动**：前景（浮尘/发丝/窗帘）＋ 中景（人物动作/呼吸）＋ 背景（光影变化/绿植晃动）。禁止任何一帧定格超过 1 秒。

## 空间连续性

- 302 宿舍：进门左侧玄关鞋架，右侧小厨房吧台；房间中部矮桌 + 地毯；靠窗三张单人床成品字形，窗台有绿萝与暖光小灯串；墙面米白，墙裙浅绿，窗外是爬藤与梧桐。
- 宿舍楼：老式水磨石地面、浅绿墙裙、铁扶手楼梯、声控灯。
- 校园林荫道：两侧梧桐、红砖教学楼、远处操场。
- 教室：木桌木椅、黑板、百叶窗、后排靠窗位固定给桃柒。

## 镜头语言（详见 assets/style/camera-language.md）

- 主用 35mm（环境关系）、50mm（对话）、85mm（情绪特写）。
- 浅景深，焦点永远在说话人或情绪主体；背景 bokeh 呈暖绿光斑。
- 每次切换镜头前 0.3 秒留一个小动作（眼神、呼吸、手指），让剪辑有落点。

## 音乐节奏（后期，不进 prompt）

- 0:00–0:20：轻快电子节拍 + 尤克里里，泡面番开场感。
- 每段结尾 1 秒：一个短促的"叮"作笑点标记。
- 糖点镜头（白砚替桃柒整理）：音乐降一半，只留环境音与呼吸。
- EP 结尾：片名卡（后期叠加）。

## API

- 默认 `seedance_2.5` + 30s（相邻两段合并）；不可用回退 `seedance_2.0` + 15s 逐段。
- 首帧图放 `frames/first-frame.png`，关键参考图放 `frames/`，尾帧放 `frames/last-frame.png`。
- 提交参数、task id 写进该段 `output/api-submit.json`。
- 生成视频带"豆包AI生成"水印，后期用 mediakit-cli erase-video-subtitle-pro 擦除（顶部 16% + 底部 16% 条带），再 4K/60 增强、拼接、加片头。
