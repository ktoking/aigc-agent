# 连续性 · EP001

## 时间轴

同一早上 07:00–08:00。S01–S05 在 302 宿舍内连续发生（起床 → 扎头 → 早餐 → 镜子 → 出门），S06 下楼，S07 走到校门口，S08 第一节课。

## 服装连续性

全段三人常服不换：桃柒粉短针织（扣三颗）+ 白背心 + 格纹百褶裙 + 黑过膝袜 + 白厚底鞋；星籁黑 PU 夹克 + 紫缎面吊带 + 黑皮短裤 + 白蕾丝长筒袜 + 黑短靴；白砚象牙白斜肩短针织 + 黑微喇皮裤 + 银腰带 + 黑尖头靴。

唯一例外：S02 桃柒头顶被扎两个小揪，S02 镜头四拆掉后必须恢复原发型（发顶留一点被扎过的蓬）。

## 状态连续性

| 状态 | 建立 | 延续 |
|---|---|---|
| 桃柒耳机挂颈侧（S01 醒后） | S01 | S02–S08 均在颈侧，S08 搭在桌上 |
| 星籁手机不离手 | S01 偷拍 | S06 偷拍、S07 边走边看 |
| 白砚端着杯子 | S01 递水 | S02–S05 杯子在她手上或桌上 |
| 桃柒鞋带松开 | S06 镜头一 | S06 镜头三系紧，S07 起走路正常 |
| 纸条 | S05 出现 | S08 变成手绘 Q 版纸条（同一种纸） |

## 视线与距离

- 桃柒与白砚的身体距离逐段缩短：S01 约 1.2m（递水）→ S02 约 40cm（拆发圈）→ S04 约 30cm（镜前）→ S06 约 20cm（系鞋带）→ S07 拉开（校门口）。
- 星籁始终在"两人之外的半米"，负责观察。

## 禁止

- 不允许同一段内换发型、换服装、换瞳色。
- 不允许白砚在 S08 之前露出明显笑容（只有 S07、S08 的 0.5cm 浅笑）。
- 不允许桃柒主动说出"喜欢"之类的台词。
