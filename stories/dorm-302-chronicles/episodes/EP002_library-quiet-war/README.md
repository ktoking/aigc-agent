# EP002 · 图书馆静音战争

《302 寝事》第二集，9 月复习周的周六下午。16:9，120 秒，8 段各 15 秒。对白是现场说话，进阅览区后只用近距离轻声交谈。

## 故事

星籁把桃柒的路线折页翻了一面，手指又停在校门上。路线明明是从校门到旧图书馆，她在梧桐分岔口却跟着箭头绕了个圈。周一要交这份作业。桃柒把试稿塞进帆布袋，拉她下楼，让她拿着图走一遍。

到了分岔口，星籁又要往右。桃柒叫她看树，自己先折向左侧的红砖转角。走过足够看见旧馆门的那几步，她回头确认星籁跟上没有。星籁这才提起，白砚进馆前问过桃柒来不来。桃柒捏着袋带，让她先看路。

旧馆窗边，白砚把留在身旁的椅子让出来。桃柒本来要去对面，听了这声「这边」才坐过去。星籁去对面靠走道的座位，把手机倒扣着充电。白砚把建筑笔记推到两人中间。星籁也送来一张废纸，铅笔线在分岔口兜了个圈。桃柒征得白砚同意，才去翻她的笔记。

一张旧照片从内袋滑出来。桃柒接住，反扣着递回去。白砚自己翻给她看，是妈妈以前拍下的旧馆转角。照片里，梧桐树干后面露出一截红砖墙，从路上走过去时也是这个角度。白砚说她小时候也来，妈妈爱坐窗边。桃柒等她把照片放回去，才重新摊开自己的稿。

桃柒划掉原来孤零零的箭头，把梧桐、露出来的墙角和左转箭头画进同一格，新箭头离开了容易压住它的折缝。她照星籁刚才的折法合上一翼，递过去再让她试一遍。这次星籁的手指过了分岔，停在旧馆门上。白砚想收下改好的这张。桃柒说还没印，白砚伸过手，说这张就行。

桃柒的手已经伸到椅边去够包，又松开了袋带。「下周六，你还坐这儿吗？」白砚抬眼答她：「坐。给你留位。」桃柒从包里拿出画本，把耳机取下来放到桌边。白砚把笔记往窗边挪了挪。对面的星籁等两人说完，才问插座能不能也留给她。桃柒把借出去的橡皮要回来，白砚把折页夹进笔记。桃柒收近一点椅子，在刚腾出来的位置接着画。

## 连续性

- **一张试稿。** 米白 A5 三折路线折页。原有的低饱和珊瑚色箭头和铅笔草图一路保留。S06 才划掉旧箭头，留下指向树后砖墙的新路线。发灰的旧照片属于白砚，内容是当年的建筑与树，没有人物。
- **一条实地路线。** 校门起步，梧桐处分岔，左侧经过红砖转角到旧图书馆，右侧小径会绕回校门。折页、现地和旧照片从不同角度给出同一个转角。
- **一张阅览桌。** 白砚坐同侧靠窗一端，桃柒坐紧邻的椅子，星籁坐对面靠走道和插座一端。S03 落座后持续用这一张桌，窗光一直从同一侧进来。
