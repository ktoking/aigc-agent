# 动态漫合成架构

## 定位

默认交付是“3-4 张真人静帧镜头 + HyperFrames 本地合成”，不是 15 秒扩散视频。每段可独立导出 9:16 MP4，再拼为正片；15 秒是节奏目标，不是裁切语音的硬上限。

## 每段轨道

| 轨道 | 内容 | 来源 |
| --- | --- | --- |
| 0 | 单张真人镜头图（3-5 秒） | `frames/shots/` |
| 1 | 局部放大或背景虚化副本 | 同一镜头图 |
| 2 | 怪物 / 黑金纸屑 / 光影叠层 | CSS + 静帧局部遮罩 |
| 3 | 黑金言灵、碎纸、尘粒 | CSS + GSAP |
| 4 | 台词字幕、气泡和冲击字 | 文本轨 |
| 5 | 旁白、台词、环境声、BGM | 音频轨 |

## 两种视觉模式

- `live-cinematic`：真人电影感静帧，慢推、分层、环境粒子与切镜；主生产模式。
- `motion-comic`：保留为低成本备选，不作为当前 EP001 交付。

## 生成门禁

- 先完成配音、用 `ffprobe` 读取真实台词时长，再做字幕节奏；每句必须完整播放，镜头和段长随音频延展。
- 连续动作只有在静态合成无法表达时，才提交视频 API。
- 角色、背景、道具必须分层；不要将故事板文字上传给视频模型。
