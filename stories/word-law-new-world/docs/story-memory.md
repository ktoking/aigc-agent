# 故事圣经

## 一句话卖点

陆野重生回界门降临第一天，觉醒“言出法随”，别人还在逃命，他已用一句话把新世界的规则变成自己的武器。

## 世界

2079 年，天空裂开九道界门，城市一夜被称为“新世界”。规则不是完全崩坏，而是会被强意志短暂改写。所有人都能看见倒计时，只有陆野知道：七天后，活下来的人会被分成猎物和执笔者。

## 主角

陆野上一世死于界门清算。他重生后不解释来历，只利用未来信息抢先救人、夺资源、拆掉反派布局。能力名“言出法随”：说出明确、可见、四字以内的命令，目标会被现实强制执行数秒；每次使用，右瞳金字更亮，耳鸣和记忆缺页更重。

## EP001 固定事实

- 时间：界门降临后第 17 分钟，傍晚。
- 地点：裂隙街地铁口与废弃商场前广场。
- 陆野状态：刚重生，未受伤，灰蓝夹克、旧表、背包。
- 宁晚状态：拿着断裂警棍，正被“巡界犬”逼入地铁口。
- 首次能力指令：`停下。`
- 结尾发现：界门广播点名“陆野”，提示他不是唯一知道未来的人。
