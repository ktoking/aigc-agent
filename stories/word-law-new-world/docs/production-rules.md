# 生产规则

## 画面与资产

- 画幅：9:16；输出主体放在中心 60% 区域。
- 风格：原创真人电影感静帧短剧，真实皮肤、布料与灾变城市，冷灰基调、黑金言灵特效；不做满屏碎光、游戏 UI、霓虹网格或动漫线稿。
- 镜头资产：每段生成 3-4 张真人静帧，按景别分为危险全景、反应近景、主角台词中景、段尾钩子图；背景与人物分层副本可后续补充。
- 特效：能力启动时，黑色细碎纸屑向内收束，金色篆体“言”从右瞳掠出；不要火焰、雷电或 RPG 面板。

## 连续性

- 陆野全季前半段固定灰蓝夹克、黑内搭、黑色旧表、深灰背包；右瞳金字只在发动能力时出现。
- 宁晚固定短银灰发、暗红风衣、断裂警棍。
- EP001 天色为阴云压城的傍晚，界门蓝灰裂光只在天空与玻璃反射中出现。
- `segment_02/03/04` 的首帧必须继承上一段尾帧的站位、道具与光线。

## 声音

- 陆野所有对白与第一人称内心独白固定使用豆包 `zh_male_taocheng_uranus_bigtts`；宁晚固定使用 `ICL_uranus_zh_female_xingganmeihuo_tob`。不因情绪或剧集临时换音色。
- 旁白必须是陆野第一人称内心想法，与角色台词分轨生成；普通对话不追求口型，使用镜头切换、反应近景和过肩镜头。
- 每段只留关键短句与内心落点；环境声包括远处警报、界门低频嗡鸣、碎玻璃和脚步。

## 禁止项

- 不出现真实人物、学校/品牌 logo、已有 IP 标识。
- 不让男主衣服、发色、旧表消失；不把言灵画成手机弹窗或游戏 HUD。
- 不用长篇旁白解释规则；规则通过动作和后果呈现。
