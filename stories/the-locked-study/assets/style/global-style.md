## 调色基线

- 色温：室内暖金（壁炉/台灯光源）vs 室外冷蓝（暴风雪）。两套色温在同画面内对撞。
- 饱和度：中低饱和，自然真实色彩。
- 影调：高对比暗部，阴影丰富但不死黑；壁炉光是主光源，侧光勾勒人物轮廓。
- 颗粒：自然细腻胶片颗粒 + 轻微暗角。
- 质感：真实皮肤毛孔、丝绒与羊毛布料纹理、金属酒具反光、皮革手套纹路。

## 色彩体系

| 色 | 用途 |
|---|---|
| 冷蓝灰 | 窗外暴风雪、夜雪、冷调阴影 |
| 暖金黄 | 壁炉火光、台灯光、酒液反光（限于光源与物体，禁止大面积） |
| 深棕黑 | 木墙板、家具、人物深色服装 |
| 灰白 | 雪、白手套、呼出的白气 |
| 暗琥珀 | 白兰地酒液 |

## 光影规则

- 客厅：壁炉为主光源，暖光从一侧打亮人物，窗外冷蓝光作轮廓/背景光。
- 书房：台灯为主光源，光锥内是尸体与酒杯，其余沉入暗部。
- 反转段落：Arthur 站在壁炉前，火光把脸切成明暗两半。

写实、电影感、低饱和、冷蓝对暖金、克制、压抑、优雅、英国庄园、丝绒、羊毛、皮革、胶片颗粒、暗角、轻微呼吸感。
