# 镜头语言（Camera Language）— THE LOCKED STUDY

## 基调

克制、优雅、电影化。少切镜、长镜头倾向；运镜服务于“观察”与“猜疑”，不做炫技。

## 运镜类型

| 运镜 | 用途 | 出现段落 |
|---|---|---|
| 肩后跟随 | 侦探进入、走向书房 | Seg1 |
| 缓慢环绕（半圆） | 侦探问询，扫过众人 | Seg2 |
| 镜头滑行（glide） | 从一人移向下一人，行为即介绍 | Seg2 |
| 倒退跟拍 | 侦探走向书房，众人下意识跟随 | Seg3 |
| 过肩首次揭示 | 越过 Hale 肩膀第一次看到尸体 | Seg1 |
| 缓缓转头特写 | 侦探反问“白兰地？” | Seg4 |
| 后拉构图 | 最终定格：Arthur 被孤立，门框画中画 | Seg4 |
| 轻微手持呼吸感 | 全片基调，稳定克制，不快速乱切 | 全片 |

## 构图原则

- 前景遮挡：用人物肩部、门框、烟雾作前景，增强空间层次与压迫感。
- 人物站位固定：Eleanor 壁炉旁、Clara 窗边、Arthur 酒柜旁、Owen 火边/门边、Morris 门边笔直。站位即性格，不得随意移动。
- 反应镜头优先：谁在听、谁不看尸体、谁先接话——用反应建立猜疑。
- 孤立 Arthur：其他人“自然地、不自觉地”离开他半步，不用夸张后退。
- 门框画中画：结尾镜头后拉穿过书房门，人物缩小，形成越来越窄的取景。

## 时间轴密度

- 30 秒一段：每 3-5 秒画面或信息变化一次。
- 每个镜头至少 4-6 个连续可见动作点（主体动作 + 道具变化 + 环境反应 + 旁人反应 + 视线/表情变化 + 声音触发），避免静态拉图。

## 特写清单（物件即证据）

- 门锁（被撞坏）→ Seg1/Seg4
- 酒杯（半杯白兰地）→ Seg1/Seg4
- 怀表 → Seg4
- 每个人的鞋 → Seg1 结尾
- 珍珠项链 / 茶杯 / 烟灰 / 袖口 → Seg2 行为介绍
