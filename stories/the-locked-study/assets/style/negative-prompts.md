# 负面提示词（Negative Prompts）— THE LOCKED STUDY

## 通用负面（每条提示词必带）

```text
不要字幕，不要水印，不要logo，不要可读文字，不要屏幕文字
不要动漫风，不要卡通，不要游戏CG感，不要3D渲染感，不要塑料皮肤
不要过度锐化，不要鱼鳞状网格，不要满屏微纹理，不要明显AI伪影
不要静态拉图，不要图片变形过渡，不要人物瞬移，不要换房间
不要新增角色脸，不要额外手指，不要畸形四肢，不要夸张表情
不要金黄色满屏，不要暖橙满屏（壁炉暖光仅限光源范围）
不要血腥，不要夸张血迹，不要恐怖惊悚元素（本片是克制悬疑）
不要静态定格超过1秒，不要空镜头，不要背景完全静止
```

## 人物负面

```text
不要换脸，不要改发型，不要改服装材质，不要东方面孔
不要年轻化/老年化，不要添加多余面部标记，不要改变珍珠项链/白手套/皮手套等标志物
```

## 表演负面

```text
不要手舞足蹈，不要戏剧化夸张表演，不要大喊大叫（Owen 除外但有限度）
不要疯狂大笑，不要过度煽情，不要夸张的“凶手狞笑”
不要任何角色做出与站位不符的大幅度移动
```

## 尸体负面

```text
不要血腥，不要伤口特写，不要恐怖化妆，不要夸张扭曲姿势
尸体只呈现“倒在书桌边、台灯亮、半杯酒”的压抑构图
```

## 台词/音频负面

```text
不要旁白解说，不要画外音解释，不要长篇对白
原生音频不做多角色精准对白；关键台词走后期配音
```

## 用词禁忌（避免反向污染）

避免在提示词中写“慢动作、停顿、静止、定格、静态、PPT、长时间停在……”等词，改用正向动作要求。
