# 场景卡：大客厅（DRAWING_ROOM）

## 基本信息

- **场景 ID**：`SCENE_DRAWING_ROOM`
- **用途**：Seg1 后半 / Seg2 / Seg3 全段 / Seg4 结尾
- **时间**：深夜，暴风雪夜

## 可见特征

- 英式古典大客厅：深色木墙板、水晶吊灯、古老落地钟、大理石壁炉（炉火正旺）。
- 落地窗结霜，窗外冷蓝暴风雪可见。
- 酒柜（暗色木，玻璃杯与酒瓶）；沙发与扶手椅；若干边桌（一张被撞歪过）。
- 通往书房的走廊与门。

## 人物固定站位（站位即性格，不得随意移动）

| 人物 | 固定位置 |
|---|---|
| Lady Eleanor | 壁炉旁扶手椅，端茶杯 |
| Clara | 窗边，抽烟看风雪 |
| Arthur Vale | 酒柜旁，整理袖口 |
| Owen | 火边/门边，烤手踱步 |
| Morris | 门边，笔直站立 |

## 变化范围

- 壁炉火光跳动；落地钟敲响；Owen 从火边转身；Arthur 被孤立后其他人后退半步。

## 禁止变化

- 禁止改变家具布局、落地钟位置、壁炉位置；禁止出现现代物品（手机、电视）；禁止大面积暖色（暖光限于壁炉与灯）。

## Prompt 关键词

grand English drawing room, dark wood paneling, marble fireplace with warm fire, tall grandfather clock, frosted windows with blizzard outside, drinks cabinet, crystal chandelier, warm golden firelight vs cold blue window light, restrained elegant
