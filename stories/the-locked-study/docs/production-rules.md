# 生产规则（Production Rules）— THE LOCKED STUDY

## 视觉总控

全片 16:9 横屏，真人实拍电影质感。低饱和、冷蓝色暴风雪 + 暖金色壁炉光的强对比。禁止过度锐化、鱼鳞状网格、满屏微纹理、游戏 CG 感、动漫感、塑料皮肤。详见 `assets/style/global-style.md` 与 `assets/style/negative-prompts.md`。

## 人物锁

6 位角色外观必须严格符合 `assets/characters/<ID>/00-character-card.md` 与参考图：

- `EDWARD_HALE`：深灰三件套 + 黑色羊毛大衣 + 皮手套，深色带灰短发，锐利克制。
- `LADY_ELEANOR`：黑色丝绒裙 + 珍珠项链，灰金盘发，苍白高贵。
- `CLARA_VALE`：深褐长发，深色精致连衣裙，夹烟。
- `ARTHUR_VALE`：银灰背头，深色三件套，礼貌冰冷。
- `MORRIS`：白发，黑色燕尾服 + 白手套。
- `OWEN`：深棕乱发，粗花呢外套，湿靴。

禁止换脸、改发型、改服装材质；禁止把人物画成东方面孔或年轻化/老年化。

## 一眼识人设计（本片核心）

人物不靠介绍，靠行为认出来。每段必须通过动作标签、职业性格、前景遮挡、空间走位、反应镜头、物件特写、停顿来建立性格，禁止旁白介绍。

- Eleanor：珍珠项链 / 茶杯 / 不看尸体 / 皱眉纠正失礼。
- Clara：一直抽烟 / 烟灰很长 / 心不在焉看风雪 / 被问时才回头。
- Arthur：最镇定 / 最少说话 / 轻微微笑 / 整理袖口 / 礼貌打断。
- Morris：白手套 / 扶正桌子 / 接大衣 / 命案时仍像履行职责。
- Owen：湿靴 / 烤火 / 搓手 / 抱怨暴风雪 / 声音最大。
- Hale：跺雪 / 摘手套 / 观察鞋子 / 观察门锁 / 观察酒杯 / 先不说话。

## 镜头与表演禁忌

- 禁止大段对白；全片 18 句以内，靠动作与反应推进。
- 禁止字幕、屏幕文字、水印、logo。
- 尸体不血腥：只呈现“倒在书桌边、台灯亮、半杯酒”的压抑构图。
- 反转靠“有人知道了不该知道的细节”（口误“白兰地”），禁止侦探长篇推理。
- 群戏走位要克制：孤立 Arthur 用“自然的半步后退”，不用夸张后退。
- 单段 30 秒：动作链路要写足 4-6 个连续可见动作点，避免静态拉图。

## 视频模型规则

- 固定 Seedance 2.5（seedance_2.5），duration=30，ratio=16:9，图生视频。
- `director-promt.txt` = 用户确认的原文提示词，逐字透传，禁止改写。
- 参考图默认：本段首帧 + 本段尾帧 + 关键角色参考图（2-3 张），共 3-5 张。
- 原生音频优先环境声（风雪、壁炉、落地钟、脚步）；关键台词建议后期配音。
- 四段串行提交与 QA：上一段 `output/video-qa.json` 为 passed 前，禁止提交下一段。

## 负面提示词

- 不要字幕、水印、logo、可读文字。
- 不要静态拉图、图片变形过渡、人物瞬移、换房间。
- 不要新增角色脸、额外手指、畸形四肢、AI 伪影。
- 不要过度锐化、鱼鳞网格、满屏微纹理、塑料皮肤。
- 不要金黄色满屏、不要暖橙满屏（壁炉暖光除外，限于光源范围）。
- 不要夸张表情、不要戏剧化手舞足蹈（本片是克制表演）。
- 完整负面清单见 `assets/style/negative-prompts.md`。

## 失败停止线

- 隐私审核拦截：停止，不换错图、不自动重试。
- 角色错脸 / 服装漂移：回到角色参考图重新提交。
- 参数 400 / ModelNotOpen / 额度不足：停止并报告，不自动换模型。
