# QA 清单 — EP001 THE LOCKED STUDY

## 剧集级

- [ ] 总时长约 120s（4 × 30s），16:9 横屏。
- [ ] 无字幕、无水印、无屏幕文字（`video-ocr` 抽帧验证）。
- [ ] 无血腥画面；尸体保持压抑构图。
- [ ] 6 位角色外观与角色卡/参考图一致。
- [ ] 段间连续性：站位、服装、灯光、道具一致。
- [ ] 反转成立：Arthur 口误“白兰地”之前，侦探从未提过毒在酒中。

## 段级（每段单独检查）

### Segment 01（00:00-00:30）
- [ ] 暴风雪开场强钩子；门被推开、跺脚抖雪。
- [ ] Morris 报告“书房门从里面反锁”。
- [ ] 一眼扫过五人，各自行为标签清楚（Eleanor 茶杯 / Clara 长烟灰 / Arthur 袖口 / Owen 湿靴烤手 / Morris 笔直）。
- [ ] 首次揭示尸体：非血腥、台灯亮、半杯白兰地。
- [ ] 尾帧：众人目光汇聚 Hale，Hale 看门锁/酒杯/鞋。

### Segment 02（00:30-01:00）
- [ ] Hale 问询走位：慢半圆扫过众人。
- [ ] 每人一句半句 + 行为即性格（Eleanor 不喝茶 / Clara 弹烟灰 / Owen 转身外露 / Morris 扶正桌子 / Arthur 最平静）。
- [ ] 尾帧：Arthur 与 Hale 第一次真正对视。

### Segment 03（01:00-01:30）
- [ ] 落地钟敲响，房间静止一瞬；Hale 不看钟看人。
- [ ] Clara 掐灭又点第二支；Owen 爆发抱怨；Eleanor 皱眉；Arthur 冷淡讽刺。
- [ ] Eleanor 指认 Arthur 是最后一个陪喝酒的人；Owen 跟进。
- [ ] Hale 走向书房，众人下意识跟随；尾帧停在门槛，尸体在背景。
- [ ] “可这不是我要问的”转折成立。

### Segment 04（01:30-02:00）
- [ ] Hale 进书房观察：门锁、酒杯、尸体、怀表。
- [ ] “他不是在这间屋子里被杀的”反转成立。
- [ ] Arthur 口误“如果毒在白兰地里”——全场静住。
- [ ] Hale 反问“白兰地？”；Arthur 表情首次僵住。
- [ ] 其他人自然半步后退孤立 Arthur；尾帧门框画中画。
- [ ] CUT TO BLACK。

## API/视频级

- [ ] 每段 `output/video-qa.json` 为 passed 后才提交下一段（四段串行）。
- [ ] 用 `ffprobe` 验证时长 ≈30s、分辨率 1280×720、有音频流。
- [ ] 抽帧检查开头/中段/结尾与切镜附近：人物脸、服装、人数、场景、口型归属、音频。
- [ ] 台词口型风险：原生音频以环境声为主，关键台词走后期配音。
- [ ] 隐私审核拦截 → 停止并报告，不换错图。
