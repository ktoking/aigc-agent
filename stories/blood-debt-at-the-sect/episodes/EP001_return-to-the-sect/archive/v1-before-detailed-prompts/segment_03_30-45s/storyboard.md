# 第03段《破山门剑阵》故事板 v1

全片30–45秒，本段15秒；目标结果：两名守卫先后倒在外院石地，地面阵纹熄灭；男主右手剑尖朝下、刃口新增一处小缺口，抬眼看向台阶顶端。

| 段内时间 | 镜头、动作、接触点及结果 |
| --- | --- |
| 0–3秒 | 男主用剑身向外拨开陆青长剑，接触点在两剑前端三分之一；陆青失衡靠向石栏但未受致命伤，男主从他内侧跨入外院。 |
| 3–7秒 | 接男主跟拍，两名守卫在外院先后抬剑，领头喊“封山！别让丹房的事传出去！”脚下两道金纹交汇成阻路剑阵。 |
| 7–11秒 | 男主压低重心，先挑开画面左守卫的剑，右手回切胸甲接缝；守卫一倒地，左半阵纹断灭。只表现这一组明确接触。 |
| 11–15秒 | 右守卫直刺，男主转身避开、用剑柄撞其下颌，再收臂刺中护甲下方；守卫倒地、全阵熄灭。男主收剑看台阶，最后1秒稳定；不出现喷血或断肢。 |

## 对白／旁白

- 段内3.2–6.8秒，领头守卫：“封山！别让丹房的事传出去！”

## 声音

桥面脚步接外院脚步；三次明确金属接触、剑柄撞击、两次倒地声、阵纹破裂脆响；无新增旁白。

## 首尾连续性

首帧：男主站在桥端，右手长剑已完全出鞘，陆青横剑位于右前方，继承第2段当前状态。

尾帧：两名守卫先后倒在外院石地，地面阵纹熄灭；男主右手剑尖朝下、刃口新增一处小缺口，抬眼看向台阶顶端。

陆青留在桥上，不再追杀；两守卫倒地不复活，男主剑刃小缺口延续；下段同一台阶起战。
