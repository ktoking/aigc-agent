# 第04段《斩执法长老》故事板 v1

全片45–60秒，本段15秒；目标结果：白璃倒在丹殿门边，弯刀落在台阶；男主左上臂被割伤、袖口破裂，右手直剑有缺口，左手推开丹殿门一道缝。

| 段内时间 | 镜头、动作、接触点及结果 |
| --- | --- |
| 0–3秒 | 低机位从弯刀刃口带到白璃脸，她挡在台阶顶说“丹成之前，你进不去”；男主踏上第一阶。 |
| 3–7秒 | 白璃只跃下两级台阶，弯刀由上向下斜劈男主左肩方向；男主右移躲过主体刃线，刃尖划伤左上臂，衣袖局部破裂。 |
| 7–11秒 | 白璃站稳后横斩；男主退半步以直剑贴住弯刀外侧，借刀势将其引向画面右侧石柱；接触点与刀刃嵌柱结果同框可读。 |
| 11–15秒 | 趁白璃弯刀短暂卡住，男主跨入其右侧，直剑一次掠过颈侧，以前景衣摆遮住伤口；白璃失力倒下、弯刀脱手。男主跨上门槛、左手推门，最后1秒稳定门缝。 |

## 对白／旁白

- 段内0.3–2.8秒，白璃：“丹成之前，你进不去。”

## 声音

弯刀破风、袖料撕裂、直弯双刃摩擦、石柱崩小屑、刀落石阶；无多余喊招或旁白。

## 首尾连续性

首帧：男主站外院左下方，右手缺口直剑朝下；白璃在右上方台阶顶，右手暗红弯刀，丹殿大门在其身后。

尾帧：白璃倒在丹殿门边，弯刀落在台阶；男主左上臂被割伤、袖口破裂，右手直剑有缺口，左手推开丹殿门一道缝。

白璃此后死亡，不再出现助战；男主左上臂伤口、破袖、直剑缺口与左腕半簪延续到丹殿。
