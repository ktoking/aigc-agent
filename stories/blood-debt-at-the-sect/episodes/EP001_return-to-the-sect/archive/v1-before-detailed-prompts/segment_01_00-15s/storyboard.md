# 第01段《山门怒斥》故事板 v1

全片0–15秒，本段15秒；目标结果：男主右手将青霜剑抽出一掌宽，蓝光照亮左腕半簪，陆青仍在前方，未开战。

| 段内时间 | 镜头、动作、接触点及结果 |
| --- | --- |
| 0–3秒 | 第一帧陆青已经横剑拦路，过肩近景看清他面对师兄说话；镜头不先飞越宗门。 |
| 3–7秒 | 切男主侧面近景，压住怒火回应；他的右手握紧剑柄，左腕半截银簪露出。 |
| 7–11秒 | 低机位慢推，男主说完“吃人的世界”，拇指推开剑格；衣摆向后扬，不停走位。 |
| 11–15秒 | 男主直视陆青说“我看谁敢拦我”，只抽剑一掌宽，蓝光扫过半簪；最后1秒稳定手部构图，尚未击倒陆青。 |

## 对白／旁白

- 段内0.0–4.5秒，陆青：“师兄，你住手吧，师傅已经原谅你了。”
- 段内5.0–10.8秒，谢无咎：“去他的修仙，不过是吃人的世界。”
- 段内11.3–13.8秒，谢无咎：“我看谁敢拦我。”

## 声音

开场即人声；山风、衣料猎猎、剑格轻响，末尾一声短促低频，不抢台词。

## 首尾连续性

首帧：石桥近景，谢无咎在左前景背对镜头，陆青在右前方两米处横剑拦路；男主青霜剑在鞘，左腕半截银簪可见。

尾帧：男主右手将青霜剑抽出一掌宽，蓝光照亮左腕半簪，陆青仍在前方，未开战。

下段从同一半簪特写进入过去回忆；本段不提前打山门战。
