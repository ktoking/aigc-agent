# 第07段《以伤换毁炉》故事板 v1

全片90–105秒，本段15秒；目标结果：丹炉炉眼局部破裂，丹火沿尚未断开的金线倒灌玄衡左掌、其护体金罡熄灭；男主左肩被玄金剑刺穿并钉在身后石柱，右手已拔回青霜剑。

| 段内时间 | 镜头、动作、接触点及结果 |
| --- | --- |
| 0–3秒 | 男主右剑高位刺向玄衡咽喉作为佯攻；前脚迈入，左肩留在玄金剑的直刺线上。机位保持男主左、玄衡右、炉眼右后的关系。 |
| 3–7秒 | 玄衡右手玄金剑直刺男主左肩，剑尖继续进入男主身后左侧石柱；男主闷哼，左肩固定、躯干偏转，未发生断肢或血浆喷溅。玄衡因贴近而让出其左肋下方到炉眼的低位通道。 |
| 7–11秒 | 男主右臂从玄衡左肋下方送剑，沿近距离直线刺入既有炉眼缺口；给出剑尖接触铜壁、旧裂纹扩展、炉眼局部爆裂的连续结果。男主右手随后拔回自己的青霜剑。 |
| 11–15秒 | 丹火沿供能金线逆流玄衡左掌，左掌灼伤、护体金罡碎灭；玄衡右手被反噬震松剑柄，后退半步。男主肩头仍留玄金剑、右手握青霜剑，最后1秒稳定，尚未杀师。 |

## 对白／旁白

- 无对白、无旁白，仅保留呼吸与动作音效。

## 声音

短促呼吸、直剑入石、男主受伤闷哼、青铜裂响、丹火倒灌低轰、金罡碎裂；无对白、无旁白，不喊招式。

## 首尾连续性

首帧：男主左前方抬剑，左肩露出；玄衡右前方挡着丹炉，左掌与炉眼金线连接，炉眼有上一段形成的新缺口。

尾帧：丹炉炉眼局部破裂，丹火沿尚未断开的金线倒灌玄衡左掌、其护体金罡熄灭；男主左肩被玄金剑刺穿并钉在身后石柱，右手已拔回青霜剑。

仅毁丹炉正面炉眼，不炸塌丹殿；炉侧遗骨衣角保留。男主已拔回青霜剑，玄金剑留在左肩及石柱，师傅右手空。
