# 第08段《血债了结》故事板 v1

全片105–120秒，本段15秒；目标结果：男主背对镜头走到丹殿门口，右手提缺口青霜剑、左肩伤和破袖保留；师姐遗骨与半簪以焦黑衣角包好收入怀中，左腕只剩红绳；玄衡倒在炉台旁，玄金剑仍钉石柱，炉火渐灭。

| 段内时间 | 镜头、动作、接触点及结果 |
| --- | --- |
| 0–3秒 | 男主咬牙向前侧身，左肩脱离留在石柱上的玄金剑，右手青霜剑抬起；玄衡失去剑罡，只能空手抓向男主右腕。 |
| 3–7秒 | 男主将右腕压低避开抓握，直剑从玄衡抬臂下刺入胸腹交界，以衣袖和侧后机位遮伤口；玄衡撞上炉台滑倒、停止动作。男主抽回剑，明确完成诛师。 |
| 7–11秒 | 男主在炉侧内沿把少量灰白遗骨与左腕取下的半截银簪放入焦黑衣角，双手一收包好收入怀中；伤口限制左肩动作，不展示骨骼特写。 |
| 11–15秒 | 男主右手提剑走向左后殿门，门外云海透入微暖天光；镜头留在殿内，看他离去、玄衡尸身与石柱上金剑，最后1秒稳定，炉火缓慢熄灭。 |

## 对白／旁白

- 无对白、无旁白，仅保留呼吸与动作音效。

## 声音

脱剑时克制闷哼、兵刃接触衣甲、倒地声；随后只留衣料与沉重脚步、微弱炉火和门外山风。无说教、无师姐幻声、无新反派。

## 首尾连续性

首帧：继承上段：男主左肩被玄金剑钉在石柱前，右手握青霜剑；玄衡左掌灼伤、右手空、金罡已灭，丹炉局部损毁。

尾帧：男主背对镜头走到丹殿门口，右手提缺口青霜剑、左肩伤和破袖保留；师姐遗骨与半簪以焦黑衣角包好收入怀中，左腕只剩红绳；玄衡倒在炉台旁，玄金剑仍钉石柱，炉火渐灭。

完整结局，不追加复活或幕后黑手；伤势、剑的归属、半簪移入包裹状态均落实。
