# 第05段《丹殿见师傅》故事板 v1

全片60–75秒，本段15秒；目标结果：男主被金色护体剑罡震退到左侧石柱前，右手剑仍在；玄衡在右方，左掌继续吸取丹炉金气；炉眼旧裂纹、炉侧衣角与遗骨清楚存在。

| 段内时间 | 镜头、动作、接触点及结果 |
| --- | --- |
| 0–3秒 | 镜头随男主推门入内，短中景交代门、男主、玄衡、丹炉及左侧石柱的相对位置；丹炉金线流入玄衡左掌，右手玄金剑下垂。 |
| 3–7秒 | 切炉侧烧焦黑衣角与少量灰白遗骨，再切男主左腕半簪，他向玄衡说“她叫你一声师傅，你把她炼成了丹”。遗骨位置在炉侧内沿。 |
| 7–11秒 | 玄衡冷淡回答“她的灵根，正好补我的伤”，左掌继续纳气；镜头看清金线起点是正面炉眼，炉眼上方有旧裂纹。男主踏进一步。 |
| 11–15秒 | 男主右手直刺玄衡胸前；玄衡右剑横格，护体金罡将男主震退两步至左侧石柱前。正面接触后退，不飞出十米；最后1秒稳住两人方位。 |

## 对白／旁白

- 段内3.0–7.7秒，谢无咎：“她叫你一声师傅，你把她炼成了丹。”
- 段内8.0–10.8秒，玄衡：“她的灵根，正好补我的伤。”

## 声音

木门推响、丹火低鸣、人声近而清楚、最后一次清晰格剑与短促金罡冲击；无师姐声音或幻影。

## 首尾连续性

首帧：从上段丹殿门缝继续，男主左手推门、右手持剑，左上臂破袖；玄衡位于画面右侧，丹炉在其右后方1.5米。

尾帧：男主被金色护体剑罡震退到左侧石柱前，右手剑仍在；玄衡在右方，左掌继续吸取丹炉金气；炉眼旧裂纹、炉侧衣角与遗骨清楚存在。

建立丹炉供能和炉眼旧裂纹，作为后续反击因果；师姐未复活。男主站位左、玄衡右、丹炉右后不反转。
