# 第01段《山门怒斥》故事板 v3

全片0–15秒；段内15秒。

首帧：35mm中近景，男主黑银肩背占画面左侧四分之一，陆青在右侧清晰对焦，铁剑横在胸前，男主青霜剑仍在左腰鞘内，双方未接触。

尾帧：85mm手部特写，男主左手扣住左腰鞘口，左腕半截银簪在画面中央；右手只将青霜剑拔出约12厘米，冰蓝刃光掠过半簪焦黑断口。陆青在右后方虚焦，未受伤。

空间：黄昏石桥，桥宽约3米，左右是低石栏和云海。谢无咎处于画面左前方，陆青在右前方约两米，身后通向外院的石阶。镜头始终留在二人连线靠石栏这一侧，不越轴；男主看画面右侧师弟，师弟看画面左侧师兄。背景仙宫仅作远景轮廓，不插空镜。

## 逐镜动作

L01｜00.00–04.70s 横剑劝阻

镜头设计：35mm过肩中近景，机位高约1.45米，距陆青约2米；以男主肩背为左前景框景，摄影机向陆青缓慢推进约20厘米，全镜焦点留在陆青眼睛。

子节拍1：0.0–1.8秒：开场第一帧已经横剑，陆青右肘微屈、剑尖偏向画面左侧石栏，身体挡住去路；他说“师兄，你住手吧”，眼睛盯男主，不看镜头。左脚前踏半掌，后脚仍留桥内侧。

子节拍2：1.8–4.5秒：接着说“师傅已经原谅你了”，右手的剑没有主动前刺；喉结轻动、眉心收拢，左手抬至腹前又停住，表现想劝又怕师兄出剑。

子节拍3：4.5–4.7秒：师弟收住最后一个字，男主左前景肩部因吸气轻抬，作为反打切点。

执行节拍：第一句话在0秒起声，剑先处于拦路状态，人物关系先于风景；师弟只劝阻、不进攻。

L02｜04.70–10.90s 压怒反打

镜头设计：切到50mm男主胸上近景，陆青灰蓝肩袖在画面右缘虚焦；机位与前镜同轴线一侧，缓推约15厘米，固定焦距，不同时变焦。

子节拍1：4.7–7.0秒：男主视线先扫过师弟胸前宗门玉牌，再抬到他眼睛；下颌绷紧，低声说“去他的修仙”，嘴角不笑、不夸张歪嘴。

子节拍2：7.0–10.8秒：说“不过是吃人的世界”；句尾压低而非拖长喊叫，右肩略前送，画面下缘可见右手压住剑柄。风将黑发从颈后拉向左后方，轮廓暖光仍在右脸边缘。

执行节拍：台词完整连贯，眼神由玉牌到对手只发生一次；镜头推进承接怒意，不绕人物旋转。

L03｜10.90–13.90s 拔剑前的警告

镜头设计：保持50mm，切略低于胸口的四分之三近景；男主在中央偏左、师弟仍在右前方画外，摄影机只向右横移约10厘米，让剑柄进入右下角。

子节拍1：10.9–11.3秒：男主拇指顶开剑格，左手落到左腰稳定剑鞘；肩部降低半寸，重心移到前脚。

子节拍2：11.3–13.8秒：他说“我看谁敢拦我”，视线不离师弟；右手闭紧剑柄，剑仍未完全拔出。最后“我”字落下才开始抽剑。

执行节拍：拇指开格→左手稳鞘→右手抽剑，动作有先后，不在说话时挥剑乱舞。

L04｜13.90–15.00s 蓝光照见遗物

镜头设计：切85mm腰部手部特写，略俯拍，左腕银簪位于中央，右手剑柄在右侧；摄影机几乎固定，仅随手水平后移数厘米，焦点由刃缘转到半簪断口。

子节拍1：13.9–14.5秒：右手抽剑约12厘米，露出的蓝光从鞘口移向银簪，左手仍牢牢扣鞘；剑与鞘只有一套。

子节拍2：14.5–15.0秒：半簪焦黑断口被蓝光点亮，手指因用力轻颤；右手停止继续拔出，但剑穗与发梢仍在风中微动，准确进入尾帧。

执行节拍：只完成一掌宽的拔剑；尾帧的半簪位置为下一段匹配剪辑锚点，不冻结画面。

## 对白

0.0–4.5秒｜陆青：“师兄，你住手吧，师傅已经原谅你了。”
5.0–10.8秒｜谢无咎：“去他的修仙，不过是吃人的世界。”
11.3–13.8秒｜谢无咎：“我看谁敢拦我。”

## 连续性

本段男主无战斗伤，剑刃完整。青霜剑只拔出12厘米，不能提前完全出鞘、劈人或让陆青倒地。半簪始终固定左腕。
