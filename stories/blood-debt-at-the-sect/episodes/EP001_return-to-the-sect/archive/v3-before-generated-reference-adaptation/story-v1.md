# 《焚宗：师姐的血债》小说式正文 v1

“师兄，你住手吧，师傅已经原谅你了。”

陆青横剑站在石桥中央。谢无咎的剑还在鞘里，黑色衣摆被山风吹向身后。他看了一眼陆青胸前的宗门玉牌。

“去他的修仙，不过是吃人的世界。”

他推开剑格，蓝光沿剑脊露出一线。

“我看谁敢拦我。”

左腕的红绳勒着半截银簪，焦黑的断口擦过皮肤。丹殿里那股焦味又涌了上来。

前夜，谢无咎被定在丹殿门侧，手掌抵住束缚阵，指节泛白。侧墙两个被抓来的凡人缩在铁栏后。师姐沈照月曾为他们砍断锁链，此刻却被金纹束在丹炉里。玄衡抬手合拢炉盖。她盯着门边的谢无咎，只来得及喊出一个字：“走！”

炉盖落下。她的气息断了，银簪从炉沿滚落，断成两截。谢无咎后来逃出丹殿时，只带走了其中一半。

现在，陆青的剑被拨向石栏。他踉跄让开，谢无咎从他身旁跨过，没有追击。

外院里，两名执剑守卫封住台阶。领头的抬剑下令：“封山！别让丹房的事传出去！”两道金纹从他们脚下合拢，横在谢无咎胸前。他压低剑尖，先挑开左侧守卫的剑，反手划过对方胸甲的接缝；再借转身绕开右侧直刺，剑柄撞中下颌，一剑刺入对方护甲下方。两人先后倒地，阵纹断灭。

台阶上，白璃的暗红弯刀已经出鞘。她一脚踩住殿门前的石阶：“丹成之前，你进不去。”

弯刀从上往下劈落。谢无咎侧身，左上臂仍被刃口划开。下一刀横扫，他后退半步，将直剑贴在弯刀外侧，让对方的刀势沿剑身滑向石柱。刀刃咬进柱面的一瞬，他跨进白璃的右侧，剑光掠过她颈侧。弯刀落在石阶上。她跪下，倒在门边。

谢无咎推门入殿。玄衡正把丹炉涌出的金气纳入左掌，右手的玄金剑垂在身侧。炉侧压着一角烧焦的黑衣，那是沈照月的衣袖。

“她叫你一声师傅，你把她炼成了丹。”

玄衡看了眼他的伤口。“她的灵根，正好补我的伤。”

青霜剑迎面刺来。玄衡抬剑格开，护体金罡将谢无咎震向石柱。金气仍从炉眼不断流进玄衡左掌。炉眼上方，一道旧裂纹被火照得发红。

谢无咎压住左臂的伤，又扑上去。他低身斜切，剑尖掠过玄衡腰侧，余下的剑气击中丹炉。炉眼崩出一个缺口，金线突然一滞。玄衡的护体剑罡也暗了一下。他立即横移，挡住丹炉，金气重新接上。

“你的剑，是我教的。”玄衡向前压剑。

谢无咎的目光停在那道新缺口上。他抬剑佯攻玄衡咽喉，左肩却露在剑锋前。

玄金剑刺穿他的左肩，将他钉向身后的石柱。谢无咎闷哼，右手没有松。他不再格挡，借两人贴近的距离，将青霜剑从玄衡左肋下方送过，直刺已经崩裂的炉眼。

青铜炸开。炉内翻涌的丹火顺着尚未断开的金线倒灌，玄衡左掌猛地焦黑，护体金罡寸寸熄灭。他想退，谢无咎已经拔回自己的剑，猛地侧身脱离肩头的玄金剑。

玄衡伸手去抓。青霜剑从他抬起的手臂下刺入。他撞上炉台，缓缓滑倒，再没有动。

谢无咎撑着炉沿站了片刻，扯下左腕红绳，把半截银簪与炉侧留下的灰白遗骨放进那片焦黑衣角。他将布角收紧，贴身放好，提着缺口长剑走出丹殿。

风穿过敞开的殿门。玄金剑仍钉在石柱上。炉火一点点熄了。
