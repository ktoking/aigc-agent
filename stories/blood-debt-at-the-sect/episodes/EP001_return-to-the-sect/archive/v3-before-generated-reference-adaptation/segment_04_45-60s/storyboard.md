# 第04段《斩执法长老》故事板 v3

首帧：35mm低机位双人中景，男主右手缺口直剑在左下前景，白璃位于右上方台阶，右手暗红弯刀斜垂，丹殿闭门在她后方。

尾帧：50mm男主肩侧近景，左手将丹殿门推开一道窄缝，左上臂衣袖有新刀伤；白璃倒在门边石阶、暗红弯刀脱手留地，右侧石柱有新刀痕。男主右手仍是缺口青霜直剑。

空间：丹殿前只有一组短而宽的石阶，门在右后方，石柱在画面右缘。男主位于左下阶口，白璃在右上方，相距约一米半；白璃下两级就能落到男主前侧。两人交锋始终在门前这两米范围，不瞬移到另一广场。摄影机在台阶左前方，男主左、白璃右。

## 逐镜动作

L01｜00.00–03.00s 长老封门

镜头设计：35mm低角度中景，机位离台阶约60厘米高，男主剑尖在左下，白璃站右上；镜头沿台阶抬高并缓推约20厘米，不先单拍空刀。

子节拍1：0.0–1.4秒：白璃右腕转动使弯刀红刃对着男主，左脚卡住通向门槛的路径，目光向下盯住男主右手剑柄。

子节拍2：1.4–2.8秒：她说完“丹成之前，你进不去”，下颌略抬，左手张开平衡身体；男主前脚踏到最下一阶边缘，不回嘴。

子节拍3：2.8–3.0秒：白璃重心压到前脚、右肘上抬，准备下劈；剪在刀开始运动之前。

执行节拍：台词0.3秒起声，白璃的封门位置与下一刀来向在同镜交代。

L02｜03.00–06.50s 下劈造成第一处伤

镜头设计：40mm双人全身中景，机位侧向拍台阶，摄影机随白璃落阶向左下平移约40厘米；不能用俯拍丢掉脚步。

子节拍1：3.0–4.2秒：白璃向下跨跃两级，落脚后屈膝缓冲，右手弯刀由右上斜劈男主左肩方向，红色光迹只贴刃缘并在半秒内消失。

子节拍2：4.2–5.3秒：男主向自身右侧横踏半步，右手剑尚在低位，身体避过主要刃线；弯刀尖掠过左上臂，先划开衣袖，再出现一条有限暗色伤痕。

子节拍3：5.3–6.5秒：男主左肩收紧、呼吸一顿但脚下站稳；白璃前脚落稳，将弯刀收至身体右侧准备第二次横斩，不在空中连续砍。

执行节拍：落阶→站稳出刀→男主让位→刃尖擦伤→双方收势；不能左臂未接触先流血。

L03｜06.50–10.50s 借横斩把刀引入石柱

镜头设计：50mm腰以上双人中近景，保留右侧石柱与两剑全段；摄影机在原侧略退20厘米留出动作，焦点不离接触平面。

子节拍1：6.5–7.8秒：白璃右手横斩男主腰胸之间；男主后撤半步，右手抬直剑，用剑身外侧贴住弯刀靠近刀尖的三分之一位置，手肘贴近肋部承受冲力。

子节拍2：7.8–9.2秒：男主转腰把来刀向画面右侧引出，刀沿直剑外侧滑过，有短促摩擦火星；两刃不黏死、不互相穿过。白璃上身顺势向右偏，重心跟出。

子节拍3：9.2–10.5秒：弯刀前端咬入右侧石柱浅层，形成一道新斜痕，少量石屑往下掉；白璃右腕被卡住半拍，男主左脚已经跨进她持刀侧近身距离。

执行节拍：贴刃、导向、嵌柱三个接触结果清楚；石柱在前镜就可见，不临时长出来挡刀。

L04｜10.50–13.20s 抓住卡刀的半拍

镜头设计：65mm侧后近景，机位在白璃肩后偏侧，男主脸与右手剑同时可见，衣摆在下缘作遮挡；镜头向左短跟男主半步。

子节拍1：10.5–11.7秒：男主右剑从胸前短距离划向白璃颈侧，不大幅抡圆；剑锋通过时白璃前景肩甲和飞起衣带遮住伤口。

子节拍2：11.7–13.2秒：白璃握刀的手指松开，弯刀沿柱痕滑落；她先膝盖落阶，再侧倒在门边，眼神失焦，动作终止。男主不补刀，抬脚越过弯刀。

执行节拍：伤口不展示，死亡通过失握、落刀和倒地连续表现；白发只属于白璃，不切换成师姐脸。

L05｜13.20–15.00s 推门承接丹殿

镜头设计：50mm从男主左肩后方近景跟拍一步，画面右下保留右手青霜剑，左上臂破袖在近景清楚；摄影机与门同步推进约30厘米。

子节拍1：13.2–14.2秒：男主向门槛迈半步，左臂因伤抬得低，只用左掌抵门板，右手剑保持斜下不碰门。

子节拍2：14.2–15.0秒：门开出约一掌宽的缝，暖金丹火从缝隙扫到他的侧脸；保持门缝构图，白璃尸身仅在后下方虚焦，不出现师傅的重复身体。

执行节拍：从门外冷光自然接门内暖光，下一段继续同一推门动作；右剑、左掌和左臂伤各有位置。

## 对白

0.3–2.8秒｜白璃：“丹成之前，你进不去。”

## 连续性

开场无左臂伤；第一刀只划伤左上臂，之后袖口破裂与少量暗色血痕保持。白璃用弯刀、男主用直剑，两种兵器不能合并或互换；最后白璃死亡，不起身再打。

下段首镜直接从门缝继续推开，不重演一遍杀长老。左上臂伤、剑缺口与半簪延续。
