# 第08段《替天行道，血债了结》故事板 v3

全片105–120秒；段内15秒。

首帧：65mm双人近景，玄衡活着靠在炉台、双眼睁大，右手空、左掌灼伤，金罡已灭；男主右手青霜剑抵其心口未刺入，嘴角鲜血、左肩刺伤清楚，玄金剑留柱。

尾帧：35mm殿内中广景，男主右手重新提青霜剑，带着怀中的遗骨与半簪包裹向左后殿门走去，左腕只剩红绳。左肩与左臂伤仍在，嘴角大部分血迹已擦掉，左拇指残留少量血色；玄衡倒在炉台旁已死，玄金剑留柱，炉火渐暗。

空间：同一丹殿：玄衡后腰靠右侧炉台，男主在左前约半米，右剑已抵心口。玄金剑留左侧石柱，男主左肩与左上臂都伤，左肘贴身即可让左拇指触下唇。炉台近侧留放青霜剑空位，焦黑衣角内已有少量遗骨；最后殿门约在左后两米，不切新场景。

## 逐镜动作

L01｜00.00–03.80s 玄衡惊问剑法来历

镜头设计：65mm玄衡胸上近景，男主剑尖在画面下缘抵住他心口，男主黑银肩袖在左缘；机位略低于玄衡眼睛，缓推约12厘米，不拍成已死的呆滞脸。

子节拍1：0.0–0.5秒：玄衡盯着抵住心口的青霜剑尖，瞳孔骤紧、下颌松动，原本的冷硬神情变为惊惧。

子节拍2：0.5–3.7秒：玄衡抬眼盯住男主，惊问“你……是如何习得这剑法的？”“你”之后留一次短停顿，尾句难以置信地失声；胡须随急促呼吸微颤，双手不恢复法力，右手无力停在身侧。

执行节拍：这是活着但已被制住的惊惧，剑法的陌生来自师姐私下教过男主的回锋势；不要先刺死再问。

L02｜03.80–06.40s 左拇指抹血，冷声回答

镜头设计：65mm男主胸上近景反打，机位同轴一侧、略低于眼睛，玄衡虚焦在右缘；右下角始终看得见握剑右腕，镜头缓推约10厘米。

子节拍1：3.8–4.6秒：男主盯着玄衡，受伤左上臂贴身，仅屈左肘让左拇指够到下唇，由嘴角向外抹去一线鲜血；痛得吸气半拍，肩部不高举。右手稳剑不移。

子节拍2：4.6–6.3秒：男主放低左手，露出拇指上少量鲜血，低声说“不过是替天行道。”重音落在“替天行道”，不仰头狂笑、不对镜头说话。

子节拍3：6.3–6.4秒：收住尾字，目光没有离开师傅，右手握柄收紧，接下一剑。

执行节拍：先抹血再说指定回应，抹血用左手，右手不同时离开剑柄；句子是当面对敌的冷答，不另加旁白感悟。

L03｜06.40–07.80s 最后一剑，师徒恩断

镜头设计：50mm侧面双人中景，摄影机固定同侧，能看见男主前脚和玄衡靠炉台的身体；衣袖遮挡伤口，不以血浆表示力度。

子节拍1：6.4–7.1秒：男主前脚踏实，沿已经抵在心口的直线把青霜剑送入一掌，动作短而决绝；玄衡呼吸顿住，胸肩因受力僵直，无金罡再生。

子节拍2：7.1–7.8秒：男主抽回青霜剑，玄衡膝盖软下，后腰沿炉台滑落到地，头侧垂、手落地，停止动作；这之后没有遗言。

执行节拍：回答完整结束后才刺，刺入后才倒地；玄衡此处明确死亡。

L04｜07.80–08.50s 放剑腾手

镜头设计：65mm炉侧石台手部近景，略俯视，空位与焦黑衣角同框，镜头不移动。

子节拍1：7.8–8.2秒：男主把青霜剑横放石台靠近自己一侧，剑柄在左、剑尖指右，避开遗骨衣角；金属碰石一声轻响。

子节拍2：8.2–8.5秒：右手完全松开剑柄，左前臂低位靠台，视线落向左腕半簪；剑留在画面边缘，不能消失。

执行节拍：放下剑再解半簪，不让一只手同时握剑和包布。

L05｜08.50–12.60s 半簪归于遗骨

镜头设计：65mm俯斜手部近景，石台、同一柄青剑、衣角和左腕均在画内；摄影机随右手轻移数厘米，保持一镜连续。

子节拍1：8.5–9.7秒：右手挑开左腕红绳活扣，取下半截银簪，红绳仍留腕上；左肩不抬，只用左前臂靠台减轻疼痛。

子节拍2：9.7–10.4秒：右手把半簪放进已经盛有少量遗骨的衣角，左手低位按住一角，不拍骨骼特写。

子节拍3：10.4–11.7秒：右手合拢衣角，其余角随着左指轻扶收入同一小包；动作克制，没有不相关停顿或回忆插镜。

子节拍4：11.7–12.6秒：右手将包裹收入胸前内襟，左腕只剩红绳，左拇指血迹变淡仍可辨；画面边缘青霜剑一直留台。

执行节拍：解活扣—放簪—合布—收入怀，四个小动作占4.1秒，不能颠倒或凭空出现包裹。

L06｜12.60–15.00s 提剑向殿外走去

镜头设计：35mm中广景，机位在炉台旁约1.3米高，先轻跟男主拿剑起身，再停在殿内，让他走向左后方门口；柱上金剑与玄衡尸身留在景深。

子节拍1：12.6–13.2秒：男主右手重新拿起石台青霜剑，左臂垂低，左肩保护性下沉；包裹已在怀中，不能还留在台面。

子节拍2：13.2–15.0秒：男主提剑朝殿门走两三步，右剑尖斜下、左臂不摆动；门外云海缓动，炉火在身后缩小。镜头停留殿内，尾帧只要求向门口离去，不为赶路突然瞬移出殿。

执行节拍：先拿剑再走，死亡与遗物归属明确；没有师姐幻声、新反派或未完待续。

## 对白

0.5–3.7秒｜玄衡：“你……是如何习得这剑法的？”
4.6–6.3秒｜谢无咎：“不过是替天行道。”

## 连续性

惊问发生在师傅被回锋制住、尚未中最后一剑时；他不能已经死亡再说话。男主用左拇指抹下唇鲜血，左肘贴身、只屈肘不大抬肩；右手始终稳剑直到最后刺击，之后明确放剑、包遗物、再取回。指定回应“不过是替天行道。”只说一次，不扩成长篇说教。

最后一剑后玄衡明确死亡，师姐遗骨与半簪包好随男主带走；左腕只留红绳、嘴角血已擦去，玄金剑留柱，青霜剑右手提走。结局完整，不追加新敌人或复活。
