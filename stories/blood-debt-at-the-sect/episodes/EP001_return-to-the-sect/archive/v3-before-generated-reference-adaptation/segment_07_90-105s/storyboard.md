# 第07段《毁炉回锋，反制师傅》故事板 v3

全片90–105秒；段内15秒。

首帧：40mm双人中景，男主左前右剑抬起、左肩露出，嘴角有细血痕；玄衡右剑待刺、左掌连炉眼金线，炉眼已有新缺口，左柱在男主后方。

尾帧：50mm双人中景，玄衡后腰抵炉台、双手失势，男主右手青霜剑尖抵住他心口但尚未刺入；男主已脱离柱上玄金剑，左肩刺伤、左上臂刀伤与嘴角鲜血保留。玄金剑单独留在左侧石柱；丹炉局部破裂、玄衡金罡已灭。

空间：沿前段攻防轴：男主左前近柱，玄衡右前，丹炉偏右后。近身后炉眼距男主右肩约1.2–1.4米，右臂加95厘米剑刃可达；柱面紧邻男主左肩后方。后半段男主先脱离柱上金剑，再用右手青霜剑回锋；玄衡失防后空手抓腕，男主借其抓势制住胸前，最后停在剑尖抵住心口而未刺入的状态。

## 逐镜动作

L01｜00.00–03.40s 血债质问与师傅压杀

镜头设计：40mm侧面双人中景，机位在原轴线同一侧，缓推约20厘米，保持双方剑尖与左柱可见。

子节拍1：0.0–1.9秒：男主低声逼问“师姐的命，你拿什么还？”，前脚压入半步，右剑高位佯刺玄衡咽喉，左肩留空；嘴角细血痕不擦。

子节拍2：1.9–3.4秒：玄衡头肩后收避高刺，右手金剑从下方抬平，2.0–3.4秒喝“孽徒，找死！”；剑尖对准男主左肩，左掌仍接炉眼。

执行节拍：质问引出师傅出手，两个声口不重叠；高刺是诱招，不先命中咽喉。

L02｜03.40–05.80s 左肩受刺，剑尖入柱

镜头设计：50mm侧近景，左肩、玄金剑与身后柱面同框；摄影机随受力后让约15厘米，保持右手青霜剑在下缘。

子节拍1：3.4–4.6秒：玄衡右臂直送，金剑刺入男主左肩外侧，衣料破开，男主左指张开、肩部向后受力；不拍穿肉特写。

子节拍2：4.6–5.8秒：剑尖顺余势进入后方石柱浅层，石粉落下；男主屈膝稳定，左肩受限但右臂仍可动，右肘沉向腰侧，眼睛看炉眼新缺口。

执行节拍：命中后受伤、受力后入柱，男主右手剑不掉。

L03｜05.80–08.80s 借近身通道破炉并拔剑

镜头设计：35mm低机位近侧中景，向右平移约25厘米，清楚露出男主右臂、玄衡左肋下空隙和炉眼同一条斜线。

子节拍1：5.8–6.9秒：男主左肩贴柱，右臂从玄衡左肋下方送出青霜剑，沿短直线到达炉眼缺口，不穿过师傅身体、不发飞剑。

子节拍2：6.9–7.9秒：剑尖先接触缺口，右臂继续送入一掌；旧裂纹扩开，炉眼局部铜片崩裂，蓝光只贴近刃缘。

子节拍3：7.9–8.8秒：男主右肘回收，把青霜剑明确拔离炉眼，收至胸前低位；炉侧内沿衣角和遗骨仍在，铜屑不盖住两个人。

执行节拍：接触、破炉、拔回有连续过程；收回剑才能在后面回锋。

L04｜08.80–10.80s 丹火反噬，玄衡失防松剑

镜头设计：65mm近景，以炉眼为后层、玄衡左掌与侧脸为前层，镜头固定，拉焦一次由裂口到掌心。

子节拍1：8.8–9.7秒：金气在破损炉眼爆燃成暗红火焰，沿原有炉眼→左掌连接失控窜入；玄衡左指蜷缩、掌部有限焦黑，护体金罡从掌侧迅速碎灭。

子节拍2：9.7–10.8秒：玄衡肩部被反噬震退，右手松开金剑柄；金剑仍留男主肩侧与石柱，不能随玄衡退走。男主身前金罡阻碍已经消失。

执行节拍：火焰与原金气同向，改变的是性质和强度；先失防，后回锋才有用。

L05｜10.80–12.00s 脱离柱上金剑

镜头设计：50mm男主肩侧近景，与前镜同轴一侧，摄影机随他向前短移约20厘米，柱上金剑留在画内。

子节拍1：10.8–11.5秒：男主先稳住双脚，左手低位扶柱，身体沿金剑原轴向前退出，左肩侧脱离剑刃；右手青霜剑低持，嘴角因内伤又积一线鲜血。

子节拍2：11.5–12.0秒：肩部完全脱离，男主后脚跟进，玄金剑单独留柱；玄衡空出的右手已经伸向他握青霜剑的手腕。

执行节拍：先脱剑再迈步，受伤的左臂只作低位支撑，不突然双手大开。

L06｜12.00–15.00s 以师姐的回锋势制住玄衡

镜头设计：40mm双人侧近中景，镜头轻向右横移约30厘米随腕部，保留右手、剑身与玄衡心口，不快速环绕。

子节拍1：12.0–13.0秒：玄衡右手抓向男主握剑腕，男主以剑脊贴住其腕侧向外引开，右肘收近腰，手腕下沉；动作节奏与第2段师姐双指外引沉腕相同。

子节拍2：13.0–14.1秒：男主借玄衡抓势转动腰胯，青霜剑经短小下弧向内回挑，绕过抬起的手臂；只一条贴刃细蓝弧线，不挥出巨型月牙光斩。玄衡伸手路线被带偏。

子节拍3：14.1–15.0秒：剑尖转为直指心口，轻抵衣甲而未刺入；玄衡后腰抵炉台、双眼骤然睁大，男主稳住右手，左臂垂低，双方仍有呼吸。

执行节拍：外引—沉腕—回锋—抵胸为已经学过的一式，不加新境界或第三人救场；最后师傅活着，留下一段惊问。

## 对白

0.0–1.9秒｜谢无咎：“师姐的命，你拿什么还？”
2.0–3.4秒｜玄衡：“孽徒，找死！”

## 连续性

先有毁炉造成的失防，再有既有回锋势制敌，二者缺一不可；回锋势是师姐早已私下教男主练过的短招，前段只有提醒，不是新获得力量。玄金剑刺入左肩并留柱，玄衡松手后男主脱离；青霜剑破炉后必须拔回、再用于回锋。结尾玄衡仍活着，剑尖抵胸，能在下段完整惊问；本段不提前杀师。

下段首帧直接接青霜剑抵心口、玄衡活着惊惧的站位；男主已经脱离柱上玄金剑，左肩伤与嘴角鲜血保留。玄金剑不再回到任何人手中。
