## 每段固定内容

1. 基本规格写明集名、段号、全片时间、本段15秒、画幅、CG风格、清晰度意图与当前文本状态。
2. 有序参考输入逐张说明用途、实际文件、存在状态和编号。每段2—3张剧情关键帧，加本段实际演员三视图。群演出镜时记录其造型参考状态。多角度人物图只代表同一位演员。
3. 人物锁写全本段角色脸型、年龄观感、发型、衣色、武器收纳位置和表演状态，只写本段实际出场者。
4. 空间锁写清前后左右、相对距离、入口出口、人物站位、道具状态、光线方向、背景主次。动作必须能在已写空间内完成。
5. 首尾状态写清本段接上段的具体姿势、物件和声音，以及交给下段的动作方向。两张关键帧各自负责的时刻与构图明确。
6. 逐镜设计包含下列全部字段，覆盖0—15秒。
7. 对白与内心逐句列出说话者、声音类型、实际文本和段内窗口。动作可与对白同步推进。
8. 声音写清现场声、对白、内心、传音和脑补声场的进入与退出。
9. 连续性写清能力来源、角色信息边界、道具亮暗、衣服武器与空间方向。
10. 画面输出约束固定包含无字幕、无屏幕文字、无水印，并按本段补充人物和动作禁项。

## 每镜必填字段

| 字段 | 写作要求 |
| --- | --- |
| 时间 | 段内起止秒数，连续覆盖到15秒，交代切镜或同镜转焦。 |
| 焦段与景别 | 标注全画幅等效焦段，例如28mm中广景、50mm双人中景、65mm中近景、85mm手部或眉眼特写。CG按该透视关系设计。 |
| 机位与构图 | 摄影机在人物哪一侧、平视或俯仰、主体在画面何处、前中后景各是什么，以及必要留白。 |
| 运镜 | 写清推、拉、摇、移、跟、升降、环绕或固定机位。移动时给方向、速度感、跟随对象与落点，必要时标注近似距离。固定机位时写清画内持续发展的动作。 |
| 焦点 | 说明初始焦点、必要的转焦目标、转焦触发动作。焦点选择帮助观众看见关键信息。 |
| 画面动作 | 按起势、执行、结果写清身体、手、物件、视线、衣料和环境的可见变化。每镜有正在完成的事。 |
| 声音 | 对应实际台词窗口，标明嘴是否动、环境声如何变化、音效与哪次接触或动作同步。 |
| 衔接 | 说明眼线、动作、声音或画面方向如何接下一镜，末镜写清如何进入下一段。 |

## 连续动作与节奏

- 通常每段5—7镜，每镜约1—4秒，根据完整台词与动作长度调整。120秒全片的8段各自完成一次局面变化。
- 人物说话时同步做有目的的动作，例如转向入口、收手、检查掌位、下踏板、让路、供灵。台词说完后，结果立刻影响下一镜。
- 内心戏在现实中对应视线、呼吸、指尖、步幅或物件状态的变化。单纯反复眨眼、重复吞咽不能承担整段推进。
- 紧张的短暂犹豫可以保留。犹豫期间仍有可见变化，例如对方继续供灵、门扉继续开合、扶手随抓握受力、背景继续沿航路移动。
- 大景和脑补镜头也有明确运动路径、作用对象和结束状态。恢宏感来自尺度、构图、运动和声场的共同变化。
- 保持主轴与视线关系。跨轴或大幅改机位时先写交代空间的镜头，让观众知道人物位置。

## 台词饱满与声音归属

- 每句增加提问、选择、应对、误会依据或行动结果。男主内心接地气，外部对白端着架子且可能卡词。配角按其动机与实际所知说话。
- 对话尽量形成抛出、回应、执行、后果。动作段允许声音留白，留白期间画面必须推进。
- 以正常可表演的语速预排，台词与内心共用同一条时间线。配音前标记为文字估排，实测后再校准。
- 外部对白有相应口型。内心与传音的发声角色嘴唇闭合，通过脸部近景确定声音归属。
- 男主听不到传音和他人的内心。观众可在配角视角听见，切回男主及时恢复现场声，避免把观众信息剪成男主已知。
- 配角脑补从该角色近景进入，回到同一角色退出。脑补画面恢宏、严肃、夸张，现实施法者与效果来源始终明确。

## 无字幕与当前交付范围

画面统一采用无字幕规格。对白、内心和传音通过声音表达，屏幕上无台词字卡、人物名牌、解释文字、游戏UI、可读咒文和水印。道具纹样采用不可读的简洁装饰纹路。

本次用户要求补充剧本、提示词及规范，交付范围为文本。当前剧集记录媒体待制作状态，后续媒体工作按用户当次指示执行。未来用户请求编写提示词时，文件应清楚标记实际素材与任务状态。

## 交稿复核

逐镜检查焦段、景别、构图、运镜路径、焦点、动作、声音、衔接八项。再核对15秒连续覆盖、台词可表演性、首尾状态、参考文件真实性和无字幕规格。最后执行仓库L01—L06与S01—S06，保留对应稿件版本的审读记录。

## EP003 v2时间压缩实例

一个时辰剧情时间可用同机位香长、日影、姿态匹配与角色外部对白压缩呈现，单段成片仍15秒。烹饪数分钟可用入水、熟度和装碗的动作匹配压缩。提示词分别标记剧情经过时间与成片长度，人物、道具及时间变化有可见依据，画面没有时间字卡。
