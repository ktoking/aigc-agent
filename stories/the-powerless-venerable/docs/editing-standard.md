# 成片剪辑规范

用户于2026-11-17确认，后续《本座今日不飞》成片按本规范执行。参数入口为templates/editing-profile.json，片头模板为templates/creator-intro.html。

## 片头与画面

署名片头位于0—2.1秒，黑底白字，显示Create By、西瓜终结者AIGC、AI-GENERATED CINEMA。中文使用细宋体，英文使用Cormorant Garamond衬线及斜体。统一0.3秒渐显渐隐。片头模板以1280×720为设计基准，随成片分辨率等比缩放。

从第二集起，署名片头结束后接第一集的穿越自述，成片时间为2.1—7.4秒。复用片段长5.3秒，保留原画面、配音及三句字幕“我穿越了”“成了修仙界的镇宗大尊者”“可我半点仙力都没有啊！”。独立SRT将自述字幕加上2.1秒偏移，当集字幕按正片起点7.4秒顺延。署名片头与穿越自述分别计时，复用画面缩放到当集输出分辨率。[固定自述素材](../assets/branding/series-cold-open/EP001_穿越自述_4K.mp4) · [源时间码与字幕](../assets/branding/series-cold-open/source.json)

素材按剧情和实际对白确定顺序。沿用源素材分辨率与16:9比例，统一30fps。正片开头从黑0.3秒渐显，结尾0.3秒渐隐至黑。段间叠化0.2秒，使用段尾静帧手柄保护完整对白。片尾收至纯黑后结束。

## 配乐与混音

默认使用Groovy Hammond，固定线性增益0.119。署名片头静音，配乐从穿越自述的第一帧开始，使用同一条轨道连续铺到当集片尾。正片画面切入时，音乐从前一拍继续播放。全轨起止各0.3秒淡入淡出，片尾全黑时静音。复用的穿越自述素材携带原对白和环境声，当集配乐在剪辑工程内统一添加。

配乐时长覆盖自述与当集正片的总和。当前Groovy Hammond采用0–96秒主体乐段循环，在接环处使用40毫秒等功率短交叉淡化。配乐的对白避让和笑点停拍参数均为关闭。混音输出采用固定峰值修正，避免整体自动增益带动配乐起伏。对白与原片声音先按既有基准准备为−18 LUFS、峰值−2 dBTP，再以对白轨增益1混合。

## 字幕

生成源镜头保持干净无字幕。后期成片按实际语音转写并对照剧本校正人名、宗门、修仙术语与同音字，字幕覆盖真实对白与内心声。按语音停顿分短句，避免叠字。

字幕采用白字、深色薄描边与小面积半透明深底，位于底部安全区。720p设计基准字号36px、底部容器边距72px，随输出分辨率等比放大。检查源片已有烧录字并处理重复显示。

## 输出与核验

交付H.264＋AAC MP4，48kHz双声道，快速起播。核验剧情顺序、对白完整、字幕同步、七处或实际数量的0.2秒叠化、首尾0.3秒淡化、BGM固定增益与循环接点、黑屏静音、画面字幕范围及文件完整解码。人工听感检查按实际完成情况记录。
