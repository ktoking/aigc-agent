# 制作规则 v3

- 从EP003起，后续每集约120秒，8×15秒；16:9写实国风CG，沿同一演员基准。台词窗口按文字估排，制作时以实际声音校准。
- 每段通常5–7个短镜头，约1–4秒，先动作、后理解、马上出现后果；每段至少两次状态变化。不得只拍人物说完一句再等反应，也不以无因果乱切制造快。
- 笑点以严肃电影机位呈现：男主内心现代、慌乱试招，台面上卡词学尊者说话；各弟子有明确归属的自疑心声和汗、视线、手部动作。无表情包、歪嘴、漫画汗滴、字幕梗、笑声音轨或滑稽乐器强提示。
- 当前人物三视图为全新阵容new-cast-v1，谢无咎白衣青襟玉簪，白璃赤棕高马尾与雾蓝衣，沈照月青衣矩形玉梳，玄衡棕袍低冠，陆青浅杏袍布头带。人物健康干净。
- 男主的任何特效都不能来自本人。云驾由陆青维持，白璃御空、玄衡护场均明示施术者；不把其他人法术剪成男主施法。
- 画面干净、干燥、适度细节，不加废墟、暴雨、过锐和满屏微纹理。笑点靠真实物件：浮云、长阶、无轮云辇、木轮运粮车、马鞭、拜帖。
- EP001每段现有2张选定剧情关键帧与本段出演人物的三视图，全部放本段frames。重绘淘汰稿在production/images-v1/rejected，当前输入顺序见reference-plan.json。


- 现代网络词、荒唐咒语与吐丝手势已由用户明确授权；现代用词只限男主内心，不带入配角古风话和现代服装道具。咒语在脑内，嘴唇不动；吐丝手藏袖内，门人只看见停步背影。
- 副角色内心先用脸部近景定位，再切对照。陆青担心自己催行的时辰有误，玄衡只查自己的礼单；两者不自动理解男主真实原因。
- 站很久用三段连续站位、反复同构背影和等待微动作表现，约请登云至步行的二十余秒剧情时间，不加半炷香等无法对应的字幕。

## 2026-11-17连载与视觉更新

- 整集观感为70%沙雕喜剧、20%装逼爽感、10%身份暴露危机。喜剧优先落在信息差、动作后果和严肃执行上。
- 男主现实侧使用扶手、脚踏、嘴唇、衣袖和掌位等近景，内心口吻日常、具体。其对外仪态保留镇宗尊者的克制和端正。
- 敌人和长老的想象可使用恢宏远景、庄严构图、夸张尺度与低沉声场。通过配角眼睛近景进入想象，再切回同一张脸，现实与想象的声音分开。
- 每段2–3张剧情关键帧优先覆盖主要动作与结束状态，按剧情转折补充中间节点。脑补场面写入导演文本，场景和道具设计放assets，段内按实际演员配置三视图。
- 每集记录触发误会的原话、旁人理解、实际行动、所得回报及下一集遗留要求。阶段推进见series-progression.md。

## 导演提示词与无字幕规格

后续执行[prompt-writing-standard.md](prompt-writing-standard.md)。该文档记录EP001、EP002实际提示词长度与结构，逐镜填写焦段、景别、机位构图、运镜、焦点、完整动作、声音及衔接。参考详写范围为每段约2800—4200个非空白字符，配合逐镜语义审读发现遗漏。

画面按无字幕规格设计，台词、内心、传音均由声音承担。人物说话时动作继续推进，停顿有画内变化与明确原因。当前用户要求交付文本，EP003记录为媒体待制作。

## 后期成片的固定规范

用户2026-11-17确认的后期标准见[editing-standard.md](editing-standard.md)，机器参数见../templates/editing-profile.json。生成源镜头使用无字幕规格，成片后期加入对白字幕。BGM固定增益0.119，循环铺满正片，画面与音乐起止0.3秒渐显渐隐，段间叠化0.2秒，片头使用已确认的细宋体与衬线英文署名。
