# 连载方向草案

EP001《尊者今日走陆路》：已写完整120秒，解决不会飞的出行，结尾出现徒手切磋难题。

EP002《本座只是皱了个眉》：已写60秒、4×15秒。主角焦急皱眉被误认为霸体起势，弟子讲传说，白璃谨慎请留手；裴长庚驾天衡迎客鹤来迎，赔罪、制止切磋，主角强撑如此甚好后随他离场。

EP003《本座一句都没说》使用原八段剧本的第1—4段。男主听不到传音，问明来意后登坛参加至尊讲道。因不懂筑基，他沉默一个时辰，被长老与弟子当成无言大道。

EP004《本座只想吃碗面》使用原八段剧本的第5—8段。讲道后男主想吃火锅，膳房送来九转龙髓丹。他尝不惯便偷偷要清汤卧蛋面。长老将吃面理解成斩断仙道执念，下令仙宴改素面。

EP005《本座只敲了三下》为120秒、8×15秒。大长老讲断云关、沧陵和栖云三桩旧事，随后请尊者为后日的山门试阵留真元。谢无咎观察三路先散后稳，用木筷分次给口令，弟子立起练阵护幕。厨子领命给练阵者添肉。正式主阵石随即上案，大长老请谢无咎后日亲手开灵。

剧本默认按120秒、8×15秒设计。这次用户要求将八段源片剪为第三、四集，两集各67.8秒含片头。五阶段方向与70/20/10观感见[连载推进](series-progression.md)。当前主角仍以被动避险与普通生活需求为主，EP005从仙宴改素面之后继续。


后续事件库：

- 传音密议：EP003开场先呈现落地后的冷场，谢无咎追问才得知裴长庚用过传音。后续可继续写会盟中要求当面说带来的议事方式改变，再发展到外门执事陈情。
- 辟谷与饭：EP004已兑现吃面的小回报，随后从仙宴改素面向膳房安排、普通食物与宗门模仿扩展。
- 神剑演武：他自己不会起剑，主动请各弟子先练；真正的教习负责纠正动作，他凭听取意见分配资源，外派访客却坚持要看他示范。
- 陌生旧友：原主答应过的比试与暗号形成真风险，男主需要从旧物、日程与对话中找信息，不让对方只靠他沉默就永远相信。
- 凡人护送：他把路线交给真正熟悉山路的车夫，却碰上需要修士出手的危险；必须依靠提前安排的同行者／护送，不可临时觉醒或永远等路过高手救场。

后续事件库仍为设计方向。持续保留零修为，成长来自判断、安排与人际信任。新集需另写完整因果与文案检查，不直接把本页当成可生成台词。
