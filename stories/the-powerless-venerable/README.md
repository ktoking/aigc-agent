# 仙尊不会飞

现代普通人穿成青玄宗镇宗大尊者，却没有灵力、不会任何原主技能。他的普通自救被认真执行，名望暂时护住他，也不断带来新的邀招。

现采用全新人物阵容new-cast-v1，人物关系为谢无咎尊者、沈照月内务护法、玄衡掌门、陆青近侍、白璃邻宗同位尊者。各宗均有大尊者，男主不独占世界顶点。
