# 全剧画风

电影级写实国风3D CG，16:9，现行人物基准为new-cast-v1，按assets/character-manifest.json及对应演员实际基准图锁定。

谢无咎象牙白袍配深孔雀青襟，沈照月松石青衣，白璃雾蓝衣与赤棕高马尾，玄衡棕褐宗主袍，陆青浅杏袍，裴长庚浅灰白袍与烟青披肩。冷灰云海、暖色柔和轮廓光、清楚大形和适度细节，画面干净干燥。

整体按70%沙雕喜剧、20%装逼爽感、10%身份暴露危机把握。人物保持严肃电影表演，男主现代内心与配角恢宏脑补交替，行为后果承担笑点。输出画面无字幕、无可读解释字卡、无水印。提示词按docs/prompt-writing-standard.md完整填写。
