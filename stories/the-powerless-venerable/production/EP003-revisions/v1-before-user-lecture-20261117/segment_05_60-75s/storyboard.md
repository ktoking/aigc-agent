# EP003第05段《旧例还得刷法力》故事板 v1

全片60–75秒，本段15秒。

## 起点

两人位于盟印台左右，谢无咎右手将伸未伸，两处掌位均暗。

## 终点

裴长庚向左掌位注灵，左半印亮起，右掌位仍暗。谢无咎听见需要仙力，停住伸手，裴长庚开始催问。

## 声音

D01｜0.2–4.8秒｜裴长庚／外部对白｜“你我各注一缕仙力，便可开印。”

D02｜5.2–9.0秒｜谢无咎／内心｜“这旧例还得刷我的法力？”

D03｜11.2–14.5秒｜裴长庚／外部对白｜“谢道友，只需一缕便够。”

## 镜头

### L01｜0–2.7秒

焦段与景别为全画幅等效50mm，两人隔台双人中景。

机位与构图为台面同侧双人中景，裴长庚左、谢无咎右，两个掌位完整留在前景，殿门仍关。

运镜为平稳向前推约二十厘米，老者抬手、男主停手与解释同步发生。

焦点安排为焦点从老者说明的嘴移向两人不同的手部动作，保持关系可认。

画面动作按以下顺序推进。老者平常地解释各注一缕仙力，抬起右手悬于左掌位上方。男主刚抬起的手停住。

声音安排为本镜对应D01裴长庚／外部对白，跨镜同句连续发声一次。脚步、木踏板、细金灵流和转轴声按本镜实际接触与运动同步进入。

镜头衔接为沿老者抬手落灵的方向切左掌位特写，外部对白继续。

### L02｜2.7–5秒

焦段与景别为全画幅等效65mm，裴长庚手与左掌位特写。

机位与构图为略俯拍老者右手和台面左掌位，右侧暗掌位边缘入画，手与光源连接完整。

运镜为跟细金灵流轻下摇，终点是左半印纹铺亮的结果，右侧始终保持暗色。

焦点安排为从指尖转焦左印纹，再让右侧暗掌位保留可辨对比。

画面动作按以下顺序推进。细金灵流从老者指间落入左掌位，左半印线亮起。右掌位与另一半印线保持暗色。

声音安排为本镜对应D01裴长庚／外部对白，跨镜同句连续发声一次。脚步、木踏板、细金灵流和转轴声按本镜实际接触与运动同步进入。

镜头衔接为男主视线由左亮移向自己的手，切其脸部反应接内心。

### L03｜5–7.5秒

焦段与景别为全画幅等效85mm，男主眉眼近景。

机位与构图为男主在台右侧的近景，亮印反光轻映下颌，右掌位在下方虚焦，老者居画外左。

运镜为向右侧移约十厘米，跟随眼睛由左亮到自身手的视线移动，终点落在收紧眉心。

焦点安排为锁眉眼，嘴唇闭合，内心所指的法力要求来自刚听见的解释。

画面动作按以下顺序推进。男主看一眼亮着的左半印，再看自己的手，内心问旧例是否还得刷法力。

声音安排为本镜对应D02谢无咎／内心，跨镜同句连续发声一次。脚步、木踏板、细金灵流和转轴声按本镜实际接触与运动同步进入。

镜头衔接为沿其低头视线切右掌位与悬手，内心声音可自然跨切。

### L04｜7.5–10秒

焦段与景别为全画幅等效65mm，男主手与右掌位。

机位与构图为台面高度的男主手部特写，手悬在暗掌位外沿，袖口落在右边，左半光路仍在后景。

运镜为固定机位，画内指尖先蜷后缩半寸，左路灵流持续前进，手与掌位的距离增加。

焦点安排为焦点锁手指与暗掌位边缘，保留接近但始终没有触碰的关系。

画面动作按以下顺序推进。他的手悬在掌位外沿，指尖蜷一下，缓缓缩回半寸。右掌位一直没有变化。

声音安排为本镜对应D02谢无咎／内心，跨镜同句连续发声一次。脚步、木踏板、细金灵流和转轴声按本镜实际接触与运动同步进入。

镜头衔接为手缩回引出老者侧目，下一镜用老者脸承接追问。

### L05｜10–12.7秒

焦段与景别为全画幅等效65mm，裴长庚脸部反打，台面维持左亮右暗。

机位与构图为老者在台左侧的近景，右手供灵仍在画面下方，男主袖子虚焦置于右前景。

运镜为轻推约十厘米，随老者由印纹转目光看男主，供灵的手持续稳定。

焦点安排为先锁老者眼睛，再小幅下调让手中光路清楚，不切断力量来源。

画面动作按以下顺序推进。老者保持左路供灵，侧目看男主，提醒只需一缕仙力，语气平常。

声音安排为本镜对应D03裴长庚／外部对白，跨镜同句连续发声一次。脚步、木踏板、细金灵流和转轴声按本镜实际接触与运动同步进入。

镜头衔接为其唤谢道友的声音把视线交还男主，下一镜由主角寻找可代劳的手。

### L06｜12.7–15秒

焦段与景别为全画幅等效50mm，主角视线沿左右掌位移动。

机位与构图为略俯拍台面与双方手的关系中景，左路亮、右路暗，老者空着的左手在左上角。

运镜为沿男主视线从暗掌位平摇到老者空手，再微抬镜到主角准备开口的下巴。

焦点安排为焦点依次经过右掌位、老者空手、主角脸，展示其下一步选择的实际依据。

画面动作按以下顺序推进。男主收回手，目光从空掌位移到老者尚空着的另一只手，准备把任务转过去。

声音安排为本镜对应D03裴长庚／外部对白，跨镜同句连续发声一次。脚步、木踏板、细金灵流和转轴声按本镜实际接触与运动同步进入。

镜头衔接为接下段主角询问是否能独开，空右掌位和左路持续供灵保持连续。
