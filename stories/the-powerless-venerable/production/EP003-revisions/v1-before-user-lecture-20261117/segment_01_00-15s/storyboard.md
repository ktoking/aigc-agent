# EP003第01段《方才谁说话了》故事板 v1

全片0–15秒，本段15秒。

## 起点

承接EP002离场。仙鹤平稳飞行，裴长庚前鞍御鹤，谢无咎后鞍端坐，双脚踩脚踏，宽袖里握着低扶手。

## 终点

裴长庚以真实声音追问意见。谢无咎发觉对方正在等待自己回答，却不知道刚才问了什么。

## 声音

D01｜0.3–4.3秒｜裴长庚／传音，仅观众听见｜“今年开印礼，仍照旧例？”

D02｜7.0–10.8秒｜裴长庚／外部对白｜“谢道友，方才所议，你意下如何？”

D03｜11.2–14.3秒｜谢无咎／内心｜“方才？你刚才说话了？”

## 镜头

### L01｜0–4.5秒

焦段与景别为全画幅等效65mm，裴长庚侧脸近景，远山缓慢后移。

机位与构图为摄影机在前鞍左前侧，与老者坐姿眼线等高。老者居画面右侧，后鞍扶手留在左后景，远山为低对比背景。

运镜为随鹤同速左侧伴飞，缓推约十五厘米到老者眼睛，画内山脊继续向后移动。

焦点安排为焦点锁老者眉眼，嘴唇同在清晰景深内，确保传音时闭口可见。

画面动作按以下顺序推进。老者扶着前鞍，微微回头，嘴唇闭合。传音完整留在其近景中，声音干净贴近。

声音安排为本镜对应D01裴长庚／传音，仅观众听见，跨镜同句连续发声一次。以风声、衣料和玉铃为底声，传音只在老者视角出现，切回主角恢复其现场声。

镜头衔接为沿老者回望的眼线切后座，声音在切点换成男主所听到的风声。

### L02｜4.5–6秒

焦段与景别为全画幅等效65mm，谢无咎近景，保持后鞍靠背和前座肩背的定位。

机位与构图为同侧后鞍平视，男主脸位于右侧三分线，前座肩背在左前景虚焦，木靠背与扶手框住身体。

运镜为侧移约十厘米绕开衣袖遮挡，落点露出他扣紧扶手的手背，画内云层持续后退。

焦点安排为从男主眼睛短暂转焦到袖下指节，再回眼睛，配合抓握收紧。

画面动作按以下顺序推进。切到男主立即只剩风声。男主不知道有人询问，盯着前座后背，袖内手指压紧扶手。

声音安排为本镜由现场声承担节奏，人物动作与物件状态持续推进。以风声、衣料和玉铃为底声，传音只在老者视角出现，切回主角恢复其现场声。

镜头衔接为男主视线仍盯前座，下一镜反切老者再次回头。

### L03｜6–7秒

焦段与景别为全画幅等效85mm，老者眼睛与闭合嘴唇，短停后转成过肩。

机位与构图为保持前鞍同侧眼线，老者眉眼在画面上半部，嘴唇完整入画，后鞍方向留出视线空间。

运镜为固定伴飞相对机位，老者在画内由前望转为侧后望，玉铃边缘经过画面下角。

焦点安排为锁住眼睛与嘴部，借其目光移动把注意力送向后鞍。

画面动作按以下顺序推进。老者等不到回答，再看后座。仙鹤翼尖从画面边缘掠过，前后鞍位置稳定。

声音安排为本镜由现场声承担节奏，人物动作与物件状态持续推进。以风声、衣料和玉铃为底声，传音只在老者视角出现，切回主角恢复其现场声。

镜头衔接为老者吸气张口时接双人关系镜头，外部对白从下一镜起清楚进入。

### L04｜7–11秒

焦段与景别为全画幅等效50mm，同轴前后双人侧面中景。

机位与构图为摄影机位于两座左侧，前鞍老者在左、后鞍男主在右，两个靠背和固定脚踏保持可辨。

运镜为平稳侧向跟飞，轻拉约二十厘米，容纳老者回头与男主抬眼，结束仍保持前后鞍同框。

焦点安排为中等景深同时保留两张脸，老者开口后重心交给男主反应。

画面动作按以下顺序推进。老者真正张嘴，以外部声音询问意见。男主先抬眼再把目光移到老者脸上。

声音安排为本镜对应D02裴长庚／外部对白，跨镜同句连续发声一次。以风声、衣料和玉铃为底声，传音只在老者视角出现，切回主角恢复其现场声。

镜头衔接为男主抬眼的动作接下一镜脸部，台词结束后由其内心声音接入。

### L05｜11–13秒

焦段与景别为全画幅等效85mm，谢无咎眉眼近景。

机位与构图为后鞍同侧平视特写，男主眉眼居中偏右，画面左边保留一小条老者肩背作为视线参照。

运镜为缓推约五厘米，落在眼睛微睁与眉心收紧的变化，鹤的起伏只作轻微整体位移。

焦点安排为焦点稳定在双眼，嘴唇闭合可见，内心声音从近景归属男主。

画面动作按以下顺序推进。男主眼睛微睁，内心疑问开始，嘴仍闭合。

声音安排为本镜对应D03谢无咎／内心，跨镜同句连续发声一次。以风声、衣料和玉铃为底声，传音只在老者视角出现，切回主角恢复其现场声。

镜头衔接为顺他向下看扶手的眼线切到手脸同框，延续内心句。

### L06｜13–15秒

焦段与景别为全画幅等效65mm，男主手与脸同框。

机位与构图为摄影机略低于男主胸口，扶手在下前景，男主脸在上方，衣袖覆盖手腕但指节可辨。

运镜为微微上摇跟随男主准备开口的抬头，最后停在脸与手同时可见的位置。

焦点安排为由松开一指的手转回嘴角，接住吸气动作。

画面动作按以下顺序推进。他松开一根手指，想接话又吸住气。老者继续等他，场面从乘坐变成必须作答。

声音安排为本镜对应D03谢无咎／内心，跨镜同句连续发声一次。以风声、衣料和玉铃为底声，传音只在老者视角出现，切回主角恢复其现场声。

镜头衔接为本段末保留吸气未答的连续动作，下段同一后鞍近景直接接他要求重说。
