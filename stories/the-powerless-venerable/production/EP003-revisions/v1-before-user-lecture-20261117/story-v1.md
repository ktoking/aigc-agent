# 《本座今日不飞》EP003《你倒是开口啊》小说式剧本 v1

风从鹤背两侧刮过去，我的衣袖贴住了扶手。前面的老头回了一下头，我立刻把背挺直。

【裴长庚视角｜传音】

“今年开印礼，仍照旧例？”

【谢无咎视角】

我盯着他的后背，等那片山头从脚底过去。老头又转过来，这回嘴动了。

“谢道友，方才所议，你意下如何？”

方才？你刚才说话了？

我把下巴往上抬了一点。

“方才那句……再说一遍。”

老头点点头。

【裴长庚视角｜传音】

“今年开印礼，仍照旧例？”

【谢无咎视角】

他的嘴合着，眼睛却一直看我。我侧过一点头，耳边还是风。

这是在传音？

完了，语音频道我也进不去。

我扶牢木栏，朝前座挪了半寸。

“道友……开口说吧。”

老头停了停，嘴终于动起来。

“老夫传音惯了。今年开印礼，仍照旧例？”

远处露出一座殿顶，白玉平台就在檐下。我赶紧点头。

“照……旧例。”

老头转回前面，抬手引着白鹤往下落。我又把刚松开的扶手攥住了。

白鹤收翼往平台上落，我的手又攥紧了一点。

慢点慢点，别给我整俯冲啊。

两级木踏板搭在石地上。老头先下去，回头看了一眼我还抓着的扶手。

“道友，已经落稳了。”

我扶着鞍，一阶一阶踩到底，鞋底站实了才肯松手。

“嗯……本座知道。”

“开印台就在前面，道友请。”

我拢好袖子，跟他走到殿门前。那里摆着一方青玉台，左右各刻着一个掌位。我站到右边，看他往左边抬起手，便也把手从袖子里抽出来一点。

“你我各注一缕仙力，便可开印。”

老头指间落下一道细金光，左边的掌位亮了，纹路顺着玉台铺开一半。

我的手停在另一半上面。

这旧例还得刷我的法力？

我把手往回缩了半寸，掌位仍旧黑着。老头看过来。

“谢道友，只需一缕便够。”

我看向他空着的那只手，又看了一眼台面。

“道友一人……也能开吧？”

老头的眉毛抬起来了。

【裴长庚视角｜内心与脑补】

一人分御两路……他在考老夫的控灵？

苍茫山海间，一座高大玉阙悬在峰顶。裴长庚立在门前，两股金色灵流自掌间分开，沿两道山脊掠向高门。

【谢无咎视角】

左边的玉台还亮着，老头看了我半天。我把脚尖往袍子里收了收。

你倒是说行不行啊。

“你想考老夫？”

我把那只手藏回袖子，迎着他的目光点了一下头。

“道友……自可一试。”

“那便看好了。两路灵息，分毫不差。”

老头说着把掌心往台中一移，细金光分成两束，另一半掌位也亮了。光沿地上的嵌线走到门前，两扇殿门缓缓向里推开。

我袖子里的手终于松下来。

我就这么一说，他把活儿全干了？

老头收了手，转头看我。

“道友，这一手如何？”

我赶紧点头。

“甚……甚好。”

“好在何处？”

我的头点到一半，停住了。

老头朝敞开的殿门一让。

“走，入席细说。”

殿里几张席位上已经有人，听见门响，都转头看过来。老头走到门边，还等着我。

我还得写观后感？
