# 第06段《这道门绕不开》分镜 v3

开场：车夫坐稳、手握缰绳尚未发车，沈照月站窗边准备说完，主角刚把车帘放下。

结束：沈照月补完消息，主角想绕路却发现出宗必经山门；白璃来访的白色身影已在车前上方出现，主角的逃开计划被堵住。

L01｜0–3秒｜终于有独处半秒

镜头：65mm车厢内近景，车帘遮外界。

动作与因果：主角放下帘，肩背松半寸，轻擦掌汗，内心想先离山。外面车夫正检查缰绳，没有凭空扬鞭冲走。

L02｜3–5.5秒｜拜帖消息补完

镜头：50mm窗外沈照月近景，焦点在她和拜帖。

动作与因果：沈照月在窗边说白璃来邀尊者同行赴会，语气是明确行程提醒，指尖把拜帖收好，不做玄学猜测。

L03｜5.5–8.5秒｜刚放下的帘又掀开

镜头：65mm主角手挑帘到侧脸，轻推不超过15厘米。

动作与因果：主角听见后手停，再挑开帘支吾问能能绕过去么，努力压低声线却在第一个字卡住，袖内另一只手抓住坐垫边。

L04｜8.5–11.5秒｜普通车夫指出实路

镜头：35mm从驾驶位朝唯一山门看。

动作与因果：车夫回答，抬鞭只指门口车道；两侧是真悬崖和山壁，不存在可以随意绕出去的空地。

L05｜11.5–15秒｜邀访真的挡在前方

镜头：28mm车前中广景，轻抬镜后稳定。

动作与因果：白璃白发与黑红衣带从云侧落向车前，来源是她自己的御空，不是主角召来。主角挑帘的手停住，车还没发动，风险真实入场。

## 对白与内心

0.0–2.7秒｜谢无咎／内心：“先下山，找个没人的地方苟住。”
3.0–6.0秒｜沈照月：“白璃尊者来邀您同行。”
6.4–8.0秒｜谢无咎：“能、能绕过去么？”
8.4–10.9秒｜车夫：“下山只有这一道门。”

内心不动口、旁人听不见；文字估排未配音。
