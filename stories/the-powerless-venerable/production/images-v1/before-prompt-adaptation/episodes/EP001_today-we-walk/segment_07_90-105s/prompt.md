人物：
- C01 谢无咎：青玄宗镇宗大尊者；现代普通人穿越进其身体，外形与原主相同，当前灵力、护体、神识、御剑及一切原主技能均不可用。表面寡言镇定，独处或内心才惊慌。普通人的观察、常识和求助能用，不能突然觉醒。
- C02 沈照月：青玄宗内务总管兼护法，真实有修为，办事快，记得预约与行程，敢做必要提醒。敬重原尊者战绩，按现有信息判断主角在敛息、亲近门人；不预先知道穿越秘密。她活着，和男主无前故事的师姐死亡关系。
- C03 白璃：邻宗镇宗大尊者，与谢无咎原主属于同一层次，称“谢道友”，不向其跪拜。黑红甲、白发、角形金属发冠、单柄弯刀。认真好胜，三年未切磋，前来邀招；尊重其真实旧战绩，但不会无条件把任何话当圣旨。
- C04 玄衡：青玄宗掌门，负责山门事务及晚辈安全；外貌年长但宗门辈分低于驻颜年轻的镇宗尊者。严肃、谨慎、真正懂修炼。他收剑步行是服从巡山安排，最后清场是防误伤，不是愚蠢吹捧。他不是旧故事中炼丹杀人的师傅。
- C05 陆青：尊者近侍，熟悉宗门礼仪，平常御剑但缺乏凡俗出行经验。最容易按师门旧战绩推测尊者举动，表现在学着收剑、抢着随行和期待观战；不反复说“原来如此”。
- C06 外门车夫与搬货弟子：复用两名灰黑弟子演员，壮实者为运粮车夫，较瘦者负责牵马搬货。真实会驾马车，修为低但有职业技能；在第4–8段出场，不充当武装反派。

世界与行程：青玄宗尊者谢无咎今日赴天衡宗会盟，各宗都有自己的顶层尊者。陆青备云，玄衡持青色会盟请柬；沈照月在下山平台候行程，另有白璃邀同行的小拜帖。白璃可先在青玄宗山门邀同行，因与原主三年未切磋而请一招，不把她写成大会已经开始后的另一时间线。

空间：S02_gate_square；云台至广场是实地短廊，下山石阶与盘山车道并列，云辇和卸粮木车都候在同一个平台。木车只走车道，不走三千级台阶。

L01｜0–3秒｜同位来客

动作与因果：白璃落地站稳，拱手称谢道友，只有平辈礼，不跪。男主车内面色平静，车夫拉住缰绳让马不前行。

L02｜3–5.5秒｜邀招有真动作

镜头：50mm白璃半身，镜头退半步容纳弯刀。

动作与因果：白璃右手把弯刀横在身前示礼，说请赐一招；刃不朝车夫，不表现为来袭杀人，刀周只有她自身克制的气流。

L03｜5.5–8.5秒｜只在帘内露怯

镜头：85mm男主袖内手与目光交替的近景。

动作与因果：主角握紧坐垫，目光扫过刀尖后立即收回，内心用没学闪避的现代说法急问拿什么接；表情仅喉结轻动，不张大嘴尖叫。

L04｜8.5–11.5秒｜旁人准备观战

镜头：35mm车后中景，摄影机横移约30厘米。

动作与因果：陆青下意识向前半步想看，玄衡抬手挡住晚辈，沈照月收拜帖站车侧。人人按可能切磋准备，不齐声喊尊者无敌。

L05｜11.5–15秒｜措辞打开另一扇门

镜头：65mm男主车窗近景后切白璃右手。

动作与因果：主角先卡住今日的首字，再强压声音说不动兵器，抬空左掌原意示停；白璃点头，把弯刀转向腰侧开始收起。男主以为暂过，观众看到误会正在发生。

对白／内心时间轴（各说一次）：
0.2–2.8秒｜白璃：“谢道友，三年未见。”
3.4–5.3秒｜白璃：“请赐一招。”
6.0–8.8秒｜谢无咎／内心：“我连闪避都没学，拿什么接啊！”
11.4–13.8秒｜谢无咎：“今、今日……不动兵器。”

声音与表演：标注内心时只让观众听见，所属角色嘴唇不动；先用该角色近景定位心声再切反应镜头，绝不让旁人回应听不到的话。男主脑内是现代年轻人的急促语气，可用技能全灰、蛛丝走你、苟住、司机等情境词；真实开口模仿修仙语汇，本座、今日、亲近门人等字眼在紧张时卡住、找词，不能自信流利念金句，也不能每字都结巴。配角对外仍正常古风，内心按自己的具体担忧说，不会现代梗，不知道男主秘密。每句时间仅为文字估排，配音后校准，不截尾、不强压语速；声效让位台词。

喜剧动作与等待：乱试咒语和吐丝手只出现在前段既定镜头，始终失败。主角正面和袖内镜头可见动作，从门人背后看他则像久立不动；穿插汗珠、紧指、检查请柬与云团来表现等待，不用长静帧或片上时间字卡。除已写心声不追加全员反复悟道的夸词。
