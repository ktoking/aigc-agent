# 《本座今日不飞》故事包

## 独立范围

用户2026-11-16要求新开修仙喜剧，复用上一故事人物外形。只复用脸、发型和服装，人物身份和关系在本目录重设。先读docs/story-memory.md、production-rules.md、audience-strategy.md、season-arc.md、workflow.md以及角色卡。

## 核心规则

- 男主穿越为青玄宗镇宗大尊者，确实零修为，也不会原主技能。当前设定持续如此，不擅自安排封印解开、隐藏无敌肉身、心跳威压、系统代打或临时觉醒。
- 原主真实强大，每个正式门派都有自己的镇宗尊者。男主是顶层群体中的一员，不是唯一凌驾全界的人。白璃是同位强者，称谢道友，不向男主跪拜。
- 敛息在顶层修士中存在；隔空无法凭一个“气息全无”就确证夺舍，强行验魂需要接触或对方配合且属于严重冒犯。实战、长期相处和原主私密知识会揭穿他，不能设成永远查不出。
- 危险来自身份冒用／疑似夺舍被审问、原主旧敌和宗门失去威慑后的压力，不写成门人只因他弱就无缘无故杀他。
- 2026-11-17用户更新：男主内心采用现代口吻，允许情境网络梗、游戏词和荒唐咒语；真实说话时支吾着模仿修仙语气，不把现代梗说给门人。允许弟子、掌门分别猜测尊者停顿并担心自己的具体疏漏，以明确角色内心和不同动机表现；他们互相听不见心声，猜测不自动成为事实。配角保留正常智力，不齐声悟道，不靠歪嘴、Q版或笑声催笑。
- 当前首集120秒、8段各15秒；用户嫌上一片不紧凑，本剧每段有明确新问题和动作后果，不以增加台词字数代替推进。
- 沿用电影感写实国风CG，外部对白与男主现代第一人称内心交错；按用户最新要求可插入明确标注的配角内心，以该角色近景锁定声音归属，不把男主变为读心者。
- 图片合同沿用用户最后选择：每段只2张剧情关键帧＋本段实际出场人物三视图，全部在本段frames，场景与道具图不塞进segment。本轮是设计剧本，未生成新关键帧；不得伪称已有图片或直接可提交。
- 交稿执行仓库script-language-checklist的L01–L06、S01–S06并保存当前版本记录。明确的搞笑题材允许人物因情境产生的幽默，仍禁硬拗段子。
- 不接入Git/Cursor/Skynet hooks或统计。不得自动提交视频、配音或批量生图。
