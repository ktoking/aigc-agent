人物与信息边界
# C01 谢无咎

# C02 沈照月

# C03 白璃

# C04 玄衡

# C05 陆青

# C07 裴长庚／鹤归上人
裴长庚，号鹤归上人，天衡宗前任镇宗尊者、白璃授业恩师，与谢无咎原主平辈有旧。已将宗门日常镇守交给白璃，自己云游，此番应会盟之约乘迎客鹤返山，亲自来迎谢无咎。白璃尊师，裴长庚对谢无咎行平辈礼。

白璃已收法相，裴长庚在车窗旁，迎客鹤伏低、双人鞍踏板展开，众人在路侧，谢无咎还坐木车里。

主角接受移驾邀请，说如此甚好，踩实地与木踏板坐到白鹤后鞍、握低扶手。裴长庚坐前鞍御鹤带他飞离，众人目送；男主内心盯着坐稳抓紧，实际暂时躲开切磋。

逐镜设计
L01｜0–3.3秒｜迎客的人给出离场办法

镜头：50mm车窗与裴长庚双人中景，横移约30厘米露出伏低白鹤的后鞍。

动作：裴长庚侧身引向双人鹤鞍，说请道友移驾同赴会盟。主角目光先看老者，再看有靠背、低扶手和脚踏的座位，嘴角想松又收住。沈照月松开车门旁位置，为他下车留路。

L02｜3.3–6.3秒｜老宗师也按旧名望猜测

镜头：65mm裴长庚眉眼近景，先看主角皱眉渐松的脸，再看他拢袖的普通手。

动作：老者内心说气息敛得如此干净又精进了，嘴不动。他结合原主旧战绩把没有外泄灵压当成收放自如。主角此时正从马车木踏板踩回地面，肩背保持挺直，脚步只按普通人的步幅走。

L03｜6.3–9.9秒｜硬撑一句如此甚好

镜头：50mm白鹤后鞍与两人侧面中景，轻退给主角跨踏板留空间。

动作：裴长庚用手示意有靠背的后座，说道友请坐。男主先吞咽一下，8秒以努力压稳的声音说如此甚好，拢起宽袖，用一只手扶真实木扶手，脚踩低踏板坐入后鞍。老者随后坐前鞍。

L04｜9.9–12.5秒｜坐着也要装从容

镜头：65mm男主后鞍胸上近景，焦点带到袖内抓扶手的手指。

动作：内心短短提醒坐稳抓紧别往下看，嘴唇闭合。主角肩背仍端正，双脚踩固定脚踏，手隐藏在宽袖里攥紧低扶手。裴长庚在前鞍抬手御鹤，光与风仅从他手势和白鹤翼面来。

L05｜12.5–15秒｜驾鹤离场，切磋已躲开

镜头：28mm地面仰拍中广景，沿白鹤起飞方向轻抬镜，末尾保留路侧送行者。

动作：白鹤双足蹬地、双翼下压离地，前后鞍各一人，身体由木鞍承托，主角双脚始终在脚踏。白璃收着刀站路侧，玄衡与陆青等人目送。主角坐后鞍只敢看前座老者的背，鹤沿通往天衡宗的云侧航路飞出山门。

表演和声音
男主脑内急促现代，真实说话卡住本字，最后的如此甚好是强压住慌张的低稳声。皱眉、张嘴无声、紧指、吞咽都由普通人的肌肉动作完成。配角心声按镜头中角色归属，互相听不见。陆青的霸体传说是他听来的夸张说法，玄衡按自己见过的破阵前神色防误伤，白璃把霸体当成指点，裴长庚据旧交战绩误判主角敛息。鹤鸣、玉铃先于老者入画，羽翼风声、木踏板受力与脚步对应动作。台词窗口为文字估排，制作时按实测语音校准。

连续性约束
男主无仙力、护体、霸体、神识、御剑或飞行技能。其眉心无符文、手掌无光、脚下无气浪。旧战绩只通过角色回忆台词与传闻表达。法相属于白璃，御鹤属于裴长庚，后座与扶手承托主角身体。裴长庚对白璃是师长，对谢无咎是故交平辈。人物脸与衣服、单刀收鞘位置、空驾驶位、收法相时序和鹤鞍前后座保持清楚。镜头使用清楚大形与适度细节，人物表情和空间主次可读。
