# 第02段《咒语吐丝御剑，全都没用》分镜 v3

开场：陆青刚请登云，男主站在实地，双手藏在袖内；玄衡在后方廊口持青色会盟请柬。

结束：男主已试咒语、吐丝手势和隔空御剑，全部无效，仍没迈步；陆青额角与后领出汗，怀疑云驾准备，玄衡开始检查礼单。

L01｜0–2秒｜先拿咒语碰碰运气

镜头：65mm袖内手部特写，固定机位；仅露主角自己的护腕与衣料。

动作与因果：承接前段右手悬在袖内。主角先并食中两指，左手勉强兜在右手下面，边排手势边在脑内想咒语。动作来自现代人模仿，不是正确功法；嘴唇闭合。

L02｜2–4.6秒｜妈咪贝贝烘，飞

镜头：50mm腰以上侧面近景，轻推10厘米；脚部另用同轴低位插镜。

动作与因果：内心念咒，右手两指向上勾一下，身体本能提气抬胸，衣摆被自然风吹起一点，但鞋底始终落在石面。插入鞋底不动的低机位，马上切回脸，他从期待变为僵住，不腾空也不垫脚冒充成功。

L03｜4.6–6.9秒｜袖子里变成吐丝手

镜头：85mm手部特写，机位从主角前侧观察袖内，后方门人看不到。

动作与因果：主角换姿势：右手中指、无名指弯向掌心，拇指、食指、小指伸开，用蜘蛛侠吐丝式手势连续弹腕两下，方向向自己的前下方，不指人。内心说蛛丝走你。每次手腕伸出都在衣袖内缘收住，没有丝、光、烟或能量反应；不换现代服装。

L04｜6.9–8秒｜别人眼里他一直没动

镜头：35mm从陆青后方看主角背影，固定重复第1段的站位和构图。

动作与因果：男主仍背对两人站在台前，双袖垂落遮住手，脑内吐槽已停一拍。陆青还伸着手，手肘悄悄降低半寸，抬眼看看男主又马上低头；远风与衣带声短暂突出，第一次让观众感到两边经历的时间不同。

L05｜8–10.4秒｜最后试着叫剑起来

镜头：65mm左腰鞘口和袖内手同框，固定机位后轻上摇到主角侧脸。

动作与因果：主角隔着衣袖对左腰剑柄勾两次指，内心先喊御剑起再补起啊。剑柄和剑鞘位置全不改变，扣带不松。他看完剑又看手，呼吸短了一次；不拔剑、不靠手拉剑制造反应。

L06｜10.4–12秒｜等待先压到弟子身上

镜头：85mm陆青额角与眼睛近景，焦点从鬓边汗珠拉到瞳孔。

动作与因果：主角无声抬起下巴维持体面。陆青误以为尊者在等他补报，额角出汗，后领渐湿，手仍指向云。他先检查云与台沿间隙，再看身后玄衡，未得到提示；不加流汗卡通线条。

L07｜12–15秒｜开始怀疑出行准备

镜头：50mm陆青脸与举着的手同框，缓后退20厘米纳入玄衡低头查请柬的动作。

动作与因果：陆青内心问尊者为何不动、云是否备错，嘴唇不动；他只把原有云团再向台沿靠近一点，试着修正准备。主角注意到云更近了反而把鞋尖缩回半掌。玄衡也因长久停顿开始检查请柬，接下一段不同方向的猜测。

## 对白与内心

0.0–1.8秒｜谢无咎／内心：“咒语？先试一个！”
2.0–4.4秒｜谢无咎／内心：“妈咪贝贝烘——飞！”
5.0–6.8秒｜谢无咎／内心：“蛛丝……走你！”
8.0–10.1秒｜谢无咎／内心：“御剑，起！起啊！”
12.0–14.8秒｜陆青／内心：“尊者怎么不动？云备错了？”

内心不动口、旁人听不见；文字估排未配音。
