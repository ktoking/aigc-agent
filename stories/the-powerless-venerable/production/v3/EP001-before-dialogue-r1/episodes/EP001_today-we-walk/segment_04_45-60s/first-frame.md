# 第04段开场关键帧设计 v3

状态：四人从云台短廊来到下山平台；长阶、盘山车道、沈照月候着的云辇和卸粮木车处于同一可见空间。

拟生成剧情关键帧1：35mm从短廊出口跟到男主侧面，略下俯同时容纳长阶、男主抬起的鞋和旁边车道。画面捕捉本段开场动作的单一瞬间：主角刚要下第一阶便问山门多远。陆青答三千级石阶，主角鞋尖从台阶上方收回，脚落在同一平地平台。台阶蜿蜒向下，旁边盘山车道与卸粮区明确同平台连接，不让车驶上石阶。

图像只表现可见的人物与动作，不把上述时间、内心文字、声音、镜头标签画进去。风格16:9电影国风CG、干燥布景、干净大形、适度细节。仅使用本段frames中的实际角色三视图。当前未生成PNG；共规划2张剧情关键帧，第二张见last-frame.md。
