# 第04段《三千阶，换有轮子的》分镜 v3

开场：四人从云台短廊来到下山平台；长阶、盘山车道、沈照月候着的云辇和卸粮木车处于同一可见空间。

结束：男主从无轮云辇改选木轮运粮车并已坐入车厢；沈照月的小拜帖提醒被打断，她留在窗边；玄衡上前准备护送，车夫在驾驶位旁，车未动。

L01｜0–3秒｜看一眼就收脚

镜头：35mm从短廊出口跟到男主侧面，略下俯同时容纳长阶、男主抬起的鞋和旁边车道。

动作与因果：主角刚要下第一阶便问山门多远。陆青答三千级石阶，主角鞋尖从台阶上方收回，脚落在同一平地平台。台阶蜿蜒向下，旁边盘山车道与卸粮区明确同平台连接，不让车驶上石阶。

L02｜3–5.8秒｜车倒是早准备了

镜头：35mm平台侧面中广景，短横摇同时露出沈照月和她身旁的低浮云辇。

动作与因果：主角说备备车。云辇本来就候在平台旁，沈照月随队走到这里后，右手引它在原地挪近一尺；不是临时跑远调车。主角看见悬空车底，肩膀停住；仅沈照月指尖与车底薄云有光。

L03｜5.8–7.8秒｜补上轮子这个条件

镜头：50mm男主与车底同框，机位略低，镜头固定。

动作与因果：主角支吾说要有轮子的，手指只指石地，立即转头找普通交通工具。玄衡收着剑站侧后，没有主动施法补轮子，也不当场喊高深。

L04｜7.8–10.4秒｜普通运粮车就在旁边

镜头：35mm沿主角视线横摇到三米外卸粮区，再跟他绕过云辇走两步。

动作与因果：沈照月问运粮车，画面中壮实车夫牵着棕马，瘦搬货弟子刚搬完最后一袋粮，空的木车厢与宽木踏板清楚可见。主角说就那辆就向它走，车夫立刻在原地侧身扶辕；木车不跨空间被牵过来。

L05｜10.4–12.9秒｜一边上车，一边错过提醒

镜头：50mm木车踏板到车帘的侧向跟拍，沈照月在车窗外同轴并行。

动作与因果：主角扶车框踩一阶宽踏板进车厢，普通体力无需飞跃。沈照月跟上举出较小白璃拜帖，刚开始报白璃尊者的拜帖；青色会盟请柬仍由玄衡拿在后方，两个物件不混。车夫仍在驾驶位旁牵缰，车没发动。

L06｜12.9–15秒｜先躲进车里再说

镜头：65mm车帘内外双层近景，固定镜头保留木板座位与外面玄衡肩部。

动作与因果：主角打断说上上车再说，转身坐进车厢，手先抓住帘边；沈照月话没报完，停在车窗旁继续等他说完。玄衡走近车窗准备提出御剑护送，接第5段。瘦搬货弟子已经离踏板，车夫尚未上座。
