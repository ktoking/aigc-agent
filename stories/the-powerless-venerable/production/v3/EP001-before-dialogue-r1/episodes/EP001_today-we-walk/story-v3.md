# 《本座今日不飞》EP001 小说式剧本 v3

我穿越了，成了修仙界的镇宗大尊者。

石台外是云海，背后站着拱手低头的掌门。我在袖子里并起两根手指，捏得指节发紧，掌心连一点光都没有。

可我半点仙力都没有，技能全灰！

“尊者，今日赴天衡宗会盟，诸位尊者已在等候。请登云。”

陆青抬手，一团云贴到台沿外。他侧身相请，我往下看了一眼，鞋尖停住了。

怎么办？我连飞都不会！

咒语？先试一个！

妈咪贝贝烘——飞！

我憋住气，手指向上一勾。鞋底仍旧牢牢贴着石头。

我把中指和无名指压向掌心，照着印象里的吐丝手势弹了两下手腕。

蛛丝……走你！

袖子晃了一下，什么也没出来。我又勾勾手指，盯住腰间的剑。

御剑，起！起啊！

剑没动。我赶紧把手缩回去，下巴还得端着。

【陆青视角｜内心】

尊者怎么不动？云备错了？

陆青把云往台边挪近一点，抬起的胳膊仍不敢收。他额角的汗已经滑下来，尊者依旧站着。他垂眼看见自己的练功剑，后背又紧了一层。

早课偷懒……尊者看出来了？

【玄衡视角｜内心】

礼单到底漏了什么？

玄衡翻过青色请柬，把封口又按了一遍。前面的尊者没开口，他也不敢催。

【谢无咎视角】

“弟、弟子知错。”陆青忽然把身子躬得更低。

我半转过头。他额角冒着汗，眼睛压根不敢看我。

啊？他怎么先自首了？

我张了张嘴，瞥向身后的石廊。

“本、本座今日……步行，亲近门人。”

说到步行，我已经先往实地迈出一步。

“收剑，随行。”玄衡立刻让自己的剑归鞘。陆青撤了云，沈照月合起原定空行路线，三个人又整整齐齐跟了上来。

我走出短廊，看见下山长阶，刚抬起的脚又停住。

“山门多远？”

“三千级石阶。”

我把脚收回平台。“备……备车。”

沈照月抬手，把本来候在平台旁的云辇引过来。我看了看悬空的车底。

“要、要有轮子的。”

她望向几步外的卸粮处：“运粮车？”

“就那辆。”

壮实车夫牵着马让开车门，搬货弟子把最后一袋粮搬走。我绕过云辇，扶着车框踏进木车厢。沈照月跟到车窗旁，拿起一张比会盟请柬小的拜帖。

“白璃尊者的拜帖——”

“上、上车再说。”我赶紧坐下。

玄衡还在窗外拱手：“弟子御剑护送。”

“诸位……先回。”

车夫听见这话，以为自己也被遣走，捧起马鞭从驾驶位旁退开。“尊者，谁来驾车？”

“你留下。”

他看看我，又看看玄衡，膝盖一弯。“弟子才炼气——”

“会驾车，便好。”

车夫赶紧上了前座，玄衡侧身给他让路。陆青还想跟，被沈照月挡住。我终于放下帘，掌心在衣料上擦了擦。

先下山，找个没人的地方苟住。

“白璃尊者来邀您同行。”沈照月把刚才没说完的提醒接上。

我又挑开帘。“能、能绕过去么？”

“下山只有这一道门。”车夫抬鞭指向前方。

门外云层一分，白璃落到车前。白发与黑红衣带垂下来，她朝我行了平辈礼。

“谢道友，三年未见。”

她右手的弯刀横到身前。“请赐一招。”

我瞄了一眼刀尖，手已经抓紧坐垫。

我连闪避都没学，拿什么接啊！

“今、今日……不动兵器。”

我抬起空左掌，想让她先停一停。

“好，那便徒手。”

她真把刀收了。

“退后，别误伤！”玄衡护着陆青和两个外门弟子往路边退。车夫跳下驾驶位，也跟着跑了，沈照月牵住马头，车前顷刻空出一片地方。

我伸向前座的手刚抬起来，白璃已经望过来。我只好慢慢收回袖子。

司机别走！我说的是今天不打啊！

白璃往前踏了半步，立掌待招。她掌侧的气流掀起车帘，我攥着帘角，手心又全是汗。
