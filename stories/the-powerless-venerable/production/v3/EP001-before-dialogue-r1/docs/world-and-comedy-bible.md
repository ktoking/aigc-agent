# 世界与喜剧机制 v3

## 一句话

全宗最不能露怯的人，恰好连飞都不会；他每一次普通的自救，都被当成尊者的新安排认真执行。

## 原主与穿越者

原主谢无咎曾真正保住青玄宗与山门，有可靠的旧战绩和弟子的亲历佐证。穿越者只占有外貌、身份和随身物，没有技能记忆；普通人的体力与痛感，不自动继承护体。穿越原因暂不解释，也不靠“能力其实还在”收尾。

他想先安全离开宗门，再找机会了解规则或求助。若被认作占据尊者身体的外来魂魄，可能被拘魂审问；原主旧敌也会趁机动手。门人并非天然恶人，他要避免的是被识为陌生冒用者。

## 各宗顶层

各个正式门派都有镇宗尊者，地位高于日常掌门，彼此平辈往来。有各自术法、旧伤、边界和立场。谢无咎原主不是天下唯一最强。白璃会约切磋、会观察异常，不能一见零气息就跪认他更高一境。

顶层敛息常见，形貌不变与旧声望足以先让人按本人处理；不能无限免检。邀请出招、御剑示范、私人约定、需要灵力的法器都是可验证风险。

## 每场喜剧的因果

真实危险／普通需求→男主做具体选择→他人结合旧声望和眼前信息理解→采取实际行动→暂时过关但下一件事更难。

三层人有区别：陆青最爱跟着学；沈照月按行程和实务理解，能提醒；玄衡讲安全与礼仪；白璃以同辈判断。按用户2026-11-17更新，猜测也可直接使用明确角色心声：陆青怕偷懒练剑被发现，玄衡怕礼单疏漏。两人都只依据主角停步沉默，不知道他的无效试招。不能让男主听到这些心声，不为每个镜头配深不可测赞词。

男主有普通人的眼力、算账、沟通和分工能力。允许这些真帮助人，从而赢得新的真实信任；不能突然背出失传功法或总靠巧合让敌人自己死。

## 第一集具体兑现

他避开登云，也真的弄到一辆会有人驾驶的凡人马车；把车夫留下的理由是对方真的会驾车。下属不是不会解绳子的傻子。最后“今日不动兵器”被白璃理解为徒手约招，由实际语境产生误会，给下一集明确难题。

## 可持续升级

私下练也始终没有灵力；名望越高、来求指点的人越多。他应学会借助专业人员、发问、把任务交给能做的人，同时承担安排的结果。沈照月可以逐步察觉他不同，但何时知道真相留待后续用户选定，不预设她早已知情包庇。


## v3表演与会盟背景

主角现代思维与修仙人的真实语汇分开：脑内可以技能全灰、咒语与吐丝等乱试，外部则卡词学本座、亲近门人。原主确实强大，旁人因旧声望先把停顿理解为审视自己；这只延迟暴露，不保证永远有效。

EP001的具体出行目标为赴天衡宗会盟，诸宗尊者候行程；没有设定大会已开场或具体倒计时。白璃在青玄宗门前邀同行，先请求与三年未见的旧识切磋。男主没有完成赴会，先想离开山门找无人处躲着。玄衡持青色大会请柬，沈照月持白璃小拜帖，两者不能合并。
