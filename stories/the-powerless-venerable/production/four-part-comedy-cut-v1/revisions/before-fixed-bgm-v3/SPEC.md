# 四段修仙喜剧合辑

本次按用户提供的四个视频顺序合并，原始1280×720，输出30fps，H.264与AAC。时间线62.5秒，片头2.1秒，剧情60.4秒。四段均保留完整对白，补齐到15.1秒，画面边界以0.2秒叠化连接，音频按完整对白拼接。

片头为纯黑底白字，单行“Create By 西瓜终结者AIGC”。字体清晰克制，0.3秒渐显，正片0.3秒从黑显现，结尾0.3秒渐隐。字幕按实际语音时间重排，中文专名按剧本校正，白字、薄深色描边，位于底部安全区。

配乐改为用户指定的Groovy Hammond。配乐轨仅覆盖正片2.1–62.5秒，两端0.3秒淡入淡出，跟随对白动态让位。片头黑屏期间静音，正片渐隐至黑后结束。

不添加贴纸、表情包、满屏跳字、额外镜头或加速对白。
