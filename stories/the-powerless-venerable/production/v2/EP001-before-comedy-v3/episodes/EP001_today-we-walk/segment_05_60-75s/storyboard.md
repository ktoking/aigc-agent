# 第05段《会赶车就行》节拍设计

目标变化：主角坐木车内，玄衡提出护送，车夫站驾驶座旁，陆青准备跟，沈照月仍等着补报拜帖。 → 主角支开御剑随从、留下真正会赶车的人，车夫坐驾驶位；掌门让路、陆青没能随行，主角得到真实出行办法。

L01｜0–3秒｜护送又加人

镜头：50mm车窗与玄衡同框。

动作与因果：玄衡向车窗拱手，准备抬手出剑护送；主角从车帘缝看到他要一路跟着，马上开口请众人回去。

L02｜3–6秒｜留下谁

镜头：35mm马车侧面中景，清楚显示驾驶位。

动作与因果：掌门停手退开。车夫听见你们回去，以为自己也在被遣回之列，把马鞭两手呈起、退出驾驶位，才紧张问谁来驾车；不是忘了自己会赶车。瘦搬货弟子把缰绳交回车夫后退到路侧。

L03｜6–9秒｜凡人技能派上用场

镜头：65mm车夫与车帘内手指近景。

动作与因果：主角只指车夫，说你。车夫先看自己再看几位高阶修士，身形僵一下；指人不发光，不误剪成主角施法。

L04｜9–12秒｜修为不够的误解

镜头：50mm车夫半身，机位平视。

动作与因果：车夫边自报才炼气边准备下拜，主角在帘内抬普通手势示意停；没有人真把车夫当能御剑的高手。

L05｜12–15秒｜专业的人上驾驶位

镜头：35mm侧向跟车夫跨上车辕。

动作与因果：主角说会赶车就行，车夫赶紧上驾驶位握缰，玄衡认真让路；陆青刚伸脚想跟，被沈照月轻挡住。地位反差用行动落地，不加夸赞段子。

## 对白

0.1–2.2秒｜玄衡：“弟子御剑护送。”
2.5–4.1秒｜谢无咎：“你们回去。”
4.6–6.8秒｜车夫：“尊者，谁来驾车？”
7.2–8.0秒｜谢无咎：“你。”
9.2–11.8秒｜车夫：“弟子才炼气——”
12.1–14.4秒｜谢无咎：“会赶车就行。”
