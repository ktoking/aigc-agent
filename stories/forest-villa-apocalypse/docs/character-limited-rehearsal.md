# 角色限知演绎

## 用户确认的方法

一个子agent代表一个人物，不是一位分集编剧。角色agent使用Terra，首次创建不继承主对话，不读取剧本文件。全剧框架只归导演持有。

## 信息边界

每位角色只接收自身经历、已确认的关系、当下所在位置、可见事件、实际听见的对白。不能传递其他人的内心独白、未在场的诊断、敌人的真实计划、下一幕结局或剧本目标。

导演可以设计外部事件，但不告诉角色该说什么或该得出哪个未来结论。不同地点必须说明通过监控、对讲机还是当面获得信息；没有传递就不知道。

## 逐轮流程

1. 导演给角色当前可感知信息，不给完整剧情。
2. 角色返回已知事实、当下目的、一句自然回应、一个动作或神情、尚未知事项。
3. 导演检查事实与人设；出错只纠正已知事实，不直接灌入标准答案。对话先不设字数上限，不为了15秒省掉主语或动词。
4. 将实际说出口的对白传给当场能听见的角色。角色内心目的不传递。
5. 各角色回应后，导演选择可拍动作并安排镜头。若段落超时，删减重复事件或调整镜头，不将对白压成术语。
6. 成稿记录对白来源与必要编辑。导演改写或合并过的句子须注明，不能称为角色原话。

## 人设

- 许砚：沉着、实干、能听取意见，不斗嘴，不做危险逞强；知道什么和能保证什么要区分。
- 叶凝霜：高冷成熟、独立有判断，不撒娇或求夸；关心同伴不等于失去冷静。
- 白棠：有观察能力，汇报看到的具体对象，不念“后方武器未放”式简报，不替观众问无意义问题。
- 沈知夏：温和专业，先问症状再判断，不凭职业获得全知能力；新异能效果必须实际验证。
