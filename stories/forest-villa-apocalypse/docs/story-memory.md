# 林中别墅末日堡垒 故事记忆

- 一句话卖点：丧尸爆发后，许砚不挤避难所，搬回林中别墅，把一栋旧度假屋改成末日堡垒。

## 世界观

丧尸爆发已经开始。城市出现咬伤、高烧、抽搐、攻击事件，官方暂称为新型狂犬病变种，但传播速度远超普通疾病。城里超市、医院、避难点迅速失控。许砚没有重生，也没有完整预言未来，他只是根据近期异常和爆发当天的情况，判断城市很快会乱，立刻搬回之前买下的林中别墅。

林中别墅位于山路尽头，是许砚之前买下的现代三层平层山林别墅。它有高围墙、电动铁门、车库/仓储入口、地下室、露台阳台、旧井、后院、林地、溪水、屋顶太阳能板、备用储能电池和独立发电机房。它不是天然安全屋，必须通过囤货、加固、发电、净水、监控和种养殖逐步升级。

电力设定：末世爆发后市电已经中断。白天主要靠屋顶太阳能板给屋内备用储能电池充电；夜晚或阴天靠柴油发电机补电。储能电池能维持基础照明、监控、水泵和冰箱一段时间，但不能长期支撑全屋高负载。柴油、发电机噪音和电池电量会成为长期压力点。

## 核心故事

许砚带白棠回到林中别墅，第一阶段先做三件事：把物资搬进来、把门窗封起来、让水电能独立运转。每日 0 点，一个末日生存抽卡系统出现，每天只能抽一次。抽卡不能直接解决所有问题，只能补关键短板，让他们多一个当天能执行的任务。

抽卡方向固定为四类：

1. 生活物资卡：净水滤芯、蔬菜种子、盐、药品、消毒片、太阳能配件、蓄电池线缆、柴油稳定剂。特点是马上用得上，但数量不大。
2. 建设材料卡：给围网、木板、钉子、水管、门锁、砌块、砂浆、防潮膜、感应器等有限实体材料。系统不代替施工，搬运、测量、砌筑、接线和安装都由人物完成。
3. 生存技能/图纸卡：净水系统图纸、鸡鸭棚结构图、简易温室图纸、陷阱图纸、发电机维护手册。特点是给方法，不直接变出成品。
4. 稀有生态卡：土壤改良剂、耐寒种子包、鸡鸭幼崽兑换券、小型鱼苗、菌菇包。它们只能改善生产条件，作物和牲畜仍要经历种植、饲养、病害和收获周期。

稀有设备补充规则：抽卡可以极低概率给一台现实存在的生产或运输设备，例如农业无人机、微耕机、孵化箱，但必须同时写清能源、载重、噪声、耗材、维护和使用范围。设备只能降低某一项劳动或运输风险，不能自动生产、无限运输或取代人物决策。

后续山里几户人家陆续出现，有人求救，有人合作，有人抢物资。主线仍以种地流 / 建家流为主，不把别墅发展成大收容所。许砚原则上不放外人进主楼，只在外门、车库隔离区或围墙外交换物资：水、药、柴油、种子、鸡鸭幼崽、工具和情报。丧尸也不是白给：前期被灯光和声音吸引，中期学会踩点、绕后、断电，后期出现能指挥低级丧尸的高级感染体。
