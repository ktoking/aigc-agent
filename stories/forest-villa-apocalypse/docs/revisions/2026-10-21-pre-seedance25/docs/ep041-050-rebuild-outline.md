# EP041–EP050 重构母版

版本：2026-10-08-human-dialogue。由用户要求重做EP041以后的全部剧本。本文件替代此前EP041–EP050的冲突大纲与凑字数规则。

## 本轮方向
EP041验证救援可能性，EP042付出体力完成救援，EP043冬狼杀害清醒的炎魁、当夜准备装甲，EP044团队守门并结束冬狼围困。EP045–EP050不重复开战，按保住生产、改善越冬、可靠供暖、备件育苗、维修贸易、收获晚饭推进。

## 格式与节奏
EP041保持4×15秒、每段4镜；EP042–EP050保持已有2×30秒、每段8镜，共22段160镜。剧本时长不是API能力证明。所有导演稿纯文本，prompt.md逐字同步。不恢复已删除的旧15秒目录。

30秒段至少8个实际镜头，15秒段默认4镜头。镜头数不等于台词句数或参考图数；每镜推进动作、观察、反应或结果，不靠重复正脸口播、空推拉和静态摆姿填时长。镜长按表演分配，不机械平分秒数。

新增镜头示例：EP042第一段依次为呼唤、举火、挡火、制止贸然靠近、医生观察、冰障融化、转移位置、炎魁转身。观众能看见下一步为何发生，不靠角色讲解八遍。施工、修理和收获段同样补上亲手操作与实际使用结果。

## 废止的写法
- 废止每段7000字、每镜头3–4个子节拍、每子节拍必须有对白的凑数要求。
- 不规定每句必须十几个字；完整意思、听见后的回应与可表演性优先。
- 不让“火力”“下盘”“接它”“印在松”这种孤立词组代替观众能懂的动作。
- 不用每集坏一件、每人报一句代替故事。日常戏必须有选择、劳动结果和关系变化。
- 不拿角色的未来知识写现在的台词，不把推断说成已确认事实。

## 角色知识边界
- 许砚只能根据队友报告、监控与实物检查下判断；不能识别未见过的陌生人背景。
- 白棠懂已实践的种养和库存，主动提出生产安排；不会永远等男主布置。
- 沈知夏先检查再给结论；EP041只证明残留可以处理，EP042成功不能推广成所有印记或疾病必治。
- 叶凝霜知道自己的受控经历、炎魁和冬狼，但不知道别墅所有设备原理；不改变高冷克制的人设。
- 来客只报告自己的泵房、盐、坏水泵和待验材料，不替主角总结全球局势。
