# EP044 台词通读：这扇门，你进不来

版本：2026-10-21-seedance25-story-rebuild。先只读角色对白，检查是否像一轮交流。

承接：冬狼昨夜射杀刚清醒的炎魁。许砚已给唯一外骨骼充电，炮台弹药所剩无几，主路仍被塌方阻断。

## Segment 1：最后一轮子弹

情境：同一黎明，门外进攻与门内抵抗交叉剪辑

1. 冬狼：枪声少了，继续撞门！
2. 许砚：白棠，帮我看着门外。
3. 白棠：锁扣歪了，你别松手。
4. 白棠（画外音）：还剩一轮，现在打吗？
5. 许砚：打，把门口的人逼开！
6. 白棠（画外音）：打完了，炮台没弹了。
7. 沈知夏（画外音）：护臂过热了，不能再硬撑。
8. 冬狼：别撞了，我要里面的人活着。

## Segment 2：这次不再跟他走

情境：承接炮台停止开火，仍是同一黎明

1. 冬狼：叶凝霜，出来跟我走。
2. 叶凝霜：炎魁已经清醒了，你还杀他。
3. 冬狼（画外音）：松开！你敢对我动手？
4. 叶凝霜：你再也控制不了我了。
5. 白棠（画外音）：冬狼倒下了，他们在撤。
6. 许砚：别追了，先确认他们走远。
7. 叶凝霜：他们没进来吧？
8. 许砚：没有。走，咱们回屋。
