# EP044 故事板总览

冬狼昨夜射杀刚清醒的炎魁。许砚已给唯一外骨骼充电，炮台弹药所剩无几，主路仍被塌方阻断。

人物目标：守住外门；叶凝霜要亲手结束冬狼的控制。

转折：炮台打空使冬狼认为近身控制许砚的机会到了；他走近门口，进入叶凝霜能控制的近处雪地。

回报：门没有打开，冬狼死在墙外；叶凝霜被自己选择的同伴接住。
