# EP046 故事板总览

新膜补住温室，卷材还有有限余量；叶凝霜只能做轻劳动，炮台仍然没有弹药。

人物目标：把鸡棚和鱼池一起保住，让家里恢复正常出产。

转折：材料不够各搭一座大暖棚，三人按原设施分配剩膜；叶凝霜第一次主动接手一项日常。

回报：鱼还在游，鸡重新喝上水，白棠从窝里拿出一枚蛋。
