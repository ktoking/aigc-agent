# EP045 故事板总览

冬狼已死。门锁变形、炮台空仓；农业区未遭敌袭，旧棚膜因风雪松脱。

人物目标：把家恢复到能安心过夜、下一茬菜还能活的状态。

转折：修好门后才看见温室漏雪；临时保苗撑到零点，抽到保温膜也仍需亲手补棚。

回报：两个人把同一扇门修牢，也把两盘活苗保住。
