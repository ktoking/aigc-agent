# EP008-EP020 剧情骨架

## 核心推进

- 建家种田是主线：鱼池、菜地、鸡鸭、储能和高墙必须持续产生收益，也持续消耗水、电、饲料和人力。
- 抽卡只给工具、种子和有限方法；白棠的生产型异能也不能凭空制造物资。
- 人类强盗线从沈知夏的逃亡自然引出；罗彪一伙是未感染的地痞恶势力，会踩点、欺骗、断电和利用丧尸。
- 丧尸线继续保留普通型、攀爬型和后续策略型感染体，不让人类敌人永久取代末日威胁。

## 三种异能固定边界

- 白棠“生长时序加速”：每日一次，一个有限培育单元，资源和母体消耗不减。
- 沈知夏“生命修复”：每日一次较重外伤或两次轻伤，使用后低血糖、发热、乏力；不能净化感染或再生。
- 罗彪“体能爆发”：最多三分钟，体能提高一倍；之后整整一天严重乏力。
