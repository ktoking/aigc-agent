## 已发生的事

以现有 EP039、EP040 新版 director-promt.txt 为准。冬狼的两辆炮车和装甲车已经失去行动能力。大型变异体已被击杀，海克斯装备池开放但未抽取。炎魁被冬狼控制，正在融化围墙外的冰层；主体围墙仍完整。凝霜认出他，希望救他。时间仍为同日，不能无解释跳到第二天。原有反应堆供电正常，唯一炮台仍在二楼阳台；弹药消耗但不能凭空断电。凝霜疲劳，不能立即恢复到连续施放大型冰瀑的状态。

## 人物演绎

- 许砚：沉着、决策具体，听完信息再决定；不斗嘴、不打岔、不冒险让敌人主动控制自己。关心同伴用行动和合理安排，不用哄小孩式台词。
- 叶凝霜：高冷、成熟、有主见。明确表达判断与能力限制，不撒娇，不求表扬，不反复问有没有成功；保留对被控制者的共情，但不是软弱或突然失控。疲惫由呼吸、手和姿态表现。
- 白棠：聪明、执行利落、有真实情绪；负责监控和生产，问题来自当前决策需要，不替观众问所有名词，不重复所有人已经听见的信息。
- 沈知夏：成熟温和的医生，专业且独立。区分观察、推测、已验证效果；不保证没试过的疗法，不把治疗扩大为远程控制他人。
- 冬狼：用明确的要求威胁人，控制欲强；不用连续谜语狠话，不凭空知道主角内部计划。
- 炎魁：受控时没有自主违抗；清醒由明确的外力解除烙印造成，不能靠喊名字或意志突然挣脱。恢复后疲惫、能自己做选择。暂无数字人ID，优先背影或单独画外音，不能借用主角脸。

## 四集剧情

### EP041：先弄清怎么救

1. 冬狼停止片刻火攻，通过扩音器要求交出凝霜。许砚拒绝；凝霜明确炎魁身不由己，先争取停止伤害他。
2. 沈知夏检查凝霜已破碎烙印处，在得到同意后清除残留，凝霜原有局部刺痛消失。只是验证残留可处理，不保证完整烙印也同样容易；凝霜不再次被远程夺回控制。
3. 冬狼再次命令炎魁前进烧门，炎魁被迫靠近围墙。许砚提出先阻止火焰、保住院门，再让医生接触救治；不让许砚独身出院献身，不重复造装备。
4. 白棠确认周围敌人仍在远处；凝霜休息后只用小范围冰层暂时限制炎魁动作，火焰减弱。许砚在门内准备救援，医生待命。结束在炎魁暂时被制住、还没有解除烙印。

### EP042：把人救回来

1. 承接受困炎魁，许砚在掩护下经外门短距离将人移进门内隔离救治位，白棠确认人已进门后关门。用清晰空间转换，不一镜包含所有人。不能穿火、无防护触摸燃烧物，也不描绘现实战术教程。
2. 沈知夏先检查烙印，在接触状态下尝试解除完整印记；说明比残留更难。炎魁只是动作减弱仍未清醒，不能先说感恩台词。
3. 经过持续接触，完整烙印消退，火焰熄灭；炎魁恢复自主。医生检查反应，凝霜听到后确认他可以不再服从。救援明确成功，但医生疲劳。
4. 炎魁自愿提供冬狼还会逼其他人攻击的情报，许砚不要求刚获救者立即上阵。夜色渐深，白棠看到外围火力持续；手机显示当天抽卡即将刷新但不提前抽。交代围困持续到午夜。

### EP043：抽卡破局，结束冬狼

1. 午夜更新，装备池三选一：短时防护外骨骼、便携观察设备、未知卡；保留一次刷新权但许砚主动不用，按眼前防护需要选外骨骼。不重新首次解锁三选一，不免费多抽。
2. 手机投影明确展示外骨骼轮廓，再在工作台落成；人工穿戴、测试一次，系统或医生说明高强度只能维持十五分钟、过热需停机。反应堆供电不代表外骨骼永不热停。用四镜清楚做完，不瞬间全身凭空长甲。
3. 冬狼看到炎魁恢复自主，企图在外门夺回控制。必须先由远景显示他带人靠近，不瞬移入院。许砚穿甲在门内挡住一次攻击，凝霜小范围限制冬狼行动；炮台只牵制远处攻击者，不扫射混在一起的己方。
4. 冬狼仍企图攻击凝霜；许砚阻止，凝霜直接冰封冬狼结束战斗，无血腥特写。冬狼明确死亡，不再逃走拖一集；其他人丢下武器逃离。外骨骼热警报响，许砚停机，代价兑现。不给谜语遗言，不凭冬狼死就假定所有烙印自动消失。

### EP044：赢来的东西用来建家

1. 次日天亮确认攻击者离开，检查墙外冰层损伤和库存。回收敌车的普通金属板与可检查的工具，不默认敌方弹药匹配炮台，更不把战利品全都变成即插即用。
2. 白棠与许砚用既有工业金属打印仓制造防护板连接件，人工修复院门的外侧保护层，并给外骨骼设置通风停放位。保留建造过程，不能一镜整座别墅升级；电力正常，设备需要维护。
3. 炎魁完成必要救治后主动选择去南边堡垒，先通过电台确认对方愿意接应再给粮食和路线。不强迫刚被救者报恩、不说“别再被控制第二次”。不新增永久住户，不再次举办凝霜入伙仪式。
4. 回到温室或菜地，白棠检查覆盖和作物，凝霜参与日常但保留冷静气质。以修好家、恢复生产的可见成果收束；新探索线索可为无人机看到的废弃温室，明确是无人机画面，不写“雪线在动”的谜语。只提出后续探索，不又立刻尸潮压顶。

## 制作约束

每集4段，每段4镜，每镜有台词；15秒以内、16:9、480p、有声音；导演提示词纯文本，保留景别、构图、运镜手法、画面内容、说话者绑定和台词。镜头不标固定秒数。对白不硬凑80–90字，优先完整意思与人物回应，动作段为动作留时间。一个镜头一个主要动作，避免一镜多次交谈与反应。

每段最多3个已绑定数字人。可以有非露脸敌方远景，但不得增加清晰人脸；每镜尽量一人开口。人物与背景参考合计至多9项，背景参考只列用途、不编造已生成路径；资产图未核验要明确待补。默认不使用人物首尾帧。

原版“没电了、储能见底、主动让冬狼烙印、凝霜再次入伙”等不得沿用。不能因人设高冷就使用省略主语的战术黑话，不能每句都是命令。其他集不在本次覆盖范围。
