# 林中别墅末日堡垒 工作流

## 剧集生成前

1. 阅读本故事 `AGENTS.md` 和 `docs/production-rules.md`。
2. 检查上一集 `continuity.md`，确认物资、伤口、门窗、灯光和丧尸位置。
3. 确认本集只做一个核心生存任务。
4. 确认数字人资产 ID 是否需要写入 `api-request.md`。

## 资产生成前

- 人物优先使用火山 Ark 数字人资产 ID。
- 场景资产优先补：林中别墅外观、室内仓储、地下室、发电机棚、山路、后院菜地。
- 首尾帧必须让观众看懂空间变化，不只做氛围图。

## 视频提交前

- `director-promt.txt` 只写导演指令，不写本地路径、不写密钥、不写 signed URL。
- `api-request.md` 写清模型、数字人资产 ID、首尾帧、场景图和参考图上传计划。
- 默认使用低成本模型草稿，动作逻辑稳定后再定稿。
