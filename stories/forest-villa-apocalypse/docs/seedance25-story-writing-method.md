# EP044 起的创作与提示词方法

资料核查日期：2026-10-21；分段更新日期：2026-11-12。当前EP044–EP050共七集、二十八个15秒段，每段四镜。没有提交新视频；旧30秒稿保存在docs/revisions/2026-11-12-pre-15s，原output不移动。

## 现稿问题与这次改法

过去把字数、镜头数、台词数、参考图数量当成质量目标，导致一段里反复出现同一条禁令、同一个状态、同一种慢推。EP044–EP045还曾出现导演稿和prompt副本对白不一致。检查数字可以发现漏项，但不能证明一场戏好看。

先写事件和一轮连续对话，再分配到每集四段、每段四个具体镜头。每镜保留一句具名发声；手部、设备、动作镜头由同一场人物画外音承接。跨段问答直接续接，不重新报幕或重念上一句。不设7000字最低线，也不把精简说明解释成模型官方字数上限。

每集只抓一个观众期待：守住家、修回家、恢复产出、互相照顾、投资下一茬、交易成交、坐下吃饭。角色需要的东西先让观众看见，做成后的好处也要当集兑现。结尾可以是一个想做的新项目或回头订单，不必每次又出故障、又来敌人。

## 本剧可反复使用的三种故事结构

### 防守与异能

已建防线承压 → 主角看见具体短板 → 既有装备或队友能力争取窗口 → 对手因自身目标犯错 → 一次可读的反击 → 消耗与人物关系留下结果。

EP044：炮台空仓、装甲过热不是凭空削弱；冬狼想控制活人，因此选择靠近。叶凝霜在近处反击，结束控制关系。胜利以后先把人扶回去，战斗消耗进入下集。

### 抽卡与建造

先看见生活需要 → 三张卡形成真实取舍 → 只领取一张 → 投影占位、实体材料出现 → 人手安装 → 眼前生活因此好一点 → 留下有限余量或下一次需求。

EP045为保住已经种下的苗选膜；EP048在即时罐头和育苗灯之间选未来产出。不能每次都抽到无限粮仓，不能让机器替人决定或自动施工。

### 生产与交易

自用先留足 → 多出一小份 → 对方先提出需要与筹码 → 实物验货 → 双方人工交接 → 服务带来下一单 → 收成进自家餐桌。

EP049以菜蛋换盐，不拿药品当永远可消耗的货币。EP050修泵换打印料，原料再支持建造，逐步形成能持续的交换方式。

## 台词怎样写

每句先回答三个问题：此刻对谁说；刚看见或听见了什么；想让对方接下来怎么做或理解什么。先连读整集16镜对白，再检查每个15秒段的四句是否自然接续；完整句优先，不压成暗号。

许砚临战直接作决定，生活里能承认顾虑也会照顾人；白棠可以心疼苗、分配库存、打趣，不固定替观众问蠢问题；知夏有自己的专业意见，照顾人时会坚持；叶凝霜清冷少言，以主动接手家务和真实选择表现融入。不同人物不轮流报同一种状态。

对比示例为本轮原创：

- 旧式暗号：电不能断，监控都靠它。改为对当前事实的回应：灯还亮着，怎么地板越来越冷？
- 无缘由指令：先有棚，才养得住。改为指向眼前行动：上边留着，不能全封死。
- 抽象承诺：先活下去才有资格救人。改为真正接住同伴：没有。走，咱们回屋。
- 机械汇报：本次修复完成。改为人物关系中的回应：先修好这一台，再叫师傅。

这些是表达思路，不是每集都要重复使用的口头禅。

## Seedance 2.5 导演稿

用本故事`templates/seedance25-director-template.txt`。现行目录为segment_01_00-15s至segment_04_45-60s，每段四镜，不固定每镜秒数。每镜包含景别、构图、运镜手法、画面内容、表演、人物与参考绑定、说话者绑定和声音。换场用明确硬切，施工或升温等待用时间省略，不靠画面融化或持续口播挤占动作。

对白只在本镜出现一次，写成`角色台词（情绪）：{完整内容}`；动作说明不再次复述对白，不添加字幕。声音中的动作音用尖括号，角色画外音明确来自哪个现场或对讲。系统规则和人物内心留在剧本说明，不把看不见的因果直接塞给视频模型。

数字人置于导演稿顶部，具名、绑定资产、写全服装；镜头内最多两张清晰脸，单段最多三名清晰角色。无人物场景资产只锁建筑或道具。当前脚本支持精确全输入编号，本轮采用全输入顺序1–9，身份声明与场景声明分区展示，避免两个编号体系混用。

九项是本项目这批交接规划，不是Seedance 2.5官方输入上限。官方当前允许更多参考素材，但这不构成多放图就更好的保证。本轮没有擅自增加人物和素材数量。
