# FVA_EVOLVED_DRAW_SYSTEM_001

- 名称：进化后的每日抽卡界面。
- 触发：EP027，许砚击杀高阶飞行变异体后，由系统提示抽卡异能升级。
- 载体：仍使用许砚原有手机，不凭空出现新的终端或全息控制台。
- 规则：每日零点恢复一次领取资格，出现三张候选卡，只能领取一张；以EP027现行导演稿的“没有刷新”为准，没有刷新功能。资格可以当日稍后使用，不得同日重复领取。
- 五类用途：`建造`、`生产`、`防御`、`探索`、`???（未知）`。
- 未知卡：选择前只显示 `???` 和模糊图标，不显示完整效果、稀有度保证或风险说明。
- 视觉：三张横向卡片，没有可用刷新按钮；界面克制、清楚，不做大型游戏 HUD。
- 限制：不能锁卡、指定类别、反悔或额外领取；选择后另外两张立即失效，未选物资不实体化。
