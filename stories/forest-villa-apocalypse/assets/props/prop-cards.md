# 林中别墅末日堡垒 道具卡

## 核心道具

### 抽卡手机

- 功能：每日 0 点抽卡。
- 表现：手机屏幕上出现简洁卡牌界面，不能满屏游戏化。
- 第一集卡牌：蓝色物资卡，柴油发电机维修包。
- 参考图：`references/draw-card-phone-interface.png`

### 柴油发电机

- 功能：别墅初期供电核心。
- 风险：噪音会吸引丧尸，故障会导致冰箱、监控、水泵停摆。
- 第一集重点：维修包让观众理解抽卡不是装饰，而是能救命。
- 参考图：`references/diesel-generator.png`

### 柴油发电机维修包

- 功能：EP001 抽卡产物，说明抽卡会给“刚好有用”的生存物资。
- 内容：火花塞、滤芯、皮带、机油、维修手册、小工具盒。
- 表现：蓝色物资卡对应的实体维修包，放在木桌或发电机旁，真实可用，不要科幻宝箱。
- 参考图：`references/generator-repair-kit.png`

### 物资墙

- 内容：大米、面粉、罐头、压缩饼干、桶装水、药箱、柴油桶。
- 表现：要清楚、可数、真实，不要虚化成氛围背景。
- 参考图：`references/supply-wall.png`

### 别墅平面图

- 功能：展示许砚的加固计划。
- 内容：一楼封门窗、二楼观察点、地下室储粮、后院种菜、发电机棚隔音。
- 参考图：`references/villa-defense-map.png`
