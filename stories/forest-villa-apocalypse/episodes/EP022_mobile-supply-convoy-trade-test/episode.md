# EP022：移动补给车队的火力试探

EP021 结束后，许砚三人已经确认低频声源盒不是偶然出现。无人机沿着撤离路线继续搜索，在雨后的山路上拍到三辆没有固定营地的补给车：两辆大型货运卡车和一辆支援面包车，车旁有四名安保人员，队伍始终保持移动。

车队负责人顾承泽很快主动接入频道，先解释自己用声源盒把丧尸引到别墅和山谷堡垒附近，是为了测试两边的火力、尸群反应和山路是否安全；谈到最后，他才自报“顾总”，拿汽油提出换粮。顾承泽的异能能让主货车已有的油路、电路、照明和通信持续工作，他不怕自己把燃料用空，因此可以把车队搜来的汽油、滤芯和维修件拿出来报价。车上的人仍然要吃饭，车体、轮胎和维修件也不会自动恢复。

顾承泽没有一开口就说自己缺粮，而是先解释测试原因，再自报“顾总”，直接提出用汽油换粮；交易过程中，他又送出大批丧尸进山、A市失守和变异体增多的情报，并把自己包装成穿梭山林做交换的商人。许砚手里只有自产大米、蔬菜和鸡蛋的可交换余量。三人不让车队进院，也不交出种子、完整路线和全部防线数据，而是用重载无人机在废弃木材装卸场完成第一次远程交易。

这一集的爽点不是把新势力打跑，而是看见一个油嘴滑舌的商人先解释测试，再自报“顾总”拿汽油换粮，又用A市失守和变异体情报让交易显得合理。顾承泽完成交易后离开，表面带走声源盒，随后在车内判断别墅火力很强，提出下一次进院当面验货和交换。三人得到实用物资，也接受了一个看似合理的交易提议；顾承泽的真实目的暂不揭露，留到后续反转。

| Segment | 核心任务 |
| --- | --- |
| 01 | 无人机发现移动补给车队，并确认他们用低频声源盒把丧尸引到别墅和堡垒附近 |
| 02 | 顾承泽主动接通频道，解释测试火力，最后自报“顾总”提出汽油换粮 |
| 03 | 双方在废弃木材装卸场用无人机完成第一次远程交换，顾承泽送出A市失守和变异体情报，并介绍自己是跑山商人 |
| 04 | 别墅三人核对情报后，镜头切到顾承泽驾驶室；他判断门外交易不够方便，提出下一次进院当面验货和交换物资 |
