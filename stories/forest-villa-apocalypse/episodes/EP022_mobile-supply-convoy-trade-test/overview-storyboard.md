# EP022 总览分镜

| 段落 | 事件 | 结果 |
| --- | --- | --- |
| 01 | 无人机拍到三辆移动补给车和车边的低频声源盒 | 许砚确认车队故意把尸群引向别墅与山谷堡垒，先跟踪不射击 |
| 02 | 车队负责人顾承泽主动接入频道，解释测试火力，最后自报“顾总”提出汽油换粮 | 他先稳住对话，再把真正交易目的说清楚，车内油电用不完成为他的交换底气 |
| 03 | 车队在废弃木材装卸场停靠，顾承泽送出丧尸进山、A市失守和变异体增多的情报，并介绍自己是跑山商人 | 情报让假交易看起来合理，别墅用有限收成换汽油和维修物资，双方不见面 |
| 04 | 别墅三人核对情报后，镜头切到顾承泽驾驶室 | 顾承泽判断门外交易不够方便，提出下一次进院当面验货和交换物资；真实目的留作后续悬念 |

## 四拍卡

1. 许砚的目标是确认新车队是否与声源盒有关；障碍是车队一直移动且安保人员保持警戒；他选择让无人机跟踪而不是开炮；结果是拍到声源盒和丧尸转向的对应关系。
2. 顾承泽的目标是让车队安全通过山区并把粮食换回来，最终还想抢走别墅物资；障碍是他不知道别墅和堡垒的真实火力；他选择先解释测试、送出外部情报、自报“顾总”提出汽油换粮，再把假交易变成侦察手段；结果是放弃硬闯，改用智取。
3. 许砚的目标是换到长期有用的维修物资；障碍是不能让外人进院，也不能消耗种子和全部粮食；他选择先核对情报，再用无人机远程交换；结果是双方第一次完成不见面的交易。
4. 三人的目标是保住防线信息；障碍是顾承泽已经观察过炮台射界和堡垒火力，还把交易伪装成情报交换；他们选择限制交易品类、路线和后续测试；结果是得到滤芯和零件，却不知道顾承泽已经把他们列为掠夺目标。
