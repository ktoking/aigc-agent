# EP025：金属打印仓，第一件造货舱

前山道路被彻底炸塌后，车辆已经无法抵达别墅，往后的远程交换越来越依赖重载无人机。许砚再次抽中二阶科技设备卡：工业级金属打印仓。设备没有凭空落地，手机先在车库投出一台 1:1 蓝色轮廓，三人共同避开医疗区、车行通道和逃生门，确定维修位置后才让设备沿投影从底座向上实体化。

打印仓不是无限制造机。它要单独接电、闭式冷却和排风，初始只有五公斤启动合金，也只开放十二张基础图纸。沈知夏完成喷头精密校准后，三人必须在有限材料里选第一件成品。

炮台零件很重要，但唯一车路已经断掉。许砚决定先打印一只模块化密封无人机货舱，让今后的粮食、药品和维修件不再暴露在雨里。打印持续数小时，首件成品安装到重载无人机腹部，通过四十公斤静载测试。

第一件成品兑现后，沈知夏拿出炮台上次维修时换下来的磨损转向齿轮。打印仓成功扫描尺寸并保存成维修图纸，但启动合金已经用完。EP026 将从搜集废金属、筛选高强合金和给唯一一座炮台准备维修件继续。

| Segment | 核心任务 |
| --- | --- |
| 01 | 手机投出打印仓 1:1 放置轮廓，三人避开医疗区和车道，确认位置后让设备实体化 |
| 02 | 三人接入独立供电、冷却和排风，沈知夏校准喷头，同时明确五公斤合金限制 |
| 03 | 在十二张基础图纸里取舍，最终选择模块化密封无人机货舱 |
| 04 | 数小时后货舱打印完成并通过四十公斤测试，结尾扫描磨损炮台齿轮并保存维修图纸 |

## 本集冲突

- 机会：打印仓让别墅第一次拥有自主制造金属零件的能力。
- 限制：只有五公斤启动合金、十二张基础图纸，复杂件失败会浪费原料。
- 选择：暂缓炮台维修件，优先解决断路后的无人机密封运输。
- 爽点：第一只银灰色密封货舱从打印仓完成，重载无人机通过四十公斤测试。
- 后续风险：逆向扫描只能记录结构，不能凭空补充材料；后续仍需搜集废金属与高强合金原料。
