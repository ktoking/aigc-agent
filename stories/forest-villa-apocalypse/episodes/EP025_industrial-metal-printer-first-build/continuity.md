# EP025 连续性

- 承接 EP024：前山唯一车行道路已经被整面塌方永久截断，普通感染体无法上山，柴油皮卡和顾承泽车队也无法驶近别墅；对外运输以重载无人机和山下中转点为主。
- 人物锁：本集只有许砚、白棠、沈知夏三名常驻角色；不生成安装工、路人、系统人物或角色分身。
- 新设备 `FVA_INDUSTRIAL_METAL_PRINTER_001` 不得突然出现。Segment01 固定过程为“手机投出 1:1 轮廓 → 三人移动投影并确认检修空间 → 许砚确认放置 → 设备从底座向上实体化”。
- 放置锁：打印仓位于车库独立维修区，右侧靠近水电接口，左侧保留医疗区和担架通道，正面保留检修空间；不得堵住车库门、逃生门或皮卡位置。
- 外观锁：单台炭黑与深灰封闭柜体，琥珀色观察窗、蓝色窄状态灯、侧面原料舱、下部回收抽屉和减震底座；四段保持同一型号、比例和方向。
- 安装锁：独立供电支路、两根闭式冷却软管、一根短距排风管和一个废料回收箱。微型反应堆只提供电力，不与打印仓合并，也不展示内部。
- 原料锁：启动合金总量为五公斤，画面使用一个小黑箱里的五根银灰合金锭表达有限库存；本集打印货舱消耗首批材料，不能在结尾恢复满箱。
- 图纸锁：初始只开放十二张基础图纸。打印仓不理解人物口头需求，也不能凭空设计复杂设备。
- 首件成品 `FVA_MODULAR_DRONE_CARGO_POD_001` 为单只银灰色密封货舱，固定在现有重载农业无人机腹部；四十公斤是本集静载测试，不代表新增无限载重。
- 时间锁：Segment03 启动打印后经历数小时，Segment04 才出成品；不在几秒内瞬间完成大型金属件。
- 结构扫描锁：Segment04 使用炮台上次维修时换下来的单个磨损转向齿轮总成。正在阳台值守的唯一一座炮台保持完整；本集只保存维修图纸，不立即打印备件。
- 下一集问题：启动合金已经用完，普通废钢、铝材和适合炮台齿轮的高强合金来源将成为新的外出或交易动力。
