# EP025 总览分镜

| Segment | 画面推进 | 叙事作用 |
| --- | --- | --- |
| 01 | 抽卡后手机投出 1:1 打印仓轮廓；三人移动投影、避开医疗区和车道，确认后设备沿轮廓实体化 | 让新设备有清楚的放置因果，不凭空跳出 |
| 02 | 独立支路、闭式冷却、排风依次接好；沈知夏校准喷头，五公斤启动合金摆到台面 | 把“有设备”变成“付出安装和耗材成本才能用” |
| 03 | 十二张基础图纸只允许先做一件；三人放弃炮台件，选择密封无人机货舱并启动打印 | 用现实运输缺口推动选择，不轮流念功能 |
| 04 | 数小时后银灰货舱出仓、装机并通过四十公斤测试；扫描旧炮台转向齿轮并保存图纸 | 兑现生产爽点，并把下一集推进到高强合金与防线备件 |

## 四拍卡

1. 三人想获得新的生产设备；阻碍是打印仓体积很大且不能堵住医疗与逃生动线；他们先移动 1:1 投影再确认放置；可见变化是设备在选定位置实体化。
2. 三人想让打印仓开机；阻碍是高功率、冷却和喷头偏差；他们完成独立接线并由沈知夏校准；可见变化是设备通过空载自检，但五公斤材料成为硬限制。
3. 三人想利用第一批合金解决最急的问题；阻碍是十二张图纸只能先选一件；他们根据道路已断的现实选择密封货舱；可见变化是合金进入料舱、打印正式开始。
4. 三人想验证第一件成品是否可靠；阻碍是打印耗时且成品仍需装配测试；货舱通过四十公斤静载后，他们把旧炮台齿轮放入扫描托盘；可见变化是打印仓保存了维修图纸，但缺少继续制造的高强合金。
