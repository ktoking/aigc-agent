# EP047 台词通读：有电，为什么屋里还冷

版本：2026-11-12-four-15s。四段连续读，不在段头重念上一句。

## Segment 1：灯亮着，地板却冷了

1. 白棠（画外音）：灯还亮着，怎么地板越来越冷？
2. 许砚：不是停电，我去看看供暖那一路。
3. 沈知夏：我跟你去，别又一个人熬一夜。
4. 许砚（画外音）：这头是热的，进屋那根却不热。

## Segment 2：最后一个备用件

1. 沈知夏：先别拆，我试着让它动一次。
2. 沈知夏（画外音）：这只卡死了，得换个好的。
3. 许砚：还剩一个，换完就没备件了。
4. 沈知夏：先换。总不能让大家冻着等。

## Segment 3：热水终于进屋了

1. 许砚：坏的先留着，回头看看能修什么。
2. 沈知夏：现在开吧，我看着有没有异常。
3. 许砚（画外音）：这根也热了，问问屋里怎么样。
4. 白棠（画外音）：地上暖了，被子我先不拆了。

## Segment 4：带着终端回屋看

1. 沈知夏：再看一会儿，别刚回去又冷了。
2. 许砚：带着终端回屋看，你手都冻凉了。
3. 许砚（画外音）：明天先补备件，不能再只剩一个。
4. 沈知夏：明天再忙。今晚先把觉睡够。
