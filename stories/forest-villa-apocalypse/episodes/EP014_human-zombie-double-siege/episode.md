# EP014：异形变异体团灭强盗，三人借电网一箭反杀

EP013结尾出现的异形外形变异感染体先偷袭并杀死罗彪与残余强盗，随后沿别墅高墙巡猎下一个目标。许砚、白棠和沈知夏立刻关闭不必要的灯光与噪声，在监控里观察它的路径。三人利用围墙电网、有限警报和弓弩设下诱导点：白棠和沈知夏把它引到墙边，许砚主动现身激怒它，变异体攀墙时被电网定住，许砚一箭命中头部将其击杀。最后，变异体头部被固定在墙外警示架上，普通丧尸开始避开这段围墙。

| Segment | 核心任务 |
| --- | --- |
| 01 | 变异体团灭罗彪，别墅立刻静默 |
| 02 | 静默观察，变异体沿墙巡猎 |
| 03 | 三人设下电网诱导点 |
| 04 | 电网定住变异体，许砚一箭终结 |
