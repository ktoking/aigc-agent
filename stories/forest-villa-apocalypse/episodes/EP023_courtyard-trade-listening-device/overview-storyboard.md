# EP023 总览分镜

| Segment | 画面推进 | 叙事作用 |
| --- | --- | --- |
| 01 | 顾承泽带货进前院，沈知夏验抗生素并把窃听器放入屏蔽盒，许砚点破后送客 | 让第一次面对面交易立刻出现信任裂缝 |
| 02 | 顾承泽上车收起笑容，车内重新评估；别墅三人复盘并恢复值守 | 交易结束后双方都没有放松，危险转为判断 |
| 03 | 顾承泽通讯器试探“硬闯”，许砚用六座炮台反问 | 用具体火力数字完成一次不动手的交锋 |
| 04 | 顾承泽提出情报换粮，三人交换眼神后答应 | 合作开始，但把信任和利益明确分开 |

## 四拍卡

1. 顾承泽的目标是把货送进前院并观察别墅内部秩序；阻碍是许砚只开放有限区域；他的选择是用客气和窃听器同时做交易与侦察；可见变化是窃听器被沈知夏发现。
2. 沈知夏的目标是确认抗生素能否使用并保护医疗区；阻碍是窃听器藏在包装夹层；她选择不当众争执，先封存设备；可见变化是顾承泽知道自己已经露馅。
3. 许砚的目标是把交易结束在冲突之前；阻碍是顾承泽用通讯器试探火力；他选择报出六座炮台的实际威慑；可见变化是顾承泽停止挑衅。
4. 三人的目标是换到持续有用的情报和粮食；阻碍是顾承泽不值得完全信任；他们选择先做小额、可追溯的合作；可见变化是双方从试探转入有条件交易。
