# EP023：进院交易，窃听器露馅

EP022 之后，顾承泽提出下次进院当面验货。许砚没有把人放进主楼，只开放前院交易区，规定货物在门口清点，车队不能越过第二道安全线。顾承泽带来抗生素、滤芯和车辆维修件，礼貌得像一个真正来做生意的商人。

沈知夏验货时，从抗生素包装的夹层里捏出一枚米粒大小的窃听器。她没有当场拆穿，只把设备放进屏蔽盒，继续用平静语气确认药品效期。顾承泽看见了，却只僵了一瞬；许砚随后点破这件事，没有争吵，也没有把交易升级成冲突，只告诉他下次想听什么可以直接问。

顾承泽离开后重新评估三人的反应。通讯器里，他先拿“硬闯”试探许砚的底线，许砚用六座炮台反问，逼他把火力差距算清楚。顾承泽没有继续挑衅，第二天主动提出用情报换粮食。许砚征询沈知夏的判断后答应合作，但双方只是建立交易关系，信任仍然没有建立。

| Segment | 核心任务 |
| --- | --- |
| 01 | 顾承泽进入前院完成第一次当面交易，沈知夏从抗生素包装中发现窃听器，许砚平静点破 |
| 02 | 顾承泽离开别墅后收起商人笑容，三人复盘他的行为，双方都恢复夜间值守 |
| 03 | 顾承泽用通讯器试探别墅火力，许砚用六座炮台反问，顾承泽算清差距后暂时收声 |
| 04 | 顾承泽主动提出情报换粮，三人确认后答应第一次合作，双方各自准备下一次交易 |

## 本集冲突

- 表面冲突：第一次进院交易中，顾承泽把窃听器藏进药品包装，沈知夏发现后没有立即翻脸。
- 人物冲突：顾承泽用客气和试探确认三人的底线，许砚用具体火力数字把话题拉回现实。
- 结果：交易关系成立，信任没有成立；顾承泽知道别墅不是普通幸存者据点，许砚也知道对方会把生意和侦察混在一起。
- 成本：别墅第一次开放前院交易区，暴露了进出流程；后续必须重新检查货物、限制进院范围，并调整对讲机和监控权限。
