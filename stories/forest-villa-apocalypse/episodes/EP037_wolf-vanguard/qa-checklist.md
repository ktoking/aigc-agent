# EP037 质检清单

## 剧集连续性
- [x] 紧接EP036结尾叶凝霜走出别墅面对先遣队，同一傍晚连续
- [x] 叶凝霜已是别墅的人，冬狼一方都知道她反了，不再伪装身份
- [x] 炮台EP035已解冻，本集只作后备威慑未开火，逻辑连贯
- [x] 主力从"三天后"提前到"明早就到"，只剩一天，衔接EP038连夜备战

## 角色一致性
- [x] 叶凝霜：以别墅成员身份直接出手，冰墙挡弹、冻地封足、冰锥缴械、冰封埋葬，一人立威
- [x] 许砚：控制室看完全程，确认她站队后拍板连夜布防
- [x] 白棠：控制室看监控，回放录音锁定主力提前
- [x] 沈知夏：控制室待命支援、参与布防
- [x] 先遣队统一白色防寒服，与EP033/034一致

## 剧情逻辑
- [x] 叶凝霜先劝退、对方先开枪才动手，出手有理
- [x] 一人镇压先遣队，展现冰系战力，不靠别墅火力开挂
- [x] 情报来源：小头目被冻前吼出"主力明早到"，被录音坐实，非巧合
- [x] 信任确立：许砚亲眼见她直接冰封先遣队，确认她站队别墅

## 制作规范
- [x] 每段15秒以内，16:9横屏，480p
- [x] 每段4镜头，每个镜头都有台词（无空镜头）
- [x] 单段台词80字以内（57/39/40/41）
- [x] 叶凝霜台词为冷感女王式：短句宣判、居高临下，无弱势问句、无病句
- [x] 数字人/服装绑定正确，全别墅只有一座炮台，资产参考图不出现人物
- [x] director-promt.txt / prompt.md / storyboard.md 三文件一致
