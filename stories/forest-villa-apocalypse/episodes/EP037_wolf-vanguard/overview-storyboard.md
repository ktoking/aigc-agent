# EP037 总览故事板

## Segment 1｜她让路，对方不肯走

1. 认出叶凝霜：小头目停下脚步，从上到下打量画外叶凝霜，嘴角慢慢扬起，故意提高声音让她听见。
2. 压住第一次怒气：她捏紧手指，再慢慢松开；吸一口气后开口，给对方离开的机会，不释放异能。
3. 继续羞辱：小头目见她没有出手，笑意加重，略向前探身，说完等她反应。
4. 第二次让他停下：她抬眼看向小头目，肩膀绷紧，没有接骂；脚步声在台词后停止。

## Segment 2｜最后一次警告

1. 拿过去羞辱她：他先上前一步再站定开口，故意模仿训斥语气；没有开枪。
2. 说出被控制的事实：她呼吸停了一下，视线短暂垂下，随后抬头直视对方；声音压低但字句清楚。
3. 把痛苦当笑话：他嗤笑着说完，才朝画外手下使眼色；画外传来举枪的衣料摩擦声。
4. 看见枪口后警告：她看见三人抬枪，脸上的犹豫消失，身体保持静止；台词结束后才在指尖出现微弱寒雾。

## Segment 3｜开枪之后，她不再留手

1. 命令开火：小头目先下令，随后枪声响起；半透明冰墙竖起挡弹，表层冰屑擦过叶凝霜脸侧，无伤口特写。
2. 忍耐结束：她闭了一下眼再睁开，抬手压向雪地；冰面向前扩散，两名手下的滑雪板被锁死。小头目转身欲跑，脚下也开始结冰。动作全程无对白。
3. 慌忙改口：他发现迈不开步，停止挣扎转头求停，笑容彻底消失，讲话急促但不连喊。
4. 回应刚才的枪声：她看一眼冰墙上的弹痕再看向小头目，说完才攥紧手，冰层迅速攀上三人身体，尚未封住小头目头部。

## Segment 4｜刚才骂得最狠的人，先求饶

1. 先低头求饶：他被封到颈部以下，急忙看向叶凝霜，眼睛里只剩慌乱，称呼由冰女改成名字。
2. 回到最初的选择：她没有被求饶打断，视线停在他脸上，语气比前面更低、更稳。
3. 搬出最后的威胁：他见求饶无用，急忙喊出冬狼抵达的时间，声音由软变硬；门外既有监控收音保存这句话。
4. 结束战斗：叶凝霜说完才收拢手掌；远景中冰壳向内压紧，喊声戛然而止，碎冰与雪雾遮住一切身体细节。雪雾散后只留三处沉入积雪的冰封残块，明确三人死亡，不留活捉或解冻生还暗示。最后停在她放下仍微颤的手，不切控制室、不加许砚呼叫。
