# EP044 台词通读：这扇门，你进不来

版本：2026-11-12-four-15s。四段连续读，不在段头重念上一句。

## Segment 1：门锁快撑不住了

1. 冬狼：枪声少了，继续撞门！
2. 许砚：白棠，帮我看着门外。
3. 白棠：锁扣歪了，你别松手。
4. 白棠（画外音）：还剩一轮，现在打吗？

## Segment 2：最后一轮打完了

1. 许砚：打，把门口的人逼开！
2. 白棠（画外音）：打完了，炮台没弹了。
3. 沈知夏（画外音）：护臂过热了，不能再硬撑。
4. 冬狼：别撞了，我要里面的人活着。

## Segment 3：她不再听他的命令

1. 冬狼：叶凝霜，出来跟我走。
2. 叶凝霜：炎魁已经清醒了，你还杀他。
3. 冬狼（画外音）：松开！你敢对我动手？
4. 叶凝霜：你再也控制不了我了。

## Segment 4：守住门，也接住她

1. 白棠（画外音）：冬狼倒下了，他们在撤。
2. 许砚：别追了，先确认他们走远。
3. 叶凝霜：他们没进来吧？
4. 许砚：没有。走，咱们回屋。
