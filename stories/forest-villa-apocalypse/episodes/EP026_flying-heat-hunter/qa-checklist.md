# EP026 QA Checklist

- [x] 一集 60 秒，四段，每段 15 秒以内。
- [x] 每段严格四镜头，保留景别、构图、运镜手法、画面内容和说话者绑定。
- [x] 不使用无人机诱敌；飞行变异体主动追踪反应堆散热。
- [x] 变异体有急停、滚转、贴屋脊、声波扰动和主动破坏，战斗不写成站桩挨打。
- [x] 别墅只有一座自动炮台，所有新增资产和提示词均禁止复制。
- [x] 白棠通过画面证据发现固定爬升路线，许砚的预瞄命令原因清楚。
- [x] 沈知夏只恢复既有雷达同步，不制造零件或远程控制炮台。
- [x] 异能枪只发出决定性一枪，能量耗尽后消散。
- [x] 高速感由翼面动作、雨水尾涡、屋顶积水和真实运动模糊共同表现，不用瞬移或整团模糊。
- [x] 声波特效使用空气折射、雨滴外推、玻璃共振和监控雪花，不使用发光魔法圈。
- [x] 终结特效只有一发蓝白脉冲，以低压通道、环形水幕和环境震动表现冲击，不做火球或爆炸碎尸。
- [x] 飞行变异体当集死亡，坠落围墙外，不进入院内或主楼。
- [x] 两块太阳能板、一只摄像头和一段护栏受损，胜利有代价。
- [x] 五张新增资产均为无人、真人实景、1600x900 横屏。
- [ ] 视频提交前逐段 dry-run，核对数字人顺序、参考图数量和“唯一一座炮台”负面约束。
- [ ] 正式视频按 Segment01 到 Segment04 串行生成并逐段检查。
