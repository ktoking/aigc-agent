# EP049 台词通读：这一筐菜，不只换一包盐

版本：2026-11-12-four-15s。四段连续读，不在段头重念上一句。

## Segment 1：这一筐菜换一包盐

1. 白棠：咱们吃的留好了，这点可以换。
2. 泵房住户（画外音）：就这一包，没开过封。
3. 许砚：这筐菜、两枚蛋，换你这包盐。
4. 泵房住户（画外音）：成，家里好几天没见着青菜了。

## Segment 2：货换完了，还有台坏泵

1. 白棠（画外音）：蛋在上边，拿的时候托住底。
2. 白棠：行，这几天做饭不用省着撒盐了。
3. 泵房住户（画外音）：还有个坏水泵，你们能帮忙看看吗？
4. 许砚：先放那儿，我看过再给你准话。

## Segment 3：维修能不能换原料

1. 许砚：支架歪了，里面还得查。
2. 白棠：真修好了，能不能换点打印料？
3. 许砚：你那边有这种机器用的料吗？
4. 泵房住户（画外音）：仓库里有几桶，我先把照片发你。

## Segment 4：先修好这一台

1. 许砚：明天带来看看，能用咱们再谈。
2. 白棠：许师傅，修理铺这就开张了？
3. 许砚：先修好这一台，再叫师傅。
4. 泵房住户（画外音）：那我明天再来，辛苦了。
