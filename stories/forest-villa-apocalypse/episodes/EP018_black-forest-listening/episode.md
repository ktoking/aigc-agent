# EP018：监听到山对面的异能堡垒

夜里，门柱对讲机突然串进陌生基地的防御频道。许砚三人不开口，只把炮台长焦转向声音方向，第一次看见山谷另一端的大型多人堡垒。对方火力和异能都强得多，却因为基地大、灯多、人多，持续把尸潮和大型变异体引到墙下。女首领陆青岚在五米内操控钢板、弹箱和防线物件，勉强带队守住一波进攻；战后她得知南区哨岗失守、食物见底，只能组织敢死队外出找粮。

| Segment | 核心任务 |
| --- | --- |
| 01 | 对讲机自动串台，许砚确认山里还有人并决定隐藏 |
| 02 | 炮台长焦观察大堡垒，看见对方异能和重火力迎战大型变异体 |
| 03 | 视角进入山谷基地，陆青岚布置防线、物资与击退路线 |
| 04 | 尸潮暂退，南区失守和缺粮迫使陆青岚准备敢死队 |
