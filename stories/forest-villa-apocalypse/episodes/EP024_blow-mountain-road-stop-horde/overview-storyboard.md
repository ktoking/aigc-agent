# EP024 总览分镜

| Segment | 画面推进 | 叙事作用 |
| --- | --- | --- |
| 01 | 高能爆破箱刚抽出来，炮台便发现尸群已经进山；许砚当场决定用无人机送往狭口 | 把抽卡和危险压在同一段，前五秒直接起冲突 |
| 02 | 无人机吊放密封箱，尸群进入狭口，三人确认后引爆整面前山 | 十五秒内完成部署与爆破，兑现本集最大动作爽点 |
| 03 | 无人机观察塌方下方，感染体反复攀爬失败；返航画面暴露别墅过于显眼 | 先兑现防守成功，再自然引出新的暴露问题 |
| 04 | 白棠直接催熟门外既有树带，许砚放飞无人机从山下与两侧绕行验证 | 外圈巡航完全找不到别墅，直接兑现隐蔽堡垒爽点 |

## 四拍卡

1. 三人想利用当天抽卡补防线；阻碍是尸群已经上山；他们选择立刻启用高能爆破箱；可见变化是无人机带箱起飞。
2. 三人想在尸群到达别墅前封路；阻碍是爆破会切断己方车行通道；他们确认路上无人后仍选择引爆；可见变化是整面前山掩埋道路。
3. 三人想确认塌方是否真的有效；阻碍是感染体仍在下方聚集；无人机持续观察并确认它们爬不上碎石陡坡；可见变化是危险被挡住，却暴露别墅太显眼。
4. 三人想隐藏别墅轮廓；白棠直接催熟门外既有树带，许砚立即用无人机绕山验证；可见变化是正面和两侧都只剩树林，完全找不到别墅。
