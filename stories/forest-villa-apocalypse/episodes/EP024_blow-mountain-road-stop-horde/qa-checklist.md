# EP024 质检清单

- [ ] 16:9 横屏、4 段、每段 15 秒以内、每段固定 4 镜头。
- [ ] Segment01 已完成抽卡和发现尸群；Segment02 已完成布置和炸山，不再拖到 Segment04 才爆破。
- [ ] 每个镜头包含景别、构图、运镜手法、画面内容、说话者绑定与自然口语台词。
- [ ] 别墅背后完整大山，正面只有一条盘山路，不生成第二条道路或另一栋别墅。
- [ ] 整面前山从上到下滑落，巨量山石掩埋数百米道路；不是只断一小截路面。
- [ ] 爆破地点远离别墅；主楼、围墙、电网、农业区、能源棚和背后主山保持完整。
- [ ] 不展示爆破模块内部、精确装药、钻孔或可复刻施工步骤。
- [ ] 尸群只做远距轮廓，无真人感染体近景、无血腥和断肢内脏。
- [ ] Segment03 明确普通感染体无法攀上松散陡坡，同时通过无人机画面发现别墅过于显眼。
- [ ] 白棠只加速门外原本存在的六至八棵年轻常绿树，不凭空造林，不让树穿过建筑和道路。
- [ ] 加速前后使用同一机位、同一栋别墅、同一道路和同一组树；只改变树高、树冠和遮挡程度。
- [ ] 无人机从山下、左侧和右侧绕行时只能看到连续树林，别墅、屋顶、太阳能板、围墙、电网和大门均不可见。
- [ ] Segment04 直接完成催熟、无人机起飞、绕行验证和确认隐藏，不插入补水、施肥、把脉、休息或菜地安排。
- [ ] 三名数字人身份、发型和固定服装正确，别墅与院内没有额外人物或重复分身。
- [ ] 四段视频如需提交，严格按 Segment01 至 Segment04 串行；上一段未通过人物、服装、动作、地形、口型和音频检查，不提交下一段。
