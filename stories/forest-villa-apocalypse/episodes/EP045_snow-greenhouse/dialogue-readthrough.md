# EP045 台词通读：仗打完了，家得修回来

版本：2026-11-12-four-15s。四段连续读，不在段头重念上一句。

## Segment 1：先让门能锁住

1. 白棠（画外音）：锁扣都歪了，这门得先修。
2. 许砚：工具给我，别再用手顶了。
3. 白棠（画外音）：新的好了，螺丝也找齐了。
4. 许砚：推一下试试。行，锁住了。

## Segment 2：把两盘苗救回来

1. 白棠（画外音）：坏了，这两盘菜还在淋雪。
2. 白棠：根还好，先搬到屋里。
3. 许砚：我先夹住，今晚别再进雪。
4. 白棠：棚还漏着，催大了也得冻坏。

## Segment 3：这次选保温膜

1. 许砚：保温膜、灯，还有一张未知。
2. 白棠：选膜吧，我还想吃自己种的菜。
3. 许砚（画外音）：就它了。明早一起把棚补上。
4. 白棠（画外音）：够补漏的那面，别一下用光了。

## Segment 4：把漏风那面补好

1. 许砚：你那头拉平，我这边压着。
2. 白棠：扣好了，你可以松手了。
3. 许砚：不灌风了，把那盘苗拿回来。
4. 白棠：先好好活着，收菜还等着你们呢。
