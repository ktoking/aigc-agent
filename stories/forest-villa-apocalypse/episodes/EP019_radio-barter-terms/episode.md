# EP019：粮食换火力，第一次隔空合作

承接 EP018，山谷堡垒的粮食见底，陆青岚只能派小队去旧粮仓碰碰运气。小队刚离开，短波里就传来变异体袭击的求救声。许砚听清对方缺的是粮，自己缺的是能守住别墅的枪械，于是主动接入频道，提出用自产粮食换异能生成的临时重火力。

双方不报坐标、不见面，只用重载无人机完成第一次交换。无人机故意绕过山脊和林线，却在途中发现大批变异体正向山谷堡垒聚集。粮食和武器各自到手后，许砚把三把临时异能枪械分布到别墅三处火力位；陆青岚也确认了尸群动向。两个基地从此建立有限的战略合作：许砚方供给食物，山谷堡垒提供有限火力与外部情报。

| Segment | 核心任务 |
| --- | --- |
| 01 | 山谷堡垒断粮出队，变异体袭击迫使陆青岚收缩 |

| 03 | 无人机绕路运粮，并侦察到变异体集结 |
| 04 | 异能枪械抵达别墅，双方建立有限战略合作 |
