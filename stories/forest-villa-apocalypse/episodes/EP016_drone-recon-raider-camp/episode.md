# EP016：梅雨断电，抽到微型反应堆

梅雨连下数日，太阳能无法补足储能消耗，柴油只够再撑两晚。许砚抽到一台密封式微型核能发电模块，三人将它安置在远离主楼的独立能源棚，接入既有冷却水、储能和发电机切换线路。沈知夏的异能第一次延伸到精密设备校准，让沉睡的控制模块通过首次自检。

这不是一座可拆解、可复制的核设施，而是不可打开的成套密封发电模块。它只解除梅雨季的基础供电危机，仍依赖冷却水、滤芯、独立线路、周期检查和三人的维护。

| Segment | 核心任务 |
| --- | --- |
| 01 | 梅雨耗尽储能，抽到微型核能发电模块 |
| 02 | 模块进入远离主楼的独立能源棚 |
| 03 | 接入冷却与储能，知夏完成首次精密校准 |
| 04 | 稳定供电上线，新的维护缺口出现 |
