# EP005 QA Checklist

- [ ] 是否先抽到无人机，再由电台紧急求救说清丧尸进山、山路不通和村里缺物资。
- [ ] 无人机是否为现实重载农业运输设备，不是军用武器或科幻飞船。
- [ ] 是否明确最大载重 35 公斤、两组电池各有任务、山区信号盲区和噪声风险。
- [ ] 交换是否付出十公斤大米、两袋盐和一瓶消毒液，不是免费获得鸡鸭。
- [ ] 是否获得一公两母鸡、一公一母鸭，数量和笼子保持一致。
- [ ] 白天是否固定为六只可见个体，多数缩在背阴处低活动。
- [ ] 夜晚是否明确为十八只从林中出现并在岔路聚集，而不是无来源地瞬间变成尸潮。
- [ ] 是否把“白天低活动、夜间聚群”写成当前观察倾向，而不是绝对安全定律。
- [ ] 丧尸是否会因近距离旋翼声抬头和移动，但不会跳起抓到高空无人机。
- [ ] 外来幸存者是否只用远景、背影或手部，不出现未经锁定的清晰正脸。
- [ ] 四段是否都为真人写实 `16:9`，每段最多四个连续镜头。
- [ ] 结尾是否明确十八只丧尸聚群后沿别墅方向上行，并触发关灯、停发电机。
