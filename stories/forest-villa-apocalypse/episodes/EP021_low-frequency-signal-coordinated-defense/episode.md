# EP021：两座堡垒第一次协同开火

EP020 结尾，别墅监控在林线捕捉到一个没有身份标记的移动红点。许砚没有把它当成普通丧尸，而是回放声音和路线，发现红点其实是沿山路依次亮起的低频声源标记。丧尸会在声音响起后改变方向，像被人牵着走。

许砚通过短波联系陆青岚，确认山谷堡垒南坡也出现了三个相同信号。别墅这边先守自己的围墙：许砚控制自动炮台压住远处目标，白棠和沈知夏用交易得来的临时异能枪处理靠近墙根的丧尸；山谷堡垒只在远处开火带过，双方不暴露坐标，也不派人进入黑林追击。

这一集的爽点不是“开枪就赢”，而是让观众看见别墅现有防线怎样配合：自动炮台先压远处，异能枪补掉靠墙目标，高墙和电网把最后一道线守住；但炮台会耗弹，异能枪的蓝光也会变暗。尸群暂时退回林线后，返航无人机带回一枚声源盒，沈知夏确认它被人为改装过。陆青岚也找到一枚，说明有人正在拿尸群测试两座基地的防线。

| Segment | 核心任务 |
| --- | --- |
| 01 | 许砚三人从监控红点和脉冲声音中确认有人在用声源引导丧尸 |
| 02 | 陆青岚确认堡垒南坡也被同一批声源覆盖，两边约定先关灯、守门、无人机查路 |
| 03 | 别墅阻击丧尸：许砚控制自动炮台，白棠和沈知夏用异能枪补杀靠墙目标；堡垒只作远处炮声背景 |
| 04 | 火力暂时止住尸群，弹药和储能被消耗；声源盒显示人为改装，幕后对手正式出现 |
