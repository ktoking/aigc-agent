# EP050 台词通读：这一顿，是我们自己挣的

版本：2026-11-12-four-15s。四段连续读，不在段头重念上一句。

## Segment 1：旧水泵重新转起来

1. 许砚：里面没坏，换这个支架就行。
2. 白棠（画外音）：真转起来了，这回能交货了。
3. 许砚：再试一会儿，别拿回去又停。
4. 白棠（画外音）：今天催这一盘，别的让它慢慢长。

## Segment 2：留一把，晚上煮面

1. 白棠：好了，再长就老了。
2. 许砚（画外音）：今晚能吃上了，留一把煮面吧。
3. 白棠：早留好了，咱们自己得先吃。
4. 许砚（画外音）：我去交货，回来就吃饭。

## Segment 3：先验结果，再交货

1. 许砚（画外音）：试过了，水流稳，拿回去能用。
2. 许砚（画外音）：这袋料试过了，咱们就这么换。
3. 泵房住户（画外音）：下批菜苗，也能给我们留一点吗？
4. 许砚：等苗长稳了，我再联系你。

## Segment 4：这顿饭，坐下来吃

1. 白棠（画外音）：面好了，谁再忙就自己吃凉的。
2. 沈知夏：都坐下，今天别站着吃了。
3. 叶凝霜：这菜，比罐头好吃。
4. 许砚：那就多种一点，往后常吃。
