# EP046 台词通读：今天终于又有蛋了

版本：2026-11-12-four-15s。四段连续读，不在段头重念上一句。

## Segment 1：水口冻住了

1. 白棠（画外音）：水口冻住了，难怪它们不喝。
2. 许砚：先换温水，这个拿进屋化开。
3. 白棠（画外音）：鱼池也结冰了，这边得留一截。
4. 叶凝霜：这边交给我，你们去铺另一头。

## Segment 2：剩膜两边都用上

1. 许砚：上边留着，不能全封死。
2. 白棠：这边不吹了，剩下的给鱼池。
3. 许砚：别压住水管，这里还得循环。
4. 白棠（画外音）：还好，还知道来找吃的。

## Segment 3：窝里又有蛋了

1. 叶凝霜：水通了，它们开始喝了。
2. 白棠：有了，今天又下蛋了！
3. 叶凝霜：以后这边我来照看，喂多少？
4. 白棠：照这勺来，吃完了再添。

## Segment 4：巡查拍到一缕烟

1. 白棠（画外音）：今晚加个蛋，谁也别抢。
2. 许砚：你先收好，我巡完就回来。
3. 许砚（画外音）：南边那间泵房，好像有人。
4. 许砚：先记着，别惊动他们。
