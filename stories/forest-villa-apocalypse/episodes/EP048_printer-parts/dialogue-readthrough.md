# EP048 台词通读：这次抽卡，给下个月用

版本：2026-11-12-four-15s。四段连续读，不在段头重念上一句。

## Segment 1：先备能打印的零件

1. 白棠：这个能不能多打两个，省得再等？
2. 许砚：支架能打，里面的电子件做不了。
3. 许砚（画外音）：先备这些，坏了能马上换。
4. 白棠：留点原料吧，后面还得用。

## Segment 2：门加一层，苗也得育

1. 许砚（画外音）：锁已经修好了，再给外面挡一层。
2. 白棠：扶稳了，你装吧。
3. 白棠（画外音）：这里要有盏灯，还能再育一层。
4. 许砚：今天的卡还没抽，正好看看。

## Segment 3：罐头还是育苗灯

1. 许砚：真有育苗灯，也有一箱罐头。
2. 白棠：选灯吧，罐头吃完就没了。
3. 许砚（画外音）：行。下个月这盘菜，就靠它了。
4. 许砚：先装这一层，别一下铺太大。

## Segment 4：灯亮了，门口也来人了

1. 白棠：这一盘先试，长稳了再加。
2. 白棠（画外音）：这回下雪，也有地方育苗了。
3. 泵房住户（画外音）：有人吗？我带了盐，想换点吃的。
4. 许砚：可以，把东西放到门口镜头前。
