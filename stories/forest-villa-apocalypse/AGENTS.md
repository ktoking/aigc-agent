# 林中别墅末日堡垒 故事包说明

## 故事范围

本目录维护《林中别墅末日堡垒》的所有非通用规则。生成剧情、分镜、首尾帧、视频 prompt、角色资产或连续性文件时，必须优先遵循本目录规则。

## 必读顺序

1. `docs/story-memory.md`
2. `docs/production-rules.md`
3. `docs/audience-strategy.md`
4. `docs/season-arc.md`
5. `docs/workflow.md`
6. `assets/` 下角色、场景、道具、风格资产
7. `episodes/` 下上一集内容

## 默认剧集格式

- 一集 60 秒。
- 一集拆成 4 段。
- 每段 15 秒以内。
- 每段必须有 `storyboard.md`、`first-frame.md`、`last-frame.md`、`prompt.md`、`director-promt.txt`。
- `director-promt.txt` 是能直接交给视频 API 的纯文本导演提示词。
- 数字人资产 ID 写在角色卡和 `api-request.md`，不要写成“图片路径”。
- 当前目录例外：EP041 保持四段15秒；EP042–EP050沿用已建立的两段30秒，不恢复已删除的旧分段。剧本分段时长不代表任一视频API必然支持。
- 30秒段至少拆成8个实际镜头，15秒段默认4镜头；逐镜编号，不把几个动作挤在同一个大标题下冒充完整分镜。从EP042起，新写或重写的每个镜头至少有一句实际发声的对白；不能用重复报状态或反复切同一张说话的脸凑镜头。
- 每镜必须有动作进展、观察所得、人物反应或结果兑现；固定机位也要拍到人物、物件或环境的实际变化。运镜不能代替动作。镜长按表演需要分配，不机械平分秒数。
- EP041–EP050的新剧情母版为 `docs/ep041-050-rebuild-outline.md`，逐句通读稿为 `docs/ep041-050-dialogue-readthrough.md`。旧视频不反向覆盖新稿。

## 本剧本核心锁定

- 主角锁：许砚，林中别墅业主，冷静实干，不说谜语，所有判断都要给出具体原因。
- 女主锁：白棠，固定女主之一，年轻利落的建造搭档；先作为民宿员工进入堡垒秩序，擅长记录、调度和种养执行。她服从已确认的安全规则，但会提出具体的资源和操作问题。
- 第二女主锁：沈知夏，县医院急诊医生，成熟冷静的长发御姐；数字人 `asset-20260310030618-88hlb`。她留深栗色微卷长发，穿暗酒红医护工装，与白棠的鼠尾草绿短款工装、轻快执行感明确区分。EP010 被救后觉醒有限治疗异能，并直接接手车库医疗区；她遵守别墅的生存规则，但医疗判断由她独立负责。
- 强盗头目锁：罗彪，末日前盘踞当地的地痞头目，末世后带未感染手下抢村夺物；数字人 `asset-20260310022222-kjz8z`，固定使用 `FVA_RAIDER_LEADER_OUTFIT_001`。
- 服装锁：数字人资产只锁脸，不锁服装。许砚、白棠、沈知夏、罗彪分别固定使用各自 Outfit ID；每个有人物的提示词必须写全基础服装，不得只写“同一套工装”。
- 世界规则锁：丧尸爆发已发生，许砚搬回之前买下的林中别墅，囤货、加固、抽卡、种养殖，逐步建立山林堡垒。
- 系统锁：每日 0 点抽卡 1 次，卡牌以“刚好能解决生存问题”为主，不给无敌爽。
- 科技树锁：EP015 起，许砚累计完成 15 次抽卡后解锁二阶科技卡池。普通卡仍是物资与零件，稀有卡是设备或设计图，SSR 是长期基地核心；任何科技卡都必须有供电、弹药、维护、安装或冷却代价，不能自动把别墅变成无敌堡垒。
- 炮台数量锁：别墅只有一座 `FVA_AUTO_TURRET_001` 自动炮台，固定安装在二楼阳台。任何后续剧本、资产图和视频提示词都不得生成第二座炮台。
- 视觉风格锁：真人短剧质感，林中别墅、货车囤货、发电机、铁门、监控、地下储藏室，画面要清楚可读。
- 常驻人数锁：叶凝霜在EP035获救并被接纳后，常驻者为许砚、白棠、沈知夏、叶凝霜四人；此前沿用各集既定人数。常驻四人不等于每段都要四人出场：每段最多三名清晰人物，每个实际机位最多两张清晰脸。未明确写入镜头的角色不得生成；禁止路人、陌生帮手、背景人影或重复分身。
- 防线空间锁：变异体始终从围墙外发动攻击。涉及电网时，固定动作路径为“墙外冲刺 → 攀住外墙 → 身体进入墙顶电网区 → 被电网短暂定住 → 倒回墙外”；禁止它跳入院内、落到阳台/露台、扑到窗台、贴窗攻击，或绕过围墙直接进入主楼。
- 禁止偏差：不要写重生；不要让男主说“命运”“有人嫌我们死得慢”等谜语台词；不要用大段抽象旁白解释世界观。

## 台词规则

- 台词要像正常人在危机里说话。
- 具体信息由整段对话和画面共同交代，不要求每一句都承担说明任务。
- 同一段台词必须彼此承接：前一句提出问题、情绪或选择，后一句要真正回应，不能三个人轮流汇报状态。
- “每镜至少一句”只保留声画节奏，不是每镜交一条情况汇报。先写这一场人物各自想要什么、怕什么，再把八镜台词当成一轮连续对话通读；相邻两句若删去人物名也听不出回应关系，就重写。
- 允许停顿、迟疑、反问、玩笑、担心和熟人之间的照顾；先写人物当下最自然的反应，再检查观众是否能听懂。
- 不要把“能力每天一次”“设备剩余多少”“下一步做什么”等设定重复念出口，画面已经表达的信息不再用对白复述。
- 男主可以冷静，但不能装神秘。
- 避免“先活下去才有资格救人”“这不是结束，是开始”这类空泛句。
- 动作仍承担主要叙事；从EP042起每镜的一句台词应回应眼前动作、上一句话或人物关系，不复述画面和设备状态。
- 废止“每个子节拍必须说话”“每段必须写满7000字”“所有句子必须切短”的旧写法。完整话、真实回应、动作因果优先。从EP042起是明确例外：每个实际镜头至少一句具名对白；手部、道具或远景镜头可用现场角色画外音，写清声音来源，不给非说话人补口型；台词之间仍可留停顿。
- 先写出角色看见了什么，再写判断；推测要保留“可能”“先检查”等不确定性，不能替角色提前知道剧情。
- 白棠已经成长为能独立安排种养、库存和警戒的搭档，不再固定承担提问；叶凝霜清冷克制，不撒娇耍贫；许砚临战沉着，不打岔；沈知夏给专业意见但不无条件保证。
