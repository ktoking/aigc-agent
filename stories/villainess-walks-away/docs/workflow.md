# 本剧工作流

1. 阅读本剧AGENTS、story-memory、production-rules、season-arc和原始设定。
2. 写小说式正文novel.md，再形成episode.md中的第一人称旁白与角色对白。
3. 逐句检查L01—L06、S01—S06与身份、道具、视角；记录稿件版本。
4. 依homecoming格式写24镜：功能、动作、镜头、台词、声音、结束状态；用户指定四段各30秒，每段十图，目录固定segment_01_00-30s、segment_02_30-60s、segment_03_60-90s、segment_04_90-120s。
5. 用户要求继续制作时，先建立独立人物脸与服装基准，做少量风格样张。当前assets-v1人物参考是本轮生成基准，用户尚未确认选脸。
6. 按实际配音和角色表演校准时间，控制120秒预算；先改分配与停顿，必要压缩台词须作为新稿保存，不截尾字。
7. 按每段上传计划制作首尾帧与参考图，真实文件放本段frames/，登记职责与状态；每段严格10张，按1—10对应director-promt.txt和reference-manifest.json，核对后再提交。
8. 视频生成之后统一配音、音乐与叙事UI合成；需要字幕时另按用户要求添加。
9. 验证图片一致性、动作和口型、音画时长、完整解码与实际播放，再交付成片。当前没有执行这些制作验收。
