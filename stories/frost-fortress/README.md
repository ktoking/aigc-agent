# 《极寒末日，我的房车是移动堡垒》（v2 现实主义版）

- Story ID：`frost-fortress`
- 形式：第一人称静帧叙事，仓库默认剧集格式（60 秒 / 4 段 / 每段 15 秒以内）。
- 阶段：v2 现实主义引擎，EP001—EP012 十二集剧本全部完成，待用户审阅；尚未授权生图、配音或视频。
- 一句话卖点：欠薪的汽修工住在自己收来的二手房车里，全城只有他把寒潮红色预警当真——停暖停电之后，他的车成了街上唯一的暖房，也成了所有人的目标。

## 引擎说明（v2）

- 无重生、无年会、无系统、无异能：一切优势来自职业手艺、住车的现实处境和认真对待预警。
- 生存优先：剧情主轴是生存的算术账（油、电、粮、温度），对抗与智斗从生存资源里长出来。
- 现实主义：欠薪抵货、物业寻租、社区团长、偷油贼、黄牛床位、一氧化碳中毒、安置点封条、转运专列——全部为现实中存在的事物与流程。
- 对标《末日寒潮我有移动堡垒我怕谁》保留：极寒灾种、房车移动堡垒、生存博弈循环；删除（用户指示）：重生、年会、系统面板。差异记录见 [references/benchmark-beatmap-v2.md](references/benchmark-beatmap-v2.md) 修订节。
- 非圣母红线：帮人一律交易——修东西收物资、账本记账；对绝望者指路不给房；善行只给自家账上的人。
