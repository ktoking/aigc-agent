## 一、故事承诺

欠薪三个月的汽修工江彻，把住了三年的二手房车提前做了保温。寒潮造成停暖停电后，车里能睡人、能煮饭，他便成了周围人眼里的物资户。江彻用维修换食物、燃料和落脚地，也不断为离车干活付出库存失守的代价。直到第二波寒潮，他必须在煤老板的供货条件和自己的独立住处之间谈出一条活路。

观众每集能看到一笔具体变化：拿到设备、补回油、收到工费、换到库房，或者失去一批存货。主角的手艺增加议价能力，也使别人找上门；车能移动，固定库房和合作关系却带不走。

## 二、沿用设定与本稿调整

沿用：江彻，28岁机电维修技师；四万八收来的二手依维柯房车；无重生、系统、异能；手账记收支；帮工按约结算；孙广顺的人情互换；多人物各推进一线；车内暖黄、室外青白，真人写实、干净干燥。

- **资产**：存款23000元，卖相机800元，欠薪14000元；EP002抵货12000元，剩余2000元继续追索。相机款不是凭空新增收入，需在正文写成交。
- **有限燃料**：建议把旧稿矛盾的400/800升，改成备用油160升、8个20升容器，车辆主油箱另记。只带途中所需，备用油存放在符合储存条件的独立区域，不能堆在睡铺旁。具体存放、载重与容器在设备选型时核对。
- **资源损失**：EP004一桶20升被取，追回未耗部分，差额及锁损按核实结果赔付；EP009固定库房再丢两桶共40升及一箱配件。连续耗用另记，不用“买入减被盗”冒充剩余油量。

## 三、全季故事梗概

郑怀山欠着三个月工资，工友堵在车行办公室门口。江彻还得回院子里的房车过夜。气象预报提示强寒潮，他摸到窗框边漏进来的风，把原本准备买电热毯的钱留下，卖掉相机，补保温、检修驻车加热器，预备食物和燃料。车行随后宣布拿库存抵工资，他逐件查验设备，挑走能用的柴油发电机、电瓶、防滑链和工具，把未抵完的工资留在欠条上。

第一夜停暖停电，江彻靠先前的准备保住住处。孙广顺家的水管损坏，他带料修好，老人拿腌菜抵材料，添了一双棉鞋垫。后来油量出现亏空，江彻查封签、留意记录仪，找到了偷油的猴三。油追回一部分，门锁却得换。此时社区团长何丽抬高菜价，他借刘秀的渠道直接采购，何丽便在群里把他的车说成大粮仓。江彻拿出库存和购货凭据配合陈珂核实登记，接下楼里的循环泵维修，和孙广顺一起把暖气恢复，工费由住户按约直接结给二人，赖广发伸手代收未果。

供暖恢复后，煤源成了下一笔支出。柴万仓掌着周边可联系到的煤货和运输，愿意给配额，却要江彻随叫随到。江彻先做一单维修，收一单费用。随后社区发生一氧化碳中毒，顾春梅负责救治衔接，陈珂协调他的车做有记录的应急转运。医院门口的黄牛拿床位收钱，医生核实后把人交进急诊。江彻返程遭人拦路索车，只能退回旧路。等他回到车行，固定库房已经被撬。车随人出去保住了，留下的油和配件却少了一批。

江彻不再把全部库存放在空院里。他向汽配城管理处提出以维修抵租，把工具搬进B2，车留室外前场，换来有人值守的落脚点。何丽的货迟迟不到，团购退款单转到了陈珂手里；赖广发的收费记录也被住户拿来核账。第二波预报到来，柴万仓以长期供货为条件再次要求收编。江彻把服务范围、出工次数、燃料预付和住处独立逐项写进合同。到了最冷的一夜，他削减非必要用电，按已有设备和燃料供给守住暖屋与房车。收音机传来转运车队预计四十八小时抵达的消息，他用近期实耗重算这两天的取暖和转运储备，在账页上划出了不能动用的那一栏。

### EP001《工资没到，寒潮先到》

时间：12/28—1/3。主冲突：工资未到账，还要动用存款准备过冬。

1. **开场**：郑怀山把讨薪的人挡在办公室外，江彻的手机弹出寒潮预报；当晚他仍要回车里睡。
2. **加压**：窗边漏风，存款还得支付吃住。他列出保温和供热的支出，撤掉电热毯订单，把相机卖出。
3. **选择与回报**：修加热器、压好保温帘，完成一次试机；分批购入的备用油与粮食分别入库，屋外的风变大，铺位终于能保温。胡凯劝他留钱过年，江彻继续按清单备货。
4. **后果**：预警再次升级，车行群却通知次日清点库存抵薪。江彻把工资条放进工具包。

静帧锚点：闭着的办公室门→漏风窗缝→保温完成的铺位→工资条。账变：相机款入账，保温与维修支出逐项记录。

### EP002《一万四，拿什么抵》

时间：1/4白天。主冲突：抵来的设备是否真能使用。

1. **开场**：郑怀山推出折价单，要求领货的人先在工资结清栏签字。
2. **加压**：江彻查出其中一台设备不能正常工作；对方只认单上折价，不愿再降。
3. **选择与回报**：江彻只签实际接收部分，换成经检验能用的发电机、电瓶、工具和防滑链，取得12000元抵货单。胡凯拒绝接机器，继续追讨现金，留下自己的欠条。
4. **后果**：余欠2000元另留签字。傍晚他在合适的室外位置试机，车灯亮起，院外路灯却停了。

静帧锚点：结清栏→检测结果→分开签下的抵货单和欠条→车亮街暗。账变：设备入账12000元，欠薪余额2000元。

### EP003《停暖第一夜》

时间：1/4夜—1/5。主冲突：失暖后，住处和水源同时吃紧。

1. **开场**：楼道暖气停了，孙广顺拿着已经缴过费的收据敲物业的门；赖广发隔着开电暖气的小屋，再要一笔运转费。
2. **加压**：老人水管损坏，物业无人处理。江彻检查后报价材料，以腌菜抵账，约好动工。
3. **选择与回报**：水阀修复并完成检查，孙广顺交菜时添了棉鞋垫；二人聊到锅炉房，江彻得知他的老本行。
4. **后果**：江彻回车记下材料和当夜用油。胡凯在群里询问供电办法，江彻回复设备需求及报价，关好库存区，给桶口加上封签。

静帧锚点：旧收据与新收费条→受损水阀→腌菜与鞋垫→封好的油桶。账变：材料换腌菜，人情另记；供热耗用开始逐日登记。

### EP004《少了一桶油》

时间：1/8—1/9。主冲突：油会继续丢，江彻必须找出进入路径。

1. **开场**：备用油区封签断了，一桶20升油不见；院墙豁口留着新脚印。
2. **加压**：江彻收紧储存和门锁，检查既有记录仪的视野，夜里留下观察，拍到再次靠近油区的人。
3. **选择与回报**：记录中的衣着、容器与现场人物对应，猴三承认取油，退回剩余柴油；江彻留存记录，要求补齐已耗油与锁损。
4. **后果**：猴三拿不出全部现金，把柴万仓煤场的短工结算条也拿了出来，写下余款；江彻记下煤场地址。

静帧锚点：断封签→记录画面→归还的油桶→结算条。账变：20升出库、实退数量与差额分行登记；柴与偷油是否有关仍未知。

### EP005《团菜先收钱》

时间：1/11—1/12。主冲突：补菜要付高价，另找渠道又会招来排挤。

1. **开场**：何丽把上一轮已付款的菜也扣着，要求补差价才交货；团购群里有人追问，被她踢了出去。
2. **加压**：刘秀拿到可核实的市场余货信息，江彻付渠道和运输费用，自行检查货品，买回可食用部分。
3. **选择与回报**：补菜入库。何丽在群里夸大他的库存，几名住户跟陈珂来到车前要求核实。
4. **后果**：江彻按登记范围提供票据和实际数量，陈珂记录澄清；赖广发随即提出借发电机保供，江彻要求先看设备和服务结算条件。

静帧锚点：未交货订单→验过的菜→车门外登记本→待检的设备单。账变：蔬菜、渠道费入账；不靠一句讨薪消除保供压力。

### EP006《工费直接给师傅》

时间：1/13—1/14。主冲突：供暖循环故障，物业要借机控制工费。

1. **开场**：赖广发要从维修工费里再抽三成，否则不给锅炉房钥匙；暖气仍冷的住户拿出前几轮缴费单，要求管理方当面核账。
2. **加压**：江彻与孙广顺在管理方配合下确认循环泵机电故障，约定维修范围、验收与物资结算；不动锅炉承压本体。
3. **选择与回报**：完成修复，由现场管理人员复核后供热恢复。江彻和孙广顺收到约定物资，孙家的份额抵作技术劳务。
4. **后果**：赖广发要代收，住户按签好的单子直接结算。管理方随后拿来下一批煤的预付款单，供货方是柴万仓。

静帧锚点：重复收费单→循环泵故障→回暖的管道→煤货预付款单。账变：工费物资与师傅分账；配件、耗材扣出。

### EP007《先修一台》

时间：1/16。主冲突：煤老板愿意供货，但想连人带车一起留下。

1. **开场**：柴万仓把优惠煤价和入伙条件放在一张纸上，要求江彻把车停进煤场。
2. **加压**：眼前几家客户的煤都等着这条运输线，江彻也需要煤；他拒绝马上长期绑定，提出先按次维修。
3. **选择与回报**：现场检修一台已停用的热风设备，完成故障排除和试机验收，收下这一单费用，换到一批有付款、签收记录的供煤安排。
4. **后果**：柴只同意这一单，不保证下一批配额。回去时，陈珂告知保供协调会的地点，江彻把供货单带上。

静帧锚点：捆绑条件→故障部件→验收签字→只覆盖一批的供货单。账变：一次维修收入；煤按实到数量入账。

### EP008《叫不醒的三个人》

时间：1/18。主冲突：社区出现中毒患者，可用转运运力不足。

1. **开场**：协调会被求助打断，附近一家三口叫不醒，顾春梅前去处置并联系急救。
2. **加压**：急救衔接需要时间，顾春梅确认可用的转运办法；陈珂协调江彻用车，登记燃料、清洁及用车费用。
3. **选择与回报**：江彻按医生安排腾出安全运送空间，把人送到急诊交接。黄牛索钱许诺床位，顾春梅向接诊人员核实，患者按病情收治。
4. **后果**：陈珂确认应急用车记录，江彻拿着交接单返回；出发时走过的主路已有新的交通管制，他转向已确认可通行的辅路。

静帧锚点：求助现场→用车登记→急诊交接→封闭主路。账变：燃料及清洁支出，对应应收用车费用；不新增送医特权。

### EP009《车不能给》

时间：1/18夜。主冲突：返程有人设障索车，离开的库房也暴露在风险中。

1. **开场**：辅路前方新堆了障碍，有人招手要江彻停车开门。
2. **加压**：一人索要房车避寒。江彻在尚能退回的距离停住，通过车窗沟通，拒绝交车，只提供现场见过的转运告示信息。
3. **选择与回报**：他确认车后路段畅通，退回此前经过的岔路，付出绕行的时间和油耗，带车回院。
4. **后果**：库房门已被撬，留在里面的备用油少了40升，配件少一箱。房车随他出去未受损；他拍下现场，先封存剩余物资。

静帧锚点：障碍前的安全距离→锁住的车门→退回的路口→被撬库门。账变：绕行耗油、库房损失分别记；失窃者身份未定。

### EP010《B2只放货》

时间：1/19—1/21。主冲突：独守空院守不住库存，换地点也要付出劳动。

1. **开场**：江彻给库门换锁，留下来的货仍无人值守；他登记失窃后去谈汽配城的落脚条件。
2. **加压**：管理处有闲置B2储物工作区、地上值班房和室外停车位，需要人维护照明与应急用电，但要核清供热和看守责任。
3. **选择与回报**：江彻限定服务工时与范围，以工抵租，先检查地点和通行条件，再用地面路线搬入物资。车留在室外前场，发电也留在合适室外位置。
4. **后果**：刘秀带来何丽的退款单，请陈珂协助核对；孙广顺带来新保供联系人，赖的代收权已被收回。强子也到了，送来柴万仓下一轮商谈的邀请。

静帧锚点：独守的旧库门→分用途的空间→搬入的库存→新供货邀约。账变：保证的维修工时抵租，搬迁费用及剩余库存盘点。

### EP011《供煤可以，车不入伙》

时间：1/23。主冲突：第二波寒潮临近，单次供货撑不起接下来的需求。

1. **开场**：柴万仓交清上一批煤，把下一批的零散配额压下，改推长期协议；条件是江彻搬到煤场，优先修他的设备。
2. **加压**：江彻带来管理方确认的用量和维修清单，柴则拿出排队的客户单。双方都承担设备停机、断供和交通受阻的成本。
3. **选择与回报**：江彻提出限定设备范围、出工次数和应急优先级，要求燃料预付、不得单方扣费，住处和车留在汽配城；柴看过成本后同意，把口头承诺写进合同。
4. **后果**：首批供货验收后入账。更低温预报到来，江彻与管理方取消非必要用电，把适用燃油与可用供热设备列为下一夜的优先项。

静帧锚点：新增绑定条款→双方用量单→改过的合同→按用途分配的储备。账变：预付维修对价、实收燃料、待履行工时分栏；不凭一顿饭获得全城垄断权。

### EP012《四十八小时的油》

时间：1/24—1/26。主冲突：第二波最低温逼近-45℃，现有消耗会缩短储备时间。

1. **开场**：低温预报兑现，管理方值守发现负载接近限额，先前的日耗记录已经偏低。
2. **加压**：孙广顺配合管理人员检查地上供热设备，刘秀按已同意的轮值表分配值守；顾春梅巡查既有住户，陈珂核实转运安排。B2保持储物用途。
