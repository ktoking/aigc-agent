# 受众与表达：红果向（v2 现实生存流）

## 平台与打法

- 目标平台：红果短剧＋抖音分发；对标末世赛道头部，走现实生存流的差异化。
- 红果爆款三件事：前 3 集定生死（EP001 现实身份钩+EP002 抵薪爽+EP003 灾变对比）、卡点集（EP006 征用危机、EP009 拦车+被撬、EP012 倒计时）、每集尾钩具体化（数字、条子、帖纸、账本）。
- 与上一版差异：删掉重生/年会/系统后，代入感来源从"金手指"换成"这个人的处境和你我一样，只是他当了真"——评论区第一条话题：如果是你，你信预警吗？

## 情绪按钮（按集埋设）

- EP001：现实共鸣——欠薪、住车省房租；预知优越感换成"清醒者孤独"。
- EP002：抵薪爽——别人抢着对骂，他挑走最值钱的铁；"你要不要？工资条换。"
- EP003：对比之王——23℃涮羊肉变 23℃熬白菜的账本现实；物业收钱vs爆管。
- EP004：智斗爽——头发丝验锁、蹲守反拿；小贼背后大势力。
- EP005：愤怒——团长哄抬+舆论围攻；清醒——账本怼征用。
- EP006：民生爽——锅炉修好、全楼物资上门；孙大爷出山的师徒暖线。
- EP007：压迫+谈判智斗——柴老板考题（动过手脚的热风炉）。
- EP008：窒息感——CO 中毒、救护车占线；冷血——黄牛卖床位。
- EP009：道德张力——拦路的不是坏人，是绝望的人；"指路不给房"。
- EP010：危机——基地被撬；转身——夜移地下车库；恶人下场快报。
- EP011：谈判高光——"这叫门面，不叫不听话"。
- EP012：生存大考+倒计时——"还差四十八小时。油，够。"

## 恶人恨值管理

- 每个恶人的恶有现实利益逻辑：赖广发吃保供、何丽吃差价、猴三吃油水、郑怀山吃现金流、柴万仓吃垄断。
- 下场由世界结算：赖被业主赶、何姐崩盘、郑怀山被汇票坑；柴万仓不倒——他讲规矩，是可谈判的恶，最可怕。
- 医院黄牛与拦路人写"绝望之恶"——不洗白，不给方便，但让观众懂。

## 互动钩子（评论区引导）

- 中期预报挂出来，你会信吗？你账户里有几天的取暖钱？
- 孙大爷免单，其他楼户按平米交物资——这规矩公道吗？
- 拦路的绝望人，该不该开车门？

## 标题与封面方向

- 标题：数字反差（"全城零下四十度，我车里二十三度——因为我是修车的"）、身份反差（"欠薪三个月，老板拿发电机抵了工资，救了我全家命"）、规则钩子（"我的善意，明码标价"）。
- 封面：车内暖黄账本特写 vs 车外青白长队；锅炉房新锁＋"城北燃料"牌子。
- 标签方向：极寒末世、现实生存、房车、人性。

## 第一人称语气规范

- 冷、短、带账本味；报数字代替抒情；不解释任何设定。
- 允许处境内冷幽默（"项羽还管饭呢"），每集至多一处。
- 情绪全部落在动作：贴头发丝、压被子、划掉"物业代收"。
