# 长线规划：极寒末日，我的房车是移动堡垒（v2 现实主义版）

总主线：欠薪的机电维修工住在自己收来的二手房车里，全城只有他把寒潮红色预警当真；停暖停电后，他的车成了街上唯一的暖房——物业要征、团长要抢、贼要偷、煤霸要收编。他用手艺、账本和不肯白给的原则，在恶人堆里把一台二手车经营成一座移动堡垒。

## 长线限制

- 无重生、无系统、无异能、无无限物资；一切装备须现实存在。
- 主角非圣母；恶人下场由世界结算；柴万仓长线养，可合作可翻脸。
- 对比手法每集至少一处；手账台账逐集登记。
- 对标基准剧 50 集体量可扩；第一人称信息边界不破。
