# 重生空间囤货爽剧 EP21-EP70 10 秒剧本

## 统一参考图说明

```text
9:16竖屏，10秒，3D动漫短剧，末日重生囤货爽剧。参考图1锁定女主的人脸、高马尾、黑色短款机能外套、深灰工装裤、橙色工牌、黑色手表和黑色短靴，不要换脸，不要换衣服。
```
## EP21 医院药库

```text
女主从空间门落到医院药库走廊，红色警报灯闪烁，墙上有抓痕和血迹但不要血腥。她刚打开药库门，就看见里面的药品已被人提前搬走一半。

空间自动扫描剩余药品，退烧药、抗生素、绷带、消毒液成排进入空间。远处传来婴儿哭声和感染者低吼。

台词：
女主：“上一世，药比黄金贵。”
女主：“这一世，我先拿走救命的。”
护士声音：“谁在药库？”
女主：“还活着的人。”

结尾：女主回头，看见一名护士抱着孩子躲在门后。
```

## EP22 护士母子

```text
医院药库内，护士抱着发烧的孩子，警惕地看着女主。女主没有解释，直接从空间取出退烧贴和水放到地上。

护士以为她要抢药，女主却只收走过期前可用的药品，并留下儿童药。走廊外感染者撞门声逼近。

台词：
护士：“你也是来抢药的？”
女主：“我抢的是时间。”
护士：“孩子撑不了多久。”
女主：“那就先让他活过今晚。”

结尾：护士看见女主掌心空间旋涡，震惊后退。
```

## EP23 医院电梯

```text
女主带护士母子撤离药库，医院走廊灯光忽明忽暗。电梯门突然打开，里面挤满感染者影子。

女主抬手把旁边金属病床吸入空间，再瞬间放出堵住电梯口。感染者撞在病床上，电梯门被卡住。

台词：
护士：“你到底是什么人？”
女主：“死过一次的人。”
小孩虚弱：“姐姐，外面是不是世界末日？”
女主：“是，但我们还没输。”

结尾：楼梯间传来幸存者组织的脚步声。
```

## EP24 药库名单

```text
楼梯间里，幸存者组织的人冲进医院，手里拿着药库清单。领头人发现药被收走，立刻怀疑女主。

女主站在楼梯平台，身后护士母子躲着。她把清单上的救命药逐一收入空间，只留下空药箱。

台词：
领头人：“药呢？”
女主：“被会用的人拿走了。”
领头人：“交出来，基地统一分配。”
女主：“上一世，你们统一分配给了自己人。”

结尾：领头人认出女主，喊出她前世死前听过的代号。
```

## EP25 前世代号

```text
医院楼梯间，领头人说出“冷库07号实验体”。女主眼神一变，快速闪回上一世：自己被绑在冷库门口，空间异能被抽取。

她意识到上一世的死亡不是偶然，而是组织早就盯上了空间异能者。女主抬手打开空间屏障。

台词：
领头人：“你果然提前觉醒了。”
女主：“所以上一世，是你们杀了我。”
领头人：“异能属于基地。”
女主：“我的命，只属于我。”

结尾：女主把整段楼梯扶手收入空间，敌人失衡跌倒。
```

## EP26 救护车钥匙

```text
女主带护士母子冲到医院后门，暴雨里停着几辆救护车。她从空间取出工具，快速打开车门。

护士提醒油不够，女主抬手从空间放出之前收走的汽油桶。远处组织成员追来，手电光扫到车窗。

台词：
护士：“你连汽油都有？”
女主：“末日里，能动的东西都要收。”
护士：“你要带我们去哪？”
女主：“先离开会吃人的医院。”

结尾：救护车启动，挡风玻璃外出现一群感染者。
```

## EP27 救护车冲围

```text
救护车冲出医院后门，感染者扑向车窗。女主坐在副驾驶，抬手把路边隔离栏收入空间，再瞬间释放成路障甩在车后。

组织车辆跟上来，车灯刺眼。护士开车发抖，女主冷静指路。

台词：
护士：“他们还在追！”
女主：“追得越紧，死得越快。”
对讲机男声：“活捉空间异能者。”
女主：“来抓。”

结尾：女主指向前方黑暗隧道，救护车冲进去。
```

## EP28 隧道断路

```text
救护车进入城市隧道，前方堵满废车。女主下车，掌心空间扩大，把挡路车辆一辆辆收入空间。

护士第一次看见她的空间容量，震惊到说不出话。隧道深处却传来密集脚步声。

台词：
护士：“你能装下整条街？”
女主：“现在还不能。”
护士：“那以后呢？”
女主：“以后，我要装下一座城。”

结尾：隧道深处亮起几十双感染者眼睛。
```

## EP29 隧道爆燃

```text
感染者从隧道深处扑来。女主把废车重新释放成两道车墙，再从空间取出汽油桶滚向车墙。

她点燃应急信号棒，火光照亮她冷静的脸。组织车辆刚追进隧道，就被车墙挡住。

台词：
组织成员：“她堵路了！”
女主：“不是堵路。”
女主：“是清场。”
护士：“快上车！”

结尾：火焰在车墙后爆开，女主关上救护车门。
```

## EP30 新安全点

```text
救护车冲出隧道，抵达废弃物流园。女主看见仓库标牌，快速闪回上一世：这里三天后会成为黑市粮仓。

她决定提前占下物流园。空间光圈展开，门锁、叉车、电瓶、木箱被快速收整。

台词：
女主：“冷库只能躲。”
女主：“这里，能建基地。”
护士：“你一个人守不住。”
女主：“所以我要先选人。”

结尾：仓库深处传来一个少年声音：“别进来，这里有陷阱。”
```

## EP31 陷阱少年

```text
物流园仓库内，一个少年躲在货架后，手里拿着自制陷阱开关。女主看出地上的绳线，没有踩进去。

少年说这里是他哥哥的地盘。女主看见他背后有工程图和仓库钥匙，判断他懂结构。

台词：
少年：“再走一步你就死。”
女主：“绳结打反了，最多摔断腿。”
少年：“你怎么知道？”
女主：“上一世，我踩过更狠的。”

结尾：仓库卷帘门外，黑市车队抵达。
```

## EP32 黑市粮仓

```text
黑市车队停在物流园外，领头人宣布这里已经被他们接管。少年脸色发白，说哥哥就是被他们带走的。

女主站在仓库门内，抬手把门口一排粮箱收入空间，黑市成员看到后立刻举枪威胁。

台词：
黑市头目：“小姑娘，把仓库交出来。”
女主：“你们来晚了。”
少年：“他们会杀人的。”
女主：“那就让他们先饿。”

结尾：女主把整扇卷帘门收入空间，黑市众人暴露在尸群视线中。
```

## EP33 空门诱敌

```text
卷帘门消失，黑市成员以为仓库失守，冲进来抢物资。女主却提前把重要物资收入空间，只留下空箱和陷阱。

少年按下开关，货架倒下阻断退路。门外感染者被枪声吸引，开始围向黑市车队。

台词：
黑市头目：“货呢？”
女主：“在你们碰不到的地方。”
少年：“你真把门收走了？”
女主：“门也是物资。”

结尾：女主从空间放回卷帘门，把黑市头目关在仓库外。
```

## EP34 少年加入

```text
黑市成员被迫撤退，少年看着女主重新加固仓库，第一次放下开关。护士母子从救护车下来，仓库临时安全点成型。

女主递给少年一张空白名单，让他登记能用的人和工具。

台词：
少年：“你不怕我背叛？”
女主：“怕，所以先给你能活下去的理由。”
少年：“我会修电。”
女主：“那你现在值十箱水。”

结尾：少年说物流园地下还有一座备用油库。
```

## EP35 备用油库

```text
女主和少年进入地下油库，墙上有旧发电设备和柴油桶。空间扫描后显示油量足够支持基地运转一周。

他们刚开始收油，地面传来爆炸声。黑市头目在外面放火，想烧掉仓库逼女主出来。

台词：
少年：“他们要烧仓库！”
女主：“烧吧。”
少年：“里面还有物资！”
女主：“真正的物资已经不在里面。”

结尾：女主把油库入口收入空间，火焰从头顶蔓延。
```

## EP36 火场转移

```text
仓库起火，护士抱着孩子，少年背着工具箱。女主打开空间，把所有人短暂转移到空间边缘的黑暗房间。

众人第一次进入女主空间，看见堆成山的水、药、食物和设备。空间深处那扇“安全屋权限”门微微发光。

台词：
护士：“这里是你的空间？”
女主：“暂时只能停留几分钟。”
少年：“这些够活多久？”
女主：“够我们反攻。”

结尾：空间门外，黑市头目发现仓库空无一人。
```

## EP37 反抢黑市

```text
女主从空间门出现在黑市车队后方。她趁黑市成员救火混乱，把车上的粮食、武器、油桶和地图全部收入空间。

黑市头目回头时，只看见空车。女主站在车顶，雨水打湿黑色外套，眼神冷静。

台词：
黑市头目：“你偷了我的车队？”
女主：“你叫抢，我叫回收。”
黑市头目：“我记住你了。”
女主：“上一世你也这么说。”

结尾：黑市头目拿出一张照片，照片上是女主前世死亡现场。
```

## EP38 死亡照片

```text
黑市头目亮出照片，女主看见上一世自己倒在冷库外的画面。她意识到黑市和组织早有交易。

头目说只要交出空间核心，就告诉她是谁下的命令。女主没有上当，直接收走他手里的照片。

台词：
黑市头目：“想知道谁杀你吗？”
女主：“我会自己查。”
黑市头目：“你斗不过基地。”
女主：“我斗过死亡。”

结尾：照片背面露出一个地址：中央广播塔。
```

## EP39 广播塔线索

```text
女主回到临时基地，把照片背面的地址摊开。护士认出中央广播塔是救援队的临时指挥点。

少年修好旧收音机，广播里传出通缉令：悬赏空间异能者，举报者奖励安全区名额。

台词：
广播：“目标女性，高马尾，便利店制服。”
护士：“他们在全城找你。”
女主：“正好。”
少年：“你要去广播塔？”
女主：“我要让全城先看清他们。”

结尾：广播突然插入闺蜜声音：“我知道她的弱点。”
```

## EP40 闺蜜直播

```text
广播塔画面里，闺蜜被救援队包装成受害者，哭着指控女主抢药、害死幸存者。城市各处幸存者开始相信她。

女主没有生气，打开空间取出医院药库监控备份和冷库门口记录。

台词：
闺蜜：“她有物资，却见死不救！”
护士：“她在撒谎。”
女主：“让她说。”
少年：“为什么？”
女主：“谎话说满，打脸才响。”

结尾：女主决定潜入广播塔。
```

## EP41 潜入广播塔

```text
夜晚暴雨，女主独自来到中央广播塔外。门口有救援队巡逻和感染者诱导装置。她利用空间收走监控摄像头和门禁锁。

上一世闪回：她曾在这里排队求救，却被拒之门外。现在她从后门进入。

台词：
女主：“上一世，我跪在门外。”
女主：“这一世，我从里面拆。”
巡逻员：“监控怎么黑了？”
女主：“因为我来了。”

结尾：女主看到广播室里，闺蜜正在化妆准备第二场直播。
```

## EP42 直播反转

```text
广播室内，闺蜜对镜头继续装可怜。女主突然从空间中放出医院监控画面，投到直播大屏上。

画面显示女主救护士母子、闺蜜带人追杀、救援队抢药。直播间弹幕式反应不要出现文字，用众人震惊表情表现。

台词：
闺蜜：“她是怪物！”
女主：“那你是什么？”
闺蜜：“你怎么会有这些？”
女主：“上一世我输在没证据。”

结尾：救援队队长关掉直播，亲自走进广播室。
```

## EP43 队长现身

```text
救援队队长进入广播室，身穿干净制服，表面温和。他叫出女主的名字，并说她父母曾经也参与空间实验。

女主第一次听到父母线索，手指微微收紧。队长趁她分神，让人封锁出口。

台词：
队长：“你和你母亲一样，不适合拥有空间。”
女主：“你认识我妈？”
队长：“她比你听话。”
女主：“那她为什么死了？”

结尾：队长拿出一枚和女主空间同色的蓝色晶核。
```

## EP44 蓝色晶核

```text
蓝色晶核出现，女主掌心空间剧烈震动。队长说这是第一代空间核心，能强行剥离异能。

广播塔天线开始释放蓝光，女主空间里的物资出现短暂失控，水箱和药箱晃动。

台词：
队长：“交出空间，你可以活。”
女主：“上一世你们也这么承诺？”
队长：“上一世你没资格谈条件。”
女主：“这一世，我有。”

结尾：女主把广播室地板收入空间，所有人瞬间下坠。
```

## EP45 塔内坠落

```text
广播室地板消失，队长和手下跌入下一层。女主用空间临时落点稳住自己，抓住闺蜜衣领。

闺蜜哭着求饶，说自己只是想换安全区名额。女主看见她口袋里有母亲旧照片的一角。

台词：
女主：“照片哪来的？”
闺蜜：“队长给我的！”
女主：“你还卖了什么？”
闺蜜：“我只说了你的生日。”

结尾：蓝色晶核亮起，女主空间门被强行撕开。
```

## EP46 空间入侵

```text
蓝色晶核撕开女主空间入口，救援队试图直接进入空间抢物资。空间内护士、少年和孩子看到裂缝，立刻准备防御。

女主意识到空间不再绝对安全，必须升级权限。她冲向晶核，把手按上去。

台词：
护士：“有人要进来了！”
少年：“门关不上！”
队长：“你的空间，现在属于基地。”
女主：“未经允许，谁都别想进我的家。”

结尾：空间深处“安全屋权限”门第一次打开。
```

## EP47 安全屋权限开启

```text
空间内部扩展成一座简易安全屋：货架、冷库、电源、净水设备自动归位。女主获得第一条权限：非授权者进入会被空间排斥。

救援队成员刚踏入空间，就被蓝光弹回广播塔。队长脸色第一次变了。

台词：
系统低语：“安全屋权限开启。”
女主：“原来空间也能认人。”
队长：“这不可能。”
女主：“现在，轮到我定规则。”

结尾：女主把闺蜜推出空间门，自己转身消失。
```

## EP48 全城通告

```text
女主重新接管广播塔信号，不露全脸，只播放救援队抢药和实验晶核画面。全城幸存者看见真相，救援队信誉崩塌。

队长下令切断电源，女主直接从空间释放发电机，让广播继续。

台词：
女主：“想活的人，别信免费救援。”
女主：“药、食物、安全点，我会用规则交换。”
队长：“切断信号！”
女主：“晚了。”

结尾：广播发出地址：物流园临时交易点。
```

## EP49 交易点开放

```text
物流园外，幸存者陆续赶来，有人带工具，有人带情报，有人带伤员。女主站在门口，建立第一条交易规则。

护士负责登记，少年负责检查物资，小孩坐在旁边喝水。空间光圈在女主身后稳定旋转。

台词：
女主：“不白送，不抢夺。”
女主：“药换情报，水换劳动，食物换秩序。”
幸存者：“我们凭什么信你？”
女主：“因为我先救人，再收账。”

结尾：一个老人递上父亲留下的旧空间研究笔记。
```

## EP50 父亲笔记

```text
女主打开父亲旧笔记，里面记录空间异能不是天降，而是灰雨前的实验副产物。她母亲曾是第一代空间宿主。

笔记最后写着：不要相信中央安全区。女主抬头，看见远处安全区灯塔亮起。

台词：
女主：“爸妈早就知道末日会来。”
护士：“那他们为什么没告诉你？”
女主：“也许他们没来得及。”
老人：“你母亲最后去的是中央安全区。”

结尾：安全区广播点名女主，要求她交出空间。
```

## EP51 安全区邀请

```text
中央安全区派出无人车，送来邀请函和一张母亲旧照片。邀请函说只要女主带空间进入安全区，就给她最高权限。

女主看着照片，没有立刻拒绝。少年担心这是陷阱，护士提醒安全区有更多病人需要药。

台词：
少年：“他们想抓你。”
护士：“但安全区可能有你母亲的线索。”
女主：“陷阱也要去。”
少年：“为什么？”
女主：“因为猎人也会踩进自己的套。”

结尾：女主决定以交易队身份进入安全区。
```

## EP52 交易车队

```text
女主组建交易车队：救护车、黑市改装车、装满假物资的空箱。真正物资都在空间里。

幸存者们第一次看到有秩序的末世队伍。女主让所有人戴上编号牌，禁止私自开箱。

台词：
女主：“记住，车上没有核心物资。”
少年：“那这些箱子？”
女主：“给敌人看的。”
护士：“如果他们搜身呢？”
女主：“那就让他们搜空。”

结尾：车队驶向中央安全区，路边出现被灰雨侵蚀的巨型路牌。
```

## EP53 入城检查

```text
安全区门口，守卫强行检查车队。所有箱子打开后都是空的，守卫以为女主虚张声势。

女主拿出一瓶药和一箱水，表示只做等价交易。守卫伸手抢，药瓶瞬间被空间收回。

台词：
守卫：“进安全区，物资先上交。”
女主：“交易，不是上交。”
守卫：“这里我们说了算。”
女主：“那我就不进。”

结尾：安全区内传来病人暴动声，守卫被迫放行。
```

## EP54 病区谈判

```text
安全区病区内，缺药病人躺满走廊。女主拿出药品，却要求负责人公开药品分配名单。

负责人拒绝，称末世不能讲公平。女主转身就走，病人家属拦住负责人。

台词：
负责人：“你这是趁火打劫。”
女主：“你们藏药，才叫趁火打劫。”
病人家属：“名单呢？”
女主：“名单公开，药立刻到。”

结尾：负责人背后，一个穿白大褂的人认出女主母亲的名字。
```

## EP55 母亲同事

```text
白大褂老人把女主带到病区后的小实验室，说她母亲曾在这里留下数据。墙上挂着第一代空间实验照片。

女主看见照片里母亲的手腕上，也有同样的空间蓝光。老人警告她，安全区首领一直在等第二代空间宿主。

台词：
老人：“你母亲不是病死的。”
女主：“谁杀了她？”
老人：“她拒绝交出空间。”
女主：“那我知道自己该怎么做了。”

结尾：实验室门外，安全区首领的声音响起：“欢迎回家。”
```

## EP56 首领会面

```text
安全区首领走进实验室，外表温和，背后跟着武装人员。他说女主的空间是人类共同财产，不该被个人占有。

女主反问上一世为什么把她推出冷库。首领微笑，说必要牺牲换来多数人存活。

台词：
首领：“你母亲曾经理解这个道理。”
女主：“她理解，所以她死了。”
首领：“你可以比她聪明。”
女主：“我只会比她更难杀。”

结尾：首领启动实验室封锁，蓝光罩住女主。
```

## EP57 封锁实验室

```text
实验室封锁启动，空间能力被压制。女主掌心蓝光变弱，首领命令抽取空间坐标。

女主没有慌，她早把一枚空间标记藏在少年身上。物流园安全屋收到警报，少年立刻启动备用计划。

台词：
首领：“你的空间现在打不开。”
女主：“你确定？”
首领：“别装了。”
女主：“我从不只留一扇门。”

结尾：实验室地面出现第二道空间裂缝。
```

## EP58 备用空间门

```text
备用空间门从实验室地面打开，少年把工具箱扔进来，护士同步释放烟雾弹。女主抓住机会破坏封锁装置。

首领第一次失控，命令开枪。女主把子弹轨迹前的金属柜收入空间，子弹打空。

台词：
少年远程喊：“姐，门只能撑五秒！”
女主：“够了。”
首领：“抓住她！”
女主：“你们抓的是旧版空间。”

结尾：女主收走实验室核心硬盘，跳入空间门。
```

## EP59 硬盘真相

```text
回到空间安全屋，女主读取硬盘。画面显示上一世死亡当天，安全区故意放出她位置，引黑市和尸潮逼她觉醒到极限。

更大的真相出现：灰雨感染会寻找空间能量，安全区一直用空间宿主当诱饵。

台词：
护士：“他们拿你喂怪物？”
少年：“这群人疯了。”
女主：“不是疯。”
女主：“他们把所有人都当库存。”

结尾：硬盘弹出最后一段母亲视频。
```

## EP60 母亲留言

```text
母亲视频播放，她告诉女主，如果看到这段录像，说明第二次灰雨潮即将爆发。唯一能关闭灰雨源的，是完整空间权限。

母亲说她没有完成的事，要女主自己决定是否继续。女主沉默几秒，关掉视频。

台词：
母亲：“乔乔，别为了恨活下去。”
女主：“可恨让我活到了现在。”
母亲：“空间不是仓库，是避难所。”
女主：“那我先把仓库变成避难所。”

结尾：城市上空出现第二轮灰雨云墙。
```

## EP61 第二轮灰雨

```text
灰雨云墙压向城市，感染者数量暴增。女主的交易点外挤满幸存者，所有人都想进空间避难。

空间容量有限，女主必须立刻制定入场规则。有人跪求免费进入，有人威胁暴力闯入。

台词：
幸存者：“求你救救我们！”
女主：“老人、孩子、伤员先入。”
壮汉：“凭什么？”
女主：“凭我能关门。”

结尾：空间安全屋扩容失败，提示缺少第三权限核心。
```

## EP62 第三权限核心

```text
空间提示第三权限核心位于中央安全区地下。女主意识到必须回去拿核心，否则救不了更多人。

护士负责留守，少年负责电力，女主独自准备出发。闺蜜突然被人押到交易点门口，声称知道地下入口。

台词：
闺蜜：“我能带你进去。”
女主：“你又想卖谁？”
闺蜜：“这次我只想活。”
女主：“那就证明你还有用。”

结尾：闺蜜说入口在女主母亲的墓下。
```

## EP63 母亲墓地

```text
女主和闺蜜来到安全区后山墓地，灰雨打在墓碑上。女主找到母亲墓碑，下面果然有隐藏升降门。

闺蜜趁女主分神想逃，却发现周围全是感染者。女主没有救她，只扔给她一把短刀。

台词：
闺蜜：“你真的不信我了？”
女主：“上一世之后，不信是基本礼貌。”
闺蜜：“我会死的。”
女主：“那就学会自己活。”

结尾：升降门打开，地下实验区灯光亮起。
```

## EP64 地下实验区

```text
地下实验区里，墙上满是空间宿主编号。女主看到自己的名字排在最后，状态标注为“已死亡/重启异常”。

她意识到重生可能不是奇迹，而是空间系统在死亡前触发的回档。闺蜜也看见自己名字，标注“诱导者”。

台词：
女主：“原来我重生，是系统自救。”
闺蜜：“诱导者是什么意思？”
女主：“意思是，你从一开始就是他们的棋子。”
闺蜜：“我不知道！”

结尾：实验仓里，一个和女主母亲相似的投影苏醒。
```

## EP65 母亲投影

```text
母亲投影告诉女主，第三权限核心不是物品，而是选择：空间只能扩容给被授权信任的人，不能只靠女主一个人背负。

女主不愿信任别人，投影反问她是否想变成另一个安全区首领。女主沉默。

台词：
投影：“仓库装物资，避难所装人。”
女主：“人会背叛。”
投影：“所以规则要比恨更强。”
女主：“我该信谁？”
投影：“信你亲手定下的规则。”

结尾：第三权限核心化成一枚蓝金钥匙。
```

## EP66 闺蜜挡刀

```text
首领带人闯入实验区，向女主开枪。闺蜜本能扑过去挡下攻击，被冲击波打倒。她不是洗白，只是终于做了一次正确选择。

女主抓住蓝金钥匙，空间权限开始升级。首领怒吼说她不配拥有母亲留下的系统。

台词：
闺蜜：“这次我没推你。”
女主：“别以为这样就清账。”
首领：“权限属于安全区！”
女主：“不，权限属于活人。”

结尾：空间扩容，实验区一半设备被吸入安全屋。
```

## EP67 安全屋扩容

```text
空间安全屋扩展成多层避难基地：药房、冷库、水站、电力间、临时病区全部出现。护士和少年看到新区域，立刻组织幸存者进入。

女主通过空间门回到交易点，宣布新的入场规则：每个人必须登记能力和责任。

台词：
女主：“从现在起，空间不是我的仓库。”
女主：“是所有守规矩的人最后一座城。”
壮汉：“不干活能进吗？”
女主：“能，梦里。”

结尾：灰雨云墙逼近交易点大门。
```

## EP68 灰雨冲城

```text
灰雨落下，交易点外感染者疯狂聚集。女主站在门口，用空间门分批转移幸存者。

首领却在安全区广播里宣布女主私藏避难名额，煽动更多人冲击交易点。人群开始失控。

台词：

女主：“规则选择谁先进。”

女主：“那就把门收进空间。”

结尾：女主把整个交易点大门收入空间，灰雨扑面而来。
```

## EP69 以城为仓

```text
大门消失，灰雨即将涌入。女主把交易点内的货架、车辆、围栏全部重组，像积木一样在空间与现实之间搭出临时通道。

幸存者沿通道撤入空间安全屋。少年远程控制电力，护士指挥伤员，大家第一次按规则协作。

台词：
少年：“姐，通道只能撑三十秒！”
女主：“够一百个人进。”
护士：“还有孩子！”
女主：“孩子先走，我最后。”

结尾：女主站在灰雨中，空间蓝光开始过载。
```

## EP70 灰雨核心

```text
女主独自站在灰雨里，空间过载却没有关闭。她看见灰雨云层中浮现一个巨大的蓝色核心，和母亲留下的钥匙共鸣。

首领从广播里说，只要她交出空间，就能停止灰雨。女主看着身后已经进入安全屋的人，做出决定。

台词：
首领：“你救不了所有人。”
女主：“我不用救所有人。”
女主：“我只要先救下愿意守规则的人。”
母亲投影低语：“找到灰雨核心。”

结尾：女主打开最大空间门，目标锁定城市中心灰雨核心。
```
