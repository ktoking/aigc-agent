# 受众策略（Audience Strategy）

## 目标受众

- 抖音/B 站/视频号：电影感微电影受众、废土/末日题材爱好者、Mad Max 与 AI 短片关注者。
- 无对白设定降低语言门槛，适合海外同步分发（YouTube/TikTok）。

## 传播钩子

1. **封面**：女主持枪趴在装甲列车顶部、背后雷暴峡谷——高对比废土视觉，一眼识别"电影质感"。
2. **前 8 秒**：荒原雷暴超大全景 + 干裂土地（L01）——先给"这不是普通短视频"的信号。
3. **中段视觉爆点**：峡谷桥（L13）、巨汉落地（L14）、终极撞击（L23）——评论区截图传播素材。
4. **结尾情感钩**：小孩拧开水阀、一滴水落下（L24）——"牺牲换一滴水"是情绪传播点。

## 发布建议

- 标题：《荒轨｜4分钟无台词废土微电影，护送一滴希望》
- 标签：#微电影 #废土 #赛博朋克 #AI短片 #末日
- 评论区置顶：一句话交代"无对白，请戴耳机"——音效/音乐是全片叙事的一半。

## 竞品参照

《丧尸清道夫》（Mx-Shell）：无对白+非传统主角+音画同步，抖音 4600 万+播放。本片复刻其"无对白视觉叙事+音画同步"手法，但走真人写实废土动作路线，与"机器人像素脸"区分。
