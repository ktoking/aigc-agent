# 剧集结构（Season Arc）

单集 4 分钟微电影，四幕结构。叙事时间按24组镜头对齐；音乐另以50/110/190秒为渐进转场点，可提前进入下一幕情绪。

## 四幕

| 幕 | 时间 | 镜头 | 章节功能 | 音乐 |
|---|---|---|---|---|
| ① 荒原序章 | 00:00-01:00 | L01-L06 | 建立世界（缺水废土）→ 火车/女主/净水核心登场 → 动机锚点（照片） | 低频、压迫、荒凉 |
| ② 狼群追击 | 01:00-02:00 | L07-L12 | 铁王庭出现 → 无人机 → 钩索登车 → 女主开火 → 车顶混战 → 无人机爆破 | 鼓点进入，速度上升 |
| ③ 峡谷血战 | 02:00-03:14 | L13-L19 | 峡谷桥壮景 → 巨汉登场 → Boss 战 → 坠落危机 → 核心失控 → 扑救 → 反杀 | 工业打击乐，最强动作段 |
| ④ 牺牲与希望 | 03:14-04:00 | L20-L24 | 净水站出现 → 拦截列车 → 脱钩牺牲 → 终极撞击 → 水重新流出 | 史诗悲壮 → 尾奏苍凉希望 |

## 情绪曲线

压抑（①）→ 紧张（②）→ 狂暴（③前半）→ 揪心（③后半：核心危机）→ 悲壮（④前半）→ 温柔释然（④结尾"一滴水"）。

## 反转设计

无叙事反转。唯一"反转"是情感反转：观众以为主角护送成功=大团圆，实际她选择脱钩牺牲自己——用"牺牲"换"希望送达"，落点在"水重新流出"的温柔，不做剧情急转。
