# 故事记忆（Story Memory）

## 一句话设定

世界早已缺水崩坏，铁王庭以"死亡铁路"统治废土。女狙击手携最后一枚净水核心，穿越整条铁路线，把希望送到地下净水站。

## 世界观

- **时代**：末日废土，人类文明崩坏后的若干年。水是最高货币，比弹药更值钱。
- **地理**：灰黑雷暴荒原 → 铁锈机械带 → 白色盐湖 → 黑色峡谷 → 地下净水站。
- **势力**：铁王庭——以装甲列车为移动王座、以暴力和掠夺维持统治的军阀集团。战旗暗红黑色，用摩托、皮卡、攀车者、无人机、改装战具扩张。
- **科技**：粗粝重工业遗存——重型装甲火车、焊接钢板、蒸汽黑烟、简陋武装无人机。无干净科幻感。
