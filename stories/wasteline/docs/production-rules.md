# 生产规则（Production Rules）

## 1. 提示词三件套（每条必带）

每条视频提示词 = **总控风格前缀**（`assets/style/global-style.md`）+ **镜头内容描述**（按 segment 内镜头时序连续书写）+ **负面约束**（`assets/style/negative-prompts.md`）。

## 2. 一致性规则

- P1 生成的核心资产图（女主全身/面部、巨汉、火车、净水核心、铁王庭战车、峡谷桥氛围）是**唯一外观权威**。
- P2 首尾帧、P3 图生视频必须引用对应核心资产图 URL；文字描述不得与设定卡冲突。
- 跨镜头同一角色外观不可漂移：女主棕褐乱发+旧护目镜+深棕工装+皮背带+旧护甲+长枪+匕首；巨汉莫霍克头+伤疤+骨牙项链+齿轮尖刺战锤。

## 3. 镜头与分段规则

- 24 镜头 → 8 段 × 30s：Seg1=L01-03 / Seg2=L04-06 / Seg3=L07-09 / Seg4=L10-12 / Seg5=L13-15 / Seg6=L16-18 / Seg7=L19-21 / Seg8=L22-24。
- 每段提示词按镜头先后顺序写"第几秒进入下一镜头"的节奏描述（如"前 10 秒…随后…"）。
- 段落衔接：下一段首帧 = 上一段尾帧状态延续（净水核心位置、火车破损程度、女主伤势在段间必须递进一致）。

## 4. 音效与音乐

- 枪声/引擎/金属/爆炸：Seedance 音画同步输出，后期不删除。
- 配乐 4 段式（见 workflow.md P5），只在情绪节点推进，不压关键音效。

## 5. 验收门槛

- 每段生成后：检查角色一致性、是否出现水印、是否出现动漫/塑料/过饱和/AI 伪影。
- 拼接后总时长 240s±1s；镜头时序与 L01-L24 顺序一致。

## 6. 不做什么

- 不加对白、不加字幕、不加解说。
- 不换画幅（16:9）、不换时长结构（8×30s）。
- 不出现现代城市、干净新车、科幻飞船、搞笑表情。
