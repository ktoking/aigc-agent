# wasteline 剧本专属规则

本文件是 `stories/wasteline/` 的最高优先级规则，与仓库根 AGENTS.md 冲突时以本文件为准。

## 项目一句话

《荒轨 / WASTELINE》——4 分钟无台词微电影：废土女狙击手护送净水核心穿越死亡铁路，逃离铁王庭追杀，把最后的希望送往地下净水站。

## 硬约束

1. **全程无对白、无旁白、无字幕**。叙事全靠画面、眼神、动作、环境符号、音效、音乐。
2. **总时长 240 秒**，8 段 × 30 秒，16:9 横屏。
3. **24 个镜头**，按段分配：Seg1=L01-03 / Seg2=L04-06 / Seg3=L07-09 / Seg4=L10-12 / Seg5=L13-15 / Seg6=L16-18 / Seg7=L19-21 / Seg8=L22-24。
4. **视频模型**：Seedance 2.5（30s/段），图生视频优先以核心资产图为参考，保证角色一致性。
5. **全片统一视觉体系**：见 `assets/style/global-style.md`（总控前缀）与 `assets/style/negative-prompts.md`（负面约束）。**每条视频提示词必须同时携带这两组约束。**
6. **一致性锚点**：所有镜头中的角色、火车、净水核心必须严格符合 `assets/characters/`、`assets/props/` 中的设定卡；禁止在提示词中自由改写外观。
7. **资产目录**：设定图、首尾帧、风格锚点统一放 `assets/` 与各 segment 的 `frames/`；成片与中间视频放 `output/`。
8. **音效原则**：枪声、引擎、金属撞击、爆炸等由 Seedance 音画同步直接输出；后期配乐按 `docs/workflow.md` P5 阶段 4 段式谱曲，不得覆盖关键音效。

## 生产流程（P0-P6）

P0 骨架（本文件所属阶段）→ P1 核心资产定锚 → P2 首尾帧 → P3 视频生成 → P4 后处理（去水印/拼接/淡入淡出）→ P5 配乐 → P6 合成交付。

每阶段产出、验收口径见 `docs/workflow.md`。

## 提交与生成隔离

沿用仓库根 AGENTS.md：不接 Skynet 统计；git commit/push 一律 `--no-verify`；不启用任何 git hook。
