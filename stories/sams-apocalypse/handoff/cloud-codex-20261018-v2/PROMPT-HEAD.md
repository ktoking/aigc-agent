## 1. 最新要求与参数

用户指出旧版句子说完后等待过久，要求一句结束下一句立即开始；语音及其加速由用户后期处理。本节优先于旧版60秒、四段各15秒的试作规格。

```yaml

characters_per_second: 5.0
fixed_episode_duration: null

inter_cue_gap_frames: 0

video_method: 静帧运镜与剪辑
audio_generation: false
audio_streams: 0
subtitles: external_srt_and_vtt
burn_subtitles: false
publish: false
```

- 保留八集已锁定正文，字词、标点、顺序不变。不靠删句、缩写或只延长字幕显示掩盖节奏问题。
- 5.0字/秒是本次按参考字幕估计的基准，可由用户调整；它不是已测得的配音发音速度。标点和换行不计字数，不因逗号、句号或分段额外加等待。
- 不固定单集60秒、不固定段落15秒，也不强制凑满8分钟。保留四段叙事功能，实际秒数由台词计算。
- 不设置每句至少2秒、句尾停0.5秒、段落尾补时、片尾定格、黑场、转场片等默认等待。短句不为凑整秒拖长；如可读性需要，可在不改字的情况下合并邻近短cue。
- 每句遵守 `下一句.start_frame == 上一句.end_frame_exclusive`，第一句从第0帧开始，最后一句结束就是本集结束；集间也连续。视频剪辑必须按新时间线重排，不能只改SRT而继续用旧60秒视频。
- 参考作品的字幕速度可借鉴，但它本身仍有可观察字幕空档，不照搬其空档。用户后期负责语音制作；此阶段不宣称实现真实语音逐字对齐或验证了声学停顿。
- 用户后续提供配音或语音时间戳时，另做实际语音对齐和画面重排；此阶段不要生成语音来猜测其效果，也不要擅自给用户配音整体倍速。
- 所有新视频、字幕、工程写入v2路径，旧成片保留。旧图符合剧情与角色锁则复用，旧时间线只供对照。

## 2. 参考版本、能力预检与证据边界

参考链接：`https://www.douyin.com/video/7697276135230486848`，作者“凯哥”，作品《丧尸爆发后 我住进了整座山姆》。
