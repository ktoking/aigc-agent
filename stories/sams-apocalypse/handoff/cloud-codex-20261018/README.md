# 云端 Codex 使用说明

1. 将本目录的ZIP上传到目标云端Codex工作区并解压。它只包含提示词、剧本/镜头数据和4张参考图，不包含原视频、私密配置或凭据。
2. 若云端支持长文本粘贴，直接发送 `CLOUD-CODEX-PROMPT.md` 全文。也可以在文件已可访问时发送下面的启动提示词。
3. 默认制作原故事EP001—EP008，8集各60秒，合集480秒；如仅试作第一集，将完整提示词第1节episodes改为[1]，deliver_compilation改为false。验收数量应按实际选集自动调整。
4. 只有提示词也可以启动。缺少参考图时按文字重新建立角色，不能保证与本地原版一致；原版角色与画风优先随附4张PNG。
5. 云端是否能直接生图和渲染，要由其实际工具预检确认。本次本地交付只完成提示词与参考包，尚未在目标云端运行。

## 直接发给云端的启动提示词

请读取我上传并解压的 `CLOUD-CODEX-PROMPT.md` 全文，按其中的任务参数和完整流程直接执行。`scripts-and-shots.json` 是同一套八集正文与67张故事图计划的机器可读副本，`references/manifest.json` 标明4张参考图的用途，请先逐图查看。先完成云端能力预检，再建立项目、生图、剪辑与独立字幕，最终交付无音轨MP4和外挂SRT。不要只返回计划；当前工具缺失时明确标记并继续完成不依赖它的工作，不得虚构生成或验收结果。

## 来源与边界

依据本地 `stories/sams-apocalypse/` 的AGENTS、故事记忆、制作规则、八集剧本、timeline.json、continuation-plan.json及验收记录整理。复制的原稿正文不作改写。没有复制临时生图路径、原Build输出、旧完成状态或任何凭据。原67张故事图并未全部打包；云端需要按计划生成缺失镜头，或另行导入已有故事图。
