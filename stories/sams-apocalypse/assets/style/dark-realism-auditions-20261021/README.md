# 暗黑写实画风试样

用户要求几版暗黑写实图片风格。以同一超市推车场景、近似人物和构图比较，不覆盖原漫画风格资产，也不自动替换剧集。

- 01：冷蓝电影写实，低照度工业灯与冷色空间，人物和物资清晰。
- 02：停电手电写实，头灯局部照明、深暗背景，强调停电求生压力。
- 03：潮湿工业末日写实，灰绿低饱和、轻微湿气与旧金属，保持门店完整。

采用GPT内置imagegen。原`episode-01-master.png`仅用于场景、构图和衣服参考；本次按用户要求把圆头点眼漫画人物改为成年中国男性真人质感。仅为画风候选，三张人物不作为已锁定的真人演员身份。

无血腥、无文字水印，避免过锐、满屏微纹理和过度脏乱。完整提示词和采用图片在本目录保存。
