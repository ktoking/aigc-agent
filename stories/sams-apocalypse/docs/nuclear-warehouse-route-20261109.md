## 本轮确定的创作方向

2026-11-09用户要求结束拖沓的试门、抢药和周强对抗，转向男性第一人称的核灾后生存、囤粮与据点经营。军方对已经沦陷的市中心实施核打击，郊区山姆受到冲击与落尘影响，但保住核心仓储与关键冷链。丧尸退为少量背景威胁，幸存者、粮食、能源、技术和交易成为主线。

用户授权改接旧人物及第二集。本方案优先保留已经交付的视频，承接第二集，但第三集直接以军方即将投核弹的广播消息开场，不再复述头顶敲击。旧第三集《被偷走的药箱》和“热饭换梯子”均停止沿用，不把其剧情或道具当作已经发生的事实。具体新增设施、规模及正文仍属于本轮设计，尚非已经拍出的内容。

## 一 故事如何成立

### 虚构门店的新增背景

这家山姆位于郊区物流园，由前场会员店、封闭后仓、冷链配套及地下设备层组成。后仓与地下核心区采用钢筋混凝土结构；柴油机在独立机房，进排气不通向人员避难区。灾前存在固定备用发电与储油设施，早期只抽盘两排常温货架，不等于已经清点全店或全部后勤资产。

这些是为新路线补入的虚构门店条件，不声称现实每家山姆都具备。若重剪第二集，可用两个短镜头提前建立后仓结构与设备台账；不重剪时，在第三集交代新增背景，不假称旧视频已展示。

核打击发生在市中心，郊区处于外围受损区：部分玻璃、前场灯架和设施受损，核心后仓保住，监控部分失效。前场一部分货物无法接近，不凭关闭一道门宣布整栋建筑安全。供水中断，最初一周主要留在地下；第二周恢复有限活动是依据本故事检测点的区域通告，不是时间到就安全。后续封路、扬尘和运输延期继续影响交易，两人仍住地下。这里的损害程度是小说设定，不提供爆炸当量、攻击参数或用一个距离承诺建筑安全。地下混凝土核心区用于避难，保温冷库本身不当作防核掩体。

城区高密度尸群主要毁于爆炸、火灾和坍塌；郊区保留零星感染者。不靠辐射把全地图丧尸即时清空，不发展辐射变异怪物线。军方的决定通过虚构紧急广播进入叙事，不把核打击描述为现实中控制传染病的有效方案。

### 污染与库存优势

本片区露天作物、开口水源、破损商店散装食品受到落尘影响，幸存者难以确认来源安全。完整包装、未受污染的其他库存仍可能存在。山姆的优势是封闭后仓中大批可追溯原封货物、保住的冷链和分区管理，不是别处所有罐头都已经变成毒物。

存放在遮蔽室内或完整密封容器中的食品通常可保留；包装外部可能沾灰，需按污染处置条件处理。开水不能消除放射性物质，冷冻、烹饪和真空包装也不用于消除核污染。检测仪的环境读数不等于逐件食品的核素安全鉴定。参考：[CDC辐射应急食水安全](https://www.cdc.gov/radiation-emergencies/safety/food-drinking-water-medicine-safety.html)。

核后初期就地避难，后续行动依本故事中的区域监测与应急通告展开，不把24或48小时写成自动解除危险的倒计时。人员防尘、防吸入与屏蔽外照射分开考虑；不把口罩、塑料布或防护服写成万能防辐射装备。参考：[CDC室内避难](https://www.cdc.gov/radiation-emergencies/response/get-inside.html)。

## 二 冷链供电方案

### 前期 沿用原有柴油备用电

保留第二集已经集中使用的一间小冷库，关停前场长排开放式冷柜、商场空调和大部分照明。新增少量冷藏柜供日常周转。发电机依温控与关键负载连续保障供电，不写成“每天开两小时，其余时间任由肉反复化冻”。

原稿燃油没有可靠总盘点；本次核前设备台账与核后盘点补出后勤储油。容量、实际液位、可用油量必须分开，发现设备不等于凭空获得新油。储油和独立机房受损情况在本轮虚构设定中交代，不能把全部建筑摧毁后只让油罐和主机毫发无损。

发电机必须有独立合适的散热、进排气及监测安排，不移进人员避难间、冷库或封闭生活区；便携机尤其不能在室内运行。参考：[CDC发电机一氧化碳风险](https://www.cdc.gov/carbon-monoxide/about/index.html)。

### 中期 用粮食换成套独立供电

通过园区电气维护队与其他幸存据点，采购兼容的光伏、储能、离网逆变与隔离保护设备，优先采购在外部完成匹配和验收的成套系统，由外部人员在外围机务区作业；内部接线只由具备相应能力者执行。不得以安装为由让外人进入核心仓储或居住区。可以接续园区原有未损设备，必须说明检验、运输、交换与改造过程；两人能力不够时暂不升级。

光伏白天供电并充电，储能覆盖夜间，柴油补足阴天、落尘遮光与高负载时段。旧并网光伏不能仅靠几块板子在停电后自动带起冷库。参考：[美国能源部光伏与韧性供电说明](https://www.energy.gov/cmei/systems/solar-and-resilience-basics)。

下面仅为作者核算用的假设场景，不是现实门店参数、选型结果或已经完成的工程：

| 用电项 | 新设规模 | 假设日耗电 |
| --- | --- | --- |
| 小冷冻库 | 约20—30立方米，保温完好，目标-18℃及以下 | 约20—30kWh |
| 小冷藏柜 | 少量周转食材，0—4℃ | 约3—5kWh |
| 灯、监控、控制、通信 | 只保核心区 | 约3—5kWh |
| 水泵与适用的通风过滤设备 | 按避难与人员规模核算 | 约5—8kWh |
| 厨房、工具及转换损耗余量 | 错峰使用，新增生产另算 | 约9—17kWh |
| 作者设计预算 | 小团队、小冷链，不含整店运营 | 约40—65kWh/日，先以60核算 |

示例配套为30kWp光伏与100kWh名义储能。假设等效日照3小时、整体折减系数0.75，光伏约发67.5kWh/日；若日照减半，仍须柴油补缺。储能假设可用70—80kWh，只够覆盖大约一天的上述负载，不是一周。压缩机启动功率、逆变器峰值与发电机负载须另外验算。低温、季节、屋顶安全、落尘与板面污染会改变可用产出。

柴油能支撑多久，用实际可用油量除以对应工况实测日耗油，不能凭储罐容积或柴油热值宣布“永久供电”。日常只需在剧情中交代交易补给和维护结果，不把每集写成能源故障课。

## 三 短保食品保存方案

| 食物 | 故事中的处理 | 对后续剧情的作用 |
| --- | --- | --- |
| 原本已冻结的肉、鱼虾与商用冻菜 | 集中到小冷库；按原批次和日期管理，保留循环风路 | 核后还能拿出肉食与配菜，兑现库存优势 |
| 冷链正常的新鲜肉类 | 在仍安全时分成一餐量、适当密封并分批冻结 | 避免每次解冻整箱，减少损耗 |
| 适合冷冻的蔬菜 | 按品种处理，需要焯水的依可靠流程焯水、冷却、沥干后分装冷冻 | 冻菜和常温蔬菜罐头承担中期蔬菜供应 |
| 草莓、蓝莓等适冻水果 | 合适处理后分批冷冻，或使用经过验证的果酱工艺 | 作为后期仍可拿出的高价值食品 |
| 面包与部分烘焙品 | 适合的品种分份冷冻；取当餐量复热 | 保留正常早餐和生活享受 |
| 鲜奶与乳制品 | 按品类和标签优先使用；适合的可冷冻但口感会变。长期主力用原封常温奶、奶粉等 | 避免把全部营养押在短保鲜奶上 |
| 奶油甜点、凉拌菜及易坏即食食品 | 在冷链有效、仍适用的期限内优先食用；不适合长期保存的就退出库存 | 允许有限损耗，不把所有短保品都救回来 |
| 米面、罐头、油、糖盐、干货、维生素等 | 原封分类、防潮防虫，按实际标签和开封状态周转 | 主粮与基础营养构成长期资产，几托损耗不拖垮整仓 |

冻结前食品必须仍处于可食状态；包装用于保质，不把已腐败、受污染或失控温的食品变安全。真空肉仍须冷藏或冷冻。温度目标和储存依据见[FDA食品储存](https://www.fda.gov/consumers/consumer-updates/are-you-storing-food-safely)、[USDA真空肉储存](https://ask.fsis.usda.gov/article/Can-I-keep-meat-in-vacuum-packages-at-room-temperature)。

需要焯水的蔬菜按品种处理；新食品分批冻结，不能把大量温热食品一次塞满冷库，忽略冷冻能力与新增耗电。参考：[NCHFP蔬菜焯水](https://nchfp.uga.edu/how/freeze/freeze-general-information/blanching-vegetables/)、[冻结负荷管理](https://nchfp.uga.edu/how/freeze/freeze-general-information/freezing-pointers/)。

不采用“所有熟肉真空后常温放一年”“普通电压力锅做万能罐头”等解法。若后续发展常温肉罐头生产，需要合适压力罐藏设备、验证工艺和有经验人员，不能由做熟或封口替代。参考：[CDC家庭罐藏](https://www.cdc.gov/botulism/prevention/home-canned-foods.html)。

### 与旧稿的衔接

第二集已经确认变质或舍弃的食品不复活。这里保存的是原本仍安全的剩余生鲜、旧有冻货及未全盘的原封库存。转冻和分装的准备可以补在第二集重接镜头，或由第三集明确回忆交代；不能在核后数日才开始抢救早已失温的食品。

保存方案用短蒙太奇呈现：小份包装、日期标签、装库与取餐。不要逐句讲解每种食物的处理教程。主要剧情是主角守住资产，并通过交易不断增加其可用价值。

## 四 新第三集和后续剧情

### 第三集 白光之后

男主从收音机得知军方即将对市中心实施核打击。男主看见黑夹克退出外侧检修口、周强一行四散，两人带着收音机进入地下核心区。白光、冲击、监控失联后，旧人物去向不明，旧对抗停止。

备用系统继续维持小冷库。避难阶段按广播行动，不冒险爬屋顶。依据园区分区通告使用保住的内部通道，不靠倒计时宣布安全，也不请外人进仓背书。

两人用后勤封缝材料与适配设备管理落尘风险，再把床垫、床品、衣服、美妆和餐厨用品用进生活。少量黄金首饰连标签票证收存。几公里外加油站后接大型储油基地，封闭储油罐保住、柴油充足，留守人员因水箱受放射性尘埃污染与食品短缺来换物资。对方穿防护服、开加油车，在昏黄尘土中到外围交货；首单二百升柴油换十袋十公斤大米、十箱水和两箱肉罐头，约定后续周期联络供油。内部库存和布局不外泄。

### 第四集 第一笔大生意

从已完成的柴油小单扩大到固定周期补给，搭配滤件、润滑油及兼容设备。所有交付留在外围机务区，供货方看不到内部布局。若发展供电升级，先完成选型、外部验收和外围接入的能力条件；不能用粮食随便换来一个全能团队进仓。

### 第五集 今天还有牛排

冷链稳定后，山姆开始提供有限的日用粮包和热食。通过正常吃饭、取冻菜和外部订单体现生活差距。交换以柴油、滤芯、工具、药品和服务为主；黄金可以收作附加资产，但不会凭金条给冷库供电。

### 第六集 货架上的新订单

外部家庭据点求购母婴、清洁、保暖用品。两人按尺码、型号和期限配货，用有限清单换油料及备件；外人留在外围交接处。关系推进来自两人的生活与选择，不以接纳外人入住制造矛盾。

### 第七集 两个据点的交易

郊区另一处幸存点掌握燃油或工具，双方谈长期供货与运输。冲突围绕承诺、货物质量和履约展开，主角能够选订单、定条件、拒绝不合算的交换，体现资源带来的主动权。

### 第八集 仓库外的新生活

受影响较轻、经监测允许使用的区域逐步恢复运输与小规模生产。主角继续扩展清洁储物、厨房和生活空间。少量室内栽培需另算用电、水和材料；不把一包种子瞬间变成全队口粮。核污染与零星丧尸是边界，经营和人际选择持续制造新故事。

## 五 人物与连续性处理

- 男主与许棠保留既有关系和技能，不重做许棠的入场，不切换到全知军事视角。
- 周强、黑夹克在冲击前后失联，本轮不确认死亡，不再用其反复试门或复仇拖剧情。林岚父女最后被看见往附近厚墙建筑撤离，之后失联；不安排大量惨死镜头。
- 新剧情需要后仓结构、固定柴油设施、避难空间等新增背景，在本轮版本中写清来源与状态，不把它们倒填成旧成片已经出现的事实。
- 后续主角可以拥有充足库存和稳定生活；不把资源边界写成每集饥饿、坏机器或被人抢走一半。每个完整单元给出一个可见成果。
- 配音仍沿用已选Gentleman原生1.2、emotion=calm及原有字幕和0.1秒衔接规则；本轮只写方案和剧本，不生成媒体。
