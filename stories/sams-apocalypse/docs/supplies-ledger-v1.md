# 首批物资盘点与消耗记录方案

这是本剧虚构门店的首批抽盘数，供编剧保持连续性，不是现实山姆库存或全店总量。EP003 只清点监控室附近两排常温货架；其余区域尚未清点。物资仍在各货架储存，并非男主在一天内搬完全部物资。

## 数字如何出现

剧本只讲最有画面感的部分：十八箱水、十二箱罐头、十二袋大米，以及泡面、肉干和坚果。完整数量由作者台账维护，不让一集变成报表。

EP003 的抽盘发生在本集开始前已有消耗之后，是当时实际剩余数；此前未计入的面包和牛角包不倒扣这些常温物资。EP005 给许棠的饮水开始从 432 瓶基线逐笔记录。后续精确取用数量待单集画面锁定后填写，当前不凭空填成已经消耗。
