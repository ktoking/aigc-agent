# 用户最终剪辑参考：字幕与语音差异

输入为用户本轮提供的4cb3524bf6cde48b43116ccc33fadfb5.mp4，保留源文件。ffprobe：257.766667秒，960×544，30fps，HEVC视频与单声道AAC，无外挂字幕轨。原v6为257.666667秒。接近的总时长不能证明逐句一致。

方法：提取16kHz单声道音频，用本地faster-whisper small做中文逐词时间识别、Silero VAD；以2fps截取原片字幕区域，用macOS Vision识别516帧。ASR和OCR均存在识别误差，不把同音字错识别当成原片错误；时间只是词级估计，非人工逐音素强制对齐。原始结果保留asr.json、vad.json、ocr.json，旧v6比较保留timing-comparison.json。

已观察的具体差异：

- 约68.75—70.25秒画内字幕保留“每袋十公斤”，语音识别在罐头十二箱、大米十二袋之后直接进入泡面等项目。属于文稿版本差异候选，不能用平移解决。
- 约81.48—83.56秒语音识别覆盖“我把本子上的价格划掉，改成了保质期”，旧v6同句却于82.667秒结束，局部差约0.89秒。应以该句声音重新取边界，不应顺带移动全片。
- 约217.92—219.46秒识别到关上休息室门；用户画内字幕在218.25、218.75、219.25秒均能读到该句。旧v6却把此句放在219.033—220.467秒。它前面的旧稿“半夜交班，她把温好的牛奶放在了桌上”没有在这段ASR中找到，说明用户剪辑后的局部版本已不同；不能继续套旧v6。
- 末句原v6是“停车场最远处，又有一片人影转向了我们”，用户片约256.25—257.75秒画内字幕与语音识别均为“停车场已经全都是丧尸”。这是明确文案改写。本集承接这一最终状态，再出现外来幸存者，不把新片当旧稿的逐字复刻。

结论：同时有正文改动和逐句时长变化，不能归结为单一固定偏移。用户已重做的画内字幕多处比旧SRT更接近新语音；本轮不把识别结果自动写成“全部字幕都错”。

后续规范：script/narration/project/timeline/captions同源；句ID和画面ID固定。配音做删词、加速、切段时同步记录旧新时间映射，重新出SRT/VTT和画面，不靠字符数时间继续冒充声学对齐。新十分钟版本尚无声音，字幕明确为估时。画面与SRT共用整数帧可避免内部漂移，却不能替代后期配音对齐。
