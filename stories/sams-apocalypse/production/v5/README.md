# 八集合集 v5：真人末日电影风

按用户最新要求制作：灾难最初四天的正常现代超市，建筑完整、干燥整洁，保留末日求生的光线和人物情绪。GPT内置imagegen重绘67张事件图，沿用69镜头和v4真实声音时间线。画面由固定电影风静帧与4帧短叠化组成，不声称已生成真人肢体动画。

## 交付

- output/EP001-EP008-v5/EP001-EP008_sams_apocalypse_v5.mp4：带字幕、保留原配音与BGM。
- 同目录*_clean.mp4：无字画面，保留相同声音。
- 同目录SRT/VTT与字幕ZIP：130句原文、原时间。
- 输出1920×1080、30fps、7343帧，244.7667秒。生成图片按原比例固定缩放至输出画幅，不添加动态裁切或晃动。
- Cloudflare链接和服务进程在share/，为临时本地Tunnel，需本机在线。

## 复现

1. 核对Brief.md、timeline.json、image-prompts.json，以及assets里的实际图和来源sidecar。*.correction*.json按编号后缀选择最终修正版；历史被拒绝的结果不进入成片。
2. 重绘只用GPT内置imagegen，逐镜头读取完整prompt与演员参考；没有图像工具时保留已有图，不擅自改用付费API。已归档图片不需要重新生成。
3. 使用uv run --with pillow --with numpy python scripts/render.py合成无字与带字两版；脚本相对自身定位目录。依赖v4成片及字幕，直接复制原AAC音频包，不加速、去声或重复叠加音乐。中文字体来自本机PingFang/STHeiti。
4. 使用相同依赖执行scripts/verify.py。检查分辨率、30fps、7343帧、整片解码、固定镜头差分、原AAC包hash、130条字幕字节一致；qa输出实际编码镜头总览和连续叠化帧。
5. 实际看源图、编码后总览、转场连续帧及浏览器正常速度样段；记录实际播放范围，不把倍速或总览称作完整人工正常速度听看。
6. scripts/package_sources.py归档八集镜头表与32个叙事段首尾图；scripts/share.py生成八章节播放器与字幕ZIP，并启动独立临时Cloudflare分享。

## 已采用的纠正

- 店长仅在室外或监控画面内，不能被画到男主监控室。
- 许棠观察期间与男主隔着关闭的玻璃门；外卷帘门和内门不同时开放。
- 监控室钥匙只有一把，配蓝色方牌；与店长外锁钥匙区别。
- 停电前段只用头灯与月光，最后停车场镜头没有男主擅自出门。
- 一次停车场图被图像服务拒绝，改成无伤口、无攻击的远处模糊成年人影后生成，详见logs/generation-failures.json；最终采用图是非血腥远景。

最终检查结果见output/EP001-EP008-v5/delivery-manifest.json及qa/，浏览器和外部链接检查与自动检查分开记录。
