# 《丧尸爆发后，我拥有整个山姆超市》

EP003《我终于知道自己有多少家底》

状态：后续剧本第一稿，约60秒、四段；未生成图片或视频。


### 分镜一 · 首批盘点

画面：当日下午，门外的店长已离开镜头；我带着本子、手电和推车检查监控室附近的货架。

第一人称正文：

下午，店长不在门口了。
我才敢推着车去盘点物资。
整家山姆一天清不完，我先记监控室附近的两排货架。
瓶装水，十八箱。

### 分镜二 · 能吃的东西

画面：水、罐头、大米、泡面逐项入册；后面的高货架尚未清点。

第一人称正文：

罐头十二箱，大米十二袋，每袋十公斤。
泡面八箱，肉干六箱，坚果四箱。
后面的货架，还一眼望不到头。
我以前只知道搬货累，现在看什么都亲切。

### 分镜三 · 价格变得不重要

画面：我核对面包和冷藏食品的日期，推车中放着临期食品，露营床和被子另放一边。

第一人称正文：

我又找了床、被子、手电和电池。
最贵的牛排还在冷库，面包却快到期了。
我把本子上的价格划掉，改成了保质期。
今晚，先吃面包。

### 分镜四 · 维修车的门开了

画面：监控画面里，卸货区外一辆白色维修车打开车门，一个女人举起空水瓶。

第一人称正文：

我抱着面包回监控室，画面里突然有东西动了。
卸货区那辆白色面包车，车门开了。
一个女人举着空水瓶，朝摄像头招手。
那辆车，昨晚就停在那里。
