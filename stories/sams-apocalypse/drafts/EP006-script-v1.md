# 《丧尸爆发后，我拥有整个山姆超市》

EP006《整座山姆，终于有两个人吃饭了》

状态：后续剧本第一稿，约60秒、四段；未生成图片或视频。


### 分镜一 · 内门打开

画面：第二天傍晚，观察已满约一日；我和许棠再次核对经历、检查可见伤口并确认她没有异常后，打开内门。

第一人称正文：

第二天傍晚，她在收货间待满了一天。
没有发现咬伤，精神也一直清醒。
我们再次核对完昨晚的经过，我打开了内门。
她进来后，先把空水瓶放进了回收袋。

### 分镜二 · 第一顿像样的饭

画面：员工茶水间，我煎临期牛排，许棠处理仍新鲜的冷藏草莓；餐桌放着两套餐具。

第一人称正文：

我挑了两块快到期的牛排，又洗了一大碗草莓。
她看着锅，问我会不会煎。
我说，包装上写着。
她接过夹子，把快糊的那块翻了个面。

### 分镜三 · 从一个人的家底变成两个人的日子

画面：我们坐在小桌两边吃饭，桌旁有物资清单和备用对讲机。

第一人称正文：

这是出事后，我第一次和人坐着吃饭。
她问我，明天想做什么。
我说，把旁边的休息室收拾出来，再把剩下的货架清一遍。
她点点头，说设备归她。

### 分镜四 · 我主动给出的钥匙

画面：我把监控室的备用钥匙放到她的餐盘旁。钥匙造型与店长手里的卸货门钥匙明确区分。

第一人称正文：

吃完，我把监控室的备用钥匙放在她碗边。
她没急着拿，先看了我一眼。
我说，今晚我值前半夜，后半夜换你。
她这才收起钥匙，把最后一块牛角包分给了我。
