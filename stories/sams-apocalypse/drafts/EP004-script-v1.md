# 《丧尸爆发后，我拥有整个山姆超市》

EP004《她没求我开门，先帮了我一个忙》

状态：后续剧本第一稿，约60秒、四段；未生成图片或视频。


### 分镜一 · 先隔着门说话

画面：女人没有靠近卷帘门，而是举起维修工单和工具包；我对照收货区留存的维保记录。

第一人称正文：

我没有开门，让她先站远一点。
她叫许棠，是来修冷库的。
昨晚取工具时外面出了事，她躲回维修车，没敢下来。
她举起的工单，和店里的记录对得上。

### 分镜二 · 外机旁的纸箱

画面：我通过门口对讲设备与她交流；她指向外机散热口，监控里能看到倒下的空纸箱。

第一人称正文：

我正想问她有没有受伤，冷库先报警了。
她听见动静，让我看装卸区的外机。
散热口前，倒着一堆纸箱。
她放下工具包，先把纸箱挪开了。

### 分镜三 · 她确实懂设备

画面：许棠留在门外检查外机，我在门内查看温控记录；一段时间后告警解除。

第一人称正文：

我照着她的说明，看温控屏上的变化。
十几分钟后，报警灯才熄了。
她确实懂这套设备。
可我还是没有立刻打开卖场的门。

### 分镜四 · 她先提出了条件

画面：许棠指向外门与内门之间带窗的收货缓冲间；内门保持关闭。

第一人称正文：

她看见我犹豫，指了指两道门之间的收货间。
她说，先让她待在那里，水和吃的放进去就行。
等我愿意相信她，再开里面那道门。
她连床都没要。
