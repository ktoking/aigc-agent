# 《孢海》

地面被发光的孢子云海淹没。人类在七座各有 500 层、用廊桥接起来的摩天楼里，凭腕带颜色分层生活。100 层以下窗外一直下着孢子雨，白天也见不到太阳。孢子开始往上爬后，清层队队长江烬发现，第 23 层的闸门比撤离时钟更早落下。

真人写实 AIGC 末世短剧，9:16。第一季 30 集，常规集 60–120 秒。首集《封层》从灰雨日升到七塔，再沿楼层下降认识江烬，150 秒，分 10 段各 15 秒制作。
