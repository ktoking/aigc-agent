# 真人 AIGC 制作规则

- 9:16 竖屏，60 秒，四段各 15 秒。段落视频计划用 720p 做动态样片，实拍质感、AI 虚构演员。角色文本锁定，脸部参考以之后选定的虚构演员资产为准。
- 世界色彩分为三层：地表是一整片青绿发光云海，低区走廊是浅灰、干燥的钢和混凝土，远处高区窗户是暖白。室内可见青绿反光，孢子的实体只出现在污染旧土或指定怪物身体上。
- 用塔楼上方领空压出竖向尺度，用橙色扶手和透明隔板辨认 A/B 方位。远景负责交代城市，近景负责交代闭锁、受力和人的反应。
- 韩峥造型固定深灰短发、左眉浅疤、石墨灰外套、橙色肩绊和胸前记录仪。叶岑固定低束黑发、灰褐检修服、右腕工具带。罗秀固定短黑发、暗蓝衣和浅米工装围裙。首集六名居民包含罗秀，其他五人无特写身份设定。
- 枝甲人仍有旧人衣物，露出两根主要木质腕枝，一只手有三根粗木指。动作从肩背发力，关节受力清楚。冲撞用门、玻璃和沉重脚步交代，人物形体保持完整。
- 字幕默认关闭，楼层标牌及 118 货签是必要剧情实物。模型生成预留标牌区域，数字和汉字由后期合成在物件表面。成片保持人声、动作声和环境声；按本仓库 MiniMax 合同安排人声，时间先记录为规划值，实测后锁定。
- 避免过度锐化、游戏化能量特效、密集粒子、满屏纹理、塑料皮肤、雨滴、湿地反光、脸部突变、闸门换位、多人重复和演职员字幕。
