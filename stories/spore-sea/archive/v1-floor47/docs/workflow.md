# 制作工作流

1. 参考季纲，写完连续事件和第一人称剧本，新稿按 L01–L06、S01–S06 记录审读。
2. 在总分镜放入场景坐标、角色动作和声音顺序。连续段之间同时继承姿态、光色和物件开闭状态。
3. 选择一套锁定人脸和角色参考。首帧管站位和开始态，尾帧管收束状态，第三张参考优先锁定当段最容易漂移的角色、结构或道具。人脸和怪物用无标注的独立图片。楼层和标签文字由后期加入。
4. 每段按 `storyboard.md`、`first-frame.md`、`last-frame.md`、`prompt.md`、`director-promt.txt`、`api-request.md` 组织。输入图放 `frames/`，视频、请求回执与重试记录放 `output/`。
5. 文本设定与生成服务的输入能力均需满足本集的参考关系。独立配音遵照 MiniMax 约定。制作版回填音频实测时码、参考路径、最终模型和作业状态。
6. 剪辑逐段核对过桥方向、A/B 人数、角色一致性、门与桥的状态、货签读数、语音落点。成片检查实际音视频时长、解码、镜头接缝和播放画面。
