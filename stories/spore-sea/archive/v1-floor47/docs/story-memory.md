# 故事圣经 v1.0

## 云栖塔城

孢海出现已有二十三年。灾变最初，人们从街道撤上旧城区高楼的楼顶。后来，幸存者留下几栋仍可承重的塔楼，架设高空连廊并向上增建，数座楼渐渐连成一座城市。高楼弯曲的外缘露出一部分旧楼骨架，上方是后来建的成片住宅、空中诊所和塔顶农棚。夜里，天桥灯在孢海上一层一层亮起来。

| 高度 | 生活与通行 |
| --- | --- |
| 1–39 层 | 城市最早放弃的楼层。大部分断电，仍有给排水与旧货运通道。 |
| 40–59 层 | 泵站、清洁和检修工的家庭住在这里。身份牌可领低区配给，跨区需要批次授权。 |
| 60–99 层 | 医疗、储备、居住和跨塔交通。这里的跨区闸口决定低层撤离能否继续。 |
| 100–120 层 | 官员及其家属配到顶层住宅。市政指挥、种子库和空中农场都在这里。B 塔 118 层的农场对外只登记为种子库。 |

塔龄和层高各异。A47 到 B48 的检修桥是局部错层短桥，只跨一条窄缝。居民常走的跨区连廊在 60 层。通行权限决定去路，桥梁的位置和承载决定速度。顶层维护另有连接相邻塔顶的横渡吊舱，一次只能运少量人或货。

## 灾变规则

1. 游离孢子常年悬在原来的地表，从楼上俯瞰如发光云海。灾后幸存者看到的附着都发生在地面，因此以高度画出安全区。
2. 本作虚构的孢子能在旧地表的土块上扎根，土块被带高也保留这项特性。高空的干钢板、玻璃、普通人工栽培基质都无法让它落地生长。污染货物会在接触受污染旧土的地方留下新斑块；能看到光从箱底、货槽和破损容器里的土块发出。纯粹的灯光反射可落在周边，没有实体根须。
3. 人在遭游离孢子侵袭后逐渐变成外观类似植物的结合体。完全变异后丧失理智，不会说话或辨认亲友。枝甲、菌伞、蔓足是三种外形：枝甲人四肢纤长、腕部有木质突起；菌伞人肩背扩展成宽伞轮廓；蔓足人躯干低伏，拖着数根粗根状附肢。每种保留褪色衣物，便于看出曾经是人。
4. 变异体可以沿实体通路上行。新旧土斑几乎同步亮起时，附近变异体会朝亮斑移动。塔城因此同时面对两件事：下方的怪物正沿旧货道上爬，货物流转又一路点亮它们附近的通道。隔离供货通路只影响后续亮斑和聚集，已入楼的变异体仍需隔开，感染者也无法复原。

## 人物

| 人物 | 行为与关系 |
| --- | --- |
| 韩峥，32 岁 | 特别行动队领队，40 层检修家庭出身，年轻时和叶岑修过这几座塔的旧连桥。进陌生走廊先看开门方向和人员去向。带过低区地表回收任务，认得孢海底部的绿光。习惯报出清楚的楼层与任务。以前按批次放行，曾错过一批滞留人员，此后每到对岸都亲自点人数。 |
| 叶岑，30 岁 | 行动队设施工程师，能识别不同塔的旧设备和维护记录。她会直说方案的代价，同时把路线落到人能走过去的位置。比韩峥更早意识到撤离名册造假会使部分家庭从记录中消失。 |
| 罗秀，46 岁 | 47 层洗衣房工长。熟悉低层的住户，知道哪些人听不见广播、哪些人走楼梯最慢。首集带头上桥，此后接手底层疏散名单。 |
| 周怀川，52 岁 | 市政主管，二十年前组织过第一次上塔迁徙。他坚持保住顶层农场的播种试验，农场原本要增加全城供给，失败会耗尽剩余种子。收到异常报告后仍批准继续上运，同时压住低层疏散请求，防止消息扩散。后续求韩峥带走种子时，必须交出货运调度权。 |

## 幕后真相

半年前，塔城几处高区农棚接连减产。周怀川批准从云海下运回旧地表土块，供 118 层的农场扩大试验。A 塔在 41、44、47 层设转运间，旧土转车时多次漏进同一列货运槽。第一份异常报告被降为设备清洁工单，此后货车仍能绕过与普通住户共用的隔离闸。被困低层的人既接不到上行配额，也无法关闭楼上控制的货梯。最高层早已接到旧土，异常比低层袭击更早发生。

韩峥先把人送到 B 塔，随后从货签、配车表、旧记录和顶层入口逐层查证。他要让整条撤离路和货运控制权换手，最终将还可使用的种子带到独立塔，同时把带有土块的农棚与其余空中走廊隔开。第一季结尾仍有孢海，低层名单与公共撤离权限交到两塔居民手里。
