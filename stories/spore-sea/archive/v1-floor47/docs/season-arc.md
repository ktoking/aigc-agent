# 第一季大纲 v1.0

12 集 × 60 秒。韩峥每成功转移一批人，就获得一段原本进不去的路。证据随这条路从 47 层抵达 118 层。镜头中的楼层数字、标牌和具体人物变化优先承担交代。

| 集数 | 当集难题与行动 | 回报及结尾 |
| --- | --- | --- |
| 01 四十七层 | 下行门被枝甲人撞开，上行闸被指挥席锁死。韩峥把自己的值勤牌留在 A 塔，借旧检修桥把首批六人转到 B48。 | 人救出来了。韩峥拍下沾有发光旧土、待送往 118 层的货箱。 |
| 02 第二批 | 韩峥在 B48 点完六人，值勤牌还留在 A 塔。罗秀的住户名单上还有十二名人没到集合点，三名行动不便。叶岑发现 B 塔货梯能回到 A 塔低层的共用货台，队伍从货台带上第一批滞留者。 | 他们把留在洗衣房的人接到货台。叶岑看到货梯车次有三处卸货口，和最早三处异常的楼层重合。 |
| 03 货梯还在走 | 关闭货梯会把居民和所剩下的货物困在中间层。蔓足人钻进 44 层转运间。韩峥带居民穿过两车厢间的旧货台，撤到并行货梯，再关住空车里的怪物。 | 隔着两车厢，两车之间的玻璃和钢板干净，一只掀盖货箱下亮着一条土痕。货运日志显示有带着土的货车已经抵达 118 层。 |
| 04 六十楼只留十八个 | 来自几个低层的居民汇到 60 层，分流闸按名册只放十八人。罗秀报出人名，叶岑找到名册中已经注销却仍站在他们面前的居民。韩峥用救援录像和当面点名取得当值医生支持，先把伤者转入诊所，由诊所登记其他滞留者。 | 十八个名额全部用于急需照护的人。管理方撤销韩峥的特别行动队权限，关掉他的上行通道。 |
| 05 先响的警报 | 诊所里有人拿出出事前的换班录音。叶岑跟随当年修过顶层农棚的病人进到 76 层维修档案间，找出 118 层首次异常的记录。 | 118 层的告警早于 41 层袭击十九天。同一份记录把异常照片删去，只剩周怀川的继续供货指令。 |
| 06 桥上的人 | 逃上 76 层的人堵住跨塔桥，曾经的清洁班也被逼进来。菌伞人迎面压进狭窄桥口，韩峥带几人从旧侧门让出空间，罗秀分批送人过桥。叶岑看准怪物的伞肩挡住门框，从另一扇门把留下的几个人也接上桥。 | 走失的一家重逢，桥暂时腾空。周怀川让人送来一份上行证，要求韩峥只带两个人去 118 层。 |
| 07 请你去顶楼 | 韩峥带叶岑、诊所医生上行。周怀川公开带他们去准备好的种子库，叶岑顺着运输标签找到另一侧仍在转运的货台。 | 韩峥看见上层农棚中的亮斑和关在隔间里的变异体。官方刚批准新一班空箱下行，车厢和返程箱都还沾有旧土。 |
| 08 运回去的箱子 | 换班铃一响，空箱就会送回低层。韩峥让亲眼看见照片的值班员暂扣货车，罗秀借诊所广播向居民念出三次卸货记录和收货层。 | 下行返程停了。挂在旧槽里的变异体已进入顶层农棚，防火门切断了唯一登记在册的出路。 |
| 09 顶楼也有门禁 | 农棚人员打不开内门。叶岑让里面的人按图找到一扇与检修间共墙的备用门，韩峥先推开门送伤者出去。 | 官员家属与原来不准上楼的清洁工在同一走廊排队。农场卸货口仍向其他塔开放。 |
| 10 最后一批种子 | 农场隔离前还要运走干燥种库里最后一批种子。周怀川要用 118 层那部横渡吊舱优先运种，韩峥让医生和罗秀接管载人次序，自己留下扛最后一批种子。 | 人按伤情先走，种子装进最后一班吊舱。周怀川交出货运调度权限，他家人拿到与其他住户相同的登舱次序。 |
| 11 最后一座桥 | 仍在聚集的蔓足人占住农棚货台。韩峥借周怀川交出的权限隔开顶层货桥，叶岑去侧塔接回最后一组检修工。 | 侧塔与污染农棚之间的通路全部隔开，其中一名年轻检修工在对岸按人数逐个应答。B 塔领取种子的队伍已经排到原来的官员闸口。 |
| 12 海面上的灯 | 两塔安置点粮和净水有限。罗秀用逐户确认的新名单接管配给，叶岑重新开通两塔的公共撤离通道，韩峥带队去空中桥头接遇险家庭。 | 47 层第一批获救的人领到新住处。远处一座从未接入塔群的塔亮起求救灯，韩峥拿出新地图标下路线。 |

每段真相对应一种可反复出现的实物：货签、同一辆带划痕的货车、压下的报警单、顶层农棚。前五集逐一开放物证，周怀川的命令与动机留到顶层相见后再完整揭示。
