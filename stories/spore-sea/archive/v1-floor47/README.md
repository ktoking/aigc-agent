# 《孢海之上》

**发光的孢子海吞没了地面。人类住进用天桥连起来的摩天楼，官员占着最高层，而特别行动队每晚都要下去，把还活着的人往上送。**

末世生存、架空灾变、阶层悬疑。观众跟着救援队长韩峥，看一扇扇门如何决定谁能活着上楼，也跟着他的行动记录逐渐查清孢子蔓延的路线。定位真人写实 AIGC 动态短剧，第一季暂定 12 集，每集 60 秒，9:16 竖屏，4 段各 15 秒。
