# 《孢海》故事圣经 v2.3

## 灰雨日与七座塔

| 时间 | 人们能记住的事 |
| --- | --- |
| 第 0 年，灰雨日 | 灰白孢雨落进街面、隧道和庭院。第一批感染者发作后在地面袭击逃难的人，感染波及更多住户。原来的电网与地面交通相继断开。最初躲到楼顶的人，每天用床单标记尚可接人的大楼。 |
| 第 0–3 年 | 幸存者能在高处过夜，便沿旧大楼上移。最初的救援绳和天台踏板逐渐换成跨塔廊桥。全国集中调配工程队、建材和设备，分批支援各城市的建塔工程。官方后来把这段经验写成「孢子只在地面生长」。下层居民平常能从密封窗看见孢子雨，官方给的解释是雨里只带着飘过的孢粒，塔内不会长起来。 |
| 第 3–9 年 | 各地借全国支援，在还能使用的楼体周边陆续建设云梯城。江烬所在的这一座依托七座旧塔工程的骨架加固增建，每塔 500 层。与居民通道并行的管线能在塔内和塔间输送水电。塔身按通风分区设置主隔离闸，早期旧楼段约每十层一道。23/24 层的防火隔断也接入同一套控制。《层级法》把住宅、配给和上行许可绑到腕带上。 |
| 第 7 年 | 四号塔 19 层封层。17 岁的江烬先过闸，弟弟江野留在后方。同一时期，林昭的母亲在接受净化局任务后失踪。 |
| 第 17 年，现时 | 几个月来低楼层的封层越来越频繁。四号塔近期失守 12、16、21 层，部分住户转入更高的下层。19 层仍是十年前留下的旧封区，塔内的旧货井可以绕过封住的生活走廊。23 层发出撤离指令，清层队按两分钟预案下楼。 |

塔身保留旧楼垂直的电梯井和外侧梁。幸存者后建的农架、净水仓和暖色玻璃连廊搭在旧骨架外。全城七塔都在同一片大孢海上。从高处看，孢海像一整层会发光的云，白天灰白，夜里泛青绿。100 层是雨幕上缘，100 层以下常年看不见天光，一直下灰黑色孢子雨。雨线里的孢粒是零散的暗青光。29 层和 23 层隔着密封窗能看见雨，室内主要靠人造光，居民通过内廊和封闭楼梯活动。

各城的塔群布局和楼层安排各由本地决定。本季开头的七塔只属于江烬所在的云梯城。

## 塔城怎么维持

| 系统 | 本城设定 | 首集能看到的事 |
| --- | --- | --- |
| 电力 | 每座塔的地基深处都有核反应堆，持续供给照明、净水、电梯和农场。回收的一部分余热用于种植区。 | 100 层以下窗外黑，室内灯和设备仍在运转。江烬在首集旁白里说出地基核能供电，画面仍在可见的生活层。 |
| 水 | 储水、用水、回收净化和再分配在塔内循环。净水分配受腕带和配额约束。 | 住户从配给龙头接水，可看见水管随竖梁接入各层。旁白点明水会回用。 |
| 食物 | 中层有连续的种植楼层，农场内分田区和叶菜架，供应谷物、块根和叶菜，再分给其他楼层。 | 镜头经过 210 层，远处见成排种植地，近处工人把当天收成递向配给窗。 |

## 楼层、颜色与通行

| 区域 | 层数 | 居住者与资源 | 腕带 / 空间色 |
| --- | --- | --- | --- |
| 云顶层 | 450–500 | 富户、议会和官员，优先供给净水与阳光，有独立温室花园 | 金 / 暖金 |
| 上层 | 300–449 | 技术人员和军警，配给稳定，控制塔间交通 | 白 / 冷白 |
| 中层 | 150–299 | 工人和商人，经营成片种植地与配给窗口 | 蓝 / 灰黄 |
| 下层 | 10–149 | 配给不足，居住靠近泵站和公共洗衣绳，最早接到封层，100 层以下靠人工照明 | 锈红 / 蓝灰、旧锈红 |
| 孢层 | 1–9 | 连续被孢海占据，入口及普通电梯按钮封闭 | 无 / 青绿荧光 |

- 腕带绑定阶层身份、配给和常规电梯权限。平民可在自己的层活动或按规则下行。往上需要目的层权限，消防楼梯也在级差闸口查验。
- 救援时由指挥中心开临时疏散上行通道，出口按腕带计数。一旦授权远程收回，蓝带和清层队任务权限也无法把已落下的闸门刷开。
- 墙上口号「向上永存」。29 层是清层队驻地，地理位置仍在下层，队员的中层编制由蓝腕带和黑臂章标明。四号塔 24 层有疏散平台，通向 29 层；23 层居民平时不能从这个楼梯口向上。
- 平日的同一扇门有两种用途。白班靠腕带放行，报警时让人批量跨层，撤离结束才应隔离。纸面上按「超标—广播—两分钟撤离—隔断—清层—标注弃层」执行，议会可以更改封层时刻和名单。
- 房门牌和腕带统一服务人口账。腕带终端既能给普通居民显示配给余额，也可在内部档案标明「待弃」。小满家仍被照常扣减口粮时，她的 23 层地址早已被标为三个月后不再补给。
- 城里最易拍懂的日常交换：上层持白带的人开门即走。站在同一门前的锈红带工人推着维修车，刷带后闸口关闭，旁边有人招手让他去下行。这两个动作不用旁白。

## 清层队与孢子形态

清层队接警后进到污染楼层，把居民送过闸，队尾最后退出。队员护具保留个人轮廓。战术表现采用风、光、声与虚构清层设备，动作压在走廊和楼梯内。

| 级别 | 可见特征 | 首次揭示 |
| --- | --- | --- |
| 带菌者 | 由感染者变异而来。步态和转头不自然，发作后疯狂扑向身边的人，袭击可把孢子传给更多人。 | EP001 开场灰雨里先看到远处袭击；江烬在昨夜的回放里看清带菌者已经沿楼梯向上。 |
| 藤蔓者 | 人形的肩背与几根粗藤连成一体，先在通风或楼梯阴影里看到藤 | EP001。冲进走廊后仍有人的衣袖 |
| 花苞体 | 背部合拢成一枚巨大浅色花苞，张开时像一顶罩住人头和肩的伞，光从苞片之间透出 | EP006。花苞与零号温室白百合构成相似轮廓 |
| 树巨人 | 树干形胸背与数段曾经属于人的衣物，轮廓高过普通闸口，脚步能让廊桥护栏抖动 | 中段后。一座空桥的梁影先被挡住 |

充分变异后丧失理智。它们朝可用通路和孢海信号活动，可以绕开上一次被驱离的区域。EP004 指向上方的手只是对上方脉冲作出动作，人物暂时无法解释。阿鬼的伤后白花单独记录，缓慢症状是后续共生者线索。完整变异与共生是两条不同状态。

## 编剧层真相

1. **人为弃层。** 最初的计划是集中上部可用住宅和粮水。每个拟弃层预先划定日期及撤离名额，名额外的人缺少上行授权。指挥席能把门提前落下。23 层的 17 人正落在名额外。秦衡需要留住电站、净水和部分上层人口，签字背后有真实的供应压力，也有被系统藏掉的人。
2. **信号与安全高度。** 塔顶有虚构信号源削弱孢海活动，七塔的中继把它送到较低楼层。安全线随信号衰退逐月抬升，实际保护范围向塔顶缩小。早期有人说“信号线下降”，指仪表里的信号强度下降。楼层图上的危险边界正在向上。这两种画法应同时保留方向标记。
3. **信号源是仍有意识的人。** 林昭母亲当年自愿给全城争取时间。议会随后控制她的活动与声音，从她身上取得本作用于抑制异常的虚构净化剂，长期优先给高层已有接触史的人。强行维持正在耗尽核心。孢海近期上行的转折来自保护范围缩小，而高层额外的用量使衰退加快。
4. **终局条件。** 维持原状还能换时间，关闭核心会使所有连廊暴露，唤醒她可让她和地下共生者试着互相回应。季末云海在七塔附近退下，显露出森林。远城仍由其他零号维持，道路上能听见相似但较弱的信号。
