# 制作工作流

1. 阅读故事圣经、季纲和当前集的连续性，按首集 150 秒、后续常规集 60–120 秒组织 15 秒段。
2. 用总分镜确认楼层、材料、行动方向和道具状态。按 L01–L06、S01–S06 复核正文、旁白、对白和后续集因果。
3. 先锁七塔、四号塔立面、温室与 23/24 闸口，再定江烬、阿鬼、小满的脸与服装。少量采用戴罩与裸脸对照。当季其余人物参考见定妆卡。
4. 按首帧、段内关键帧、尾帧、人物或场景参考的顺序准备图像。垂直下降优先借用前段实测尾状态，落在遮挡时可在剪辑中缩短重合部分。以同一根直线柱或闸门轴核对接缝。
5. 视频按段提交。每段查看 `api-request.md`，素材入 `frames/`，输出入 `output/`。剧情读数及片名、时间墙牌放后期，不把带字的故事板表格传给视频模型。
6. 配音实际生成后，在 150 秒内剪齐声音开口点和动作。核对七塔布局、下落方向、腕带左右、右高左低的撤离轴、17 人、四次倒计时状态和片尾实物受力。
