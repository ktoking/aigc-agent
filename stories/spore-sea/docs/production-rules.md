# 真人 AIGC 制作规则

- 9:16 竖屏，真人电影摄影质感。首集 150 秒，10 × 15 秒，制作样片按 720p 规划。七塔外景和怪物采用影视 CG 质感，实景人物有自然肤纹与服装受力。
- 云海的连续主色是灰白与青绿。第 0 年灰雨里的荧光只随雨滴显出小点。带菌者靠失衡步态、突然奔扑和逃难者的反应交代。第 17 年初晨，云海上方已有日照，100 层以下窗外仍黑。黑色孢子雨常年落在塔外，少量暗青粒子只借灯或雨线显形。云顶用暖金阳光、自然花白和透明温室玻璃；上层冷白；中层灰黄；下层锈红、蓝灰和冷白荧光；1–9 层青绿。
- 七塔远景定一个三分之四侧视布局。第 1 段沿同一条航拍路线从街道升到云海之上，用前景云遮完成灰雨日到第 17 年的时间过渡。出云后用时间字和片名交代十七年的跨越。第 2 段开在 500 层花园，以楼板截面、固定竖柱和暗梁作近处遮挡，连续向下经过 320 层电梯岗和 210 层农场。前景四号塔的竖梁方向一路稳定。第 3 段沿同一竖梁进入雨幕上缘，窗外从灰亮转为彻底没有天光，室内冷白灯接住画面。
- 60–90 秒人物生活段露脸。清层队接警前可露面，进入 23 层污染区前合上面罩；合罩后留眼睛、臂章和腕带作辨识。小满的脸只在受保护的近景中清楚可见，冲撞用成人、道具或闸门局部承接。
- 100 层以下室内以实际灯具照亮人物和动线。玻璃密封，孢子雨留在窗外，室内以干燥、可读为主。首集按场景要求保留 23 层门边擦痕、机修缝隙局部湿布和一小块积水。灯、背景和大形留出层次，不扩大成溢水、雨雾或脏乱的整廊。
- 清层队使用虚构的清层器与紫外灯。火光只对后方藤蔓，闸门重量通过装置外壳、门沿摩擦和人物下沉承载。受力点前后相同，轻量主镜时让群像只保留几名可辨背景住户。屏幕显示 17 人未通过。
- 模型画面保留标牌位置。片名「孢海」、时间提示「灰雨日」与「十七年后」、地名「云梯城 · 七塔 · 每塔五百层」、剧中「向上永存」、电梯层数、警报与腕带计数由后期加入。片尾「下集《违令》」用单独黑底，兜住上一镜门缘声。不默认交独立字幕。
- 配音遵循仓库 MiniMax 合同。江烬旁白、广播、角色对白分别排时，第一人称限江烬亲历、从公开纪年得知的事与他当前看到的情况。开场铺雨声，随后依序接入云顶瓷杯、军警步声、电梯和配给窗口声。音乐用同一条主轨从外景延续到倒计时，异常跳秒仅留一次明确断拍。
- 避免油塑皮肤、清层队换脸、错手腕带、手部增生、枪械特写、明示人体伤害、绿光覆盖整个室内、满屏微细纹理、水印和乱码。
