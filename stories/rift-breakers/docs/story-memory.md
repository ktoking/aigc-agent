# 裂界行者 / Rift Breakers — 故事记忆

## 世界观

现代都市表面平静，但城市各处随机出现"裂界缝隙"——肉眼难察的空间裂痕。缝隙另一端连接被遗忘的异空间，渗出怪物、异象、残缺记忆与古老能量。能看见并触碰裂界的人称为"界行者"。

## 角色

- **神崎凛斗**（男主，17）：普通高中生，事故后觉醒"界焰"（蓝白火焰状裂界能量），失控时半边身体蔓延黑色裂纹。冷静寡言，战斗时执拗。
- **天野澪**（女主，17）：黑长直红瞳，能力是透明几何结界与裂界感知，男主的引路人，背负秘密。
- **赤城隼**（热血搭档，18）：红发刺猬头，橙红高机动推进能量，张扬冲动。
- **白峰夜臣**（冷面强者，20）：白发黑风衣长刀，能力"断界斩"可切开空间。
- **雾原真琴**（导师，28）：长外套手套，监控室指挥官，知道全部真相。
- **黑曜**（反派，外观20+）：黑衣金纹黑发金瞳，能力"吞噬裂界"，与男主像镜像。
