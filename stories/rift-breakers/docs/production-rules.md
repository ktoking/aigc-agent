# 生产规则

## 视觉规则

- 日式 2D 赛璐璐动画，细腻上色，强光影对比
- 前半段暖色调（夕阳/晴空/霓虹），后半段冷色调（暴雨/黑紫裂缝/蓝白焰）
- 能力配色固定：界焰=蓝白、结界=透明几何、推进=橙红、斩击=白裂纹、黑曜=黑紫

## 音频规则

- BGM 已定：V3 版 195BPM 高速女声嘶吼电子摇滚
- 日语歌词：前奏无人声；A段"いつもの帰り道…"；B段"ビルの隙間に潜む…"；预副歌"指先で触れた…"；副歌"裂けた空の向こうへ 走り出せ… Rift Breakers!"；尾奏撕裂高音硬切
- 画面无字幕、无对白

## 镜头规则

- 16:9 横屏
- 前奏/预副歌段镜头慢（2.5-4s/镜），副歌段快切（0.5-3s/镜）
- 所有切换卡鼓点
- 每帧必须三层运动：前景粒子 + 中景人物 + 背景环境
