# rift-breakers 剧本专属规则

本文件是 `stories/rift-breakers/` 的最高优先级规则，与仓库根 AGENTS.md 冲突时以本文件为准。

## 项目一句话

《裂界行者 / Rift Breakers》——90 秒日式热血都市异能动画 OP：现代都市随机出现"裂界缝隙"，普通高中生神崎凛斗觉醒"界焰"能力，与伙伴们一起对抗吞噬裂界的反派黑曜。

## 硬约束

1. **90 秒 OP，30 个镜头，16:9 横屏，日式 2D 赛璐璐动画风格**（非写实、非 3D、非 Q 版）。
2. **BGM 已选定 V3 版**：195BPM 高速女声嘶吼版，电子摇滚+J-Rock 混合，副歌女声撕心裂肺。所有镜头切换必须卡鼓点。
3. **无对白、无旁白**。BGM 日语人声歌词已写入曲目，画面不加字幕。
4. **角色一致性**：6 个角色跨镜头长相、服装、发色、瞳色必须稳定，不靠参考图时也要在每条 prompt 里复述外观锚点。
5. **视觉基调**：前半段晴空/黄昏/校园/城市霓虹（暖橙蓝紫），后半段暴雨/黑紫裂缝天空/蓝白界焰（冷调高对比）。
6. **能力配色固定**：男主界焰=蓝白色火焰；女主结界=透明几何多边形；赤城推进=橙红色能量；夜臣斩击=白色空间裂纹；黑曜能量=黑紫色。

## 核心资产目录

- `assets/style/`：全局风格总控前缀、负面限制词、BGM 卡点表
- `assets/characters/`：6 个角色设定卡（暂未生成，后续补）
- `episodes/OP00_opening/`：90 秒 OP 生成工作区，3 个 segment
