## 重试策略
- 额度不足：停止，报告用户，不自动重试
- 生成失败：同参数重试1次；连续2次失败调整提示词
- 战斗场景太混乱：强化战斗动作描述，重新提交

- 尾声手指微动不明显：强化"极其缓慢地食指微微动了一下，非常轻微但确实动了"，重新提交
- 英雄睁眼（禁止）：强化"不要英雄复活睁眼，只动手指"，重新提交
