## 调色基线（阴天自然光写实）

- 色温：中性偏冷（阴天自然光），禁止暖橙/金黄
- 饱和度：中低饱和，自然真实色彩
- 影调：柔和对比，漫射光，阴影不生硬
- 颗粒：自然细腻胶片颗粒 + 轻微暗角
- 质感：真实皮肤毛孔、汗渍、皮革纹理、金属锈蚀、布料磨损、泥土灰尘
- 光学：镜头轻微呼吸感、真实景深、大气薄雾、不完美自然光影

## 色彩体系

| 色 | 用途 |
|---|---|
| 灰绿 | 森林、山谷、植被（主色） |
| 灰褐 | 岩石、城堡、泥土、沙漠 |
| 深蓝灰 | 阴影、洞穴、夜空、水面 |
| 灰白 | 阴天天空、雾气、瀑布水汽、雪山 |
| 暗金（仅限龙） | 黑龙鳞片微光、宝藏（极少量，禁止大面积） |
| 血红（仅限战斗） | 血迹、伤口（极少量，写实不夸张） |

## 各场景色调参考

- **城堡/王国**：灰石墙、绿色田野、阴天灰白天空
- **黑暗森林**：深绿、灰褐、迷雾、低光
- **瀑布**：灰白水汽、灰岩石、冷蓝绿水
- **沼泽**：暗绿、泥泞褐、灰雾、死水
- **沙漠**：浅褐、灰白天空、灼热感（但不金黄）
- **高山/雪山**：灰岩石、白雪、深蓝灰天空
- **龙穴**：深黑、暗褐、白骨、极少量暗金宝藏光
- **河流尾声**：冷蓝灰水面、灰白天空、宁静
