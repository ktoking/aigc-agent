# 镜头语言（Camera Language）

## 整体风格

荷马史诗式中世纪奇幻电影质感，阴天自然光写实摄影，镜头运动沉稳有力，配合 BGM 节奏卡点。英雄旅程用跟随镜头和广角远景，战斗场景用快切和手持，飞龙视角用平滑的第一人称航拍，坠崖用主观视角+慢动作，尾声用宁静的长镜头。

## 镜头运动

| 类型 | 用途 |
|---|---|
| 跟随镜头（tracking） | 英雄旅程中跟随他前进，增强代入感 |
| 广角远景（wide shot） | 展示宏大世界、各场景规模、英雄的渺小 |
| 低角度仰拍（low angle） | 英雄力量感、黑龙的巨大威胁、史诗感 |
| 特写（close-up） | 英雄眼神、公主表情、剑刃、龙爪、血迹 |
| 慢动作（slow motion） | 关键战斗瞬间、坠崖、尾声手指微动 |
| 手持微晃（handheld） | 战斗场景的紧张感、混乱感 |
| 第一人称航拍（FPV drone） | 飞龙视角俯瞰世界，平滑飞行，展示宏大世界观 |
| 主观视角（POV） | 坠崖时英雄的视角，快速下落 |
| 剪影（silhouette） | 英雄在城堡前、山顶、崖边的轮廓 |

## 剪辑节奏（配合 BGM）

- **Seg1（0-30s，出发+森林）**：中速节奏，建立氛围，城堡出发用广角，森林用跟随，战斗用快切
- **Seg2（30-60s，瀑布+沼泽+沙漠）**：节奏加快，场景切换频繁，每个场景 8-10 秒，用飞龙视角做场景过渡
- **Seg3（60-90s，攀山+龙穴）**：节奏先慢后快，攀山用长镜头，龙穴发现用缓慢推镜，对峙用快切
- **Seg4（90-120s，决战+坠崖+尾声）**：高潮快切→坠崖慢动作→尾声极慢长镜头，节奏从极快到极慢，形成强烈对比

## 转场

- 硬切：用于战斗节奏卡点、场景快速切换
- 匹配剪辑（match cut）：英雄的剑击匹配下一个场景的动作
- 飞龙视角过渡：用飞龙第一人称航拍作为场景之间的过渡（Seg1→Seg2，Seg2→Seg3）
- 交叉淡化（dissolve）：用于时间流逝、场景过渡
- 黑场（fade to black）：用于坠崖后的黑屏，然后切到河流尾声

## 飞龙视角（FPV Dragon Flight）

- Seg1 中后段：从城堡出发后，切入飞龙第一人称视角，飞过森林和山脉，展示宏大世界，然后切回英雄进入森林
- Seg2 中段：从沼泽到沙漠的过渡，用飞龙视角飞越大陆，展示地形变化，然后切回英雄在沙漠中
- 运镜：平滑、缓慢、有飞行感，翅膀偶尔在画面边缘出现，云层和地形在下方移动
- 目的：展示荷马史诗式的宏大世界观，作为场景过渡，增强 MV 式视觉冲击

## 禁止

- 不要快速抖动的手持（除非战斗场景）
- 不要无人机式的航拍俯瞰（飞龙视角除外，且必须有飞行感）
- 不要过度使用鱼眼或广角畸变
- 不要镜头运动与 BGM 节奏脱节
- 不要金黄色调、暖橙色调、黄金时刻、镜头光晕
