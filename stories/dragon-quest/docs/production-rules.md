# 生产规则（Production Rules）

## 提示词三件套规则
每条视频提示词必须包含：
1. 总控前缀：`assets/style/global-style.md` 完整风格描述
2. 一致性锁定：角色/道具/场景外观描述
3. 负面约束：`assets/style/negative-prompts.md` 完整负面描述

## 镜头叙事规则
1. 无对白：全片无任何对白、旁白、字幕、可读文字
2. 动作叙事：所有叙事通过动作、表情、环境、音乐传达
3. 飞龙视角穿插：Seg1 和 Seg2 各穿插一次飞龙第一人称俯瞰视角，展示宏大世界观，作为场景过渡
4. 战斗处理：战斗场景用快切和手持微晃，关键瞬间用慢动作
5. 坠崖处理：用慢动作+主观POV视角+黑场
6. 尾声处理：用极慢长镜头+特写，手指微动是最后一个镜头

## 音乐驱动剪辑规则
1. 出发卡点：Seg1 城堡出发卡 BGM 开场鼓点
2. 场景切换卡点：森林→瀑布→沼泽→沙漠的切换卡 BGM 节拍
3. 战斗高潮：Seg4 决战卡 BGM 全乐队高潮
4. 坠崖静默：坠崖时 BGM 渐弱到几乎无声，只有风声
5. 尾声留白：尾声 BGM 极弱或无声，只有水流声，手指微动时留悬念

## 一致性规则
1. 英雄外观：所有镜头中英雄的服装、疤痕、发型、武器必须一致
2. 公主外观：公主的礼服颜色（深蓝）、发色（浅金）、铁链必须一致
3. 黑龙外观：黑龙的颜色（深黑）、犄角、翅膀、红眼睛必须一致
4. 场景路线：旅程路线顺序固定，不可调换
5. 色彩体系：阴天自然光、中性色温、低饱和，禁止金黄色/暖橙色调（龙的眼睛和火焰除外）

## 音效规则
1. 环境音：每个场景的环境音（森林鸟鸣、瀑布轰鸣、沼泽泥泞、沙漠风声、山风雪声、龙穴回声、河流水声）
2. 动作音：剑击、翻滚、火焰、爪子、铁链、脚步声
3. 龙的声音：咆哮、翅膀气流、痛苦哀鸣
4. 禁止：任何人声、台词、歌词、旁白
