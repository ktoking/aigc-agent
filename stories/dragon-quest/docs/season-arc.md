# 季弧（Season Arc）

## EP001《黑龙远征》—— 英雄的牺牲与悬念

**一句话**：一位英雄从王国出发，穿越森林、瀑布、沼泽、沙漠，攀越高山，抵达黑龙巢穴营救公主；最终与黑龙同归于尽坠崖，尾声英雄浮在河上手指微动——他还活着。

**三幕结构**：
- **第一幕（Seg1-2，0:00-1:00）出发与征程**：英雄从王国出发，飞龙视角展示宏大世界，穿越黑暗森林斩杀巨狼，越过瀑布，在沼泽斩杀巨蛇，跋涉沙漠，远处出现高山。
- **第二幕（Seg3，1:00-1:30）攀山与发现**：英雄攀爬险峻雪山，到达龙穴，发现沉睡的黑龙和被囚禁的公主，英雄拔剑冲向黑龙，黑龙惊醒咆哮，双方对峙。
- **第三幕（Seg4，1:30-2:00）决战与尾声**：史诗战斗，英雄刺中黑龙要害，黑龙抓住英雄一起坠崖，黑场。尾声英雄浮在河上，手指微动——他还活着。留悬念。

**主题**：英雄的孤独与牺牲、命运的无常、营救与爱情、自然的严酷。

**情绪曲线**：庄严（出发）→ 紧张（征程）→ 恐惧（龙穴）→ 高潮（决战）→ 静默（坠崖）→ 悬念（尾声）。
