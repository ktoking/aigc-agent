# 故事记忆（Story Memory）

## 世界观
中世纪欧洲风格的奇幻世界，有王国、城堡、骑士、怪物、巨龙、魔法（极少量，主要是龙的存在）。荷马史诗式的英雄叙事，英雄独自踏上征程，穿越险恶地形，最终与巨龙同归于尽。

## 核心主题
- **英雄的孤独与牺牲**：英雄独自踏上征程，无人陪伴，最终与巨龙同归于尽
- **命运的无常**：英雄看似牺牲，但尾声手指微动，留下他还活着的悬念
- **营救与爱情**：英雄为营救公主而远征，但全片无对白，情感通过动作和眼神表达
- **自然的严酷**：森林、瀑布、沼泽、沙漠、高山——每一段地形都是考验

## 角色
### 英雄（HERO）
约28岁，高大健壮，王国骑士，沉默坚毅，左颊旧疤，暗灰链甲皮甲，深灰披风，磨损钢剑。全片无对白。

### 公主（PRINCESS）
约22岁，纤细优雅，浅金色长发，蓝色眼睛，被黑龙掳走囚禁在龙穴，穿着肮脏撕裂的深蓝色丝绒礼服，手腕戴铁链。

### 黑龙（BLACK_DRAGON）
古老的黑色巨龙，深黑色鳞片，弯曲黑犄角，红色眼睛，巨大蝙蝠状翅膀，盘踞在高山龙穴的宝藏上，掳走公主。

## 旅程路线
王国城堡 → 黑暗森林（遇巨狼）→ 瀑布 → 沼泽（遇巨蛇）→ 沙漠 → 攀越高山 → 黑龙巢穴 → 决战坠崖 → 河流尾声

## 关键符号
- **剑**：英雄的武器和意志，最终刺入黑龙要害
- **披风**：英雄的标志，在风中飘动，最终破烂不堪
- **铁链**：公主的囚禁，象征束缚
- **龙的红色眼睛**：邪恶和威胁的象征
- **河流**：净化、重生、悬念——英雄浮在河上，手指微动
- **白骨**：龙穴中前人的失败，暗示英雄的命运
