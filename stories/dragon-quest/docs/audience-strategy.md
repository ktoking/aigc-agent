# 受众策略（Audience Strategy）

## 目标受众
- **核心受众**：18-35岁，喜欢奇幻、史诗、中世纪、龙与骑士题材的观众
- **扩展受众**：指环王/权力的游戏粉丝、荷马史诗爱好者、MV式短视频爱好者、无对白视觉叙事爱好者
- **平台**：抖音/B站/YouTube Shorts，适合2分钟横屏电影感短片

## 内容定位
- **类型标签**：奇幻史诗 / 中世纪 / 龙与骑士 / 无对白视觉叙事 / BGM卡点 / MV式电影短片 / 荷马史诗
- **情绪标签**：庄严、紧张、恐惧、高潮、静默、悬念、悲壮
- **差异化**：全片无对白，全靠画面和音乐叙事；英雄与龙同归于尽的悲壮结局；尾声手指微动的悬念钩子；飞龙第一人称视角展示宏大世界观

## 发布策略
- **标题方向**：
  - 《他独自穿越半个世界去救公主，最后和龙一起坠下悬崖》
  - 《无对白｜2分钟看完一位英雄的远征，最后一个镜头我鸡皮疙瘩起来了》
  - 《他以为自己牺牲了，但河水里的手指动了一下》
- **封面**：Seg3 龙穴对峙画面（英雄拔剑指向黑龙，公主在角落，低角度仰拍）
- **标签**：#奇幻 #史诗 #中世纪 #龙与骑士 #无对白 #BGM卡点 #微电影 #荷马史诗 #指环王风 #权力的游戏风
- **评论引导**："你觉得英雄最后活下来了吗？他会回去找公主吗？"

## 音乐策略
- 4段式原创配乐：史诗管弦乐开场 → 节奏加快冒险 → 紧张弦乐对峙 → 全乐队高潮决战→坠崖静默→尾声留白悬念
- 战斗卡点BGM鼓点，增强MV式节奏感
- 坠崖时BGM渐弱到几乎无声，只有风声
- 尾声BGM极弱或无声，只有水流声，手指微动时留悬念
- 保留关键音效（剑击、龙咆哮、火焰、坠崖风声、水流声），不被BGM覆盖
