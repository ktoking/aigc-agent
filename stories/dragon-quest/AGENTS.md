# dragon-quest 剧本专属规则

本文件是 `stories/dragon-quest/` 的最高优先级规则，与仓库根 AGENTS.md 冲突时以本文件为准。

## 项目一句话

《黑龙远征 / Dragon Quest》——2 分钟无对白荷马史诗式奇幻微电影：一位英雄从王国出发，穿越森林、瀑布、沼泽、沙漠，攀越高山，抵达黑龙巢穴营救公主；最终与黑龙同归于尽坠崖，尾声英雄浮在河上手指微动——他还活着。

## 硬约束

1. **全程无对白、无旁白、无字幕**。叙事全靠画面、动作、表情、环境、音乐。
2. **总时长 120 秒**，4 段 × 30 秒，16:9 横屏。
3. **12 个镜头**，按段分配：Seg1=L01-03 / Seg2=L04-06 / Seg3=L07-09 / Seg4=L10-12。
4. **视频模型**：Seedance 2.5（30s/段），图生视频优先。
5. **全片统一视觉体系**：见 `assets/style/global-style.md`（总控前缀）与 `assets/style/negative-prompts.md`（负面约束）。**每条视频提示词必须同时携带这两组约束。**
6. **风格基线**：阴天自然光、柔和漫射光、中性色温、写实摄影、中世纪欧洲奇幻、荷马史诗质感。**禁止金黄色/暖橙色调、禁止黄金时刻、禁止镜头光晕。**
7. **一致性锚点**：英雄、公主、黑龙必须严格符合 `assets/characters/` 中的设定卡；禁止在提示词中自由改写外观。
8. **旅程路线固定**：王国城堡 → 黑暗森林 → 瀑布 → 沼泽 → 沙漠 → 攀越高山 → 黑龙巢穴 → 坠崖 → 河流尾声。顺序不可调换。
9. **飞龙视角穿插**：Seg1 和 Seg2 各穿插一次飞龙第一人称俯瞰视角，展示宏大世界观，作为场景过渡。
10. **尾声钩子**：Seg4 末尾英雄浮在河上，手指微动，留悬念。必须有这个镜头。

## 生产流程（P0-P6）

P0 骨架 → P1 核心资产定锚 → P2 首尾帧 → P3 视频生成 → P4 后处理（去水印/动态转场/拼接）→ P5 配乐 → P6 合成交付。

每阶段产出、验收口径见 `docs/workflow.md`。
