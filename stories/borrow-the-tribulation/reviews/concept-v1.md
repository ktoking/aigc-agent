## 画风判断

写实国风CG，理想化人物面容，黑银甲胄，冷灰云海与暖色逆光，悬崖仙宫；蓝色剑气、金色阵法与暗红兵器可承担不同的视觉功能。参考图为风格与可选角色依据，不视为既定人物关系。

## 三个方向

1. 《师父，请渡劫》：师父借弟子替自己承受雷劫；男主与被锁在阵中的师姐联手破阵，让师父独自面对最后一道天雷。侧重师徒背叛、破阵与反击。
2. 《借一场天劫》：被高阶修士追杀的剑修，将对方诱入自己预先布下的封谷阵，再主动突破境界；依照本故事预先交代的规则，劫区内动用法力者会引来对应境界的雷劫。他以受伤为代价撑过自己的雷劫，追杀者死于更强的天雷，封阵随之解除。侧重设局与越级反杀。
3. 《师姐最后一剑》：白发师姐被宗门认定入魔，师弟奉命行刑；交锋中，她用仅存的一次清醒把师弟的剑引向自己背后的寄生魔物。魔物死去，她失去修为、保住性命，师弟折断行刑令，带她离山。侧重误判、关系与联手求生；若选此题，正式稿须提前用影子不同步、攻击方向等可见线索铺垫寄生关系。

## 推荐：《师父，请渡劫》

角色：黑衣青年剑修；白发师姐；持剑长者师父。黑发女修参考可留作女主外形备选，不强行加入第四位主角。
地点：云海上的渡劫台及相连石桥，同一组场景。核心规则：铜制阵眼将雷劫经金色锁链转嫁给弟子；斩断锁链后，铜环会使其重生；毁掉铜环才能解除替劫阵。

| 估计时间 | 剧情与画面 |
| --- | --- |
| 0–10秒 | 第一道天雷劈下，师父毫发无伤；雷光沿金链击中跪在台边的师姐，她的一缕黑发变白。男主拔剑斩向锁链。 |
| 10–25秒 | 锁链断开，又从师父脚下的铜环重新长出。男主转而刺向铜环，被师父一剑挡回。两人的目标由动作说明。 |
| 25–40秒 | 师父将男主逼向窄桥，封住返回渡劫台的路；师姐被锁链拖向阵心。下一道雷正在云中汇聚。 |
| 40–65秒 | 男主尝试抢攻铜环，两次被拦；近身剑斗逐步把他逼至桥缘。他的剑被击出缺口，肩膀受伤。 |
| 65–85秒 | 师姐拉紧金链，将铜环从师父脚边拖偏；她的手臂被雷光灼伤。男主借这一瞬重新冲回台上。 |
| 85–105秒 | 天雷落下，师父抬剑抵御；男主放弃格挡，受伤后仍贴地滑入阵心，把缺口长剑刺入铜环接缝并压断。此前已显示铜环由多片拼接，接缝可见。 |
| 105–115秒 | 铜环破碎，金链消散。失去替劫阵的师父独自承受余下天雷，护身剑碎裂，身影被雷光吞没。 |
| 115–120秒 | 雷云散开。男主拾起半截剑，扶师姐走下石桥。渡劫台留在身后，故事收束。 |

制作方向建议：16:9，约18–24个镜头，环境和人物关系镜头与短促动作镜头交替；实际时长需按正式分镜与声音调整。本提案为动态短片方向，未采用静帧成片合同，也未提交生成任务。
