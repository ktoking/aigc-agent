# 镜头语言（Camera Language）

## 整体风格

史诗奇幻电影质感，镜头运动沉稳有力，配合 BGM 节奏卡点。锻造场景用低角度和特写突出力量感，闪回场景用慢动作和柔光突出史诗感，结尾用广角和远景突出庄严神圣。

## 镜头运动

| 类型 | 用途 |
|---|---|
| 缓慢推镜（slow push-in） | 开场、锻造专注时刻、圣剑完成时刻 |
| 低角度仰拍（low angle） | 锤击、女铁匠力量感、圣剑举起 |
| 特写（close-up） | 锤击瞬间、火星、汗水、铁锭变形、剑身符文 |
| 慢动作（slow motion） | 锤击火星、淬火蒸汽、圣剑金光爆发、插入石中 |
| 手持微晃（handheld） | 锻造过程中的紧张感、闪回战场 |
| 环绕运镜（orbit） | 圣剑完成时的 360° 展示 |
| 远景/广角（wide shot） | 洞穴全景、结尾女铁匠走入晨光 |
| 剪影（silhouette） | 女铁匠在火光前的轮廓、结尾走入晨光 |

## 剪辑节奏（配合 BGM）

- **Seg1（0-30s，低频鼓点）**：慢节奏，长镜头+特写交替，建立氛围
- **Seg2（30-60s，节奏加快）**：中速剪辑，锤击镜头卡点，闪回插入
- **Seg3（60-90s，全乐队高潮）**：快节奏剪辑，锤击+火星+金光爆发，慢动作与快切交替
- **Seg4（90-120s，庄严收束）**：慢节奏，长镜头，广角远景，仪式感

## 转场

- 硬切：用于锤击节奏卡点
- 闪白/火光过渡：用于现实锻造与闪回之间的切换
- 交叉淡化（dissolve）：用于情绪过渡
- 匹配剪辑（match cut）：锤击动作匹配闪回中的剑击动作
- 黑场（fade to black）：用于段落之间的重大转折

## 禁止

- 不要快速抖动的手持（除非闪回战场）
- 不要无人机式的航拍俯瞰
- 不要过度使用鱼眼或广角畸变
- 不要镜头运动与 BGM 节奏脱节
