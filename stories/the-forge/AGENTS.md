# the-forge 剧本专属规则

本文件是 `stories/the-forge/` 的最高优先级规则，与仓库根 AGENTS.md 冲突时以本文件为准。

## 项目一句话

《铸剑 / The Forge》——2 分钟无对白奇幻史诗微电影：一位女铁匠在火山口熔炉边，锻造一把传说中的圣剑；锤起锤落间，剑的未来命运交织闪现；最终她将剑插入石中，等待命中注定的人。

## 硬约束

1. **全程无对白、无旁白、无字幕**。叙事全靠画面、动作、眼神、火光、金属声、音乐。
2. **总时长 120 秒**，4 段 × 30 秒，16:9 横屏。
3. **12 个镜头**，按段分配：Seg1=L01-03 / Seg2=L04-06 / Seg3=L07-09 / Seg4=L10-12。
4. **视频模型**：Seedance 2.5（30s/段），图生视频优先以核心资产图为参考，保证角色一致性。
5. **全片统一视觉体系**：见 `assets/style/global-style.md`（总控前缀）与 `assets/style/negative-prompts.md`（负面约束）。**每条视频提示词必须同时携带这两组约束。**
6. **一致性锚点**：女铁匠、圣剑、火山熔炉必须严格符合 `assets/characters/`、`assets/props/`、`assets/scenes/` 中的设定卡；禁止在提示词中自由改写外观。
7. **资产目录**：设定图、首尾帧、风格锚点统一放 `assets/` 与各 segment 的 `frames/`；成片与中间视频放 `output/`。
8. **音效原则**：锤击、金属、淬火蒸汽、火山轰鸣、风声由 Seedance 音画同步直接输出；后期配乐按 `docs/workflow.md` P5 阶段 4 段式谱曲，不得覆盖关键音效。

## 生产流程（P0-P6）

P0 骨架 → P1 核心资产定锚 → P2 首尾帧 → P3 视频生成 → P4 后处理（去水印/动态转场/拼接）→ P5 配乐 → P6 合成交付。

每阶段产出、验收口径见 `docs/workflow.md`。

## 提交与生成隔离

沿用仓库根 AGENTS.md：不接 Skynet 统计；git commit/push 一律 `--no-verify`；不启用任何 git hook。
