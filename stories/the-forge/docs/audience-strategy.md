# 受众策略（Audience Strategy）

## 目标受众

- **核心受众**：18-35 岁，喜欢奇幻、史诗、电影感短视频的观众
- **扩展受众**：指环王/权力的游戏粉丝、铁匠/手工艺爱好者、MV 式短视频爱好者
- **平台**：抖音/B站/YouTube Shorts，适合 2 分钟竖屏或横屏电影感短片

## 内容定位

- **类型标签**：奇幻史诗 / 无对白视觉叙事 / BGM 卡点 / MV 式电影短片 / 工匠精神
- **情绪标签**：庄严、震撼、敬畏、温暖、希望、传承
- **差异化**：没有对白，全靠画面和音乐叙事；锻造过程的真实质感；圣剑诞生的视觉高潮；石中剑的经典意象再创作

## 发布策略

- **标题方向**：
  - 《她用一生锻造了一把圣剑，然后插进了石头里》
  - 《火山口的女铁匠，2 分钟看完一把圣剑的诞生》
  - 《无对白｜当圣剑发出金光的那一刻，我鸡皮疙瘩起来了》
- **封面**：Seg3 圣剑金光爆发画面（女铁匠双手持剑，金色光芒照亮洞穴）
- **标签**：#奇幻 #史诗 #圣剑 #锻造 #无对白 #BGM卡点 #微电影 #工匠精神 #指环王风
- **评论引导**："如果你拔出这把圣剑，第一件事会做什么？"

## 音乐策略

- 4 段式原创配乐：低频鼓点开场 → 节奏加快锻造 → 全乐队高潮圣剑诞生 → 庄严弦乐收束
- 锤击卡点 BGM 鼓点，增强 MV 式节奏感
- 段间加交叉淡化过渡，避免硬切
- 保留关键音效（锤击、淬火、金属摩擦），不被 BGM 覆盖
