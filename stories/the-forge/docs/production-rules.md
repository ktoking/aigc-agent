# 生产规则（Production Rules）

## 提示词三件套规则

每条视频提示词必须包含：
1. **总控前缀**：`assets/style/global-style.md` 中的完整风格描述（整段复制）
2. **一致性锁定**：角色/道具/场景的外观描述（从设定卡中提取）
3. **负面约束**：`assets/style/negative-prompts.md` 中的完整负面描述（整段复制）

## 镜头叙事规则

1. **无对白**：全片无任何对白、旁白、字幕、可读文字
2. **动作叙事**：所有叙事通过动作、表情、火光、金属、音乐传达
3. **闪回处理**：Seg2 中的未来闪回画面使用柔光、慢动作、剪影/模糊处理，与现实锻造场景的硬光、实焦形成对比
4. **匹配剪辑**：锤击动作匹配闪回中的剑击动作，形成视觉呼应
5. **金光规则**：只有圣剑能发出金色光芒，其他物体禁止金色高饱和

## 音乐驱动剪辑规则

1. **锤击卡点**：Seg1-3 中的锤击镜头必须卡 BGM 的鼓点
2. **段落转折**：4 个 segment 的转折点对应 BGM 的 4 个段落变化
3. **高潮爆发**：Seg3 的圣剑金光爆发对应 BGM 全乐队高潮
4. **收束节奏**：Seg4 放慢节奏，对应 BGM 的庄严收束
5. **转场卡点**：段间转场（硬切/闪白/dissolve）卡 BGM 节拍

## 一致性规则

1. **女铁匠外观**：所有镜头中女铁匠的服装、疤痕、发型、道具必须一致
2. **圣剑外观**：成品圣剑的形状、剑格、符文、柄首必须一致；锻造过程中按阶段变化
3. **熔炉场景**：熔炉、铁砧、淬火槽、磨石的位置关系固定
4. **光源方向**：主光源始终来自熔炉（画面下方/侧方），禁止光源方向漂移
5. **色彩体系**：橙红火焰 + 深蓝黑阴影 + 金色圣剑光，禁止其他高饱和色

## 音效规则

1. **锤击声**：每一次锤击都有清晰的金属铿锵声，卡 BGM 鼓点
2. **淬火声**：淬火时蒸汽嘶嘶声，音量突出
3. **火山轰鸣**：背景中持续的低沉熔岩轰鸣声
4. **金属摩擦**：打磨、刻纹时的金属摩擦声
5. **禁止**：禁止任何人声、台词、歌词、旁白
