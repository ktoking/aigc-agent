# 故事记忆（Story Memory）

## 世界观

一个古老的奇幻世界，火山口深处藏着传说中的圣剑锻造炉。只有被选中的铁匠才能在此锻造出圣剑。每一把圣剑都将选择自己的主人，改变世界的命运。

## 核心主题

- **创造与传承**：女铁匠创造了圣剑，但她不是剑的主人——她将剑留给命中注定的人
- **工匠的尊严**：锻造是神圣的仪式，每一次锤击都充满力量和专注
- **命运的交织**：锻造过程中闪现的未来画面，暗示这把剑将在未来的战场和加冕中发挥作用
- **牺牲与希望**：女铁匠倾尽一生完成这把剑，然后默默离开，把希望留给未来

## 角色

### 女铁匠（BLACKSMITH）
- 约 35 岁，最后一位圣剑锻造师
- 沉默坚毅，全片无对白
- 手臂有旧烫伤疤痕，左眉有旧疤
- 对锻造充满神圣的仪式感

### 圣剑（LEGENDARY_SWORD）
- 传说中的圣剑，全片核心道具
- 从铁锭到成品的锻造过程是主线
- 锻造完成时发出金色神圣光芒
- 最终插入石中，等待命中注定的人

### 闪回中的未来角色（不出现在现实场景）
- 持剑战斗的英雄（剪影/模糊）
- 加冕典礼上的王者（剪影/模糊）
- 这些闪回暗示圣剑的未来命运，但不展示具体人物

## 时间线

- **现实时间**：女铁匠完成圣剑锻造的最后阶段（约几小时浓缩为 2 分钟）
- **闪回时间**：圣剑锻造完成后在未来的命运（战场、加冕），以碎片化画面闪现

## 关键符号

- **锤击**：创造、力量、仪式
- **火星**：灵感、希望、生命
- **淬火蒸汽**：蜕变、重生
- **金色光芒**：神圣、命运、希望
- **石中剑**：传承、等待、命运的选择
- **女铁匠走入晨光**：完成、牺牲、希望的传递
