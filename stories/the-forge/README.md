# 铸剑 / The Forge

> 火山口熔炉边，一位女铁匠倾尽一生锻造一把传说中的圣剑。锤起锤落间，剑的未来命运交织闪现——战场、加冕、英雄。最后一锤，地动山摇，圣剑诞生。她将剑插入石中，转身走入晨光，身后的剑静静等待命中注定的人。
