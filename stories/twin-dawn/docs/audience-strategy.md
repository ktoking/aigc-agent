# Twin Dawn 受众与发布策略

## 目标观众

- 喜欢末日重生、强女主、双女主羁绊、囤货爽文、异能升级和反派打脸的短剧用户。
- 偏好“主角提前知道未来”“别人慌乱我已布局”“保护重要的人”“隐藏反派露出破绽”的情绪结构。
- 适合抖音竖屏自动播放场景：开头必须一眼看懂危险或反常，不能靠长旁白进入。

## 情绪卖点

- 爽：重生后提前布局、囤货、空间异能、反派信息差。
- 急：末日倒计时、病毒爆发、黑车跟踪、顾景辰察觉异常。
- 心疼：林晚前世牺牲、沈清雪不知真相但愿意相信。
- 燃：双女主并肩觉醒、异能联手、基地防守。
- 恨：顾景辰表面温和实则控制和利用。

## 开头钩子库

| 钩子类型 | 本剧用法 | 示例 |
| --- | --- | --- |
| 时间钩子 | 末日倒计时、手机日期、停电倒数 | “距离病毒爆发，还有 30 天。” |
| 身份反差 | 林晚从濒死者变成提前布局者 | 林晚冷静划掉顾景辰消息 |
| 危险逼近 | 黑车、监控、未知来电、尸潮 | 反光里有人举起手机偷拍 |
| 关系冲突 | 沈清雪不信，林晚必须保护她 | “跟我走，世界要毁灭了。” |
| 信息差 | 林晚知道未来，反派不知道她重生 | 顾景辰看到采购记录却不知空间异能 |

## 标题模板

- 重生第 X 天，我先做了所有人不敢做的事
- 闺蜜不信末日，我当场预言下一秒
- 他以为我还爱他，其实我已经知道真相
- 别人逃命时，我的仓库已经装满了
- 末日前 30 天，我找回了唯一能救我的人

## 封面策略

- 封面主体：林晚冷静特写、沈清雪震惊表情、蓝色空间裂痕、手机倒计时、黑车偷拍。
- 封面大字：突出“重生”“末日前30天”“她不该知道”“跟我走”“空间觉醒”。
- 色彩：末日前偏都市冷白/蓝光，末日后冷灰蓝加警报红。
- 禁止：过度血腥、丧尸脸特写、游戏 UI、动漫化、廉价网红滤镜。
