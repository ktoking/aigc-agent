# EP001 Segment 01 3D 锁定风格资产 V3

本目录是基于用户上传参考图重做的 3D 非真人角色锁定版本。生成策略调整为：先生成角色 24 格标准图，再生成首尾帧和故事板镜头图。

## 角色锁定标准

### 林晚

- 参考基准：用户上传图左侧女主。
- 必须保持：极长黑直发、冷感细长脸、黑色破损战术夹克、淡蓝色空间能量。
- 痣位 QA：林晚脸上只允许有一颗小黑痣，位置为角色自己的左眼下方偏外侧。禁止雀斑、多颗痣、额头痣、右眼下痣。
- 当前风险：模型仍可能把痣画成多个点，生成视频前必须肉眼检查。

### 沈清雪

- 参考基准：用户上传图右侧女主，但更甜美可爱。
- 必须保持：短发空气刘海、柔和少女脸、白色未来战术服、无痣、温柔但坚定。
