# 霓虹镇妖师 故事包说明

## 故事范围

本目录维护《霓虹镇妖师》的所有非通用规则。生成剧情、分镜、首尾帧、视频 prompt、角色资产或连续性文件时，必须优先遵循本目录规则。

## 必读顺序

1. `docs/story-memory.md`
2. `docs/production-rules.md`
3. `docs/audience-strategy.md`
4. `docs/season-arc.md`
5. `docs/workflow.md`
6. `assets/` 下角色、场景、道具、风格资产

## 本剧本核心锁定

- 主角锁：沈曜，23 岁，短黑发挑一缕银蓝发束，黑色机能外卖夹克，红色电子符咒腰包。
- 搭档锁：九尾狐灵“阿绯”，半透明霓虹火狐，不是宠物狗，不是写实动物。
- 世界规则锁：午夜异常订单是妖物入侵城市系统的入口；订单备注是规则提示。
- 视觉风格锁：冷蓝赛博雨夜 + 朱红符火 + 半透明狐尾光。
- 禁止偏差：不要变成传统古装仙侠；不要把符咒做成复杂游戏 UI；不要长篇旁白解释。
