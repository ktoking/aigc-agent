# 霓虹镇妖师 长线剧情规划

## 总主线

沈曜通过一单单午夜异常订单封住城市里的妖物，同时寻找失踪哥哥。每个订单都像单元怪谈，但线索都指向同一个系统：灵网调度。前期是外卖规则怪谈，中期揭露平台、门禁、监控和导航都被妖物寄生，后期沈曜发现哥哥不是被妖抓走，而是主动进入灵网，试图从内部关闭妖城。
