# 霓虹镇妖师 故事记忆

## 项目定位

- Story ID：`neon-exorcist`
- 类型：赛博都市志怪 / 外卖员镇妖 / 都市规则怪谈。
- 目标平台：抖音 / 快手 / 视频号。

## 世界观

近未来山城被“灵网”覆盖。城市的监控、电梯、导航、外卖平台和门禁系统里开始出现古老妖物的影子。普通人看到的是故障，镇妖师看到的是“妖物借数据成形”。午夜 00:00 后，平台会派发异常订单：地址不存在、收件人已死亡、备注违反常识。订单必须完成或取消，拖延会让妖物获得真实身体。

## 核心故事

沈曜是全城评分最高的夜班外卖员，也是失踪镇妖师家族最后的继承人。她用电动车、路线规划、电子符咒和狐灵阿绯处理午夜异常订单。每一集都是一单看似普通、实则危险的配送：鬼楼奶茶、没有 13 层的电梯、重复下单的死人、会说话的导航。她一边攒钱还债，一边寻找失踪哥哥留下的异常账号。长线真相是：外卖平台的“灵网调度系统”正在把妖物和人类欲望配对，制造一座永不休眠的妖城。
