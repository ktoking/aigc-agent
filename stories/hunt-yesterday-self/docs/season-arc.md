# 《猎杀昨日的我》第一季规划

| 集数 | 核心动作 | 新证据 | 结尾问题 |
| --- | --- | --- | --- |
| EP001 | 救下少年 | 少年衰老、猎手同眼、六块旧表 | 前六人是谁？ |
| EP002 | 追查旧表主人 | 每块表都对应一次“获救”事故 | 米拉为何没有记忆？ |
| EP003 | 城市追捕米拉 | 猎手替米拉挡下市民攻击 | 猎手为何保护她？ |
| EP004 | 潜入时间档案库 | 米拉每次事故后都更年轻 | 她真实年龄是多少？ |
| EP005 | 居民围猎怀表 | 众人惧怕的是米拉而非猎手 | 谁制造了怀表？ |
| EP006 | 米拉杀死猎手 | 猎手记忆进入米拉 | 她会成为猎手吗？ |
| EP007 | 重走失败循环 | 猎手曾多次回来劝阻自己 | 为什么每次都失败？ |
| EP008 | 毁掉全部怀表 | 被偷寿命开始反噬米拉 | 她愿意归还生命吗？ |

## 季终选择

米拉毁掉全部怀表，身体迅速老化；她没有死，而是以真实年龄醒来。城市黑雨第一次落向地面，但远处另一座钟城开始逆雨。
