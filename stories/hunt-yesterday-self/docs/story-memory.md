# 《猎杀昨日的我》故事记忆

## 一句话

失忆少女米拉在黑雨钟城被未来的自己追杀；她以为怀表能倒流时间救人，后来发现每次“逆转”都在夺走被救者的余生。

## 观众必须先相信的误解

- 米拉是无辜受害者。
- 无面猎手想杀死她。
- 怀表能够逆转时间。
- 米拉成功救下了灾难中的人。

## 最终真相

- 猎手从未想杀米拉，只想阻止她继续使用怀表。
- 怀表用别人的余生覆盖灾难结果，因此看起来像时间倒流。
- 每次按下表冠都会触发一次“代价脉冲”：获救者在按表后的瞬间迅速衰老一段，米拉则恢复、年轻或避开死亡；脉冲结束后不会持续抽取寿命。
- 猎手是经历过无数次掠夺后回来的未来米拉。
- EP001 结束时，米拉发现自己已有六块旧怀表，证明这不是第一次。

## 世界规则

### 黑雨

- 雨滴由地面升向天空。
- 黑雨会显露时间债务：年轻人的倒影变老、伤口逆向闭合、寿命光丝可见。
- 黑雨本身不改变时间。

### 寿命怀表

- 每块表对应一个被夺取寿命的人。
- 按下表冠后，灾难结果被他人的余生覆盖，局部现实会出现精致的“倒带”表象：碎片回到断口、雨滴反走、车轮火花倒卷、撞击凹陷短暂复原。
- 代价只在按表瞬间结算一次：被救者快速衰老一段，米拉恢复、年轻或避开死亡；没有再次按表时，被救者年龄保持当前状态，不持续老化。
- 冷青光丝从被救者流入怀表，是最重要的真相证据；光丝是代价脉冲和残余连接的视觉化，不是持续吸血管。
- 怀表破碎后，被窃取的时间不能自动归还。

### 未来猎手

- 能预测米拉的动作，因为这些动作她曾经做过。
- 时间刃只切断寿命光丝和怀表连接。
- 不能直接杀死过去的自己。
- 唯一目标是让过去的米拉主动毁表。

## 主要角色

### 米拉 `HYS_MIRA_001`

- 表面年龄 17 岁，短黑发，暗色不对称短风衣，旧铜耳坠，右眼冷青。
- 求生敏捷，擅长借高架、齿轮、缆索和列车碎片移动。
- 习惯左手先护住怀表，右手抓取支点。
- 初始欲望：逃出去、找回记忆。
- 核心恐惧：自己才是灾难。

### 无面猎手 `HYS_HUNTER_001`

- 高挑女性轮廓，黑色长风衣，裂纹无表情面具，细长时间刃。
- 与米拉同样的右眼、旧铜耳坠和左手起势。
- 战斗克制精准，不做炫技式乱砍。

### 钟楼少年 `HYS_BOY_001`

- 12 岁，旧校服与红围巾。
- EP001 被米拉从列车前救下，因两次按表分别发生两次年龄跃迁，最终在 45 秒内衰老六十年。
- 他的衰老是本集的可视化证据：每次变老都必须紧贴一次按表动作，而不是持续匀速倒计时。

## 情绪引擎

追杀紧张 -> 救人爽点 -> 异常不安 -> 动作误判 -> 身份震惊 -> 道德选择 -> 更大悬念。

## 长线问题

- 前六块怀表分别属于谁？
- 未来猎手已失败过多少次？
- 毁掉全部怀表后，米拉会失去多少被偷来的生命？
- 米拉能否不再成为下一位猎手？
