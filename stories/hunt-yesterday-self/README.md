# 猎杀昨日的我

## 项目定位

- Story ID：`hunt-yesterday-self`
- 类型：暗黑架空 / 时间悬疑 / 日系战斗 / 身份对决
- 形式：9:16 竖屏 AI 漫剧
- 默认单集：60 秒，4 段，每段 15 秒以内
- 叙事：无对白优先，以动作、道具和视觉因果讲故事
- 核心卖点：少女以为怀表能倒流时间救人，实际每次“逆转”都在夺走被救者的寿命；追杀她的人是回来阻止她的未来自己。

## 关键文件

- `docs/story-memory.md`：世界规则、人物、反转和长线伏笔。
- `docs/production-rules.md`：角色锁、无对白规则、视觉和画质约束。
- `docs/season-arc.md`：第一季 8 集递进。
- `episodes/EP001_saved-boy-aged/`：完整 60 秒首集生产包。

## 生产顺序

故事规则 -> 角色/场景/道具资产 -> 单集连续性 -> 四段分镜 -> 首尾帧 -> 视频。
