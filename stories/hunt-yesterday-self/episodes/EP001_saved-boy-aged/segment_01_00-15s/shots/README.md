# Segment 01 Mini Shot Plan

## 目的

将原 `segment_01_00-15s` 拆成 3 个 5 秒 mini 小样，先验证动作逻辑和镜头衔接，再决定是否合成 15 秒正片或用更高质量模型重制。

## 官方案例结构约束

- 参考官方 curl 写法：按输入顺序写“参考图1/2/3”，每张图只负责一个主要约束。
- 文本负责动作、运镜、时间轴、声音；参考图负责身份、构图、场景或道具。
- 不上传带文字、编号、二维码、表格的故事板图。
- 动作大戏采用“动作 / 受力点 / 路径 / 运镜 / 构图 / 特效 / 声音 / 禁止项”拆解。

## 拆分

| 小样 | 时间 | 任务 | 衔接 |
| --- | --- | --- | --- |
| `shot_01A_00-05s` | 0-5s | 追逐、切链、撞栏失衡 | 使用原首帧开始；输出尾帧作为 01B 首帧 |
| `shot_01B_05-10s` | 5-10s | 翻转下坠、擦梁、落地、看到少年和列车 | 使用 01A 尾帧开始；输出尾帧作为 01C 首帧 |
| `shot_01C_10-15s` | 10-15s | 按表、事故路径倒序回溯、扑救、寿命代价 | 使用 01B 尾帧开始；输出尾帧对齐原 segment 尾帧 |

## 提交策略

默认只 dry-run。正式生成时从 `shot_01A` 开始，一次只提交一个 5 秒小样。通过人工审片后，将 `output/last-frame-generated.png` 复制或作为下一小样首帧参考。
