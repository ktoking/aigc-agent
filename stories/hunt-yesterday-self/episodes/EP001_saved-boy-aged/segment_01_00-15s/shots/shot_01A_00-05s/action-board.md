# Shot 01A Action Board

## 任务

5 秒内建立追杀压迫，并让观众看懂“猎手切断表链 -> 米拉抓表 -> 撞栏失衡”。本小样不下坠到轨道，不出现少年，不出现时间回溯。

## 动作设计

- 动作：米拉沿湿滑高架冲向镜头，猎手从高处落后追击，低位横切表链。
- 受力点：刀只命中表链；断链怀表向外甩，米拉左手抓住怀表，左肩和右肩被惯性带向护栏。
- 路径：米拉从高架深处向镜头前下方跑，猎手从身后三米压近，最终米拉撞到右侧断裂护栏。
- 运镜：低机位后退跟拍 -> 表链近景 -> 斜侧中景看撞栏。
- 构图：前 2 秒必须让米拉、猎手、表链同处一个连续空间；切链瞬间刀尖、表链、米拉左手同框。
- 光线：冷青雨光打在刀锋和怀表铜边；断链处短促旧铜火星。
- 特效：水花被脚步甩开，刀风切开雨线，金属环向两侧弹开。

## 禁止项

- 不要让猎手刺中米拉身体。
- 不要让米拉悬空飞行。
- 不要出现少年、列车、轨道、时间回溯。
- 不要把三视图画成画中画或分格参考图。
