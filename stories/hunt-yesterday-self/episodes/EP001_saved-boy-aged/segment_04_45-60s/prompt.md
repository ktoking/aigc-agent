# Segment 04 视频 Prompt

## 规格

9:16，15 秒，情绪清晰，反转信息必须可读。

## 时间轴

- 0-3 秒：严格复现桥接首帧。猎手放低时间刃，轻微侧头让同款左耳耳坠与左手护表姿势可见；镜头慢拉开，老年少年站在两人之间的后方。
- 3-7 秒：镜头进入米拉左手的第七块表盘。表盘反光依次闪过六个极短因果片段：灾难结果被冷青覆盖、不同被救者迅速衰老、米拉的脸一次比一次年轻。只表现反光，不在现实空间提前出现六块表。
- 7-11 秒：回到稳定三人中景。老年少年用双手把第七块表推回米拉；猎手把刀柄朝向米拉递出。米拉先看少年，再看未来自己，接刀。
- 11-13 秒：米拉将第七块表放在齿轮平面，一刀劈裂表盘。猎手闭眼并化为稀疏冷青光尘。
- 13-15 秒：米拉拉开风衣，准确露出六块旧表，两列三枚；脚边第七块碎表芯重新跳动，进入最终尾帧。

## 声音与约束

无对白。低频钟鸣、表针、刀柄轻响、玻璃裂声。六块旧表只能在最后 3 秒出现，准确为六；第七块保持破裂并与六块旧表分离。不出现可读受害者面孔、文字或额外身份谜团。避免鱼鳞纹、网格、菱格绗缝、塑料皮肤、颗粒、锯齿、摩尔纹和过度锐化；使用平滑哑光表面和柔和光影过渡。
