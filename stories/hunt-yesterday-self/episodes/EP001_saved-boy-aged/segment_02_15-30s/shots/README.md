# Segment 02 Mini Shot Plan

## 目标

Segment02 不再做复杂大动作，重点是让观众看懂“救人的代价”和“猎手不是单纯追杀”。三条 5 秒小样按真实尾帧顺序衔接，避免同时硬压首尾帧造成跳变。

| 小样 | 时间 | 单一任务 | 衔接 |
| --- | --- | --- | --- |
| `shot_02A_15-20s` | 15-20s | 代价可见：少年状态稳定，残余寿命光丝从少年流向怀表 | 使用 Segment01/01C 尾帧开始 |
| `shot_02B_20-25s` | 20-25s | 猎手越过米拉，只切断残余光丝，不伤人 | 使用 02A 尾帧开始 |
| `shot_02C_25-30s` | 25-30s | 米拉误判护表，带少年后退，形成下一段反击起势 | 使用 02B 尾帧开始 |

## 经验约束

- 每条只做一个动作任务。
- 不再写“反向运动后立刻正向冲过来”这类高风险运动。
- 年龄变化只作为稳定状态展示，不在镜头中持续变老。
- 参考图最多 3-4 张，人物三视图只锁身份，不做动作参考。
- 不上传故事板表格图、编号图、二维码图。
