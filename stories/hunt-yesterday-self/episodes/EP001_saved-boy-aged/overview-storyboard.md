# EP001 60秒概述故事板

## 本集一句话

米拉救下少年后发现，所谓时间倒流其实正在夺走少年的余生，而追杀她的人是回来阻止她的未来自己。

## 总体节奏

2 秒异常 -> 5 秒危险 -> 15 秒救人 -> 25 秒代价 -> 38 秒规则 -> 45 秒身份 -> 57 秒选择 -> 60 秒新钩子。

## 总览表

| 时间 | 留存任务 | 画面 | 信息变化 |
| --- | --- | --- | --- |
| 0-5s | 停留 | 黑雨上升，猎手刺偏并斩链 | 猎手行为反常 |
| 5-15s | 爽点 | 米拉坠落按表，列车碎片逆向归位，救下少年 | 建立倒流误解 |
| 15-25s | 不安 | 少年衰老，寿命光丝流向怀表 | 救人有代价 |
| 25-38s | 动作 | 两人在齿轮间交锋，猎手只攻击怀表 | 猎手可能在阻止她 |
| 38-48s | 反转 | 面具碎裂，未来米拉出现，六次救人闪回 | 怀表窃取寿命 |
| 48-57s | 选择 | 老人推回怀表，米拉劈碎它 | 米拉主动停止 |
| 57-60s | 钩子 | 风衣内六块旧表亮起 | 这不是第一次 |

## 本集关键画面

- 上升的黑雨与断裂表链。
- 少年获救后皱纹爬上手背。
- 时间刃斩断冷青寿命光丝。
- 面具裂缝后的同色右眼。
- 六块旧表在风衣内同时走动。

## 本集关键对白

无对白。

## 本集生成总提示词

9:16 暗黑原创动画电影短片，架空工业钟城，黑雨逆流，煤黑、冷青、旧铜与克制血红。米拉、未来猎手、少年和怀表严格按资产卡锁定。动作清晰、每 3-5 秒信息升级，以寿命光丝方向和少年衰老讲清规则。避免鱼鳞纹、网格、塑料皮肤、颗粒和过度锐化。

## 检查清单

- [ ] 猎手第一刀明显刺偏。
- [ ] 少年衰老连续。
- [ ] 光丝方向正确。
- [ ] 身份揭示有右眼、耳坠、动作三证。
- [ ] 六块旧表只在最后出现。
