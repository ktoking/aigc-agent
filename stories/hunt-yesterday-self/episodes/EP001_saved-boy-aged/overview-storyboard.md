# EP001 60秒概述故事板

## 本集一句话

米拉救下少年后发现，所谓时间倒流其实正在夺走少年的余生，而追杀她的人是回来阻止她的未来自己。

## 总体节奏

2 秒世界异常 -> 5 秒猎手反常刺偏 -> 13 秒局部现实精致倒带完成“救人” -> 15 秒代价第一次瞬间结算 -> 29 秒猎手只斩残余连接 -> 39 秒米拉第二次按表导致少年第二次骤老 -> 45 秒猎手身份揭示 -> 54 秒米拉主动毁表 -> 60 秒六块旧表反咬。

## 总览表

| 时间 | 留存任务 | 画面 | 信息变化 |
| --- | --- | --- | --- |
| 0-5s | 停留 | 黑雨上升；猎手的刀越过米拉肩外，只斩表链 | “追杀者”为什么不杀她 |
| 5-13s | 爽点 | 米拉坠入下层轨道，按表后雨滴倒飞、碎片回拼、列车火花倒卷，撞击路径像时间倒流一样被覆盖 | 建立“她能倒流时间”的错误认知 |
| 13-20s | 不安 | 少年在按表结束瞬间手背老化，残余寿命光丝流向表盘，但年龄不再继续推进 | 救人的代价是一次性结算 |
| 20-29s | 判断翻转 | 猎手没有追击米拉，而是精确切断残余连接；少年年龄保持稳定 | 猎手像在阻止下一次使用怀表 |
| 29-39s | 错误升级 | 米拉为逃离坍塌踏板再次按表；踏板精致倒带复原，少年才第二次骤老 | 米拉每次“修复”都在夺命 |
| 39-45s | 身份反转 | 猎手击飞表而不伤人；米拉借齿轮反冲撞裂其右侧面具 | 猎手露出与米拉相同的右眼与脸 |
| 45-54s | 选择 | 表盘反光重演六次同类因果；老人把表推回，猎手递刀柄 | 真正敌人是米拉手里的表 |
| 54-60s | 钩子 | 米拉劈表，猎手消散；六块旧表从风衣内亮起，碎表芯重启 | 她此前已经夺走六个人的寿命 |

## 本集关键画面

- 上升的黑雨与断裂表链。
- 少年获救后皱纹爬上手背。
- 时间刃斩断第一次按表后的残余冷青寿命连接。
- 面具裂缝后的同色右眼。
- 六块旧表在风衣内同时走动。

## 本集关键对白

无对白。

9:16 暗黑原创动画电影短片，架空工业钟城，黑雨逆流，煤黑、冷青、旧铜与克制血红。米拉、未来猎手、少年和怀表严格按资产卡锁定。动作清晰、每 3-5 秒信息升级；时间回退特效要精致但局部，代价只在按表瞬间结算，以寿命光丝方向和少年两次年龄跃迁讲清规则。避免鱼鳞纹、网格、塑料皮肤、颗粒和过度锐化。

## 检查清单

- [ ] 猎手第一刀明显经过肩外，只切断表链。
- [ ] 米拉两次按表分别对应少年两次清晰衰老升级。
- [ ] 少年只在按表瞬间年龄跃迁，不在两次按表之间持续老化。
- [ ] 光丝始终从少年流向怀表。
- [ ] 身份揭示有右眼、耳坠、左手起势三证。
- [ ] 六块旧表只在最后 3 秒出现，数量准确为六。
