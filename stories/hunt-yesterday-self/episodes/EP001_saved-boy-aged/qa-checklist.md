# EP001 QA Checklist

## 剧情与留存

- [ ] 2 秒内出现逆流黑雨。
- [ ] 5 秒内出现猎手故意刺偏。
- [ ] 25 秒前少年开始衰老。
- [ ] 45 秒前揭示猎手身份。
- [ ] 60 秒以六块旧表结束。

## 连续性

- [ ] 米拉短发、右眼、耳坠和服装稳定。
- [ ] 少年红围巾与衰老阶段稳定。
- [ ] 怀表链断裂后不再恢复。
- [ ] 猎手刀锋只攻击光丝和怀表。

## 生成质量

- [ ] 无鱼鳞网纹。
- [ ] 无塑料皮肤。
- [ ] 无过度锐化和明显颗粒。
- [ ] 无文字、logo、水印。

## 交付

- [ ] 四段 docs 齐全。
- [ ] API 请求文件不含 key、签名 URL 或任务返回。
- [ ] 最终首尾帧尚未生成时不标记图片交付完成。
