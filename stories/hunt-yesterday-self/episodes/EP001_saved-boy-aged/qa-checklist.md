# EP001 QA Checklist

## 剧情与留存

- [x] 2 秒内出现逆流黑雨。
- [x] 5 秒内出现猎手故意刺偏并只斩表链。
- [x] 15 秒前少年完成第一次按表后的年龄跃迁。
- [x] 少年不会在第一次按表后持续老化；两次衰老都紧贴按表瞬间。
- [x] 米拉第二次按表后少年骤老至老年。
- [x] 45 秒前揭示猎手身份。
- [x] 60 秒以准确六块旧表结束。

## 连续性

- [x] 米拉短发、右眼、耳坠和服装稳定。
- [x] 少年红围巾与衰老阶段稳定。
- [x] 少年剧情帧无胸前吊坠或第二块怀表。
- [x] 怀表链断裂后不再恢复。
- [x] 猎手刀锋只攻击光丝、表链、怀表或撤退路线。
- [x] Segment 02/03/04 首帧分别与上一段尾帧同源复制。

## 生成质量

- [x] 无明显鱼鳞网纹或菱格绗缝。
- [x] 无明显塑料皮肤。
- [x] 无明显过度锐化、摩尔纹和颗粒。
- [x] 无文字、logo、水印。

## 交付

- [x] 四段 docs 齐全。
- [x] 8 张最终首尾帧落位。
- [x] 4 张段内故事板图落位。
- [x] API 请求文件不含 key、签名 URL 或任务返回。
- [ ] 视频尚未生成，不标记视频交付完成。
