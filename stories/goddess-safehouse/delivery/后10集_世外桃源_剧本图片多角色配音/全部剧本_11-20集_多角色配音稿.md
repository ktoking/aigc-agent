# EP011《只开这一次》

**陈屿旁白**

门锁弹开的那一瞬，许知意几乎倒进我怀里。夏凛抓住她的衣领往里一带，门外的铁栅栏猛地弯了下去。三道影子挤在灯光边缘，最前面那只，手掌已经搭上门框。

**夏凛**

进来了！关门！

**陈屿旁白**

门在我手里合拢。外面撞了一下，门板没有晃。那只灰白的手停在门槛外，指尖慢慢收紧。我确认入口防护还在，才把灯关掉。

**许知意**

你的手在流血。坐下，把手给我。

**陈屿旁白**

她自己还站不稳，已经从医疗箱里拿出了纱布。我扶她坐下，把箱子推近。裂开的白大褂下面，只有几道擦伤；那些血，多数是医院病人的。她给我包好手，手指才开始发抖。

**陈屿对白**

先喝水。这里没有你要守的医院。

**许知意**

我以为……赶不到了。

**陈屿旁白**

我带她穿过卧室门框。厨房亮着，货架上米面码得整齐，桌上的火锅还没凉。她在门口停了很久。手机里，血月前攒下的三百六十安心值，跳到了三百七十。

**许知意**

还有热饭？

**陈屿旁白**

对门又拍了两下墙。王大富在喊医生。我把她面前的椅子拉开，添了一碗饭。夏凛坐回门框内侧，短棍横在膝上。外面的求救，没有人应。

# EP012《医生在我屋里》

**陈屿旁白**

王大富把带血的手贴在门镜上。他身后，另一个人端着空碗。我没开门，只把门镜的遮片合上。

**王大富及门外声音**

医生都在你家了！让她出来看一眼，能花你什么！

**陈屿对白**

不开。

**陈屿旁白**

许知意站在医疗箱边。她看了看外门，又看向我包着纱布的手，拿起剪刀，把昨天留下的胶带毛边剪平。随后，她把药品一格格放回柜子。

**许知意**

这只手今天别沾水。中午换药，我来。

**陈屿旁白**

她把名字签进屋规，回房睡了六个小时。醒来时，枕边多了干净衣服，医疗柜旁则多出一只白箱。好感三十，入住补给：缝合耗材、敷料、冲洗液。每样都有数量。

**许知意**

这些我会收好。你们受伤，先来找我。

**陈屿旁白**

安心值涨到三百九十五。页面下方还有未亮的房间：诊疗室、训练室、恒温耕地。每个图标后面，都标着尚未满足的居住条件。许知意把一碗粥放到我手边，推走了那包没泡开的速食面。

**许知意**

手不方便，就用勺子。别拿伤口试筷子。

**陈屿旁白**

门外的空碗还在响。她坐下来，陪我把这顿早饭吃完。

# EP013《灯灭以后》

**陈屿旁白**

撬棍砸上外门时，我正开灯查看台阶。两个同层住户趁亮冲了过来，其中一个把脸贴向门镜。转角的影子退进黑暗，没走远。

**王大富及门外声音**

你一个人吃得完吗？开门！

**陈屿旁白**

夏凛握住短棍。我按住她的手腕，目光留在手机上的入口状态。防护正常。墙上连一道裂纹都没有。

**陈屿对白**

留下。

**陈屿旁白**

控制器在我掌心，两盏院灯同时熄灭。楼道静了一拍，随后是撬棍落地的声音。有人拼命拧自家门锁，有人的脚步停在半路。黑暗里，扶手发出一声刺耳的弯折。

**夏凛**

门前还有一只。它没追走。

**陈屿对白**

让它等。

**陈屿旁白**

我把短棍从她手里拿下来，放在桌边。许知意已经摆好三副碗筷。我们吃饭时，门外响过一次抓挠，再没人敲门。夏凛坐了半天，终于把背靠上椅背。

**陈屿旁白**

安心值越过四百，卧室门边亮起一盏小夜灯。试用说明只有一项：关门后，隔绝屋外的声音。我让夏凛先去试。灯刚按亮，她握着杯子的手就慢慢松开了。

**夏凛**

醒了换我。你别一直坐门边。

# EP014《楼上的女孩》

**陈屿旁白**

手机震动时，一束窄光扫过门廊上沿。檐下挂着的灰白东西缩了缩，四条细长的肢体紧贴墙面。光从上面来。

**乔星野**

别往左照。它就在你灯罩后面。往上，照檐口。

**陈屿旁白**

陌生号码发来一张照片。二楼二零一的女孩站在窗内，手边摊着拆开的应急电源。我贴近门镜，切亮另一盏灯。两束光交叠，那东西沿墙爬回阴影，动作快得像一截滑走的绳。

**乔星野**

乔星野，做控制系统的。我能把灯分开控制。你那里……还能住人吗？

**陈屿旁白**

我没有答应。先让她用检修灯扫过窗下，再让夏凛从门内确认落点。她先放下绳索，等检查过再收回。窗户正对门廊，窗台离地只有一层楼；落地之后，到入口还差两步。

**夏凛**

这次从上面接。她的工具先放下来，人最后。

**乔星野**

我先把电源接好。现在剩的电，够你接人。

**陈屿旁白**

窗边的那束检修光稳住了。我把门前亮区的边缘记在纸上，划掉楼梯那条路。屋内的两个人已经轮换休息，安心值四百一十五。檐下空了，楼道里那道脚步声却始终没有离开。

# EP015《接进来就关门》

**陈屿旁白**

楼上先放下一只工具包。随后，乔星野出现在窗沿，腰间系着夏凛检查过的安全绳。两盏院灯同时亮起，照明只留在门廊和入口前。

**乔星野**

别催。我手没抖。是窗框太窄。

**陈屿旁白**

她落到门前的软垫上，腿一软，手里的电源箱碰响了地面。转角立刻传来急促的脚步。夏凛伸手抓住她的手臂，我接过箱子，把人一并带过门槛。

**夏凛**

抬脚！

**陈屿旁白**

外门合上，第一下撞击紧跟着落下。乔星野蹲在地上，抱住箱子喘了两口气，抬头看见厨房和四扇卧室门，整个人不动了。

**乔星野**

外面就一套老房子……你把这里藏哪儿了？

**陈屿对白**

先洗手，吃饭。吃完再拆你的箱子。

**陈屿旁白**

她签完屋规，吃掉满满一碗饭，筷子还攥着就开始点头。我把工具包放到她房间门边。第二天，她顶着睡乱的头发出来，手里已经画好了分路图。

**乔星野**

线太乱了。看着难受，我顺手改一下。

**陈屿旁白**

好感三十的检修套件落在桌上，配电组件正好补上她缺的接口。安心值四百四十。她摸了摸新电表，耳尖发红，把椅子往我旁边挪了半寸。

# EP016《她们睡着以后》

**陈屿旁白**

群里最后一段语音，是有人拧着干涩的水龙头骂人。紧跟着，一串消息挤上来，问我借水，借药，借一个晚上。我把手机扣在桌上。

**许知意**

该换药了。你今天只用了这一只手？

**陈屿旁白**

许知意拆开纱布，夏凛从厨房端来牛肉和蒸蛋。乔星野刚把外灯改成分路，便把空出来的一小块桌面占了，伏着画图。她画了十分钟，笔尖在纸上拖出一道长线。

**乔星野**

没睡。这个地方……还差一根线。

**陈屿对白**

图留着。去床上补觉。

**陈屿旁白**

我把她画好的那半张图夹平，又给夏凛留了满满一碗饭。许知意换好药，握住我的手腕，让我别急着起身。她的手已经不像刚进门时那么凉。

**许知意**

好了。今天不用再包那么紧。

**陈屿旁白**

下午，两间卧室先后安静下来。安心值到了四百五十五。奖励页在我手里展开：耕地能继续扩，花园、温泉浴池、诊疗室都还暗着。最下方写着，住客持续安居，可领取后续扩展。

**陈屿旁白**

我把刚烧好的水留在保温壶里，关掉走廊那盏顶灯。门外有人又喊了一声，屋里的呼吸没有被惊动。

# EP017《仓库先放着》

**陈屿旁白**

第二盏灯刚亮，门外那东西就朝前走了两步。灰白的骨片盖住额头，眼皮厚得像合拢的贝壳。普通嗜血者已经退了，它却把一只手伸向灯架。

**夏凛**

光压不住它太久。B七还有发电机，电源得早作打算。

**陈屿旁白**

我展开旧地图。到物流园，三个路口，一段地下通道。即使摸到仓库，还要装车、掉头，再从同一条路回来。我把钥匙放回抽屉，关上了地图。

**陈屿对白**

不去。库里的东西先留着，你们一个都不用拿命去换。

**陈屿旁白**

夏凛站了片刻，卸下刚挂好的装备，连同短棍放回柜边。那张一直绷着的脸松了一点。她伸手，把我衣领上没翻好的半边捋平。

**夏凛**

那你也别自己出去。要走，先叫我。

**陈屿旁白**

她转身时，手机震了一下。夏凛好感六十，亲近奖励。餐桌旁多了一只金属箱，里面是完整的房屋扩建组件，另有观察窗和预警模块。安心值四百七十。

**乔星野**

这套接口能接恒温和循环水。组件齐了，还差三十安心值。

**陈屿旁白**

门外的骨甲撞坏了灯罩。我关掉外灯，听着碎片落地，没再打开装钥匙的抽屉。

# EP018《狗牌交给我》

**陈屿旁白**

楼上有人隔着门喊，想让夏凛带队清楼。她刚把绳索收好，手停了一下。我关掉门内的对讲，接过她肩上的包。

**陈屿对白**

今天没有外出的安排。进去休息。

**陈屿旁白**

许知意已经铺好干净床单，乔星野也把控制器交到我手里。两天里，设备一项项接好，三个人轮着睡足觉。安心值最后跳了一次，停在五百。

**乔星野**

观察窗接好了。从里面看，不用往外探头。

**陈屿旁白**

夏凛没走到床边，又折回来。她摘下脖子上的狗牌，放进我掌心。金属被她握得有些热，边角磨得光滑。

**夏凛**

替我收着。醒了，我来拿。

**陈屿旁白**

我把狗牌放进床头抽屉，给她留了半杯温水。她躺下后，手在枕边摸了一下，没摸到短棍，停了停，还是闭上了眼。

**许知意**

别叫她。我看过了，她这两天太累。

**陈屿旁白**

我轻轻关上房门，回到扩建界面。恒温区，四十平方米耕地，独立诊疗室，第五间卧室，都可以开启。旧客厅的温度计却在往下掉。门廊外，第一次结了薄霜。

# EP019《门外寒潮门内田》

**陈屿旁白**

寒潮到来那天，门外的呼吸声更近了。观察窗里，骨甲个体站在薄霜上，身后还有一只伏在檐下。我按住升级确认，五百安心值归零。

**陈屿旁白**

货架后的白墙向远处退开。木地板延伸到一片翻好的黑土前，顶上是一整面柔和的天光。四十平方米耕地，旁边新开一间诊疗室和一间卧室。厨房没动，原来的货也一件没少。

**乔星野**

二十四度。不是表坏了，三个探头一样。

**陈屿旁白**

她把外套搭上椅背，跑去检查循环水。许知意推开诊疗室，药柜、检查床和清洗台整齐排着。夏凛站到耕地边，伸手试了试头顶那片天光。

**夏凛**

以后连菜都能自己种？

**陈屿对白**

先种一小块。长出来之前，吃仓里的。

**陈屿旁白**

我从保鲜货架拿出西瓜，切成四份。乔星野忙完回来，发梢都翘着，抢先拿走最薄皮的那块。夏凛脱下厚外套，许知意在水槽洗手。屋里四个人，谁都没再提外出的事。

**乔星野**

这块我先看见的。你拿旁边那块，也甜。

**陈屿旁白**

观察窗的角落，怪物仍在门外徘徊。我把画面调暗，把盐和种子移到新柜子。天光缓缓转暖，耕地边留出的那条步道，能并肩走下两个人。

# EP020《世外桃源的第一粒种子》

**陈屿旁白**

门外零下二十五度。观察窗里的扶手挂着霜，骨甲个体的影子还在楼梯下。屋里，乔星野蹲在第一畦土边，把菜种倒得太急，半包都挤在掌心。

**乔星野**

水路我会接。种子间隔……你来。

**陈屿旁白**

我按包装上的间距下种，夏凛在旁边插标牌。许知意从诊疗室出来，把三只杯子摆上操作台，第四只留给刚洗完手的我。

**许知意**

先歇会儿。土不会跑，水也够。

**陈屿旁白**

新奖励页亮起一条居住进度。三位同住者持续睡稳、吃好，后续能扩出花园、浴池和训练室。夏凛望着训练室的预览，乔星野已经把工作间画到了旁边。那些地方都还锁着，第一畦土里也没有立刻冒出嫩芽。

**夏凛**

训练室靠里一点。别吵到她们睡觉。

**陈屿旁白**

旧收音机忽然响了一下。乔星野刚修好的接收模块闪起绿灯，杂音里钻出一个女人的声音，很轻，句尾却咬得清楚。

**顾南枝**

这里是东街顾家面馆。顾南枝。门窗堵住了，外面有东西。送餐对讲机快没电了。有人听见吗？我还活着。

**陈屿旁白**

我把店名和位置记下，没有应答，也没去拿钥匙。夏凛看了一眼入口，重新坐回桌边。面馆隔着两条街，我们还没有能安全走过去的路。

**陈屿对白**

先把自己的地方建好。

**陈屿旁白**

许知意把热汤放到桌子中间。乔星野关小收音机，拿起刚才没画完的工作间。耕地的水路开始缓缓滴灌，头顶那片天光，已经到了傍晚。
