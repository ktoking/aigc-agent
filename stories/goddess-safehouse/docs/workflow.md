# 确认稿制作流程

1. 冻结用户粘贴稿，逐集替换，核对原文区间与hash，旧稿归档。
2. 沿确认稿拆cue、画面事件与角色/场景参考职责，不润色。
3. 用第一段短试听验证MiniMax接口，成功后分cue生成并ffprobe测时，保存真实参数。
4. 按实际配音重新划4—6秒为主的单图镜头，建立唯一整数帧时间线。
5. 使用内置imagegen逐镜新图，按需传角色/空间参考，保存完整prompt/hash/来源；检查人数、状态、近重复与干湿。
6. 本地渲染有声无字MP4，检查音频尾字、帧数、转场、完整解码；看联系表和正常速度播放。
7. 交付10集本地文件、图像与时间线；不默认发布公网。

失败处理：鉴权/余额不足保留错误，不改模型绕过，不重试已知失败付费请求；独立文本与素材整理继续推进。
