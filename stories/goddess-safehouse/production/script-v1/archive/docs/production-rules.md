# 生产规则

按story-film-workflow：16:9真人写实电影静帧；图像原生尺寸实测，最终1920×1080为视频导出规格。大形清楚、自然皮肤、适度细节、干燥有序，禁止过锐、鳞片纹理、全屏微细节、杂乱废墟和湿反光。原稿确需水的热水龙头和锅内蒸气只局限在剧情所需范围。

小说正文在先，旁白从正文改编。每镜一个主要可见状态，图像固定，不默认推拉。每张成片图只用一次；回忆/EP001与EP010同事件均生成不同独立图，保持人物道具状态对应。

production/script-v1为初稿版本，未获用户剧情/审美确认。镜头清单的字数/7.5秒为文字估时，start_frame/end_frame保持null；配音后须重排，主范围4–6秒，不能把全部cue机械当作最终单图时长。当前180项是事件图候选，短项应在同场语义边界重新分配时间或合并，数量随实测调整。

本轮先生成陈屿、夏凛、许知意的单人演员基准与Lv2空间基准；不生成180张无音频排时的最终事件图。基准图不可直接反复拿去拼成片。

声音默认speech-2.8-turbo/Chinese_calm_streamer_nv1；单叙述者复述必要对白，不用同音色伪装已锁定多演员。情绪与语速须先试听，voice-plan.json只记录建议。无字幕，不生成SRT/VTT。

source/adaptation-notes.md是原文差异记录；source/原稿保持不变。assets/manifest.json记录基准图prompt、来源、hash与选用状态。
