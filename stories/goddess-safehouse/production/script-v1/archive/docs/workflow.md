# 本故事工作流

1. 原稿归档、提取、核对前十集及规则。
2. 小说正文→陈屿第一人称旁白，逐集执行12项语义审读，记录稿件hash。
3. 给出事件图候选与独立prompt；文字估时不冒充实测。
4. 生成三名主角与Lv2空间基准；视觉选择为待用户审美确认。
5. 后续制作时先短段试听，再逐cue生成MiniMax配音；ffprobe测时并核对句群内部边界，按4–6秒主范围重排镜头。
6. 每镜生成独立新图，绑定参考职责/hash，检查近重复、人数和状态；不复制基准图代替事件图。
7. 本地合成有声无字视频，统一整数帧时间线，0.1秒外部空档与叠化只计一次。
8. 分开记录完整解码、正常速度播放、观看和审美意见。

本轮不调用视频API；视频API交付合同只作为后续用户另行选择真人动作视频路线时的参考，不在静帧工程创建空提交记录。
