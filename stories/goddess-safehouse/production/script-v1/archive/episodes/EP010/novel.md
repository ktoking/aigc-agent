# EP010《血月》·小说式正文

版本script-v1；剧情时间：D0，第一夜。

第二天晚上，手机上的最后一秒归零，窗外一整排楼先后熄灯。红月从楼缝里露出来，我听见远处有人尖叫，接着是楼下桌椅翻倒的声音。夏凛把外门门链拉了一下，确认锁紧，又转身看我。我已经把火锅的火调小，毛肚、牛肉和蔬菜摆在桌上，给她留着座位。
她没坐，说楼里有人跑。我把筷子放下，走到客厅的观察口。王大富从自家门前扑过来，连拍了几下门，喊我开门，十根金条全给我。那句求人的话，与三个月前群里的笑脸隔着一扇门。我回他，当初说我借钱囤货是傻子的时候，可没这么客气。
楼梯转角出现一个青灰色的人影，王大富看见，背抵住我的门往下滑。他求我快开。我没有碰门锁，先抓起院灯控制器。系统说过未经允许怪物进不了内层安全屋，可客厅外侧和院门仍然会成为暴露的位置。身边的夏凛把短棍抬起来，留开我转身的空间。
我按下开关。两盏灯同时照亮转角，那人影抬手挡眼，向后缩去。王大富趁这个空隙冲回对门，砰地关上。他还在里面喘，我能听见。夏凛回头看了一眼控制器，说昨天那次试灯没白做。我点点头，没把灯关掉。
原来压在远处的声音忽然到了楼下。有人喊我的名字，是个女人。我从观察口望出去，看见许知意一手攥着纸卡，白大褂袖口裂开，脸色发白。她扶着墙往前走，身后三道人影已挤到楼梯转角。她又叫了一次，我答，在。
手机弹出提示，检测到屋外幸存者一人，请求入住。随后一行红字盖过倒计时：开启入口将暴露安全屋位置，是否确认。夏凛已经站到我侧后方，短棍抬起，等我开门。许知意的手碰到了门板，我让两盏灯继续照住转角，另一只手按住门锁。那块确认按钮，还亮在屏幕上。
