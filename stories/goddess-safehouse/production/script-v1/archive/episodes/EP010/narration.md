# EP010《血月》·第一人称旁白

陈屿单叙述者版，角色对白由他转述；导演说明不进朗读文本。

第二天晚上，最后一秒归零，窗外整排楼先后熄灯。红月从楼缝里出来，楼下响起桌椅翻倒声。

夏凛拉了一下门链，确认锁紧。她回头看我，我正把火锅的火调小，桌上给她留着位置。

毛肚、牛肉和蔬菜都摆好了。她没坐，说楼里有人在跑。我把筷子放下，走去看门。

王大富扑过来拍门，喊陈屿，开门，十根金条全给你。他的手一直在抖。

我隔着门回他，当初在群里说我借钱囤货是傻子的时候，你可没这么客气。

楼梯转角多出一个青灰色的人影。王大富背抵住门，往下滑，又催我快开。

我没动门锁，先拿灯的控制器。夏凛把短棍举起来，给我留出转身的位置。

灯接着客厅的备用电源，外面断电，它还能亮。我摸到开关，按了下去。

两束白光同时照到转角。那人影抬手挡眼，往后缩了半步，没有再朝门口冲。

王大富撑地爬起来，冲回对门，砰地关上。他还在里面喘气，我听得很清楚。

夏凛看了一眼控制器，说昨天试灯没白做。我点点头，没把开关关掉。

楼下又响起脚步，夹着一个女人喊我的名字。我往观察口前挪了一步，再听了一遍。

是许知意。她攥着那张纸卡，扶墙往前走，白大褂袖口裂开了，脸色白得厉害。

她身后三道人影挤在楼梯转角。我叫她往亮的地方走，她抬头，朝门口过来。

手机提示，屋外一名幸存者请求入住。下一行红字盖住倒计时，开启入口将暴露位置。

夏凛站到我侧后方，短棍抬着，等我开门。我确认两盏灯都亮着，转角还在白光里。

许知意的手碰到门板，又叫了我一声。我隔着门答，在，你别离开这束光。

我的手按住门锁。手机还亮着，问我是否确认。门外，她的呼吸，已经贴到门板上。
