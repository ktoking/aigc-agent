# EP002《验证》·小说式正文

版本script-v1；剧情时间：D-89。

客厅那盒草莓先软了。果蒂边有一小片灰白，我把它连盒装进袋子。安全屋里那盒来自同一批，昨天我亲手分开，手机延时拍摄也一直开着。我擦净手，挑出屋里的一颗，切开，果肉还很紧实。能放住食物，这间屋子就值得我花钱。
手机又出现一项新手演示，询问要不要模拟屋外威胁。我站在门边，把出口留在身后，点了确认。大厅尽头变成一块展示窗，窗外是红色的夜。一道人影撞来，肩膀歪斜，眼睛被红光照亮。我往后退，脚跟碰上门槛。那东西贴着窗嘶叫，下一次撞击被红光挡住。
演示结束，窗重新变成墙。我手里的手机还开着说明页：嗜血者，畏光，畏火，听觉敏锐。我抽出采购本，写下三个词。隔着演示看见它被挡住，并不能替我测出真实血月的所有情况；我还是把探照灯和备用电源加到了清单里。
桌上那张一年清单，越算越长。吃喝只是前几行，建材、设备、衣物、备用电源一项项加进去，最低也要一百一十八万。余额四十一万两千，差七十六万八。我把原来的一人份改成三栏，第一栏先填自己的名字，后两栏空着。系统写过，住客得到允许也能入屋。
书架上放着父母的合照。那次事故前的未接电话，我至今还留在旧手机里。我把相框从账本后挪到旁边，空出地方，继续算。
借款页面显示，可借额度七十八万。我看完期限和费用，把数字抄进本子。借款到账前，所有采购先按分批交货谈，车也准备卖。我在申请上按了确认。手机转了几圈，状态变成审核中。我守着它坐了一会儿，又起身去量大厅里能摆几排货架。
