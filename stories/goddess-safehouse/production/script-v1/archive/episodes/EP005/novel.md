# EP005《冷面保安》·小说式正文

版本script-v1；剧情时间：D-85至D-84。

手电光停在叉车轮子上，女人说，停。司机踩下刹车，我从库门里走出来，看见她的制服和腰侧的短棍。她站得很直，先看运单，再看车尾，没有因为我递出合同就让路。
我说是B七的货，报备资料补来了。她问为什么车牌与旧报备单不一致。我翻到运单最后一张，是承运方下午换车，更新的回执没送到岗亭。我让司机熄火，先把副本拿出来。她借着光逐项核对，确认完车牌，才让司机下车开箱。
箱里是压缩饼干、种子和探照灯。她又问燃料。我拿出另一处储位单，她看过配送时间，在纸上画了个圈，告诉我别走错库门。我说我做过仓储，食品不会跟油桶混着放。她没接这句话，只问为什么一个人需要这么多。
我看见她左耳后有一道很浅的疤。她低头写记录时，一块旧狗牌从领口滑出来，又被她塞回去。我指着自己的粮食、水和灯，说三个月后，外面可能会出事，我准备拿这些东西保命。她手里的笔停住，抬眼问，什么事。我没有拿模拟出来的画面吓她，只说我手里有个倒计时，愿意找时间给她看。
她把检查结果填完，报出名字，夏凛。放行前，她让司机按划好的路线走，随后站在叉车与人之间，直到第一托盘落稳。我隔着货架看她，货卸到哪里，她的视线就跟到哪里。
回执有一份需要次日交岗亭。隔天凌晨，我送过去，夏凛正合上旧本子，页面上有一笔转账数额。我只看清八千，没有问收款人。她从抽屉取回我的报备单，问了一句，倒计时还剩多少。我告诉她，八十五天。她在新一页记下日期，把本子合上，推回那块狗牌旁边。
