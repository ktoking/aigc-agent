# EP005《冷面保安》·第一人称旁白

陈屿单叙述者版，角色对白由他转述；导演说明不进朗读文本。

一道手电光照住叉车轮子。女人说，停。我抬头，看见她腰侧的短棍。

我把合同递过去，她没让路，先核运单，又问司机，车牌为什么跟报备单对不上。

承运方下午临时换了车，新回执没送到岗亭。我翻到最后一张，让司机先熄火。

她对过车牌和批次，才点头让人开箱。我站在旁边，把缺的副本一张张补给她。

第一箱是饼干，第二箱是种子。她看到探照灯，停了一下，问我燃料在哪里。

我把另一处储位单递给她。她圈出地址，嘱咐司机，下一车别走错库门。

我说，食品和油桶分着放，我以前做仓储。她合上夹板，问，一个人要这么多干什么。

她低头记数，我看见左耳后有道浅疤。领口滑出一块狗牌，她很快塞了回去。

我指着水、粮和灯，告诉她，三个月后，外面可能出事。这些货，我准备拿来保命。

她手里的笔停住，问我，什么事。我说手里有个倒计时，有机会，可以带她看。

模拟画面只有我看过。我收起手机，先让司机把这批货卸完，别再堵着库门。

她在回执上签了名字，夏凛。签完，又让司机按地面的路线走，别抄近道。

第一托盘往下落，她站在叉车和人之间。货落稳了，才挪到另一侧继续盯着。

我把她的名字记在联系人后面。仓里这么多东西，夜里得有个肯认真巡查的人。

第二天凌晨，我去岗亭交副本。她正合上一本旧本子，页面边缘露着一笔转账。

我只看清八千，没问给谁。她把我的报备单取出来，压在窗口下面。

我接过单子，她忽然问，那个倒计时，还剩多少。我说，八十五天。

她翻到新一页，记下日期，又把本子合上。笔就停在那块旧狗牌旁边。
