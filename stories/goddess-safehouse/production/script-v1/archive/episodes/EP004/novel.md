# EP004《内行》·小说式正文

版本script-v1；剧情时间：D-87至D-86。

老李拆开米袋，抓起一把递给我，说是新米，一吨四千二。我先看袋口的批次，再闻米，指腹一捻，有几粒发软。库门旁另一摞同样包装的货，生产日期早了半年。我把这一袋放回去，说要近三个月、有检测单的，他换了个眼神。
B七库位的合同刚签，六辆车已经卸下。园区给了我几天中转期，往安全屋搬要按消耗和后续扩建的次序排。我让老李带我看另一批货，包装和批次都对上，谈到每吨三千二。不是拿潮米砍价，坏的便宜也不能要。他答应留货，我只先交下一批的定金。
采购本被分成两部分。食品、水、衣物放一页，电源、灯、建材另放一页。二十吨米、十吨面粉是后续分批交付的总订单，今天进库多少，我就在后面记多少。燃料送到园区单独的合规储位，不和食品挤在一起。把所有东西一次塞进老房子，车就算开得进去，门也会被箱子封住。
工人抬米时，我让他们先铺垫板，袋口朝里，交错码放，批次朝外。他们起初嫌我啰嗦，第二排码完，通道比原来多出半个身位。老李指着清单上的二十台探照灯问，我进这个做什么。我说夜里看库，顺手又订了匹配的备用电源。
晚上回小区，王大富把我问柴油配送的话截进了业主群。他把采购清单上的数量也圈出来，说有人要把整栋楼变成油库。群里一串回复往上滚，物业已经把通知贴在单元门上。
我将燃料的园区储位单号发给物业，请他们登记，没在群里争。经理回电话，说B七库里有批货的报备资料不全，明晚还要补交。我翻开文件袋，把合同、运单和清单按顺序夹好。最上面那张，收货人还是我的名字。
