# EP009《最后二十四小时》·小说式正文

版本script-v1；剧情时间：D-1。

楼下那条狗把铁链绷直了。夏凛站在窗边，几次拉上窗帘，又留出一指宽。电视快讯说多地动物持续躁动，西南方出现异常红色云层。手机上的倒计时只剩二十四小时。我拿给她看，她没再问那是不是软件作怪，转身把备用电源搬到门边。
我们最后试了一次门外灯。前些天装在院门上方的两盏灯，能照到台阶和楼梯转角，控制线绕进一零一，电源留在客厅。外门关着，灯一样能亮。夏凛站在阴影边缘给我比方向，我调到不直照对门住户的位置，把备用电源再充满。
傍晚，我经过超市，入口挤得几乎进不去。盐和水的架子空了，有人扶着推车不肯让路。我看了一会儿，转身去了医院。车后座上只有一箱我从正规门店买来的纱布和消毒耗材，票据就在箱顶。
许知意正在交班，见我抱着箱子，先问东西从哪来。我给她看清单和票据，让科室按流程登记。她叫同事接过去，自己站回走廊问我，究竟出了什么事。我把倒计时给她看，又拿出写着地址的纸卡。那张卡开不了安全屋的门，只能让她找得到我。
她说晚上还有班，病人也在等。我把卡放到她手里，告诉她，如果医院组织撤离、走不下去了，就来梧桐里三栋一零一。最好提前给我电话，没信号也尽量别独自走黑路。她看着我，问那里到底有什么。我说水、吃的、一个能休息的房间，还有一位守门的人。
她把卡收进白大褂。我回去时，王大富还在群里约烧烤，约的是明晚，谁都别躲。夏凛已经拿着短棍站在门边。天空暗了，西边的红色没退，反而压得更低。我把手机接上电源，最后一次给许知意发了地址，然后关上外门，留院灯的控制器在手边。
