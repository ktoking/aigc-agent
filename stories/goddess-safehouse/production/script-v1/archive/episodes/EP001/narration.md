# EP001《倒计时九十天》·第一人称旁白

陈屿单叙述者版，角色对白由他转述；导演说明不进朗读文本。

王大富拿金条撞我的门时，锅里的毛肚刚下进去。他喊，十根，全给我。

我把筷子搁在碗边。三个月前，他还在业主群里问我，是不是疯了。

九十天前，马主任把三十箱货的缺口推给我。签收单上，确实有我的名字。

可那天下午，货车还没到，是他催我先签的。我去拿单子，他一把压住。

他问，证据呢。我摘下工牌放在桌上。第二天，我得去人事办离职。

我回到父母留下的老房子，梧桐里三栋一零一，连客厅灯都没开。

手机却自己亮了。我的姓名和房号下面，多出一行数字，还在一秒一秒往下跳。

距离血月降临，八十九天二十三小时五十九分。我重启手机，数字还在走。

卧室忽然响了一声。门锁自己弹开，白光从门缝里出来，一直照到我的鞋尖。

我扶住门框。十二平方米的卧室不见了，门后空空荡荡，足有两百平方米。

我扔进去半包泡面。袋子落了地，没穿过去。我又用手电，沿墙照了一圈。

我把袋子捡起来，摸过门框，来回走了两次。每一次进门，大厅都还在。

手机提示，屋内物品不会腐坏，未经允许，外来的怪物进不来。我盯住怪物两个字。

银行卡里，还有四十一万两千。我摊开纸，先写米、水、盐，再添上两盒草莓。

群里有人卖旧货架。我问他，还能不能找五吨米。王大富立刻发来一串笑脸。

他说我被裁员裁傻了。我把群聊静音，约好送货，明天先试试这间屋子。

货架还没到，墙上先亮起一道红光。检测到同类信号，数量未知。

我转身看向门口。客厅里什么也没有。手机上，那个信号没有地址。
