# EP001《倒计时九十天》·小说式正文

版本script-v1；剧情时间：冷开场D0；主线D-90。

王大富拿金条撞我的门时，锅里的毛肚刚下进去。他隔着门喊，十根，全给我。楼道里又响起一声撞击，我把筷子搁在碗边。三个月前，他还在业主群里问我是不是疯了。
九十天前，物流园办公室只剩一盏灯。马主任把三十箱货的缺口摊在桌上，签收单最下面是我的名字。那天下午，车还没到，他催我先录入。他现在只问我有没有证据。我伸手去拿单子，他用掌心压住，说人事明天办离职。我摘下工牌，塑料卡碰在桌沿上，响了一下。
父母留下的老房子在梧桐里三栋一零一。回去时，我连客厅灯都没开，手机却自己亮了。屏幕上出现我的姓名、房号，底下是一行不断减少的数字：距离血月降临，八十九天二十三小时五十九分。我退出页面，重启手机。数字还在走。
卧室传来门锁弹开的声音。那间十二平方米的屋子里，原本应该有一张床。门缝透出来的白光照到我的鞋尖。我扶着门框往里看，床没了，墙向远处延伸，足有两百平方米。我捡起半包泡面扔进去，又拿手机电筒沿墙照了一圈。包装袋落在地上，影子也跟着落下。
系统的提示停在手机上：空间折叠；屋内物品不腐；未经允许，外来怪物无法进入。我把泡面捡回来，摸过门框，又来回走了两次。大厅还在。
银行短信躺在通知栏里，余额四十一万两千。我在纸上写下米、水、盐，又添了两盒草莓，准备第二天做个对照。业主群里有人出二手货架，我问能不能再找五吨米。王大富立刻发来一串笑脸，说我被裁员裁傻了。我把群聊静音，先约了货架。
空大厅的一面墙忽然亮起红色提示：检测到同类信号，数量未知。我抬头看向门口，客厅和刚才一样暗。手机里只有倒计时，找不到那个信号的位置。

王大富拿金条砸我的门时，锅里的毛肚刚下进去。他在门外喊，十根，全给你，开门。
我夹起毛肚，涮了七下，隔着门回他，当初在群里说我借钱囤货是傻子的时候，你可没这么客气。
这是血月降临的第一夜。这顿火锅，我准备了九十天。
九十天前，我还是个被甩锅的仓储主管。马主任说，三十箱货的缺口，签收单上是你的名字。
我说，是你催我先签的。他一把压住单子，问我，证据呢。
我摘下工牌，放在桌上。第二天，我就不用再来了。
我回到父母留下的老房子，梧桐里三栋一零一，连灯都没开。手机自己亮了。
方舟安全屋系统，已绑定。下面一行数字，一秒一秒往下跳，距离血月降临，八十九天二十三小时五十九分。
我以为是诈骗软件。直到卧室的门，自己弹开一条缝，白光一直照到我的鞋尖。
十二平方米的小卧室不见了，门后是一间足有两百平方米的空厅。我扔进去半包泡面，它悬了一秒，无声落地。
系统说，屋里的东西不会坏，屋外的怪物进不来。紧接着，一行红字，血月降临后，屋外将不再适合人类生存。
我盯着银行卡，四十一万两千。又盯着那行倒计时。
我打开购物软件，搜索，压缩饼干。顺手又买了两盒草莓，一盒放屋里，一盒放屋外，做个对照。
第二天，我在业主群问，谁有大米，我收五吨。王大富回我，你是要开粮店，还是脑子坏了。满屏都是哈哈哈。
我关掉群聊，心里只有一个字，笑吧。
当晚，空厅的墙上，亮起一行红字，警告，检测到同类信号，数量未知。
我猛地回头，屋里空无一人。原来，收到倒计时的，不止我一个。
