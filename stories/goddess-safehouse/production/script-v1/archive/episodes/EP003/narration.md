# EP003《砸锅卖铁》·第一人称旁白

陈屿单叙述者版，角色对白由他转述；导演说明不进朗读文本。

车贩只肯给五万五。我把保养记录翻到最后一页，又指了指旁边那辆同款车。

三年，四万二千公里，无事故。他又绕车看了一圈，改口六万。我说，拿合同。

我核完车架号，签字交钥匙。手机震了一下，七十八万借款，也终于到账了。

存款、借款、卖车钱，合起来一百二十五万两千。我分出货款、运费，留下一笔备用。

晚上，表叔听说我借钱，筷子都放下了。他问我，到底想拿这笔钱干什么。

我说囤货。他问，三个月后睡桥洞怎么办。我把碗放下，说不用他替我担保。

那顿饭吃到一半，桌上就安静了。我把采购电话挂掉，等出门，再给司机回过去。

去签运输单时，我又碰见马主任。他问我，是不是失业了，到处找人借钱。

我跟他点了下头，往外走。他在后面说疯了。我看着司机发来的到货时间，没回头。

下午，第一批货提前合单送来，八辆车排到了小区门外。司机说，原仓库要腾位。

我让六辆先去物流园的临时装卸区，只留两辆进小区。消防通道，得给人留着。

王大富拎着鸟笼来围观，问我是不是开批发部。我请他挪一步，推车得从这里过。

天黑后，我把水和食品一车车往屋里运。先关外门，再把货推进白色大厅。

纸上算好的货量，真正落地，多出一堆包装和托盘。我挪了三次，通道还是越来越窄。

最后一车水进去，容量已经到了百分之九十八。剩下两摞货，还停在手推车上。

司机说，另外六车最多等到明天下午，再等就收占车费。我翻出物流园的电话。

我先把门前的路腾出来，封好没卸的货。门要是堵住，钱再多也没地方放。

电话接通，对方说，B七库有空位，明早来谈。我看了眼时间，距天亮还有四个钟头。
