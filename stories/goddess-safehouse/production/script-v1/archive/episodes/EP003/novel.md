# EP003《砸锅卖铁》·小说式正文

版本script-v1；剧情时间：D-88。

车贩把价压到五万五时，我把保养记录翻到了最后一页。三年车龄，四万二千公里，无事故，旁边同款车挂着六万多。他抬头看我一眼，说六万，再高不收。我接过合同，核对车架号，签字。
手机里，七十八万借款也到账了。加上存款和卖车的六万，一共一百二十五万两千。我在采购本上把这笔钱分开：货款、运费、建材，还有一块先不动。晚上亲戚叫我吃饭，表叔知道我离职又借钱，筷子都放下了。他问我买房还是做生意，我说囤货。他把声音抬起来，问我是不是想三个月后睡桥洞。我说不用替我担保，账我自己记。他没再夹那道菜。
去签运输单时，我在商场门外碰上马主任。他和新主管站在一起，问我是不是到处借钱。我把文件袋挪到另一只手，跟他点头，走了。他在背后说了句疯了，我没回去。
第一批货到得比约定更集中，八辆厢式车排在小区门外。司机说仓库要腾库，合单发了。我让六辆先去物流园的临时装卸区，带两辆进小区，不能堵消防通道。王大富拎着鸟笼站在门口，问我是不是打算开批发部。我请他让开推车经过的位置。
夜里，我把最后一车饮用水搬进折叠大厅。两百平方米并没变小，纸箱却比我在纸上算的更占地方。我按通道重新排了一遍，系统显示，容量百分之九十八。门口的推车还放着两摞货。
司机打来电话，另外六车最多替我等到明天下午，超时要算占车费。我把手推车拉出来，留住门前一条空路，给物流园拨电话。对方说，B七库有空位，明早能谈。货已经买下了，天亮前我得把它们放到一个真正能卸货的地方。
