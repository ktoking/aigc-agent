# EP006《月薪五万》·小说式正文

版本script-v1；剧情时间：D-83。

马主任把通知拍在桌上，让夏凛第二天别来了。我本来来补交库位资料，走到办公楼门口，听见他问她，一个保安为什么要拦客户的车。她说车牌没报备，换了谁都得查。马主任把纸往前推，说投诉已经到他这里，她跟谁解释都没用。
夏凛抱着一个小纸箱出来，里面只有水杯、夹板和旧本子。我在门口等她，问愿不愿意替我守一间屋，月薪五万。她停下，先问工作地址，再问雇主要她做什么。我拿出写好的三个月合同，说安全评估、值守、物资看护，合计十五万，今天预付。这笔钱从采购里挪，我在新预算上划掉备用冷柜和第二台发电机。她把纸箱换到左手，问我是不是连见都没见过她值夜。我说B七那晚见过。
她不肯先收钱，说得看地方。梧桐里一零一的院门刚开，她便沿窗下绕了一圈，指出一楼窗口低，客厅转身没有退路。我把卧室门打开，请她往里面看。夏凛停在门槛外，右手碰到短棍。她看过我，又看门内，最后自己伸手摸了墙。
我带她沿大厅走了一圈。货架挤得满，门前还留着那条通道。她用脚尖敲地，往回数门框与外墙的位置，停在两者本该重叠的地方。两百平方米的大厅，从院子外面根本找不到。她问我这是什么。我把手机上的绑定页和倒计时给她看，八十三天。
夏凛没有立刻相信血月。她先问会不会有人能把门拆走。我把目前知道的防护和离屋四十八小时后衰减的限制逐条告诉她，又递出三条屋规。她看完，问工资是不是只能在屋里花。我把预付款转了出去，给她看到账结果，她才拿起笔。
她将签好的那页推给我，自己的副本收进纸箱。墙上倒计时的红光映在她手背上。她问，归零以后，我究竟要守什么。我看着她脚边那只只装了三样东西的纸箱，说先守住这扇门，里面有我，也有你。
