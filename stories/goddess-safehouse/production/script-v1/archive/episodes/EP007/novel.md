# EP007《热水澡》·小说式正文

版本script-v1；剧情时间：D-82。

夏凛握着短棍在客厅醒来，第一句话是，我睡了多久。我把豆浆放到桌上，说六个小时。她低头看了看身上的毯子，又看门锁，脸色比昨晚还紧。她说，退役以后没连着睡过这么久。
昨夜她在沙发旁铺了一层垫子。我给她下了一碗面，她说不饿，等我转身搬货，却把整碗都吃完了。夜里我出来收碗，看见短棍从她指间落到垫子上，便放轻脚步，把毯子搭在她肩头。到清晨，手机提示，检测到住客连续深度睡眠六小时，安心值增加二十。
我把提示给她看。她皱着眉，说所以自己睡觉也在替我干活。我把工资合同推回她手边，说排班改一下，今晚不用连着守。她看了我一会儿，去把空碗洗了。
升级面板的两项要求都亮了，物资点五千，安心值二十。建材那一栏一直够，只差后面这二十。我核过待兑换的建材批次，让夏凛站到入口旁，按下确认。地面传来很轻的振动，白墙向远处展开。原来挤在一起的货架后面，逐渐出现走廊、四扇卧室门，厨房的台面和浴室也长了出来。
我先去看管线，再打开热水。水落进浴缸时，我隔着门喊了一声，真的有热水。夏凛站在走廊尽头，没有接话，手指却从短棍上松开了。我洗完出来，她已经把一间卧室的门开着，问我哪间离入口最近。我把靠外那间让给她，把钥匙放在门边。
还有些货必须留在中转仓。升级后的新空间腾出通道，我在清单上把日用品的下一批调进来。手机又跳出下一等级条件：安心值五百，当前住客一人。我往旁边添了个医疗箱，里面还空着。五百得慢慢攒，但这一屋的食物和灯，真有人受伤时，还缺一个会处理伤口的人。
