# EP007《热水澡》·第一人称旁白

陈屿单叙述者版，角色对白由他转述；导演说明不进朗读文本。

夏凛握着短棍坐起来，先问我睡了多久。我说六个小时，她马上回头看门锁。

她低头看了看毯子，说退役以后，没连着睡过这么久。我把热豆浆推到她面前。

昨晚，她在沙发旁自己铺了一层垫子。我给她煮了碗面，端过去，她先说不饿。

等我去搬货，她把面吃完，连汤都没剩。碗搁在脚边，短棍还握在手里。

夜里我出来收碗，短棍已经滑到垫子上。我把毯子搭好，没把她叫醒。

清晨手机提示，住客深度睡眠六小时，安心值增加二十。我把页面递给她看。

她问，睡觉也算替我干活？我改了排班，告诉她，今晚不用一口气守到天亮。

升级要五千物资点，二十安心值。建材早就够了，我先核对要兑换的那一批。

我让夏凛站到入口旁，按下确认。脚下轻轻震了一下，远处的白墙开始往外展开。

货架后面多出一条走廊，四扇卧室门。刚才还挤着的纸箱，终于能从旁边绕过去。

厨房台面长在走廊左侧。我先摸接缝，检查管线，再去试浴室的热水。

拧开龙头，水落进浴缸。我伸手试了温度，隔着门喊了一声，真的有热水。

夏凛站在走廊尽头，没有接话。我关门前，看见她的手，终于从短棍上松开了。

洗完出来，我换了件干净衣服。她已经把一间卧室门打开，问哪间离入口最近。

我把靠外那间给她，钥匙放在门边。她把垫子卷起来，这次没再退回客厅。

新通道腾出来，我调进下一批日用品。B七还留着储备，往后每搬一批，都得记账。

下一等级要五百安心值，屋里现在只有一位住客。我把条件记下，暂时关掉面板。

然后，我添了个医疗箱。水、粮、灯都有了，真有人受伤，这个空箱子还帮不上忙。
