# 请不要攻击送餐机器人 视觉风格

## 总体风格

高完成度 3D 动漫化短片，动作清楚，材质精细，带黑色幽默。画面不能像低成本游戏过场，必须有电影感光影和明确视觉锚点。

## 画面关键词

- premium 3D anime
- cinematic sci-fi wasteland
- neon rain
- hard surface robot
- absurd action comedy
- suspenseful reversal

## 镜头语言

- 开头用低机位追逐和中心构图。
- 打斗用近景和中近景，避免大全景群战。
- 悬疑揭示用餐箱特写、眼灯反光、扫描线。
- 结尾用门缝、停顿、微弱蓝白光制造余味。

## 禁止

- 过度赛博朋克堆满文字广告。
- 主角尺寸漂移。
- 餐箱消失或变形。
- 动作模糊到看不清因果。
