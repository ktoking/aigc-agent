## Prompt

Use the provided main reference image and the character lock as strict references. Create a production action sheet of the same small courier robot protagonist in 6 clear poses for future image consistency.

Subject lock: same `LMR_COURIER_BOT_001` robot: compact square white-and-orange worn delivery shell, glossy black face screen, two narrow blue rectangular eye lights, small black bow-tie-like front detail, orange lower trim, scratched hard-surface panels, low wheeled base with small caster wheels and round suspension joints, foldable side/rear mechanical arms, one articulated arm clamping the square orange glowing memory meal box close to the chest. The meal box remains the same square orange insulated container with black rim/lid, transparent side window, warm orange internal glow, steam, scuffed corners.

Required poses, 6 panels on one sheet:

1. Rolling forward fast with the meal box clamped close to the chest.
2. Using the body shell and mechanical arms as a shield while the meal box stays close.
3. Short jet-assisted drift with caster wheels skimming above the wet ground.
4. Mechanical arm planted on the ground for a vault or flip.
5. Low protective wheeled-base stance holding the meal box close.
6. Polite delivery stop pose with blue eye lights calm.

Scene/backdrop: simple neutral gray studio background with faint motion ghost lines only. No full battlefield. Keep all poses readable and isolated.

Style: premium 3D anime hard-surface render, cinematic material quality, crisp animation reference, consistent proportions across every panel.

Layout: six evenly spaced panels in a 3 by 2 grid, full body visible in every pose, same robot scale in all panels, meal box visible in every pose.

Consistency constraints: every panel must show the same single robot design, same head/body proportions, same face screen, same blue eye lights, same orange-white paint blocking, same wheeled base and caster wheels, same arm design, same meal box. Do not change the robot into alternate models. Do not add other robots or drones.

Negative prompts: different robot per panel, giant mecha, humanoid android, human face, biped walking pose, footstep running, random logo, unreadable text, missing meal box, changing colors, extra weapons, gore, full crowd battle, cropped limbs, blurry action, inconsistent scale.
