# LMR_COURIER_BOT_001 参考锁

## 主参考图

- 锁定参考图: `01-locked-reference/main-reference.png`
- 三视图参考图: `02-turnaround/turnaround-sheet.png`
- 动作表参考图: `03-action-sheet/action-sheet.png`
- 用途: 后续三视图、动作图、分镜首尾帧、视频提示词都必须以这张图里的主体为准。
- 角色定位: 小型送餐机器人“小满”，不是不同型号机器人集合。

## 不可变化特征

- 体型: 半人高，小型方块送餐机器人，不能变成巨型机甲、人形安卓、真人骑手或美少女。
- 头身: 方形黑色面屏，两个窄条蓝色眼灯，白橙旧配送外壳，前胸保留小黑色蝴蝶结状细节。
- 结构: 低矮轮式底盘、圆形悬挂关节、小脚轮，侧后方折叠机械臂，机械臂可把餐箱贴胸夹持或外翻成防御挡板。
- 材质: 硬表面机器人，外壳有划痕、污渍、旧漆磨损，边缘不是崭新玩具质感。
- 色彩: 白色/灰白主体、橙色配送条和底部装甲、黑色面屏、蓝色眼灯。
- 道具: 必须绑定 `PROP_MEMORY_MEAL_BOX`，餐箱不能消失、换形或变成普通饭盒。

## 可变动作

- 餐箱挡弹。
- 轮式底盘贴地滑行，餐箱贴胸夹持。
- 机械臂撑地翻滚或越障。
- 短距喷射漂移。
- 抱紧餐箱低姿防御。
- 礼貌停顿、扫描、等待签收。

## 后续生图规则

1. 每次生成主角图前，先引用 `01-locked-reference/main-reference.png`。
2. 如果要生成动作，优先引用 `03-action-sheet/action-sheet-prompt.md` 的动作集合。
3. 如果要生成三视图或模型一致性参考，优先引用 `02-turnaround/turnaround-prompt.md`。
4. 不要在同一张图里把主角画成多个不同机器人。需要多姿态时，明确写“same identical robot in every panel”。
