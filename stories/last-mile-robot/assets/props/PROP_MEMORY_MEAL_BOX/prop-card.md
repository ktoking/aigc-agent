# PROP_MEMORY_MEAL_BOX 道具卡

## 道具定位

外观看似普通外卖保温餐箱，实则封存最后一个人类意识备份。全片核心悬疑对象。

## 可见特征

- 方形橙色保温箱，边角磨损。
- 密封锁有蓝白扫描线。
- 受冲击时内部发出心跳一样的光。
- 不能提前露出完整芯片，只能通过声音、光和碎片投影暗示。

## 参考锁

- 绑定角色: `../../characters/LMR_COURIER_BOT_001/01-locked-reference/main-reference.png`
- 餐箱必须保持方形橙色保温箱、黑色边框/顶盖、透明侧窗、暖橙内光和磨损边角。
- 餐箱不能变成普通外卖袋、金属武器箱、圆筒罐或完全透明容器。

## 功能

- 防御: 可短暂展开护盾。
- 悬疑: 发出婴儿哭声、心跳声、旧录音。
- 反转: 最终显示人类意识备份。
