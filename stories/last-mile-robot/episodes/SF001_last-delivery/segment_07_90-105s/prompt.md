# Segment 07 视频生成 Prompt

## 视频规格

- 画幅: 横屏 16:9，保留画面中心 60% 安全区，便于后续裁切竖屏。
- 时长: 15 秒以内。
- 风格: 高级 3D 动漫化成人科幻短片，霓虹雨夜废墟，电影级光影，动作清晰。
- 首帧: 使用内置 image 模型正式生成的 `frames/first-frame.png`，与尾帧是不同画面。
- 尾帧: 使用内置 image 模型正式生成的 `frames/last-frame.png`，表现本段 15 秒结束状态。
- 故事板参考: `frames/storyboard.png`；如果本段有动作调度图，同时参考 `frames/action-guide.png`。

## 本段任务

全片动作爽点，小满主动保护餐箱

## 角色与场景锁定

- 角色: `LMR_COURIER_BOT_001` 小满
- 道具: `PROP_MEMORY_MEAL_BOX` 记忆餐箱
- 场景: 废弃商场中庭
- 小满必须保持小型白橙送餐机器人外形，不能变成人形机甲或真人。
- 记忆餐箱必须始终可见，保持橙色方形保温餐箱外观，不能变成武器箱或普通外卖袋。

## 动作链路

- 90-93s: 无人机同时开火，小满把餐箱护在胸前展开短促护盾；运镜：中近景定格后快切；台词：无；音效：多点激光。
- 93-97s: 小满机械臂抓住商场广告屏支架，借力横摆避开火线；运镜：横向甩镜；台词：小满: “取消超时赔付。”；音效：机械臂绷紧。
- 97-101s: 它把一架无人机砸向广告屏，广告屏爆出雪花光；运镜：爆点广角；台词：无；音效：爆裂电流。
- 101-105s: 小满落地，餐箱里女孩录音低声说“不要让他们关掉我”；运镜：推近餐箱；台词：女孩录音: “不要关掉我。”；音效：录音失真。

## 动作设计

- 动作一: 正面防御，餐箱护盾只撑 1 秒。
- 动作二: 借广告屏支架横摆，形成横屏空间优势。
- 动作三: 非致命砸机，爆点来自屏幕和火花。
- 情绪转折: 小满说“取消赔付”，说明它第一次把订单本身放在系统赔付之上。

## 首尾帧继承关系

- 开始画面: 继承 Segment 06 尾帧。小满被围在中庭，四周红点锁定餐箱。
- 结束画面: 小满落地半跪，左肩冒火，餐箱贴在胸前，女孩录音让它停住。
- 视频必须从正式首帧自然运动到正式尾帧，首尾帧不能来自同一张故事板裁切，不能使用动作指导图替代，不能突然换场景、换角色或让餐箱消失。
