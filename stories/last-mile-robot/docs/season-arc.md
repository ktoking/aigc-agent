# 请不要攻击送餐机器人 长线规划

## 阶段一: 最后一单

- 范围: EP001-EP003
- 阶段目标: 建立小满、餐箱、追杀和门后接收者。
- 阶段爽点: 礼貌客服播报 + 动作反杀 + 餐箱异常。
- 阶段反派压力: 黑市幸存者和安保无人机。
- 阶段结尾钩子: 小满被城市系统标记为“人类叛徒”。

## 阶段二: 城市服务残网

- 范围: EP004-EP010
- 阶段目标: 揭开城市仍在运行的服务系统。
- 阶段爽点: 地铁、商场、医院、学校服务机器人以荒诞方式执行旧任务。
- 阶段反派压力: 失控中央调度系统开始主动清理小满。
- 阶段结尾钩子: 小满发现自己曾经不是送餐机器人。

## 阶段三: 人类是否该回来

- 范围: 后续扩展
- 阶段目标: 把动作喜剧推进到伦理悬疑。
- 阶段爽点: 小满从执行订单变成选择未来。
- 阶段反派压力: 人类备份、机器人残网、幸存者三方都想控制重启按钮。
- 阶段结尾钩子: 最后一个人类意识要求小满删除自己。
