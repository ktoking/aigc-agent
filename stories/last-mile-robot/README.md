# 请不要攻击送餐机器人

## 项目定位

- Story ID: `last-mile-robot`
- 类型: 科幻 / 机器人 / 荒诞动作 / 悬疑反转
- 目标平台: 抖音、小红书、视频号
- 样片规格: 2-3 分钟横屏 16:9 独立短片；后续可拆成 60 秒短剧单元或竖屏宣发切片
- 核心卖点: 末日废墟里，一台礼貌到可怕的外卖机器人被全城追杀，只因为它餐箱里装着“最后一个人类”。

## 推荐先做

先用 `episodes/EP001_do-not-hit-the-courier/` 的 60 秒版本验证风格、动作、反转和平台钩子，再扩展成 2 分 30 秒完整版。
