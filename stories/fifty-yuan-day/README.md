# Fifty-Yuan-Day 故事包

> **⚠️ 已弃用（历史参考）**：本包为 v1"老周个人视角"方向，用户已否决；正式方向改为批判对照版《49秒》，见 `stories/forty-nine-seconds/`。本目录保留作历史参考，不再续用。

## 剧名

- 主标题：《一天五十块》
- 爆款向标题：《赛车起火没人敢救，只有那个日结 50 的外包冲了进去》/《救了一条命，被扣了一百块》
- Story ID：fifty-yuan-day

## 项目定位

- 类型：社会议题微电影 / 单条剧情短视频
- 形式：9:16 竖屏 AI 短剧
- 默认单集：90 秒（1.5 分钟）
- 默认结构：4 章节 6 场，每段 15 秒以内
- 目标观众：关注打工人处境、社会新闻的 20-45 岁短视频用户
- 核心情绪：愤怒 → 揪心 → 燃 → 荒诞苦笑
- 情绪卖点：共鸣（层层外包的痛）+ 反讽落点（救人反被扣钱）

## 一句话卖点

一场没人敢救的大火，只有日结五十块的外包冲了进去；他救了一条命，工资条上倒扣一百块——层层外包之下，最底层的人拿命兜底，还要为这条命买单。

## 创作边界

- 本剧为虚构创作，灵感来自 2026-09-05 China GT 上海站撞车起火事故公开报道；人物、单位、薪酬为虚构，不指向任何真实个人与单位。
- 真实事件背景仅作为片头"故事原型"一行字幕，不做任何真实姓名、真实单位点名。
