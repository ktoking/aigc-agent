# Fifty-Yuan-Day 故事记忆

## 项目定位

- Story ID：fifty-yuan-day
- 类型：社会议题微电影 / 单条剧情短视频
- 目标平台：抖音 / 快手 / 视频号
- 目标观众：关注打工人处境、社会新闻的 20-45 岁短视频用户
- 单集规格：90 秒，4 章节 6 场，每段 15 秒以内
- 一句话卖点：日结五十的外包冲进火场救人，救了一条命，工资条上倒扣一百块

## 世界观

当代中国的商业赛事行业。一场看似光鲜的 GT 超级跑车锦标赛，赛事安全保障被"层层外包"：主办方 → 甲级安保总包 → 乙级分包 → 劳务派遣，每过一层抽一次成，责任和风险逐级下放，到了最底层，一天只剩五十块日结、无培训、无社保、出事自担。链条上每一层都认为自己"照章办事"，没有人真正对"本职工作"负责——直到一场大火烧穿这层纸。

## 核心故事

正赛现场，一辆红色 GT 赛车撞墙爆燃，车手被困座舱。广播反复催促，穿荧光马甲的安全员们却全员后退——没有一个人上前。人群最前面，外包消防协管员老周攥着灭火器犹豫：五十块一天，烧坏了没人赔。闪回揭示层层外包的链条和上一位工友"公司赔三十万、到手三百块"的旧事；火场里车手染血的手拍打车窗，女儿那句"我想吃你做的红烧肉"撬动了他。他甩开同事的手冲进火场，撕下冒烟的袖子裹手，掰开车门拖出车手。第二天，他收到一面锦旗和两张五十，工资条上却写着：应结 50，违规进场扣 100，实结 -50。下一场赛事，另一个穿同样马甲的年轻人站在他站过的位置。

观众为什么看下去：每个打工人都见过"层层外包"的荒诞，老周替他们把"没人拼命"背后的账算了出来，又用一次本能的选择完成了情绪的释放——最后落点不是表彰，而是一张倒扣的工资条。

## 角色记忆

### 主角

- 编号：LAOZHOU_001
- 年龄：47
- 身份：赛事外包消防协管员（日结 50 元）
- 外貌锚点：晒黑方脸、洗得发白的深色工装、松垮荧光马甲、走路微驼、手有厚茧
- 性格：话少、认死理、习惯性忍让、见不得"人命"两个字
- 欲望：攒钱供女儿读高三
- 恐惧：女儿失望；自己也成为"看着人死却不动"的那种人

### 配角

- 编号：DRIVER_001（车手）：被困火场的 GT 赛车手，无台词；识别符号为车窗染血手印；只承担情感功能。
- 编号：XIAOLIU_001（小刘）：24 岁外包协管员，机灵怕事但心里有热乎气；屏保是房贷计算器截图；他在老周冲出去时下意识跟上前两步。

### 反派/对立面

- 编号：SUPERVISOR_001（主管）：外包公司现场主管，黑色西装外套搭马甲工装，永远捏着手机；他不是恶人，是"控成本、压人效"体系里照章办事的中间人。
- 真正对立面：层层外包体系本身——无脸、无台词，却通过工资条、马甲、罚款单显形。

## 关键场景

- S01 赛道缓冲区：事故核心空间，燃烧的红色赛车 + 贴"日结 50"标签的灭火器 + 安全线（日 外）
- S02 外包工棚：身份揭示闪回空间，荧光马甲墙 + 日结工单 + 冷白灯管（日 内）
- S03 赛后通道：落点反转空间，锦旗 + 两张五十 + 工资条弹窗（日 内）
