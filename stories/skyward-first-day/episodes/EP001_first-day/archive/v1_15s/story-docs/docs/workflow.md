# 本故事工作流

1. 当前完成文字设计：正文、对白估时、35镜分镜、8段导演提示词、文案检查。
2. 后续先做林桃、小满、顾岩、许星和明亮3D画风参考，再做分段首尾帧；真实图放各段frames/，核对后更新manifest。
3. 配音用仓库scripts/minimax_tts.py；少女声、男教师声先短试听，逐cue实测后修剪镜头余量。固定120秒，不截断语音。
4. 先验证砸钟接触顺序、空中交通空间、斗篷隐身连续性；复杂段可拆内部镜头后剪辑，仍保持段长。
5. 视频API提交前核对图片及编号，保存真实请求返回，偏差只返工该段；不得空填任务ID或成功记录。
6. 合成有声无字成片，分别记录自动检查、抽样播放、完整人工观看。当前未生成图片、音频、视频，未调用付费生成API。
