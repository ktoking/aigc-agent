# 视觉与生产规则 v2

## 画风与规格

明显非真人的高质量3D动漫电影；角色约6.5头身、圆润清楚的造型、成束头发、细腻简化肤质、可读微表情。18岁成人学生比例。白瓷、浅灰金属、透明玻璃、薄荷绿植、浅桃点缀；柔和日光，干净大形，适度PBR材质，不堆毛孔和微纹理。

16:9横屏，120秒，30fps；成片目标1920×1080，草稿可720p，上采样不称原生高清。4个30秒导演段允许段内明确剪切，35镜连续动作叙事。不是静帧片，不套每图约5秒的静帧规则。

环境整洁干燥。洗脸允许池内和手脸局部水；厨房可有少量食物蒸汽；闹钟碎片只在清扫前局部存在。城市不加雨、积水、湿反光或废土烟尘。

## 连续性

- 林桃的脸、发色、右腕环固定；睡衣→洗漱发带→出门装以明确剪切换装。出门后直到课堂不换服装、书包、发夹。
- 小满按顺序叠被、清扫、接餐；做饭的机械臂是固定家电。不要同时生成三台小满。
- 蓝白空中公交为同一辆，有座位和透明侧窗；女主上车后一直在车内。外景机位可离开车再追随，女主不在车外飞行。
- 无轨飞行汽车与有环形轨道的悬浮列车为两种系统；以高差交汇，不穿轨、不碰撞。
- 课堂四种科技分镜展示，动作依序，学生座次固定。铃后装备关闭、滑板落地、学生就座；老师入场后不继续全班乱飞。
- 旧机、透明教学罩及独立电源台在老师入场时建立；片尾保留女主离座上前的过程。旧机与小满不同。
- 历史为带边界的全息沙盘，老师画外讲解；不把老师学生瞬移到古代或暴乱现场。

## 声音

角色对白、环境音、轻电子配乐，第三人称电影叙事，不额外添加第一人称解释旁白。默认有声无字幕。对白目前估时，制作时先用MiniMax逐cue实测，不靠加速口播或截尾凑120秒。少女、机器人、健硕男教师应选对应音色；不能直接让默认女声代替全部角色。
