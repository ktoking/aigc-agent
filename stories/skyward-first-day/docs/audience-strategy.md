# 《星穹学院》受众与叙事承诺

2026-10-29：以成年观众为主的群像科幻冒险。核心体验是看一群有独立目标的年轻成年人结成队伍，在高度发达的架空世界里探索、试错、改造技术与承担决定。

- 友情有对等能力、现实分歧和选择后的信任，闺蜜拥有自己的目标。
- 热血从时间、资源与任务压力中产生，让观众看见主动行动和成本。
- 冒险通过现场细节、证据和行动展开，逐步离开校园舒适区。
- 创新是解决问题的过程：测量、改装、测试、失败、再利用，科技有清楚用途与限制。
- 架空世界包含能源、交通、AI权限与教育体系，日常生活和历史共享同一套规则。

第一集用生活开场和城市奇观建立观感，课堂让角色的工程兴趣与合作开始运作。轻松片段采用成年人自然交流，不把所有角色写成单一表情和固定吐槽。文案审读不证明受众留存或发布效果，尚未做真人观看反馈。
