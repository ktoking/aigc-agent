## 世界发展

| 相对年代 | 事件 | 画面证据 |
| --- | --- | --- |
| 2600年前 | 坠星遗址开启，人类接触断代机械文明遗存 | 地下机械环门开启、悬浮动力核心；遗址建造者及断代原因暂不下结论 |
| 此后多个世纪 | 逐步复原动力核心，发展悬浮交通与城市 | 研究台、实验核心、第一座浮空城三个阶段 |
| 约200年前 | 通用AI达到高峰，城市服务接入统一中枢 | 金色指令链连接交通、家务与工业机器人 |
| 180年前 | 中枢失控、机器人暴乱 | 金线转红，机器齐转向，居民撤离；不补造失控者或幕后凶手 |
| 此后至今 | 拆分总控、分区重建，AI能力继续提高 | 独立青色网格、人工授权节点、修复城市；控制结构与旧时代不同 |
| 当前 | 高性能AI普及，人与机器共同生活 | 家务、分层飞行车道、环城悬浮列车、科技教学 |

历史影像均为课堂全息档案，有沙盘边界；当前都市没有发生暴乱。高度发达的AI与拆分控制架构可同时成立。
