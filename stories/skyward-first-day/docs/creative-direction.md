# 《星穹学院》｜创作定位 v2

更新：2026-10-29。

## 用户已确认

正式剧名《星穹学院》。面向成年观众；内容包含友情、热血、冒险、创新、架空世界。女主18岁、甜美外形；高度发达的科技与巅峰AI背景。3D动漫、A版画风；第一集120秒/4段30秒，每段10张参考图。

## 一句话定位

在科技与AI深入城市每个环节的架空时代，一群进入星穹学院的年轻成年人学习改造装备、处理失效系统，并逐步走出受保护的城市，参与古代技术遗址的探索。他们要解决现场问题，也要决定风险、成果和责任由谁承担。

以上学院培养路线与任务主轴为创作实现提案；不自动把新反派、血统或幕后势力写成既定设定。

## 五个内容支柱

| 支柱 | 落在剧情里的方式 |
| --- | --- |
| 友情 | 林桃和许星各有专业目标、判断和利益；协作有分工，分歧会影响行动，信任通过具体选择形成 |
| 热血 | 目标紧迫、能力有限、选择有代价；人物主动行动，失败留下设备损耗、任务中止、关系或机会成本 |
| 冒险 | 从校内失效测试走向导师带队的边界检修与遗址调查，靠观察/证据确定路线，风险由环境和任务因果产生 |
| 创新 | 现有科技可以拆解、重组、试验与失败；改造需要材料、能量、冷却、权限和验证，不临时增加万能功能 |
| 架空世界 | 交通、能源、权限、教育与城市外探索有一致规则；古代遗址、暴乱史与当前生活有可追踪的联系 |

## 人物动力提案

林桃保留甜美与日常松弛，现场擅长机械装配、观察故障和快速动手；冲动时会低估设备余量，必须学会记录与修正。许星偏仿真、数据和资源调度，对风险更谨慎，也有自己的研究目标；她与林桃的分歧可以发生在真实任务中。顾岩是有现场经验的导师，带队并保留故障处置职责，不把新人随意抛进致命考验。小满保留家庭陪伴功能，主线AI还要承担城市调度、权限和工程系统角色。

## 长线任务提案

第一阶段在学院完成真实的失效测试与协作训练；随后导师带队检修一座失联边界浮空站。新人负责测量和数据复核，现场发现档案接线图与实体不符、返航窗口缩短，团队需要重新分配电力并改造现有接口，救出滞留维修人员。后续调查才牵引出遗址记录与旧时代控制结构的疑点。

此任务为可发展方向，不等于下一集已经获确认或已有分镜/图像。学院是人物进入外部世界的入口，首集保留开学生活和城市展示。

## 第一集定向改动

前60秒保留闹钟、洗漱、家务和飞行公交，建立人物日常与世界规模；同学仍可热闹地试装备，动作体现改造兴趣和操作后果。教师给出保留手动断路的具体要求，再用历史说明技术来路。片尾将单人举手按按钮改为双人接管：林桃上手，许星监测限流，顾岩保留总断路。两人的第一份操作记录把友情与工程实践接上。

## 视觉与表达

A版的柔和3D材质、配色与整洁城市保留。新制表演用成年大学生的自然目光、停顿、分工和复杂情绪；收敛娃娃化比例、幼态声线、连续歪头卖萌和所有人同一种搞笑反应。现有40张图不删除或暗中重绘，它们继续提供身份、空间和关键状态参考；后续动作与口型按新稿制作。

世界可以明亮，也容纳制度分歧、资源约束和修复责任。友情和轻松日常保留空间；情绪高潮必须有已经发生的行动和代价。
