# Story 规则：exam-day-sss-awakening

## 必读

生成本 story 的剧情、分镜、首尾帧、视频 prompt、角色资产或连续性文件时，优先读取：

1. `docs/story-memory.md`
2. `docs/production-rules.md`
3. `docs/audience-strategy.md`
4. `docs/season-arc.md`
5. `docs/workflow.md`
6. `assets/characters/EX_SHEN_JIN_001/00-character-card.md`
7. `assets/style/global-style.md`
8. `assets/style/negative-prompts.md`

## 固定规则

- 主角沈烬必须保持 17 岁高中生气质，不要画成成年人、霸总、铠甲战士或古风修士。
- SSS 能力表现为“机械天使能量投影 + 雷霆审判环”，不是男主背后直接长实体翅膀。
- 校园觉醒考试必须保留：暴雨、操场、教学楼灯光、觉醒测试石、破损准考证。
- 文件和视频 prompt 默认中文；视频 API 直投文件继续使用 `director-promt.txt` 拼写。
- 剧情短剧视频测试默认加 `--generate-audio`。
- 参考图传给 Seedance 时默认顺序：首帧、尾帧、角色/道具参考。
