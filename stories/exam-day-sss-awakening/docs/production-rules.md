# 生产规则

## 视觉锁

- 主色：冷蓝暴雨、白色雷光、少量教学楼暖光。
- 场景：雨夜学校操场、湿地反射、教学楼亮窗、觉醒测试石。
- 男主：黑色湿发、深蓝校服、白衬衫、破损准考证。
- 能力：机械天使能量投影悬在空中，不能直接附着在男主背上。

## 视频提示词规则

- 第一段可使用“五段式按镜头切片结构”：核心主题、人物设定、氛围画质、运镜规则、分镜。
- 动作复杂段再改用逐秒动作因果。
- 参考图顺序默认：首帧、尾帧、角色参考。
- 剧情测试默认 `--generate-audio`，除非明确只测画面。

## 负面约束

- 不要字幕、水印、logo、可读文字。
- 不要真实学校名称、真实考试标识、真实准考证文字。
- 不要血腥、武器、游戏 UI 面板、属性面板。
- 不要男主成年人化，不要多个男主，不要实体翅膀长在男主背上。
- 不要满屏闪电遮住人物，不要鱼鳞状网格和满屏微纹理。
