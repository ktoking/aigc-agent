# 故事圣经

## 故事名

《高考当天，我觉醒了SSS级审判天使》

## 一句话

高考觉醒日，无天赋少年沈烬在全校嘲笑中抽出 SSS 级审判天使能力，却发现自己的准考证编号属于“实验体回收名单”。

## 世界观

这个世界的高考不是普通考试，而是“觉醒统考”。每名学生会在操场觉醒台前测试天赋等级，等级决定大学、资源、城市居住权和家庭阶层。最低级学生会被分配到危险的深渊实习区。

觉醒协会表面公平，实际被财阀和研究院操控。部分学生从出生起就被植入能力种子，编号被隐藏在准考证和测试石系统中。

## 主角

### 沈烬 / EX_SHEN_JIN_001

- 年龄：17 岁
- 身份：高三学生，被长期判定为“无天赋体质”
- 外观：黑色凌乱湿发，深蓝白边校服外套，白衬衫，破损准考证
- 性格：沉默、忍耐、观察力强，爆发时冷静而克制
- 能力：SSS 级审判天使，表现为雷霆审判环和机械天使能量投影
- 禁忌：不要变成年人成熟脸，不要长实体翅膀，不要穿铠甲

## 核心道具

- 破损准考证：沈烬被嘲笑和身份异常的双重证据
- 觉醒测试石：全校测试装置，沈烬触发时先黑屏，再裂开
- 审判环：天空中的蓝白雷霆圆环，象征 SSS 级能力

## 第一集钩子

监考老师在 SSS 播报后认出沈烬编号，低声说：“17号实验体，终于回来了。”
