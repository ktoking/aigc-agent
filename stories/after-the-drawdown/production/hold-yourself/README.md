# 低谷中，守住自己

60秒横屏原创音乐动画。1920×1080，60fps。

- `index.html`：可编辑根时间线
- `compositions/frames/`：三段独立动画，内部六个视觉段落
- `audiomap.json`：原音乐0–60秒的节奏与能量分析
- `beat-map.json`：字幕与场景锚点
- `sources.md`：历史事实和创作参考
- `../../episodes/EP002_hold-yourself/output/`：成片、字幕、封面、质检

预览：`npx hyperframes preview --background --port 5216`
导出：`npx hyperframes render --quality looks --fps 60 --workers 4 --output ../../episodes/EP002_hold-yourself/output/hold-yourself_1920x1080_60s.mp4`

音乐沿用用户确认的《we never（若如初见）》。公开分享仅包含交付文件，隧道依赖本机。
