# homecoming 剧本专属规则

本文件是 `stories/homecoming/` 的最高优先级规则，与仓库根 AGENTS.md 冲突时以本文件为准。

## 项目一句话

《回家 / Homecoming》——2 分钟无台词荒诞废土短片：末日都市被怪人占领，一个面无表情的普通青年提着买菜篮回家，一路秒杀所有怪人包括怪物王，最后回到半座房子里。

## 硬约束

1. **全程无对白、无旁白、无字幕**（怪人咆哮/叫声是音效，不是语言）。叙事全靠画面、动作、环境符号、音效、音乐。
2. **总时长 120 秒**，24 个镜头，16:9 横屏。
3. **男主永远面无表情**，全片唯一表情变化是 L21 的打哈欠。不笑、不怒、不说话、不解释。
4. **男主不是超级英雄造型**：普通年轻男性，浅卡其色oversize工装衬衫内搭白T恤、深灰色宽松休闲裤、白色帆布鞋，自然慵懒半睁眼，手里始终提着米色帆布买菜篮。
5. **菜篮子是核心道具**，跨镜头必须一致，里面有青菜、胡萝卜、鸡蛋、葱、塑料袋、豆腐等日常食材。
6. **视觉基调**：写实电影感（非动漫），冷灰蓝主色调 + 橙色火光 + 霓虹广告残影，35mm 胶片质感，高对比低饱和。
7. **怪人是怪物化的人类**，不是纯动物怪：依然有人形基础但严重异化。
8. **全片唯一高饱和日常色**：菜篮子的塑料色（红/蓝），在灰褐废墟中形成"日常vs末日"反差。

## 核心资产目录

- `assets/style/`：全局风格总控前缀、负面限制词
- `assets/characters/`：男主设定卡（三视图）
- `assets/enemies/`：速度型/爆弹型/巨臂型/侦查怪/怪物王设定卡
- `assets/props/`：菜篮子设定图
- `assets/scenes/`：废墟街道、半座房子等场景卡
- `episodes/EP001_homecoming/`：24 镜头生成工作区

## 生产流程

P0 骨架（本文件）→ P1 核心资产定锚 → P2 首尾帧 → P3 视频生成 → P4 后处理 → P5 配乐（BGM 卡点）→ P6 合成交付

## 节奏原则

前半段：慢、压、监视、突然袭击
中段：连续秒杀、怪人恐惧、压迫升级
后半段：怪物王蓄力、全片最大反差（哈欠）、一拳结束、冷淡回家
