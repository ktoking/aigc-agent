# 视觉重制 v3

用户要求：所有怪人和相关分镜重做，保留男主人物参考图；统一真实电影摄影与色调，增强怪人差异和人类街区被占据的痕迹。怪物王采用约600m、肩颈穿越低云的新尺度，替代旧50m。飞行怪为长毛与真实膜翼。

## 交付范围

- `manifest.json`：39张分镜、9张怪人图，以及5张受保护男主人物图的校验记录。
- `originals/`：仅保留文本备份；旧图片已按用户要求删除。
- `world-anchor.png`：共同环境与色调参考。
- `shot-plan.json`：每张图的独立画面设计。
- `*.prompt.txt`：实际使用的内置 image_gen 提示词；不使用CLI或其他模型代替。
- `review.html`：当前重制图与缺图状态。
- 完成后分镜更新回各段 `frames/keyframe_*.png`，怪人图更新回 `assets/enemies/`。
- 旧 `frames/check/` 图片已清理；本次不生成视频。

## 统一视觉约束

阴天软光、中性冷灰与灰褐、自然肤色、少量暖色实景灯光、真实接触阴影和远景大气衰减。怪物不靠红眼、全身尖刺和发光装甲塑形。环境保留公交、阳台、超市、地铁设施，通过路障、怪人岗哨和设施被占用表达世界变化。人物动作与道具以男主三视图和当前导演稿为准。

## 造型区分

速度型：细长、低伏、运动服残片；爆弹型：梨形躯干、肩囊、管状前臂；巨臂型：单侧巨臂、工装；肌肉型：对称方形肩背、短颈；侦查型：细长竖直、单眼、衬衫；缠绕型：人形躯干与放射触肢；飞行型：脏湿长毛与膜翼；怪物王：穿云的巨型人类轮廓。
