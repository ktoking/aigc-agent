> 本片规格：2分钟 / 16:9横屏 / 24镜头 / 无对白 / Seedance 图生视频
> v2 改进：按 dragon-quest 格式重写提示词，每个镜头拆成子节拍（精确动作+运镜+环境动态），加入"禁止静态定格"硬约束，解决 v1 画面像延时摄影的问题。

## 一、通用说明

### 1.1 为什么要拆分

豆包工作台单次视频生成通常支持 5-10 秒，本片每段 30 秒，因此**每个 segment 拆成 3-4 次生成**，生成后用剪映/CapCut 拼接回 30 秒。

**总生成次数：14 次**（Seg1×3 + Seg2×4 + Seg3×4 + Seg4×3）

### 1.2 每次生成的标准操作

1. 打开豆包工作台 → 视频生成 → 选择 **Seedance 2.5**（额度不足时试 2.0 Fast / 2.0）
2. 比例选 **16:9**，时长选 **10秒**（或工作台支持的最长时长）
3. 上传对应首帧图（见每段标注）
4. 粘贴该子片段的精简提示词（从本文件复制，纯文本）
5. 开启**音画同步**（生成音效）
6. 生成 → 下载 → 命名保存

### 1.3 v2 提示词核心改进（解决定格问题）

v1 提示词是概括式描述（如"男主一边走一边最小动作处理攻击"），导致 AI 生成静态画面。v2 每个镜头拆成 2-3 个子节拍，每个子节拍有：
- **精确时间点**（0-2.5s / 2.5-5s）
- **连续动作点**（不是概括，是具体动作）
- **运镜描述**（拉远/跟随/推近/上摇/低角度仰拍/环绕）
- **环境动态**（烟尘流动/火星飘落/广告屏闪烁/碎石飞散/云层移动）

每条提示词末尾都有硬约束：
> 不要静态定格超过1秒，不要空镜头，不要背景完全静止，不要画面像延时摄影，不要动作卡顿。每一秒都有可见运动元素。

### 1.4 角色一致性锚定

每次生成时，除了首帧图，建议同时上传男主三视图作为参考图（如果工作台支持多图参考）：
`stories/homecoming/assets/characters/male-protagonist-final.png`

男主锁定描述（每条提示词已包含）：
> 约25岁帅气年轻男性，黑色短发略凌乱，自然慵懒半睁眼眼神涣散，面无表情，浅卡其色oversize工装衬衫内搭白T恤，深灰色宽松休闲裤，白色帆布鞋，右手提米色帆布买菜篮（青菜、胡萝卜、鸡蛋盒、葱、豆腐盒、塑料袋）。

### 1.5 拼接方法

全部生成后，用剪映/CapCut：
1. 按 segment_01 → 02 → 03 → 04 顺序导入所有子片段
2. 每个 segment 内部按 A→B→C(→D) 顺序排列
3. 片段衔接处用**0.3秒交叉淡化**或直接硬切（动作戏硬切更有冲击力）
4. 统一调色：冷灰蓝主调 + 橙色火光，对比度+10，饱和度-5
5. 叠加 BGM（4段式情绪谱：低频压迫→鼓点加速→工业打击→史诗悲壮）
6. 导出 1080p / 30fps

## 六、豆包工作台操作清单

### 6.1 生成前准备

- [ ] 登录豆包账号（doubao.com 或豆包APP）
- [ ] 确认视频生成功能已开通（部分功能需要会员）
- [ ] 准备好首帧图（本文件标注的 14 张关键帧，从仓库 `frames/` 目录取出）
- [ ] 准备好男主三视图（`assets/characters/male-protagonist-final.png`），如果工作台支持多图参考则一并上传

### 6.2 每次生成步骤

1. 进入视频生成 → 选择模型 **Seedance 2.5**（额度不足时试 2.0 Fast / 2.0）
2. 比例：**16:9**
3. 时长：选工作台支持的最长时长（通常 5s 或 10s）
4. 上传首帧图（图生视频模式）
5. 粘贴对应子片段的提示词（从本文件复制，纯文本，去掉代码块标记）
6. 开启**音画同步 / 生成音效**
7. 点击生成，等待完成（通常 1-3 分钟）
8. 预览效果 → 满意则下载，不满意则调整提示词重新生成

### 6.3 生成顺序建议

**优先生成 4C（一拳打倒怪物王+压没城市）**，因为这是全片最高潮和最大视觉冲击，效果决定整片质量。然后按以下顺序：

```
4C → 4A → 4B → 4D → 1A → 1B → 1C → 2A → 2B → 2C → 2D → 3A → 3B → 3C → 3D
```

### 6.4 每段验收要点（v2 新增"动态感"检查）

生成后立即检查：

- [ ] **画面持续动态**：没有超过1秒的静态定格，背景（烟尘/火光/广告屏/碎片）持续运动，没有延时摄影感 ⭐ v2 新增
- [ ] **角色一致**：男主脸、发型、服装（卡其工装衬衫+白T+深灰裤+白鞋）、菜篮子是否和首帧一致
- [ ] **无文字/logo**：画面中没有豆包水印、没有AI生成的乱码文字（广告牌文字除外）
- [ ] **无动漫感**：整体是真人电影质感，不是动漫/游戏CG/塑料感
- [ ] **动作可读**：关键动作（挡爪、出拳、爆炸、哈欠）是否清晰可辨
- [ ] **音画同步**：音效是否和动作匹配（拳击声、爆炸声、哈欠声）
- [ ] **无肢体错误**：没有多手指、扭曲手臂、穿模等明显AI瑕疵
- [ ] **菜篮子在**：男主右手始终提着米色帆布菜篮子（这是核心道具，不能丢）
- [ ] **运镜正确**：提示词中要求的运镜（拉远/跟随/推近/上摇/低角度/环绕）是否实现

### 6.5 常见问题处理

| 问题 | 处理方法 |
|---|---|
| 画面像定格/延时摄影 | 检查提示词是否包含子节拍和"不要静态定格"约束；重生成时强调"每一秒都有运动元素" |
| 男主脸变了 | 重生成，或在提示词中加强面部描述，上传男主三视图做参考 |
| 菜篮子消失/变色 | 在提示词中重复强调"右手始终提着米色帆布买菜篮子"，重生成 |
| 画面太动漫/太CG | 提示词开头加"真人实拍电影质感，35mm胶片，真实皮肤毛孔"，重生成 |
| 动作太快看不清 | 提示词中加"动作清晰可读，运动模糊适度"，或降低动作密度 |
| 哈欠变成搞笑表情 | 提示词强调"自然疲惫的哈欠，半闭眼，不夸张，不是表情包"，重生成 |
| 冲击波像动漫能量波 | 提示词强调"真实物理感的空气压缩和撕裂，可见的冲击波环形扩散" |
