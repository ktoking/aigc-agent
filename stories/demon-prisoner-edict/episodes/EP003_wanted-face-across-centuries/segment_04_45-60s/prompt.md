因果硬锁：门闩断裂 → 三名猎兵涌入，目标明确是活捉沈烬割舌抽血——他们不杀人，只割舌废掉能力后圈养 → 阿璃挡在前面但力量悬殊 → 沈烬看到猎兵手中的钳口器和铁印，推开阿璃 → 沈烬用尽全身力气从被封死的喉咙里挤出一个破碎的"退"字 → 三名猎兵同时僵住半秒（敕令不取决于声音大小，取决于意志）→ 沈烬鼻血涌出，喉间封痕加深 → 阿璃抓住半秒拉沈烬跑向后窗，敲碎窗格翻入雨幕 → 镜头留在驿站内，一名猎兵走到画像墙前撕下最旧的画像 → 画像背后的木墙上嵌着一枚锈迹斑斑的金属钳口器，与猎兵手中的一模一样但老了一百年——这是百年前割舌用的工具。

镜头一｜破门
景别：横屏固定中景。
构图：驿站大门在画面左侧被撞开，门闩断裂飞落；三名黑甲猎兵从门外涌入，居中一人持金属钳口器，右侧一人持烧红铁印，左侧一人伸手抓向沈烬；阿璃在画面右侧张开手臂挡在沈烬身前，骨针横在胸前；沈烬在阿璃身后。
运镜手法：门破时短促震动一下，随后完全固定机位，猎兵涌入时保持空间关系清晰，不跟随、不摇镜。
画面内容：猎兵动作整齐、安静，没有呐喊；钳口器是金属制的割舌固定器，用来撑开嘴部干净利落地割舌废掉能力，铁印烧得暗红但没有火焰；阿璃脸色发白，手臂在发抖但没有后退。
说话者绑定：阿璃单独开口，声音紧张但不退，正面口型清楚。对白与画面同步生成。
阿璃：
"别过来！"

镜头二｜退
景别：沈烬正面紧近景转三人中景。
构图：沈烬先居中正面，推开阿璃的手臂从画面左侧伸入；他张口，喉间暗红封痕剧烈跳动，整张脸都在用力；硬切后三名猎兵在画面中同时僵住，动作停在半途中，沈烬在右前景鼻血涌出。
运镜手法：固定沈烬口型；"退"字挤出的瞬间完全停止运镜，随后极慢数字后拉展示三名猎兵同时僵住的空间状态，不做快速运动。
画面内容：沈烬的声音不是清晰的命令，而是破碎、嘶哑、几乎听不清的气音，但三个猎兵在同一瞬间全部僵住——不是被吓停，是被敕令强制停止；沈烬的鼻血从左鼻孔涌出，滴在囚衣领口；瞳孔深处闪过一道极微弱的暗金古篆，比 EP001 的"停"暗淡得多。
说话者绑定：本镜头仅沈烬开口，他正面、嘴部和眼睛清楚；命令必须破碎、嘶哑、低沉，不能被音效盖住；敕令命中后所有猎兵静止，阿璃闭嘴。对白与画面同步生成，沈烬破碎敕令的气音与口型同步。
沈烬：
"退。"

镜头三｜半秒逃生
景别：固定中景硬切室外大远景。
构图：前半段固定室内中景，阿璃抓住沈烬手臂拉向画面右侧后窗，骨针敲碎木窗格；硬切后室外大远景，驿站后墙在画面左侧，两人从窗口翻出落入下方雨幕中的泥地，起身继续跑；猎兵在窗口开始恢复动作。
运镜手法：室内完全固定机位，阿璃拉人、敲窗、翻出都在固定画面中完成；硬切室外大远景，完全固定，不后拉、不跟随；人物从窗口翻出后自然跑向画面右前方。
画面内容：阿璃没有犹豫，抓住这半秒的空档；她用骨针敲碎窗格木屑飞溅，沈烬还在晕眩中被她拖着走；两人翻窗落入泥地，溅起泥水；猎兵在窗口开始动弹，但已经晚了；室外暴雨如注。
说话者绑定：阿璃在拉人时喊出一个字，口型急促，声音被雨声包裹。对白与画面同步生成。
阿璃：
"走！"

镜头四｜百年钳口器
景别：室内固定中景转道具特写。
构图：一名猎兵走到画像墙前，戴甲的手抬起，撕下最旧、最霉烂的那张画像；画像背后的木墙上，嵌着一枚锈迹斑斑的金属钳口器，形状与猎兵手中的一模一样，但锈蚀严重、边缘发黑，至少有一百年历史。
运镜手法：猎兵撕画时固定中景，画像落下后缓慢推近到钳口器特写，停在锈迹纹理上切黑；不做快速运动。
画面内容：画像被撕下时纸张碎裂；钳口器嵌在木墙的凹槽里，周围有干涸的暗色痕迹；猎兵的甲手悬在钳口器前，没有触碰，像是在确认什么；这不是新发现，而是一个被反复使用了一百年的割舌工具——墙上的每一张画像，都曾被它撑开嘴、割掉舌头。
说话者绑定：无人说话。只有撕纸的刺耳声响和金属钳口器的冰冷碰撞声，然后切黑。

表演要求：沈烬的"退"不是超级英雄的呐喊，而是从被封死的喉咙里挤出来的破碎气音，意志大于声音；猎兵的僵住是强制停止，不是恐惧，半秒后他们就能恢复；阿璃的反应要快，她不是等沈烬救她，而是抓住机会救人；最后的钳口器镜头要安静、冰冷，让观众自己意识到墙上几十张脸的命运。声音：门闩断裂、猎兵甲胄碰撞、沈烬挤出"退"字时喉咙的撕裂声、半秒绝对死寂、鼻血滴落、骨针敲碎窗格、翻窗泥水飞溅、雨声重新涌入——最后是撕纸的刺耳声响和金属钳口器的冰冷碰撞，切黑。
