# EP001：一句“停”，箭雨悬空

## 本集目标

在 60 秒内完成沈烬苏醒、阿璃解锁、韩枭拔刀、敕令觉醒和阿璃身份反转。观众应在本集结束时理解“沈烬能让现实服从短命令，但能力存在反噬”，并产生“阿璃究竟是谁”的追看问题。

## 完整剧情

暴雨将至，一辆破旧囚车穿过雾谷。锁链随着车轮震动，赤足踩在湿草上，沈烬嘴角带血、双目紧闭。阿璃发现他仍有呼吸，刚要靠近，沈烬突然睁眼。她压低声音：“别出声，他们在找醒过来的人。”车外脚步随即停住。

阿璃从发间抽出骨针，撬动沈烬腕上的符锁。沈烬透过帘缝看到通往祭坛的山道和残破活祭石碑。他还没来得及开口，韩枭掀帘发现松开的锁链。沈烬站起来挡住阿璃。韩枭拔刀：“原来真有一个没死透。”

韩枭把刀压向阿璃颈侧，车外弓手同时放箭。沈烬盯着逼近的刀锋，只说：“停。”所有声音瞬间消失，箭矢、雨滴和刀锋同时凝固。沈烬瞳孔深处闪过暗金古篆。

沈烬牵着阿璃穿过凝固箭雨，眼角逐渐渗血。他们刚走出箭阵，时间恢复，群箭砸进泥地。韩枭惊恐跪下：“敕令者……不是百年前就死绝了吗？”沈烬回头，阿璃仍是正常人脸，背后的雾却形成覆盖山谷的长角妖王影子。她用陌生声线说：“我终于等到你了。”

## 台词表

| 角色 | 台词 | 情绪 |
| --- | --- | --- |
| 阿璃 | 别出声，他们在找醒过来的人。 | 几乎贴耳的急促低声 |
| 沈烬 | 这是哪儿？ | 虚弱、克制 |
| 阿璃 | 去祭坛的路。想活，就别动。 | 压低声音但明确 |
| 韩枭 | 原来真有一个没死透。 | 冷笑 |
| 韩枭 | 把刀放下？你也配命令我？ | 轻蔑、逼近 |
| 阿璃 | 沈烬，别看刀——看着我。 | 紧张但镇定 |
| 沈烬 | 停。 | 低沉、清晰、不可违抗 |
| 沈烬 | 跟紧我。我不知道还能撑多久。 | 忍痛急促 |
| 韩枭 | 敕令者……不是百年前就死绝了吗？ | 失去镇定 |
| 阿璃 | 我终于等到你了。 | 陌生、低沉、平静 |

## 声音设计

- Segment 01：木轮、锁链、远雷、车篷拍击、脚步突然停止。
- Segment 02：骨针轻刮锁芯、布帘掀动、刀出鞘低鸣。
- Segment 03：弓弦齐响后被瞬间抽空，敕令“停”带极轻低频尾音，不加电子音。
- Segment 04：低心跳、血滴、时间恢复后的密集落箭、远雷和妖影出现时的低沉呼吸。
