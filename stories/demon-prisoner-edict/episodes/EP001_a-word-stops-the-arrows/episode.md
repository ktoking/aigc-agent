# EP001：一句“停”，箭雨悬空

暴雨将至，一辆囚车驶入镇妖司控制的雾谷。沈烬在车轮与锁链声中恢复意识，手腕和颈侧都留着像被火烧过的暗红符锁痕。他还没弄清自己是谁，坐在车内另一侧的阿璃已经提醒他重新闭眼：外面的押送者专门检查醒着的祭品。

阿璃从发间抽出骨针，偷偷撬动沈烬右腕的符锁。透过帘缝，沈烬看见石阶通向云中的祭坛，阿璃告诉他，他们都是被送去喂妖的人。锁芯发出轻响，校尉韩枭掀开门帘。沈烬只解开右手，左腕仍拖着断链，却主动挡在阿璃身前。

韩枭把黑刃压向阿璃颈侧，又命车外弓手放箭。阿璃没有看刀，只让沈烬看着自己、别乱动。弓弦齐响，箭从后方右侧飞来。沈烬胸口像有陌生的声音撞出来，在自己也未反应过来前说出一个低沉清晰的“停”。刀锋、箭矢和每一颗雨滴在同一瞬间凝固，瞳孔深处只闪过一道克制的暗金古篆。

沈烬牵着阿璃从凝固箭雨中穿过，右眼角逐渐渗出鲜血。他说不清这股力量在抽走什么。雨滴先恢复，箭随后沿原方向飞过或坠入泥地。韩枭认出这种已经失传百年的能力，惊恐跪下。沈烬回头时，阿璃仍保持正常人脸，却突然停步——她看着沈烬带血的脸和眼角，想起母亲生前描述过的敕令者特征，眼神从茫然变为坚定，用自己的声音说：我终于等到你了。

| Segment | 核心任务 |
| --- | --- |
| 01 | 囚车进入雾谷；沈烬醒来，阿璃让他装死；门外脚步停止形成第一重危险 |
| 02 | 阿璃用骨针解开沈烬右腕；两人确认祭坛用途；韩枭掀帘、沈烬挡人、黑刃出鞘 |
| 03 | 韩枭挟持阿璃并命令放箭；沈烬第一次发动敕令，使刀、箭、雨同时凝固 |
| 04 | 沈烬带阿璃穿过箭雨并承受流血反噬；时间恢复；韩枭认出敕令者，阿璃认出沈烬身份并说出等待多年的话 |

## 本集冲突

- 处境：沈烬失忆、重伤、双腕被锁，正在被押往祭坛。
- 选择：他可以继续装死，也可以在只解开一只手的情况下保护阿璃。
- 爽点：韩枭下令放箭后，沈烬只用一个“停”字冻结刀、箭与暴雨。
- 代价：敕令立刻让沈烬右眼流血，证明能力不能无限使用。
- 尾钩：阿璃本人没有妖化；她自己认出沈烬是敕令者（母亲告诉过她特征），说出"我终于等到你了"——她等了很多年，终于等到一个活着的敕令者。

## 声音主线

- Segment 01：木轮、锁链、远雷与脚步突然停止。
- Segment 02：骨针刮锁、锁芯松开、门帘掀动与黑刃出鞘。
- Segment 03：弓弦与箭破风被“停”瞬间抽空，只留一次低心跳。
- Segment 04：血滴、雨声恢复、密集落箭、黑刃落地与远雷。
