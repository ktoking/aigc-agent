# 全局视觉风格

唯一视觉基准：`../style-candidates/style-b-painterly-3d.png`（B：手绘材质 3D）。

原创角色，手绘材质半写实 3D 东方玄幻动画电影，古代妖灾世界。人物采用柔和雕塑体块，皮肤不出现真人毛孔；衣料、发丝、甲片和旧损以宽笔触厚涂纹理概括，保持哑光材质、干净大形和清晰轮廓。冷灰蓝低饱和调色，灰雾背景，柔和电影塑形光，体积雾、空气透视、浅景深、真实重量感与前中后景分层；暗金色只用于敕令觉醒。

画面应像高预算手绘材质 3D 动画电影截帧：比二次元赛璐璐更有体积，比真人影视和写实游戏 CG 更绘画化。禁止真人摄影皮肤、镜头照片感、黑色漫画描边、平面赛璐璐、高光塑料手办感。
