# 镇妖司外门妖铁牌阵道具卡

- Prop ID：`DPE_OUTER_GATE_PASS_ARRAY_001`
- 所属场景：镇妖司外门登记场 `DPE_DEMON_SUBDUING_OUTER_GATE_001`。
- 外形：地下维护长廊两侧分层悬挂大量无字黑铁牌，牌底以细黑实体线接入地面独立锁座；入口设多槽登记架。
- 规则：每块登记铁牌对应一条黑线和一枚共伤锁；铁牌可旋转夹击，但安全破局点是线接入锁扣的一寸连接，而不是铁牌本体。
- 连续性：铁牌统一为顶部单圆孔的无字长方形；中央维护通道始终可供一人穿行，黑线贴地或垂落，不做发光连线。
