# 故事记忆

## 一句话梗概

被押往妖血祭坛的失忆囚徒沈烬觉醒“敕令”，一句话令现实短暂停止，却发现救他的少女阿璃与妖王有关。

## 世界规则

- 镇妖司公开宣称以妖血加固边境封印，实际上把普通人和混血者一并送去活祭。
- “敕令者”能以声音短暂修改局部现实，百年前被镇妖司围剿至绝迹。
- 敕令必须是短而明确的命令；范围、持续时间和反噬随命令强度增加。
- 沈烬第一次公开能力是“停”：冻结箭矢、雨滴与刀锋数息。
- 阿璃暂时表现为同囚少女，真实身份只通过妖王影子和陌生声线提示。

## 已确认人物关系

- 沈烬本能保护阿璃，但并不知道她为何认识自己。
- 阿璃主动帮助沈烬解锁，目的并不单纯。
- 韩枭负责把活祭者送上祭坛，见到敕令后从蔑视转为恐惧。

## EP001 尾态

- 沈烬与阿璃仍在雾谷山道，箭雨已坠地。
- 沈烬眼角渗血，能力进入反噬。
- 韩枭尚未死亡，已跪地认出“敕令者”。
- 阿璃背后短暂出现巨大妖王影子，并说“我终于等到你了”。
