# 故事记忆

## 一句话梗概

被押往祭坛的失忆囚徒沈烬觉醒"敕令"——说出来就能言出法随，却被镇妖司一路追杀割舌。他和同囚少女阿璃逃出雾谷，一路逃荒到小镇，发现镇妖司用敕令者的血炼制"敕令符"，普通人也能借来言出法随的力量。

## 世界规则

### 敕令者

- 敕令者能以意志修改现实，**不限于固定词语**——说什么或想什么就发生什么。简短精确的词（"停""滑""亮""死"）反噬小，长句子、大范围、违背自然规律的命令反噬极大。
- 反噬程度与命令强度成正比：轻微命令→喉咙灼痛；中等→流鼻血、短暂失声；强力→器官损伤、永久失声；极限→死亡。
- **声音敕令**：大多数敕令者通过声音发动，声音必须抵达作用范围。对活体直接下令时，目标需要能接收声音，因此对无耳猎兵无效；对地面、兵器、车轮等死物，则是声音抵达附近后修改其局部物理状态，不要求死物具有听觉。无声环境会阻断这条传播路径。
- **意志敕令（无声敕令）**：极少数强大的敕令者可以不通过声音、直接以意志发动敕令，不需要被目标听到。沈烬天生具备此能力，但失忆后不自知，一直习惯用声音；EP001本能喊出"停"（有声），EP003失声后本能以意志默念"死"，才意识到自己不需要声音。意志敕令的反噬比同等级声音敕令更重。
- 敕令者的能力核心在意志，声带与舌只是常见的输出载体；割舌后不能再用声音敕令，但意志敕令不受影响。

### 敕令符（法器）

- 镇妖司用敕令者的精血和特殊符纸炼制**敕令符**，是消耗品法器。
- 普通人捏碎符箓并念出触发词，就能释放一次预设的敕令（如"停""退""裂"）。
- 消耗品，用一次符纸即烧成灰。越强的敕令者的血制成的符威力越大、可使用次数越多。
- 分品级：下品（单次小效果）、中品、上品（强大敕令者之血，可多次使用或大效果）。
- 镇妖司大量炼制敕令符用于维持封印、执行任务，也在黑市贩卖牟利。
- 敕令符和活体敕令者一样需要被目标听到才生效，封住使用者的嘴或制造无声环境可使其失效。

### 镇妖司

- 表面上是除妖卫道的官方机构，维持边境封印。
- **实际上由妖掌控**——当今教主本身就是妖，镇妖司的高层和精锐都是加入组织的妖。
- 靠抓捕敕令者获取精血炼制敕令符。抓捕→割舌废掉能力→圈养→定期抽血炼符，是一个永续的剥削系统。
- **割舌的目的不是取舌头，而是废掉敕令者的能力**，方便圈养取血。
- **短刀**是割舌时固定受刑者嘴部的专业工具，保证干净利落地割舌。
- **无耳猎兵**是镇妖司的精锐特种部队，本身就是加入镇妖司的妖：他们主动割去耳朵以免疫声音敕令，只听从教主和上级命令，手持短刀和网，专门在确认敕令者出没后出动活捉。日常巡逻和押送由普通镇妖司小兵负责。
- **搜查使**是镇妖司专门追捕敕令者的官员，佩戴高级敕令符，有战斗力，管理无耳猎兵。
- 敕令者被镇妖司猎杀数百年，几乎绝迹；但镇妖司始终保留抓捕能力和相关装备，因为教主需要敕令者血，且偶尔有敕令者后代觉醒。

### 妖与镇妖司的关系（核心设定）

- **妖以人肉为食**，这是这个世界的基本生存法则。
- 妖在人间没有容身之地：**要么加入镇妖司，定期领取人肉祭品作为报酬；要么拒绝加入，被镇妖司悬赏猎杀。**
- 加入镇妖司的妖可以定期获取人肉祭品，这是他们效忠教主的根本原因——镇妖司本质上是一个以人肉为军饷的妖组织。
- 镇妖司对外宣传"除妖卫道"，实际上只猎杀不肯归顺的妖；归顺的妖则成为猎兵、校尉和高层，享受人肉祭品。
- 当今教主是镇妖司的最高统治者，也是最强的妖；所有祭品最终都流向教主和镇妖司的妖群。

### 敕令者为何被归为妖

- 敕令者的血能让使用者获得言出法随的能力（炼制敕令符），这种力量被镇妖司定性为妖术。
- 因此**敕令者被官方归类为妖**，但与普通妖不同——他们的血太珍贵，镇妖司不肯收编，而是赶尽杀绝、割舌圈养、抽血炼符。
- 普通妖加入镇妖司可以活命领祭品；敕令者连投降的资格都没有，因为他们的血就是镇妖司最稀缺的资源。
- 百年前敕令者被大规模屠杀后，再也没有新的敕令者血源补充，现存的敕令符都是存量消耗品，越用越少。
- **沈烬是百年不遇的活体敕令者**——他被镇妖司捕获后，不是普通祭品，而是要被专门献给教主的珍贵血源。阿璃能判断他是敕令者（母亲教过特征：暗金古篆、反噬流血、言出法随），但无法判断具体品级。

### 囚车与教主

- 沈烬和阿璃在囚车上相遇，两人都是被押往镇妖司总坛、献给教主的祭品。
- 阿璃作为敕令者后代（潜在敕令者），也是祭品之一；沈烬因为是活体敕令者，价值远高于普通祭品。
- EP001中阿璃说"我们都是送去喂妖的"——这不是比喻，是字面意义：祭品最终会被献给教主及镇妖司的妖，普通人肉作为食物，敕令者作为血源炼符。
- 废弃驿站墙上的猎杀记录，是镇妖司百年来屠杀敕令者的罪证——每一张画像背后，都是一个被割舌抽血的敕令者。

### 墙上的猎杀记录

- 废弃驿站墙上的几十张跨世纪画像，是镇妖司的猎杀记录——每杀一个敕令者就画一张像挂在这里，每张角落都有刀痕印记。
- 画中人各不相同（不同年龄、性别、服装），但都是敕令者，都有颈侧或手腕的暗红符锁灼痕。
- 第一张画像与沈烬有几分相似（承接EP002的悬念），但整面墙是不同的敕令者，不是同一家族。
- 沈烬是被镇妖司抓到的失忆敕令者，和其他祭品一起押往祭坛。

## 人物

### 沈烬

- 失忆的敕令者，不知道自己是谁，不知道自己有能力。
- 觉醒后逐步探索能力：从无意识的"停"（有声），到失声后本能使用意志敕令"死"（无声），到有意识地尝试不同词语和控制反噬。
- 天生具备意志敕令（无声敕令）的天赋，但失忆后不自知，一直习惯用声音作为载体；EP003失声后才意识到自己不需要声音也能发动。
- 性格：沉默、隐忍、本能保护弱者，觉醒后逐渐变得果断。
- 核心弧线：从"我是谁"的迷茫，到"我要活下去"的求生，到"我要终结割舌圈养"的决心。

### 阿璃

- 她是敕令者的后代——母亲是敕令者，在她小时候被镇妖司割舌圈养，后来死在圈养所。
- 她被镇妖司当作"潜在敕令者"圈养，后来和沈烬一起被当作祭品押往祭坛。
- 她自己没有觉醒敕令能力，但母亲生前告诉过她很多关于敕令者、敕令符和镇妖司的事。
- 她帮沈烬是因为：恨镇妖司、在沈烬身上看到母亲的影子、她一直在等一个能反抗的敕令者。
- EP001结尾她说"我终于等到你了"——是她自己说的，她认出了沈烬是敕令者（母亲描述过的特征），等了很多年终于等到一个觉醒的人。
- 性格：聪明、果断、有行动力，是沈烬的"锚"——在他被反噬失去理智时把他拉回来。

### 韩枭

- 镇妖司基层校尉，负责押送祭品。
- 认出敕令者后从恐惧转为兴奋——割舌带回去抽血炼符，能领大赏。

### 搜查使（EP007后登场）

- 镇妖司专门追捕敕令者的官员，戴青铜面具，身披黑甲。
- 佩戴上品敕令符，战斗力强。
- 管理无耳猎兵，是沈烬前期遇到的最强对手。

## EP001 尾态

- 沈烬与阿璃仍在雾谷山道，箭雨已坠地。
- 沈烬眼角渗血，能力进入反噬。
- 韩枭尚未死亡，已跪地认出"敕令者"。
- 阿璃认出沈烬是敕令者，眼神从茫然变为坚定，说"我终于等到你了"——她自己的意志，不是被附身。没有妖王影子。

## EP002 尾态

- 两人进入废弃驿站，旧灯亮起，墙上同脸无字画像露出一角。
- 沈烬被禁声符锁残余封环擦过喉间，彻底失声；右掌有新鲜伤口。
- 阿璃左腕被符火擦出浅灼痕，发间骨针已使用过一次。
- 韩枭带追兵在驿站外，但雨声突然骤停——暗示追兵已逼近。
- 沈烬被禁声符锁残余封环擦过喉间，彻底失声；但他的敕令本质是意志，失声后仍可能以意志发动（他自己尚未意识到）。

## EP003 尾态

- 两人从驿站逃出，滑下山坡，摆脱追兵。
- 驿站内整面墙几十张猎杀记录画像已被揭示（画中人各不相同，都是被屠杀的敕令者）。
- 世界观揭示：妖以人肉为食，在人间没有容身之地，要么加入镇妖司定期领人肉祭品，要么被悬赏猎杀；镇妖司实际上由妖掌控，教主本身就是妖；敕令者因血能让人言出法随被归为妖，但血太珍贵不肯收编，只赶尽杀绝抽血炼符；百年前敕令者被屠杀后再无新血，沈烬是百年不遇的活体敕令者，囚车上要被献给教主。
- 阿璃确认沈烬是敕令者（母亲教过的特征），知道他要被献给教主，但无法判断具体品级。
- 追兵为普通镇妖司小兵（非无耳猎兵），破门而入后，沈烬在失声状态下本能以意志默念"死"——无声敕令，小兵当场死亡。
- 无声"死"敕令反噬极强：沈烬鼻血涌出、喉间封痕剧烈跳动、短暂晕眩。
- 沈烬第一次意识到自己不需要声音也能发动敕令——意志敕令是他的天生能力，不是新发现的技巧。
- 去掉密信/骨针/百年断刀线索，EP003不埋后续坑。

## EP005 尾态与后续硬锁

- 沈烬与阿璃已离开安魂镇外野茶棚，随山道继续北行；沈烬得到一张未使用的下品法术符纸，阿璃确认镇妖司的符已流入山中黑市。
- 沈烬本集可稳定使用短敕令和长句命令，表面没有即时反噬；这不代表他能无代价修改生死。面对远强于自己的妖王，直接"死"令会被反噬堵回喉间。
- 裂风涧的山魈王是镇妖司长期供养的地方食人妖：祭道、残破镇妖司木牌、祭盘与旧兵器都证明镇妖司定期把活人送来。
- 阿璃不具备敕令，但能以骨针、近身判断与执行力完成最后一击；精魄进入沈烬封痕后只表现为新的感知和不稳定的暗金回响，不给出固定等级或数值化技能。

## EP007 尾态与后续硬锁

- 魁冥已死，裂风涧祭场和活祭运输证据仍在；远处第二辆祭车正在靠近，沈烬与阿璃决定截车救人。
- 阿璃持有沈烬凭敕令从无到有创造的无字克妖剑，并拾得魁冥腰间无字镇妖司旧铁牌。克妖剑是目前唯一稳定留存的敕令造物，不允许随手无限复制；对剑临时附加的新性质只维持当场，并会触发沈烬颈侧封痕或远钟回响。
- 阿璃仍未觉醒敕令。她的成长来自观察、走位、骨针、克妖剑和承担近身风险，不用突然觉醒替代人物行动。
- 沈烬已知道自己能使用有声和无声敕令，但无声敕令的优势只是绕开听觉与禁声，绝不是代价更小；同等级无声敕令反噬更重。
- 从裂风涧到镇妖司外门，沿途妖怪不是随机出现，而是祭品运输、封口、收容、交易与登记组成的供养链。越接近镇妖司，登记妖越多、组织程度越高。
