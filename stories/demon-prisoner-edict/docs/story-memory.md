# 故事记忆

## 一句话梗概

被押往祭坛的失忆囚徒沈烬觉醒"敕令"——说出来就能言出法随，却被镇妖司一路追杀割舌。他和同囚少女阿璃逃出雾谷，一路逃荒到小镇，发现镇妖司用敕令者的血炼制"敕令符"，普通人也能借来言出法随的力量。

## 世界规则

### 敕令者

- 敕令者能以声音修改现实，**不限于固定词语**——说什么就发生什么。简短精确的词（"停""滑""亮"）反噬小，长句子、大范围、违背自然规律的命令反噬极大。
- 反噬程度与命令强度成正比：轻微命令→喉咙灼痛；中等→流鼻血、短暂失声；强力→器官损伤、永久失声；极限→死亡。
- 敕令需要被目标"听到"才能生效——对听不见的对象（无耳猎兵）无效。在无声环境中敕令无法传播。
- 敕令者的能力核心在声带与舌，割舌后永远不能言出法随，但人还能活。

### 敕令符（法器）

- 镇妖司用敕令者的精血和特殊符纸炼制**敕令符**，是消耗品法器。
- 普通人捏碎符箓并念出触发词，就能释放一次预设的敕令（如"停""退""裂"）。
- 消耗品，用一次符纸即烧成灰。越强的敕令者的血制成的符威力越大、可使用次数越多。
- 分品级：下品（单次小效果）、中品、上品（强大敕令者之血，可多次使用或大效果）。
- 镇妖司大量炼制敕令符用于维持封印、执行任务，也在黑市贩卖牟利。
- 敕令符和活体敕令者一样需要被目标听到才生效，封住使用者的嘴或制造无声环境可使其失效。

### 镇妖司

- 表面上是除妖卫道的官方机构，维持边境封印。
- 实际上靠抓捕敕令者获取精血炼制敕令符。抓捕→割舌废掉能力→圈养→定期抽血炼符，是一个永续的剥削系统。
- **割舌的目的不是取舌头，而是废掉敕令者的能力**，方便圈养取血。
- **钳口器**是割舌时固定受刑者嘴部的专业工具，保证干净利落地割舌。
- **无耳猎兵**是专业抓捕部队：没有耳朵（被敕令震聋或主动割耳），免疫敕令，手持钳口器和网，专门活捉敕令者。
- **搜查使**是镇妖司专门追捕敕令者的官员，佩戴高级敕令符，有战斗力，管理无耳猎兵。
- 敕令者被镇妖司猎杀数百年，几乎绝迹。

### 墙上的猎杀记录

- 废弃驿站墙上的几十张跨世纪画像，是镇妖司的猎杀记录——每杀一个敕令者就画一张像挂在这里，每张角落都有钳口器印记。
- 画中人各不相同（不同年龄、性别、服装），但都是敕令者，都有颈侧或手腕的暗红符锁灼痕。
- 第一张画像与沈烬有几分相似（承接EP002的悬念），但整面墙是不同的敕令者，不是同一家族。
- 沈烬是被镇妖司抓到的失忆敕令者，和其他祭品一起押往祭坛。

## 人物

### 沈烬

- 失忆的敕令者，不知道自己是谁，不知道自己有能力。
- 觉醒后逐步探索能力：从无意识的"停"，到有意识地尝试不同词语，到学会控制反噬，到发现意志敕令。
- 性格：沉默、隐忍、本能保护弱者，觉醒后逐渐变得果断。
- 核心弧线：从"我是谁"的迷茫，到"我要活下去"的求生，到"我要终结割舌圈养"的决心。

### 阿璃

- 她是敕令者的后代——母亲是敕令者，在她小时候被镇妖司割舌圈养，后来死在圈养所。
- 她被镇妖司当作"潜在敕令者"圈养，后来和沈烬一起被当作祭品押往祭坛。
- 她自己没有觉醒敕令能力，但母亲生前告诉过她很多关于敕令者、敕令符和镇妖司的事。
- 她帮沈烬是因为：恨镇妖司、在沈烬身上看到母亲的影子、她一直在等一个能反抗的敕令者。
- EP001结尾她说"我终于等到你了"——是她自己说的，她认出了沈烬是敕令者（母亲描述过的特征），等了很多年终于等到一个觉醒的人。
- 性格：聪明、果断、有行动力，是沈烬的"锚"——在他被反噬失去理智时把他拉回来。

### 韩枭

- 镇妖司基层校尉，负责押送祭品。
- 认出敕令者后从恐惧转为兴奋——割舌带回去抽血炼符，能领大赏。

### 搜查使（EP007后登场）

- 镇妖司专门追捕敕令者的官员，戴青铜面具，身披黑甲。
- 佩戴上品敕令符，战斗力强。
- 管理无耳猎兵，是沈烬前期遇到的最强对手。

## EP001 尾态

- 沈烬与阿璃仍在雾谷山道，箭雨已坠地。
- 沈烬眼角渗血，能力进入反噬。
- 韩枭尚未死亡，已跪地认出"敕令者"。
- 阿璃认出沈烬是敕令者，眼神从茫然变为坚定，说"我终于等到你了"——她自己的意志，不是被附身。没有妖王影子。

## EP002 尾态

- 两人进入废弃驿站，旧灯亮起，墙上同脸无字画像露出一角。
- 沈烬被禁声符锁残余封环擦过喉间，彻底失声；右掌有新鲜伤口。
- 阿璃左腕被符火擦出浅灼痕，发间骨针已使用过一次。
- 韩枭带追兵在驿站外，但雨声突然骤停——暗示比韩枭更可怕的无耳猎兵已到。
- 新增能力规则：敕令必须以清晰声音触发，失声状态下即使强迫发声也无法令现实改变。

## EP003 尾态

- 两人从驿站后窗翻入暴雨逃脱，沈烬失声加重、鼻血涌出。
- 驿站内整面墙几十张猎杀记录画像已被揭示（画中人各不相同，都是被屠杀的敕令者）；最旧画像背后嵌着一枚百年前的锈迹钳口器——这是百年前割舌用的工具。
- 暗格内发现一封前人留下的信，首句"若你看到此信，说明敕令尚未断绝"。
- 三名无耳猎兵留在驿站内，他们听不见敕令、专门以割舌圈养为目的。
- 新增能力规则：敕令不取决于声音大小，破碎到几乎听不清的气音只要意志足够明确也能触发，但代价成倍增加（鼻血、封痕加深），效果仅为半秒僵直。
