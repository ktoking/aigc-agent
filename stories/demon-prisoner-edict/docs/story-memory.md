# 故事记忆

## 一句话梗概

被押往祭坛的失忆囚徒沈烬觉醒"敕令"——说出来就能言出法随，却被镇妖司一路追杀割舌。他和同囚少女阿璃逃出雾谷，一路逃荒到小镇，发现镇妖司割下的舌头竟成了别人手中的消耗品法器。

## 世界规则

### 敕令者

- 敕令者能以声音修改现实，**不限于固定词语**——说什么就发生什么。简短精确的词（"停""滑""亮"）反噬小，长句子、大范围、违背自然规律的命令反噬极大。
- 反噬程度与命令强度成正比：轻微命令→喉咙灼痛；中等→流鼻血、短暂失声；强力→器官损伤、永久失声；极限→死亡。
- 敕令需要被目标"听到"才能生效——对听不见的对象（无耳猎兵）无效。在无声环境中敕令无法传播。
- 敕令者的能力寄宿于舌。舌头是敕令之力的载体，割下后仍保留残余敕令之力。

### 舌头法器（核心设定）

- 割下的敕令者舌头是**消耗品法器**：普通人含着或握着舌头，也能言出法随。
- 舌头是消耗品，每使用一次敕令就消耗一分，用尽后化为灰烬。越强大的敕令者，舌头能用越多次。
- 舌头法器的反噬由使用者承担，但因为不是自己的舌头，反噬表现为生命力消耗/加速衰老，而非喉咙损伤。
- 这就是镇妖司割舌的真正目的：获取可消耗的言出法随法器，用于维持封印、执行任务、高层私用和黑市贩卖。
- 舌头法器需要被"听到"才能生效，和活体敕令者一样受无声环境克制。

### 镇妖司

- 表面上是除妖卫道的官方机构，维持边境封印。
- 实际上靠割取敕令者舌头获取言出法随法器。封印维持是真的，但大量舌头被私用和贩卖。
- **钳口器**是专业割舌工具：撑开受刑者嘴部，完整取下舌头保持法器完整。
- **无耳猎兵**是专业割舌部队：没有耳朵（被敕令震聋或主动割耳），免疫敕令，手持钳口器，专门收割舌头。
- 敕令者家族被镇妖司猎杀数百年，几乎绝迹。

### 墙上的同脸画像

- 敕令者家族有极强的显性遗传，每一代男性都长着几乎相同的脸。
- 废弃驿站墙上的几十张跨世纪同脸画像，就是历代被割舌的敕令者先祖。
- 沈烬是这一代唯一的幸存者，被镇妖司抓到后失忆，和其他祭品一起押往祭坛。

## 人物

### 沈烬

- 失忆的敕令者，不知道自己是谁，不知道自己有能力。
- 觉醒后逐步探索能力：从无意识的"停"，到有意识地尝试不同词语，到学会控制反噬。
- 性格：沉默、隐忍、本能保护弱者，觉醒后逐渐变得果断。
- 核心弧线：从"我是谁"的迷茫，到"我要活下去"的求生，到"我要终结割舌"的决心。

### 阿璃

- **没有妖王残识**。她是敕令者的后代——母亲是敕令者，在她小时候被镇妖司割舌杀害。
- 她被镇妖司当作"潜在敕令者"圈养，后来和沈烬一起被当作祭品押往祭坛。
- 她自己没有觉醒敕令能力，但母亲生前告诉过她很多关于敕令者和镇妖司的事。
- 她帮沈烬是因为：恨镇妖司、在沈烬身上看到母亲的影子、她一直在等一个能反抗的敕令者。
- EP001结尾她说"我终于等到你了"——是她自己说的，不是被附身。她认出了沈烬是敕令者（母亲描述过的特征），等了很多年终于等到一个觉醒的人。
- 性格：聪明、果断、有行动力，是沈烬的"锚"——在他被反噬失去理智时把他拉回来。

### 韩枭

- 镇妖司基层校尉，负责押送祭品。
- 认出敕令者后从恐惧转为贪婪——舌头值大钱，要先封声再活捉割舌。

### 舌监（EP006后登场）

- 镇妖司管理舌头法器的高层，收藏着历代强大敕令者的舌头。
- 戴青铜面具，手持玉匣存放舌头法器。
- 他自己也使用舌头法器战斗，是沈烬前期遇到的最强对手。

## EP001 尾态

- 沈烬与阿璃仍在雾谷山道，箭雨已坠地。
- 沈烬眼角渗血，能力进入反噬。
- 韩枭尚未死亡，已跪地认出"敕令者"。
- 阿璃认出沈烬是敕令者，眼神从茫然变为坚定，说"我终于等到你了"——她自己的意志，不是被附身。没有妖王影子。

## EP002 尾态

- 两人进入废弃驿站，旧灯亮起，墙上同脸无字画像露出一角。
- 沈烬被禁声符锁残余封环擦过喉间，彻底失声；右掌有新鲜伤口。
- 阿璃左腕被符火擦出浅灼痕，发间骨针已使用过一次。
- 韩枭带追兵在驿站外，但雨声突然骤停——暗示比韩枭更可怕的无耳猎兵已到。
- 新增能力规则：敕令必须以清晰声音触发，失声状态下即使强迫发声也无法令现实改变。

## EP003 尾态

- 两人从驿站后窗翻入暴雨逃脱，沈烬失声加重、鼻血涌出。
- 驿站内整面墙几十张跨世纪同脸画像已被揭示；最旧画像背后嵌着一枚百年前的锈迹钳口器——这是百年前割舌用的工具。
- 暗格内发现一封沈烬笔迹的信，首句"若你看到此信，说明敕令尚未断绝"——是上一代先祖留下的。
- 三名无耳猎兵留在驿站内，他们听不见敕令、专门以割舌取宝为目的。
- 新增能力规则：敕令不取决于声音大小，破碎到几乎听不清的气音只要意志足够明确也能触发，但代价成倍增加（鼻血、封痕加深），效果仅为半秒僵直。
