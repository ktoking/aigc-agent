# 第一季故事弧

## 核心问题

沈烬究竟是谁？为什么墙上几十张跨世纪的画像都是他的脸？阿璃为什么说"我终于等到你了"？镇妖司用敕令者的血炼制的"敕令符"去了哪里？一个失声的敕令者，能不能在被割舌圈养前终结这百年的猎杀？

## 早期节奏

- EP001：沈烬一句"停"凝固箭雨，阿璃认出他是敕令者，说"我终于等到你了"。
- EP002：韩枭投出禁声符锁要先封声再活捉割舌；阿璃以骨针击偏但残余封环仍封住沈烬声音；阿璃从追兵的网和短刀判断出他们要割舌废掉能力、圈养抽血炼符；二人逃入废弃驿站，沈烬的血意外开启驿门，墙上露出同脸画像一角。
- EP003：驿站内整面墙是镇妖司的猎杀记录——几十张画像每张角落都有刀痕印记，画中人各不相同但都是敕令者；阿璃通过画像简介敕令者曾经遍布天下、被镇妖司屠杀一百年的历史；骨针引导开启暗格，发现一封前人留下的信——"若你看到此信，说明敕令尚未断绝"；无耳猎兵抵达，专门割舌抽血；沈烬在失声状态下以意志默念"定"，令无耳猎兵定住半秒（意志敕令第一次出现，不需要被听到），二人从后门逃脱；猎兵撕下最旧画像，背后嵌着一把百年前的割舌断刀。
- EP004：山林中沈烬声音恢复，开始有意识地探索能力——发现敕令不限于固定词，说什么都能生效，但效果越强反噬越大；学会用最短的词达到最大效果；两人看到远方小镇的灯火。
- EP005：逃到安魂镇，发现镇上有人在用"敕令符"——普通人捏碎符箓就能释放一次敕令；阿璃讲述母亲被割舌圈养的往事；小镇恶霸"铁符"用下品敕令符欺压百姓，盯上了两人。
- EP006：沈烬和铁符交手，第一次对抗敕令符使用者；发现对方不怕反噬（因为用的是符不是自己的能力），但符是消耗品，用一张少一张；阿璃献计——封住对方的嘴，敕令符就废了（符需要使用者念触发词）；沈烬用"哑"字制服铁符，铁符的最后一张敕令符在手中烧成灰；战斗惊动镇妖司。
- EP007：搜查使抵达安魂镇，带着上品敕令符（强大敕令者之血炼制，可多次使用）；上品敕令符威力碾压沈烬；搜查使故意放两人走——要等沈烬能力恢复到巅峰再割舌，取到的血炼制的符才更强。
- EP008：两人被无耳猎兵跟踪，沈烬在废弃山神庙正式训练意志敕令（EP003已第一次无意识使用）——不发声也能敕令，反噬极小，且对无耳猎兵有效（因为不需要被听到）；四个无耳猎兵进攻，沈烬和阿璃配合击退。
- EP009：搜查使亲自出手，上品敕令符 vs 虚弱的沈烬；绝境中阿璃觉醒敕令能力（敕令者血脉），两人并肩用双敕令击碎上品敕令符，击退搜查使；沈烬喉咙受重创，再次失声。
- EP010：季终——阿璃觉醒后两人暂时安全，但搜查使留下话："司主要亲自来抓你们"；镇妖司总部深处，符库最深处有一个空符位，标签写着"双生血，待炼"。

## 长线原则

- 敕令者能力不限于固定词：说出来就能言出法随，反噬与效果成正比。简短精确的词反噬小，长句子/大范围命令反噬大。
- 敕令的本质是意志，声音只是载体。意志敕令（不发声）效果弱但反噬小，且对无耳猎兵有效。
- 爽点必须伴随可见代价：EP001的"停"换来眼角流血；EP003的意志"定"换来鼻血和头疼闪回；EP006的连续抵抗换来大量失血；EP009的双敕令换来沈烬喉咙重创。
- 阿璃既是盟友也是成长线：她从"知道敕令者知识但没有能力"，到EP009觉醒自己的敕令血脉。她的母亲是被割舌圈养的敕令者，这是她的动机和创伤。
- 镇妖司并非纯粹邪恶，其维持的封印确实阻挡妖灾；但割舌圈养、抽血炼符和敕令符黑市贩卖是肮脏的现实。
- 敕令符是消耗品法器：用敕令者精血炼制，分品级，下品单次小效果，上品可多次使用；需要使用者念触发词，封住嘴或无声环境可使其失效。
- 割舌的目的是废掉敕令者的能力，方便圈养取血炼符——不是为了舌头本身。
- 墙上的猎杀记录画像是贯穿第一季的核心物证：每一张代表一个被镇妖司屠杀的敕令者，跨越一百年的灭绝史。沈烬看到这些画像的反应是"这些都是和我一样的人"，不是家族认同。
- 没有妖王、没有附身、没有残识——所有悬念都基于敕令者血脉、敕令符和镇妖司的割舌圈养系统。
