# 第一季故事弧

## 核心问题

沈烬究竟是幸存的敕令者，还是镇妖司为了控制妖王制造的"人形律令"？寄居在阿璃体内的妖王残识为何会在听见"停"后认出他？百年前被等待的究竟是沈烬本人，还是他的声音？墙上几十张跨世纪的同脸画像，和那枚百年前的钳口器，又在诉说怎样的猎杀史？

## 早期节奏

- EP001：沈烬一句"停"凝固箭雨，阿璃显露妖王影子。
- EP002：韩枭认出敕令者的舌头值大钱，投出禁声符锁要先封声再活捉割舌；阿璃以骨针击偏但残余封环仍封住沈烬声音；阿璃从追兵携带的网和钳口器判断出他们要割舌头取宝；沈烬失声状态下尝试敕令失败；二人逃入废弃驿站，沈烬的血意外开启驿门，墙上露出同脸画像一角。
- EP003：驿站内整面墙几十张跨世纪同脸画像；阿璃听见陌生女人的示警声音；骨针引导开启暗格，发现一封沈烬笔迹的信——"若你看到此信，说明敕令尚未断绝"；无耳猎兵抵达，他们是镇妖司豢养的专业割舌人（没有耳朵所以免疫敕令）；沈烬在失声状态下挤出破碎的"退"字，令猎兵僵住半秒，二人翻窗逃脱；猎兵撕下最旧画像，背后嵌着一枚百年前的割舌钳口器——镇妖司猎杀敕令者、割舌取宝的历史比想象中更长。
- EP004：无耳猎兵不会因半秒僵住放弃，他们带着更多钳口器和更残忍的手段追入山林；沈烬的声音在破碎敕令后更加虚弱，鼻血不止；阿璃体内的妖王残识在猎兵逼近时第二次苏醒，这次不是说话，而是短暂地替沈烬挡下一次攻击。
- EP005：沈烬尝试第二个完整命令"归"，却召回一段不属于他的百年前记忆；记忆中有人把妖王残识封进一个少女体内，而下令的人声音与沈烬一模一样——但他没有看清自己的脸。

## 长线原则

- 每集只新增一个明确能力规则或身份线索：EP002 新增"敕令必须以清晰声音触发，失声则无法令现实改变"；EP003 新增"敕令不取决于声音大小，破碎气音只要意志足够明确也能触发，但代价成倍增加"。
- 爽点必须伴随可见代价，避免无限制言出法随：EP001 的"停"换来右眼流血；EP003 的破碎"退"换来鼻血和封痕加深。
- 阿璃既是盟友也是悬念源：她的日常人格不预知敕令、不掌握沈烬记忆；她主动推理、救人、挡在前面，风险来自她体内会偶发苏醒的妖王残识，不以无理由背叛制造冲突。
- 镇妖司并非纯粹邪恶，其维持的封印确实阻挡更大的妖灾；但围剿敕令者不只是恐惧，更是为了割舌取宝——敕令者的舌头可炼制法器入药，价值连城。这门肮脏的生意跨越百年，背后有更深的利益链条和阴谋。
- 墙上的同脸画像和百年割舌钳口器是贯穿第一季的核心物证：每一张画像代表一个被割舌的敕令者，每一个都长着沈烬的脸——沈烬是第几个？他是轮回、是克隆、还是被反复抹去记忆的同一个人？
