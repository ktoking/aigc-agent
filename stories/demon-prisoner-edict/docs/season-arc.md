# 第一季故事弧

## 核心问题

沈烬究竟是谁？为什么最旧的猎杀画像与他有几分相似？阿璃为什么说"我终于等到你了"？镇妖司用敕令者的血炼制的"敕令符"去了哪里？一个曾被禁声的敕令者，能不能终结这百年的割舌圈养与妖食供养链？

## 早期节奏

- EP001：沈烬一句"停"凝固箭雨，阿璃认出他是敕令者，说"我终于等到你了"。
- EP002：韩枭投出禁声符锁要先封声再活捉割舌；阿璃以骨针击偏但残余封环仍封住沈烬声音；阿璃从追兵的网和短刀判断出他们要割舌废掉能力、圈养抽血炼符；二人逃入废弃驿站，沈烬的血意外开启驿门，墙上最旧画像露出与他略似的轮廓。
- EP003：驿站内整面墙是镇妖司的猎杀记录——几十张画像每张角落都有刀痕印记，画中人各不相同但都是敕令者；阿璃说明敕令者被镇妖司屠杀一百年的历史。普通追兵破门后，失声的沈烬第一次本能使用意志敕令“死”，付出强烈反噬；二人从后门与山坡逃脱。本集不保留密信、百年断刀或家族暗格。
- EP004：山林中沈烬声音恢复，开始有意识地探索能力——发现敕令不限于固定词，说什么都能生效，但效果越强反噬越大；学会用最短的词达到最大效果；两人看到远方小镇的灯火。
- EP005：逃到安魂镇，发现镇上有人在用"敕令符"——普通人捏碎符箓就能释放一次敕令；阿璃讲述母亲被割舌圈养的往事；小镇恶霸"铁符"用下品敕令符欺压百姓，盯上了两人。
- EP006：沈烬与阿璃循山道离开安魂镇，误入被镇妖司长期供养的裂风涧。守涧的巨型山魈王把二人当成新送来的活祭，立刻发动猎杀。沈烬用短敕令救人、改地形、偏移妖兵，却发现对妖王直接下"死"令时反噬强到声音被堵在喉间，只能退回到小范围、可拆分的命令；两人被逼入妖王祭场。
- EP007：祭场决战。阿璃以骨针与近身走位撕开妖王护身妖甲，沈烬以"陷"改地形、以"起"唤醒满地镇妖旧兵、以"落"组成剑雨，逐步削弱妖王。终局他以意志凝出一把无字暗金克妖剑，交给阿璃完成斩核；妖王精魄没入沈烬的封痕，留下新的能力感知与后续成长空间，不定义固定技能等级。
- EP008《祭车折返》：二人截下驶向裂风涧的第二辆祭车，对上与黑木轮轴共生的押运妖王辘魇。沈烬以“慢”“托”“回”拆解坠崖危机，并以“归她”让无字克妖剑成为阿璃常驻兵器。救下的祭品指出前方无声岭会吞掉所有知情人的声音。
- EP009《无声岭回音杀》：听骨侯替镇妖司封口灭证，把受害者声音收藏在胸腔声囊并反射有声敕令。沈烬被迫使用代价更重的意志敕令“止”，再令被偷走的回声“回”；阿璃持临时无声的克妖剑斩开声囊。岭下千愿殿以暖灯主动迎接逃民。
- EP010《千愿殿不许醒》：妖王无悲以温柔避难所诱导逃民许愿，把“自愿”变成愿契，再沿愿线吸食生命。沈烬令所有灯“照”出隐藏愿线，并把克妖剑临时约束为“只断契，不伤人”；阿璃逐根断契，受困者必须亲口说出“不愿”。殿后交易砝码与成批铁牌指向百妖夜市。
- EP011《妖市称人命》：秤骨翁经营镇妖司认可的百妖夜市，巨秤把对妖商的伤害转移到抵押人身上。阿璃以魁冥旧牌伪装买家并押上克妖剑，沈烬让囚锁“轻”、债砝“重”，二人把总吊链扣回秤骨翁自己的秤盘。夜市门开后，千妖持牌沿官道北上参加领肉日。
- EP012《吃人的，都跪》：镇妖司外门前，登记妖的铁牌与笼中人质共伤，不能直接群杀。阿璃进入牌阵中心，以“只断锁”的克妖剑斩开人质联系；沈烬按行为下令“吃人的，跪”，整条官道妖群同时跪下。外门开启后，青铜面搜查使与无耳猎兵已经列阵等待，故事进入正面拆司阶段。

## 长线原则

- 敕令者能力不限于固定词：说出来就能言出法随，反噬与效果成正比。简短精确的词反噬小，长句子/大范围命令反噬大。
- 敕令的本质是意志，声音只是常见载体。意志敕令可以绕过听力与禁声，但同等级反噬比有声敕令更重；它对无耳猎兵有效，不代表更便宜。
- 爽点必须伴随可见代价：EP001的"停"换来眼角流血；EP003的意志"定"换来鼻血和头疼闪回；EP006的连续抵抗换来大量失血；EP009的双敕令换来沈烬喉咙重创。
- 阿璃既是盟友也是成长线：她目前没有敕令，以知识、判断、骨针和无字克妖剑承担近身执行。是否觉醒留给更后阶段自然推进，EP008–EP012 不突然觉醒。她的母亲是被割舌圈养的敕令者，这是她的动机和创伤。
- 镇妖司并非纯粹邪恶，其维持的封印确实阻挡妖灾；但割舌圈养、抽血炼符和敕令符黑市贩卖是肮脏的现实。
- 敕令符是消耗品法器：用敕令者精血炼制，分品级，下品单次小效果，上品可多次使用；需要使用者念触发词，封住嘴或无声环境可使其失效。
- 割舌的目的是废掉敕令者的能力，方便圈养取血炼符——不是为了舌头本身。
- 墙上的猎杀记录画像是贯穿第一季的核心物证：每一张代表一个被镇妖司屠杀的敕令者，跨越一百年的灭绝史。沈烬看到这些画像的反应是"这些都是和我一样的人"，不是家族认同。
- 不使用附身或残识设定；妖王是镇妖司供养体系中的地方食人妖，所有悬念仍基于敕令者血脉、敕令符和镇妖司的割舌圈养系统。
