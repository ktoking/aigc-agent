# 第一季故事弧

## 核心问题

沈烬究竟是幸存的敕令者，还是镇妖司为了控制妖王制造的“人形律令”？阿璃等待的又是沈烬本人，还是他体内能打开妖狱的声音？

## 早期节奏

- EP001：沈烬一句“停”凝固箭雨，阿璃显露妖王影子。
- EP002：沈烬必须在反噬失声前逃出雾谷，阿璃第一次主动替他挡下镇妖符。
- EP003：两人进入废弃驿站，发现所有通缉令上的沈烬面孔都来自不同年代。
- EP004：韩枭带回“敕令者尚存”的消息，镇妖司派出不会听见声音的无耳猎兵。
- EP005：沈烬尝试第二个命令“归”，却召回一段不属于他的百年前记忆。

## 长线原则

- 每集只新增一个明确能力规则或身份线索。
- 爽点必须伴随可见代价，避免无限制言出法随。
- 阿璃既是盟友也是悬念源，不以无理由背叛制造冲突。
- 镇妖司并非纯粹邪恶，其维持的封印确实阻挡更大的妖灾。
