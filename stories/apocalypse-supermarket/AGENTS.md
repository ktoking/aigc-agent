# 末世超市老板娘 故事包说明

## 故事范围

本目录维护《末世超市老板娘》的所有非通用规则。生成剧情、分镜、首尾帧、视频 prompt、角色资产或连续性文件时，必须优先遵循本目录规则。

## 必读顺序

1. `docs/story-memory.md`
2. `docs/production-rules.md`
3. `docs/audience-strategy.md`
4. `docs/season-arc.md`
5. `docs/workflow.md`
6. `assets/` 下角色、场景、道具、风格资产
7. `episodes/` 下上一集内容

## 默认剧集格式

- 一集 60 秒。
- 一集拆成 4 段。
- 每段 15 秒以内。
- 每段必须有 `storyboard.md`、`first-frame.md`、`last-frame.md`、`prompt.md`、`director-promt.txt`。
- `director-promt.txt` 是能直接交给视频 API 的纯文本导演提示词。

## 本剧本核心锁定

- 主角锁：林乔，27 岁，黑色高马尾，短款黑色防水风衣，橙色超市工牌，冷静、会算账。
- 搭档锁：悬浮盘点无人机“小秤”，圆形机身，蓝色扫描眼，负责吐槽和显示库存。
- 反派锁：前 10 集主要是抢货幸存者、黑市团伙和伪善救援队。
- 世界规则锁：系统只补货“被合理交易出去”的商品，免费赠送不触发补货。
- 视觉风格锁：暖金货架灯光 vs 冷蓝末世街道，玻璃门外是雨夜丧尸和抢货人影。
- 禁止偏差：不要把林乔画成重装士兵；不要把超市变成纯军事基地；不要出现大段 UI 字幕。
