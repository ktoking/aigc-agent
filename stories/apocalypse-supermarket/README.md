# 末世超市老板娘 故事包

## 剧名

- 主标题：《末世超市老板娘》
- 爆款向标题：《丧尸爆发当天，我的超市无限补货》
- Story ID：`apocalypse-supermarket`

## 项目定位

- 类型：末世经营爽剧 / 女主掌控资源 / 轻科幻生存。
- 形式：16:9 横屏 AMG / AI 漫剧。
- 默认单集：60 秒。
- 默认结构：4 段，每段 15 秒以内。
- 目标观众：喜欢末世、囤货、经营、女主爽文和基地建设的短剧用户。
- 核心爽点：别人抢一瓶水，女主直接开启“会员制末世超市”。
- 情绪卖点：爽、急、秩序感、资源掌控、打脸。

## 一句话卖点

末世降临第一天，便利店老板娘林乔觉醒“无限补货系统”，把一间小超市经营成末世最硬的避难堡垒。
