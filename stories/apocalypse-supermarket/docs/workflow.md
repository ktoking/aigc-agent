## 四段节奏

- Segment 01：灰雨危机 + 林乔不关门。
- Segment 02：抢货失败 + 交易规则露出。
- Segment 03：补货爽点 + 规则立住。
- Segment 04：救下第一批人 + 父亲会员卡钩子。

## 生成顺序

先锁林乔三视图、小秤、超市场景和补货特效，再生成首尾帧；视频每段只承担一个任务，避免把补货、打斗、救人和系统解释塞进同一段。
