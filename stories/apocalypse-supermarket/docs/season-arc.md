# 末世超市老板娘 长线剧情规划

## 总主线

林乔从守住一间社区超市开始，用“交易才补货”的规则建立末世秩序。前期她靠规则打脸抢货者，中期扩建超市和招募员工，后期与试图接管物资的救援队、黑市团伙和灰雨感染源对抗。最终她发现父亲早已参与系统设计，而这间超市是末世前最后一次人类秩序实验。
