# 末世超市老板娘 故事记忆

## 项目定位

- Story ID：`apocalypse-supermarket`
- 类型：末世经营爽剧 / 女主资源流 / 基地建设。
- 目标平台：抖音 / 快手 / 视频号。
- 目标观众：18-35 岁，喜欢末世囤货、女主爽文、经营升级、打脸反转的用户。
- 单集规格：60 秒，4 段，每段 15 秒以内。
- 一句话卖点：丧尸爆发当天，别人抢物资，林乔把小超市开成末世唯一“有规则的安全屋”。

## 世界观

近未来城市突发“灰雨感染”。被灰雨淋湿的人会在 3 分钟内失去理智，变成追逐声音和热源的感染者。城市断电、通信不稳、物流中断。林乔继承的社区超市在灰雨降临当晚激活“等价补货系统”：只要商品通过明确交易被拿走，货架会在无人注视的瞬间自动补满；但免费施舍、抢夺和暴力占有不会触发补货。

## 核心故事

林乔原本只是被房租、债务和家族旧店压得喘不过气的小老板。灰雨爆发当天，她发现超市货架会自动补满，但前提是必须建立“交易秩序”。她没有选择当圣母，也没有选择当暴君，而是在一片混乱里立下末世超市三条规则：先扫码后取货、老人小孩半价、抢货者永不入店。随着超市变成城市里唯一稳定物资点，幸存者、黑市团伙、伪善救援队和真正的感染源都被吸引过来。林乔一边经营货架，一边建立安保、会员、雇员、仓储和避难层，最终发现系统不是天降福利，而是上一任店主留下的末世筛选机制。

## 角色记忆

### 主角：林乔 `AS_LIN_QIAO_001`

- 年龄：27。
- 身份：社区超市老板娘，前供应链数据分析师。
- 外貌锚点：黑色高马尾，利落侧分刘海，短款黑色防水风衣，橙色超市工牌，腰间挂扫码枪。
- 性格：冷静、毒舌、会算账，不轻易信人，但有底线。
- 欲望：保住店、活下去、建立能让普通人活下来的秩序。
- 恐惧：秩序崩掉后自己也变成只会抢的人。
- 能力/资源：等价补货系统、库存扫描、价格规则、超市地形。
- 口头禅或语气：“可以赊账，但不能白拿。”

### 搭档：小秤 `AS_SECURITY_DRONE_001`

- 角色功能：悬浮盘点无人机，负责扫描、吐槽、报警和库存显示。
- 外貌锚点：圆形小无人机，蓝色扫描眼，底部小票打印口，带超市价签贴纸。
- 情绪价值：轻喜剧、解释规则、和林乔互怼。

### 阻力

- 抢货幸存者：短期压力，制造“规则是否管用”的测试。
- 黑市团伙：中期压力，想控制超市补货能力。
- 伪善救援队：舆论压力，逼林乔免费开放超市。
- 灰雨感染源：长线真相，系统与感染源同源。

## 剧情阶段

- 第一阶段：开店立规矩，保护第一批顾客。
- 第二阶段：招募员工，扩建地下仓储和楼顶菜园。
- 第三阶段：黑市团伙围攻，林乔用交易规则反杀。
- 第四阶段：救援队要求接管超市，城市广播开始污名化她。
- 最终阶段：揭开系统来源，林乔选择把“交易秩序”扩展到整座城市。
