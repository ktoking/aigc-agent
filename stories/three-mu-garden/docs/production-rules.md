# 生产规则：大纲阶段

尚未确定真人或漫剧风格，不生成角色参考资产。

- 后续正式剧集沿用仓库默认：60秒、四段，每段不超过15秒。
- 场景优先复用：旧院厨房与院子、三亩菜园、镇上摊位、周砚维修铺。
- 作物必须有播种时间、成熟状态、采收与数量记录；开局首单使用原有成熟作物。
- 收入区分货款、成本、利润；生活支出与生产周转留足，不用成交额冒充净赚。
- 家庭成员自主选择；亲情进展通过劳动、钱款管理与实际生活改善呈现。
- 植物与食物画面清爽适度精细，不用过锐微纹理堆砌；田间劳作不擅自转为脏乱风格。
- 默认声音与密钥管理沿用根目录规定；本轮仅大纲，未授权范围不提前调用付费生成。
- 当前土地为租地经营，分家与合伙结算不得混同土地所有权转移。
- 加工试产对接有资质加工坊，区分可食用裂口果与需剔除的腐坏果。
