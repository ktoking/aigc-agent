# 故事包工作流

## 当前完成范围

原创选题、大纲v1、六阶段规划、前十集事件及文案审读。下一步依据用户反馈调整方向；没有已授权的整季剧本或素材批量生成任务。

## 后续生成前

读取本story的AGENTS与五份职责文档、当前大纲、已有上集与连续性记录。读取根目录 `docs/methods/douyin-short-drama-method.md` 与 `docs/contracts/video-api-handoff.md`。

## 剧本到制作

1. 按用户选定方向写正文与正式分集，明确人物目标、代价、季节、作物、钱款。
2. 按根目录 `skills/story-film-workflow/references/script-language-checklist.md` 逐句审读并记录该版本L01—L06与S01—S06。
3. 在用户要求进入相应制作范围后，确定角色、画风和声音；按实际语音时长与选定制作形式安排镜头。
4. 若制作动态视频，沿用根目录每集四个segment及各文件合同；若用户明确选择其他形式，按当次要求调整。
5. 素材、生成记录与成片放本story及对应segment目录，验收实际文件，不以文案PASS替代成片验收。
