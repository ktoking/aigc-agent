# 六人性格与无声表演 v3

无对白、无旁白；性格要能从姿态、目光、反应快慢、处理同一件事的差异读到。六人都是成年人，基本脸、体型、种族与已完成三视图一致。

## 格鲁姆｜ORC

- 性格：老实、厚道、反应慢半拍，答应照顾人就做到。
- 日常动作：先接住地图、再扶人；被泼水先确认她站稳才笑；秋天背人不抱怨，还认真按倒地图准备回头。
- 关系动机：把承诺当真，最在意伙伴是否安全。
- 战斗转化：先稳住身体替别人留机会；抵爪时看队友是否已退到掩体，再咬牙接力。
- 演法边界：不写成只会吼叫的暴躁打手，也不让他的老实变成毫无判断。


## 莱娅｜RANGER

- 性格：爱开玩笑、外向、生活里马虎，有一点笨拙，箭术专业。
- 日常动作：春天差点滑落又泼兽人；夏天一条鱼就得意；秋天疲倦时拿倒地图，被纠正后吐舌。
- 关系动机：喜欢让队伍轻松，也容易因别人照顾自己而不好意思。
- 战斗转化：看见真正龙迹就收起笑；拉弓、判断落点和最后补箭全部准确，压力下仍可靠。
- 演法边界：全员成年人，不幼态化，不让马虎导致战斗失误或变成受保护的花瓶。


## 塞维恩｜MAGE

- 性格：冷脸、克制、讲秩序，管家式照顾人，实力强。
- 日常动作：收好湿地图、翻正路线、两指托起一场鱼雨、摆正鱼篮、最后把热饮递给照顾别人的精灵。
- 关系动机：用整理、补位和解决具体问题表达关心，极少大幅表情。
- 战斗转化：施法有控制与完整预备，陨石被龙闪避仍能擦开关键甲缝；不靠压低能力给别人凑戏。
- 演法边界：不写成傲慢训人或专门端茶的佣人；冷脸萌靠细小反应而非突然卖萌。


## 堡垒—07｜ROBOT

- 性格：天然呆、认真、按字面理解，真诚模仿有机伙伴。
- 日常动作：机械指缝捧不住水；夏装在机体外套泳裤与救生圈；把覆雪石头当柴，被纠正后认真点头；披毯后学人烤手。
- 关系动机：想把帮助做对，也想加入大家的日常。
- 战斗转化：生活识别会出错，目标锁定和4+2弹药管理必须精确；战场不乱发射。
- 演法边界：不长人类皮肤，不喝普通热饮，不用屏幕文字解释情绪，不每次都制造事故。


## 瑟琳｜ELF

- 性格：可靠、细心、妈妈级别，先扶人再纠错。
- 日常动作：系靴带、接鱼篮、藤蔓连桥先试重、替机器人换柴掸雪、最后自己才接热饮。
- 关系动机：自然留意每个人的状态，也有自己的疲惫。
- 战斗转化：种根、承重、补根与战场束足是同一能力逻辑；受反力时仍继续照看队伍。
- 演法边界：不只负责照顾起居；她是能独立解决地形和战术问题的核心人物，不长篇说教。


## 烬｜DRAGONBORN

- 性格：暗黑审美、冷面、黑色幽默，行动上愿意帮忙。
- 日常动作：夏天给一条小鱼做过分庄重的黑巾告别，鱼雨来时立刻把黑巾改作接鱼袋；冬天不动声色补火。
- 关系动机：用非常认真的形式处理荒诞小事，关心藏在实用行动里。
- 战斗转化：危险里停止玩笑，靠观察和队友支援行动；变装不变脸，落稳后刺杀。
- 演法边界：不写成享受伤害同伴的恶人；黑色幽默只放补给停留，伤亡或真实危机不抖包袱。


## 关系与笑点分工

格鲁姆与莱娅是接梗慢和出梗快的互补；塞维恩通常负责实际收尾，瑟琳先顾人再处理物；机器人把同一件事理解得过于认真；烬以严肃仪式感制造短暂反差。笑不是六人同一套表情：兽人大笑、游侠扶肩笑、精灵边忙边笑、机器人模仿肩抖、龙裔冷脸改动作、法师只有嘴角微动。

夏季鱼雨是唯一完整喜剧桥段。春秋冬以轻反应与照顾为主，不每段硬塞笑点。48秒发现新龙迹后收起轻喜剧，60秒进入偷袭，战斗段不追加段子。
