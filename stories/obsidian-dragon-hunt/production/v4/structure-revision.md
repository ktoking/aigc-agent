# v4结构修订建议｜王国受灾、受命与追猎

2026-11-03；针对用户对v3开场过度欢快、旅途过长与段间衔接的反馈。本方案已获用户同意并直接落实到原EP001，正文与时间线已修改为120秒四段；已有10张参考图全部保留。执行记录见apply-log.json。

## 结构判断

v3前60秒占150秒的40%，但国王委托和当场灾害没有出现在画面里。观众会先接收一整段朋友嬉闹，再补猜他们为何追龙。问题主要是任务动机建立得晚、完整笑段和照顾动作占用太多时间。

建议将v3前两段合成一个30秒开场，加上8秒清楚的因果：巨龙袭击都城→幸存国王托付地图→六人出发。四季只保留赶路和补给里的短暂放松；整片回到120秒，仍四段各30秒。后90秒使用此前已写好的战斗主体，时码由v3减30秒即可。

## 第一段00—30秒｜无对白剧本与分镜

| 时间 | 可拍事件 | 情绪与作用 |
| --- | --- | --- |
| 00—03 | 巨龙掠过都城，火流击中塔楼，王国旗帜的一角被烧落；火光中保留同一王徽。 | 立即看到毁城的敌人和损失。只一段直接事件，不展开战争史。 |
| 03—06 | 幸存国王站在受损庭院，冠冕与烧损披风表明身份。他把带同一王徽封蜡、标有黑龙剪影的地图递给法师，六人在他面前。 | 无需讲话便能读到任务来源。国王仍活着，受灾的是都城，不说整个王国所有人都已灭亡。 |
| 06—08 | 法师接图点头，收下封绳；六人转身走向城门外的山路。镜头随他们向右，经过焦黑门柱遮挡。 | 接受委托并立即行动，不做跪拜、宣誓或逐个介绍职业。 |
| 08—12 | 春日浅河，六人沿图赶路；游侠失足，兽人接住她与地图。她不好意思地笑一下，继续上岸。树干遮挡切夏。 | 保留关系与生活马虎，主版删去完整泼水嬉闹。 |
| 12—14 | 夏季浅滩补给，空鱼篮在旁。游侠举起一条小鱼，得意看同伴。 | 捕鱼服务于旅途补给，泳装只在该补给片段出现。 |
| 14—16 | 法师冷脸抬两指，水下法阵把鱼托出海面。 | 一次简短的实力与性格反差。 |
| 16—18 | 精灵接篮、龙裔兜巾，游侠和兽人短笑，立即收鱼。前景棕榈掠过，切秋。 | 笑点在反应后立刻结束，主版删去小鱼告别仪式与全套准备展示。 |
| 18—20 | 秋山，兽人背着疲倦的游侠攀坡。她抱稳地图，法师指一下前方山口。 | 身体疲惫与仍在前行同框；不再叠加倒地图笑话。 |
| 20—22 | 瑟琳把藤桥最后一束拉紧，根连两岸基岩；队伍谨慎踏上桥。桥柱遮挡切冬。 | 已搭好的桥在收紧承重，不要求两秒内从零长完桥且走完全程。 |
| 22—24 | 冬季，机器人短焰点燃木柴，精灵挡风照看伙伴。 | 取暖是渡过寒夜；删去把石头当柴的完整笑段。 |
| 24—26 | 龙裔用掌心火补温，法师递过热杯，众人疲惫围坐。远处风声变空，音乐逐渐收紧。 | 少量温暖，随后回到任务压力，不再延长营地日常。 |
| 26—28 | 岩柱遮挡后揭出冬末热谷：新黑鳞、巨大爪印、谷底睡龙；游侠停步，笑意消失，抬手示静。 | 找到目标，放松结束。谷底裸岩与背阴残雪保留同一冬季。 |
| 28—30 | 同向岩体遮挡压缩最后数分钟的卸外披与就位；高位交代六人的埋伏点。镜末落在游侠的眼睛与手，她把手移向弓弦。 | 明确设伏时间被省略；镜末姿态直接交给下一段，不再换季或重新介绍场景。 |

上述时间为设计值，短蒙太奇不等于每个片段必须完整演完动作起止。春天接人要看到实际支撑，夏天魔法先发后鱼起，藤桥仅展示最后收束，战斗受力时间不因此删减。

## 第一段与第二段的连接

- 视觉：第一段末的东台、弓、游侠视线方向，继承到第二段起手。睡龙继续在谷北，其他五人已在同一张地图上的伏位。
- 动作：第一段结束于她把手移向弦；第二段开始于抽箭、搭弦、附能成巨箭。不是完成一次射击后再重新搭弦。
- 声音：冬营地开始减弱轻快旋律；发现足印后只留风与远处睡息；第二段听见绷弦，箭离弦后进入跟箭风切声。
- 时间：四季与设伏压时到30秒止。第二段起同一山谷连续时间，不再以蒙太奇跳过位移或命中。
