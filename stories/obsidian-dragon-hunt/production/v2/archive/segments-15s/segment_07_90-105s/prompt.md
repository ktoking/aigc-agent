# v2 导演设计｜段07

16:9，15秒，欧美奇幻电影级风格化写实3D导演草案，目标1080p/30fps；实际模型参数尚未核验。无对白、无旁白、无说明字幕、无可懂语言吟唱；保留环境音、配乐、呼吸、非语言用力声与龙吼。面部雕塑感、PBR、SSS、真实毛发、清楚大形和适度纹理；避免过锐、塑料皮肤和满屏鱼鳞网格。

第07段：第二轮协同打开刺杀线。首：刺客到东侧低骨坡后；支援者已明白同一裂口是目标。
尾：刺客站稳在缺口东侧，右腕猎龙刺锁止；尚未命中。

局部0—4秒：龙后腿压低试图展翼跃走。兽人把斧钩卡住西前爪甲缝，肩顶斧柄、脚塞进断骨槽；精灵新根束同时缠紧后踝，根端咬住两侧基岩。莱娅拉开第二支巨箭。 摄影：东侧广景把前爪、后足、两处根锚与东岩台放在同一空间，局部切到兽人脚槽。 重量：前肢与后足被同时牵住，龙起跳预备被破坏、没有真正离地；兽人仍被拖动半步，精灵的膝压进土里。 表情：兽人脸颊绷紧，精灵咬住下唇，莱娅拉弓手微颤但没有放开。 声音：斧柄吃力、脚槽碎裂、根束低鸣、巨翼拍风。

局部4—8秒：机器人发射最后两枚导弹，精准打进同一东颈肩裂口。巨龙扭头试图再截击，兽人反拧斧柄、精灵向西侧收根，使它转颈慢了一拍。两弹掀开松动黑甲。 摄影：东南机器人发射接同侧裂甲命中，刻意看清先前陨石擦痕仍在。 重量：只能发射剩下两枚；甲片先被爆压掀起再落下，不能凭空重置成完整胸甲。支援只拖慢转头而非定住时间。 表情：法师从施法疲惫中抬起目光，追随裂口并朝莱娅示意；机器人光圈持续锁定。 声音：两次发射、甲内闷爆、鳞片坠地，音乐空出一拍。

局部8—11秒：莱娅放出第二支巨型穿透箭，箭头穿进炸开的甲缝，倒刺展开楔住两片护鳞，沉重箭杆震颤，露出喉根红色囊膜。烬从东侧骨坡后探出。 摄影：东台释放中景切到东侧裂口，保留短促飞行轨迹；不再重复首轮穿越机长跟。 重量：巨箭这次命中已经受损的外甲，卡在甲边而非直接刺穿囊膜；第一轮失败与本轮条件不同。弹道不经过刺客的东侧待机点。 表情：莱娅双臂随弓回弹微落；烬看准箭杆停止大幅摆动才起跑。 声音：弓弦、箭破风、倒刺撑甲的硬响，龙痛吼。

局部11—15秒：烬踏上(8,72,z1.2)低骨梁，末步蹬实，约103.2—104秒短跃至(4.5,73)；左脚先落、膝髋弯曲，鞋底短滑后右脚补稳，猎龙刺指向裂口。 摄影：东侧35mm连续全身跟拍，蹬地—短弧—落地都留在一镜；同框可见倒刺箭杆和龙颈。 重量：腾空约0.8秒，水平约3.5米，空中不变向；落地后才进入刺击。巨龙因束足和撬甲仍能抖颈，支援者持续受力。 表情：烬咬牙承受落地，金瞳不离目标；兽人和精灵看见他落地后继续加力。 声音：骨梁踏响、两次落足、护甲受压和短喘；无口号。
