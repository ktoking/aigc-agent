# 故事圣经 v1

黑曜炎龙「瓦尔萨克」盘踞龙骨荒原三百年，焚毁城镇、吞噬军队，先前猎龙者无人生还。六位队员进入它长期据守的同一山谷，杀龙并争取全员生还。

格鲁姆／兽人／破甲；莱娅／半精灵／致盲；塞维恩／人类／冻结；堡垒—07／机械生命／保护；瑟琳／高等精灵／束缚；烬／人龙混血／斩杀。姓名、战场、弱点、魔法限制都是本次创作草案；外观参考为会话最新试样，尚非最终定脸。

瓦尔萨克四足双翼，全长约28米、翼展约34米、肩高约5米。颈腹第三列黑曜鳞的边缘卡着旧断矛，已有约四十厘米裂线；背后蓄压喉囊尚有膜壁。斧头撬开旧伤后仍需束颈暴露入口，再由长剑刺穿。喷火后再次蓄火时囊壁绷紧，刺破会使火焰热压在颈胸内部失控，先失声失衡，后经数秒倒地、余火衰灭。

两条银索在引龙前已经铺好并连接东西基岩桩。龙先扑咬，盲后挣扎，冻结后喷火，恢复视力后挣脱，反击始终服务于杀死或驱离入侵者。

结局：龙死在中央，六人存活。机器人右盾烧裂、地锚拖槽；法师前臂冻伤、精灵掌心勒伤、龙裔左膝落地吃力。没有新敌人或默认续集。
