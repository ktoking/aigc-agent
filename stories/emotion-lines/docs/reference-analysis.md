## 复刻原则

复刻的是解释关系：路径变化要对应句意，镜头尺度要对应心理尺度，文字落点要对应 BGM 的实际节奏。新片重新写文案、重新画网络，不复用作者画面。参考片不是炫技转场合集；连续图形形变比随机卡点更关键。

## 新片情绪曲线

0–15 秒：识别自己的内耗，画面逐渐收窄。15–30 秒：退后看全貌，呼吸空间打开。30–45 秒：将抽象自责拆成可处理的小问题。45–60 秒：允许继续走，给下一步留空间。
