# 视觉与运动设计

概念：光点必须真的走过路口；前进、撞墙、回退和新生长各有可见的空间结果。

- 1080×1920，30fps，60秒。墨黑 #090b08，暖白 #fff2c4，暖金 #dfbd70，冲突红 #f18b7d。
- 本地 SongtiLocal。标题60px，副行45px，节点标签保持可读，非关键远处标签收起。
- 标题y248–450；路网y490–1590；上下软遮罩避免线条穿过文字。横向出画是镜头穿行的设计。
- 六组独立几何：单行道、可回退树、多岔路桥接、直线背后的迂回、熄灭重启、三级递归光网。
- 镜头跟随行程，不是固定全图推拉。除开头与熄灭停顿，光点行进每1–2秒跨越节点。
- 轮廓与柔光双线，短拖尾、撞墙碎光、节点脉冲、分叉流光。每一处强化都响应路径事件或音乐拍点。
- 不使用未经核验的统计数据，不增加HUD或UI卡片。
