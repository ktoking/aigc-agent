# 视觉规范

概念：把自我否定具象为一个被过分放大的红色节点；拉远后，它只是一张仍然生长的生活网络中的一个点。

- 画布：1080×1920，30 fps，60 秒。
- 背景：#0b0c08，偏暖的墨黑；局部暖金光晕。
- 主色：#f3edd8；辅助：#c4bda7；强调：#e67470；节点高光：#fff6ce。
- 字体：本地 assets/songti.ttc，嵌入字体名 SongtiLocal。
- 顶部文字：中心 x=540，y=275–470，54–66 px；一次一组论点；每组留足阅读时间。
- 绘图区：x=90–990，y=560–1480；节点标签 32–38 px。
- 底部：y<1650；保留平台底部控件空间。
- 动画：细路径逐笔显现、光点行走、柔和脉冲、连续拉远；红色仅表达失败标签和过度概括。
- 留白和克制优先。不做卡片网格、游戏 HUD、夸张粒子、锋利微纹理。
- 原片关系映射：直线→分支网络；压迫性近景→释放性远景；冲突词→红色；论点出现→音乐节拍。
