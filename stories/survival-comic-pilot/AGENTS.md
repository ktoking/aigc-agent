# 生存题材静帧漫剧试作工作区

本目录保留参考研究与早期候选。用户已选择《丧尸爆发后，我拥有整个山姆超市》，后续制作位于 `../sams-apocalypse/`，以该故事自己的规则为准。

- 用户要求一步一步推进：先安装、参考分析、选故事，再剧本、画风样张、分镜与视频。
- 生图使用 GPT 自带图像生成工具；不擅自改用第三方付费生图接口。
- 不生成配音。交付无音轨 MP4 和单独 SRT，字幕不烧录到画面。
- 无配音阶段按阅读速度人工编排字幕时间；不能称为与实际配音对齐。
- 图片运镜和合成本地进行，优先使用已安装 Hypit 与 FFmpeg；尚未验证的 Runtime 不称为可用。
- 参考画面只作风格、场景组织和叙事方法分析；新人物、剧情、文本重新创作。
- 参考的日期标记属于视频内容；弹幕、播放按钮、静音提示属于播放器，不复制。
- 最终故事选定后，新建独立 story 包并优先复制根模板骨架；本目录保留参考研究。
- 不接入 Skynet，不启用 Git/Cursor hooks。
