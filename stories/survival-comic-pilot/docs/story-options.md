# 原创故事候选

以下均为原创提案，并非参考原片剧情摘要。共同采用第一人称、日记式生存推进、具体资源限制、轻量人物和可复用场景。

## 1.《丧尸断电后，我把楼顶变成了菜园》——最接近参考的制作形式

开场：“丧尸围楼第九天，楼下的人还在抢罐头。我却把最后一包方便面，换成了一袋土。”

我和一位退休园艺师困在旧公寓顶层，从剩余存粮、收集雨水到建立小菜园。菜不会一夜长成：在收获前，必须靠有限罐头熬过等待。人多一张嘴，也可能多一个能解决问题的人。

四集方向：封门和盘点 → 等待发芽时断粮 → 楼下幸存者提出交换 → 第一批收成前，储水桶出现裂缝。

画面亮点：空楼顶逐渐出现遮雨棚、种植箱和储水桶。主要复用房间、楼梯间、楼顶三个场景。

适合：喜欢经营、囤货、慢慢建设安全屋，以及紧张中带一点温暖。

## 2.《丧尸爆发后，我每天只开门十分钟》——人物冲突最强

开场：“丧尸爆发第十天，我的便利店重新营业了。但每天，只开门十分钟。”

我困在小区便利店，通过带铁栏的传货窗与幸存者交换物资。库存有限，不能随意施舍，也不能把所有人挡在外面。一个孩子每天拿一枚没用的硬币来，我逐渐发现，他家里还有一个不能出门的人。

四集方向：第一次开窗 → 建立交换规则 → 冒领物资的人出现 → 最后一份急需品应该交给谁。

画面亮点：货架随着时间变空，窗外来客变化，柜台上的交换物不断积累。

适合：想要开头抓人、每集都有选择和反转，场景又相对省。

## 3.《洪水第七天，我成了楼里的摆渡人》——视觉变化最大

开场：“洪水淹到十二楼那天，我拆了自家的衣柜。别人以为我要烧火，其实我要做一条船。”

我是一名维修工，困在楼里的幸存者把储物箱、门板和绳索交给我。我们先测试浮力，再做短距离运输，救人、带药、找高处的落脚点。暴雨和漂浮障碍始终限制行动，不能靠一条临时小船随意穿越城市。

四集方向：发现求救 → 试航失败后修正 → 第一趟运送 → 水退之前，楼内出现新的危险。

画面亮点：水线不断升高、楼道变码头、旧物逐渐变成求生工具。

适合：喜欢动手解决问题和灾难中的互助。

## 4.《极寒停电，我住进了废弃锅炉房》——氛围最强

开场：“零下三十度停电那晚，所有人都往楼上搬。我却拖着被子，住进了最脏的地下室。”

我曾做过供暖维修，知道一处停用设备间还能改造成避风点。它不提供无限热量：保温、有限燃料、通风和轮班值守都要算清。一位我曾拒绝的人，后来带回了大家最缺的东西。

四集方向：找避风点 → 第一夜的资源分配 → 燃料将尽 → 取舍与互救。

画面亮点：窗外冷蓝色风雪与室内暖色小灯对照，避难点逐步整理完善。

适合：喜欢压迫感、暖光画面和人物关系变化。

## 5.《隔壁楼，每晚只亮灯三分钟》——悬疑最强

开场：“丧尸爆发后，整条街都停电了。只有隔壁楼，每晚八点，准时亮灯三分钟。”

我被困高层，起初只把灯当成活人信号。通过反复记录闪灯规律，我发现对方在传递求救信息。但我自己的手电电量有限，回一次信，就少一次照明机会。

四集方向：发现灯光 → 试着回复 → 读出错误信息并纠正 → 对面终于传来能核验身份的线索。

画面亮点：两扇窗、夜色街区、纸上记录、手电光束，少量场景也能持续制造悬念。

适合：喜欢信息差、解谜和每集结尾的具体疑问。

## 推荐

优先选 1：最适合复用固定场景，让观众看见生存基地逐步变化。
想突出人物冲突选 2；想突出悬疑选 5。

用户选题后才写第一集完整剧本，不把上述四集方向当成定稿。
