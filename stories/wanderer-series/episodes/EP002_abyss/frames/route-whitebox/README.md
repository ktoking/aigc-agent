# EP002 航行轨迹白模

60 秒、12fps、960×540 视频；总览图为 1280×720。Blender 工程包含完整时间轴和分段标记。

蓝线为预设航线，橙色球为潜水器。水平航向保持直行，垂直方向轻微下降。外部总览机位仅用于导演预演，正式影片仍采用舱内固定机位。

| 全集时间 | 经过区域 |
| --- | --- |
| 00–07 秒 | 浅海出发 |
| 07–12 秒 | 穿越隧道 |
| 12–21 秒 | 遗迹、巨大雕像 |
| 21–30 秒 | 领航生物群 |
| 30–40 秒 | 火山、热泉、断层深沟 |
| 40–48 秒 | 大型骨骼残骸、带状生物 |
| 48–56 秒 | 滤食巨兽、海底巨物区域 |
| 56–60 秒 | 巨物远离、准备返航 |

这是一条覆盖本集全部节拍的示意路线，不是实际地理测绘或按真实尺度模拟。空间被压缩；穿越连接两个地点，不能据此计算真实距离或航速。末尾为准备返航，不包含提示词中未展示的完整回程。地形、生物是白模占位，未模拟舱内画面、水体或最终写实材质。

运行 `build_route.py` 可重新生成工程与 PNG 序列；使用 ffmpeg 以 12fps 编码 `render/frame_%04d.png` 可得到 60 秒视频。
