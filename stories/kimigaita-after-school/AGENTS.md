# 《你存在过的放学后 / 君がいた放課後》Story 说明

## 一句话

日系真人校园恋爱无对白短片，约 2 分 12 秒，15 个镜头。一个对生活没热情的呆笨少年，被一个偷偷生病却比谁都认真活着的转校女生拖着过完最后一个夏天；她走后，他在校园每个角落捡到她留下的目光，最后学会替她跑起来。

## 风格锚点

- 真人实拍，不是动漫。男主气质参考电次（呆、钝、偶尔认真温柔）；女主气质参考宫园薰（笑容、认真、笑着隐瞒）+ 蕾赛式主动拉扯。
- 视觉：岩井俊二式校园 + 新海诚光色真人化。35mm 胶片感，轻颗粒。
- **全片无完整对白、无旁白、无歌词、无字幕**。但不是哑剧：保留环境人声（老师讲课/操场嘈杂/祭典人群，听不清具体句子）+ 语气词和情绪声（女主的笑、"啊~"、"嗯~"、惊呼、娇嗔；男主的"啊？"、鼻音、喘气、闷哼；两人脚步、呼吸）。画面靠动作和眼神，声音靠环境音、语气词、后期音乐。
- **导演铁律：女主在男主面前永远笑**。不哭、不诉苦、不告别。真正的痛让观众替她受。
- 色彩弧线：L01–L02 阴天冷灰 → L03–L04 阳光进入 → L05 伏笔 → L06–L08 盛夏最亮 → L09 夜车冷 → L10 楼梯静止 → L11–L12 医院苍白 → L13 照相馆暖 → L14–L15 校园依然好看但人不在。

## 角色一致性锁（所有 segment 必带简化版）

### 男主 朝仓悠（17）

- 黑色自然碎发，略乱，发梢翘起，刘海遮眉。
- 五官普通耐看，眼神平时呆、迟钝、半睁眼；认真瞬间眼神聚焦、下颌绷紧。
- 身材清瘦。白短袖衬衫、领带略松歪斜、深色长裤、棕色学生皮鞋、黑双肩包。
- 动作：手插兜、走路晃悠、趴桌、吃炒面面包、被女主拽时一脸懵。
- 早餐道具：便利店炒面面包（L02、L11 冷掉的同一款）。

### 女主 白石凛（17 转校生）

- 自然深棕黑发，及肩中长发，发尾微卷，齐刘海。
- 圆眼，笑露小白牙，脸颊自然红晕；笑容明亮有感染力。
- 白短袖衬衫、深色领结/领带、深色百褶裙、浅色针织开衫（春秋）、白及膝袜、棕色乐福鞋、棕双肩包。
- 动作：永远在跑、回头、拽袖子、举一次性相机、仰头笑。
- 隐藏道具：裙子/书包口袋里的白色小药盒（L05 第一次吃、L09 掉座下、L10 滚楼梯）。
