# Story Memory · 君がいた放課後

## 核心

- 类型：日系真人校园恋爱无对白短片，132 秒，15 镜。
- 季节：春末（阴天教室）→ 盛夏（海边/烟花）→ 夏末秋初（医院/空病房/校园回忆）。
- 主题：她用最后时间教一个无所谓的少年认真活；她走后他替她跑。

## 跨段道具锁（必须复现）

1. **炒面面包**：S02 她掰走一半 → S11 他手里冷掉的那一个。
2. **一次性相机**：S04 入画 → S07 偷拍 → S12 留在空病房床头 → S13 洗出一整桌全是他的照片。
3. **白色小药盒/药瓶**：S05 教学楼后第一次吃 → S09 电车上掉座下 → S10 楼梯上滚到镜头前。
4. **窗帘**：S01 教室白窗帘被风吹 → S12 病房窗帘同款飘动 → S15 结尾走廊窗帘。
5. **浴衣**：S08 唯一非校服造型。
6. **病号服**：S11 唯一非校服造型。

## 伏笔（第一遍看不见）

- 她永远在跑 = 知道时间不多。
- 她爱拍照 = 知道没有未来可留。
- 她从不谈毕业/大学/未来。
- 她喜欢的全是最普通的小事（海、烟花、冰淇淋、便利店、电车）。
- 她看他的时间比看风景多。

## 导演铁律

- 女主不哭。医院里也笑。
- 男主不嚎啕。S10 是"恐惧"，S15 是"带泪的笑"。
- 不拍死亡、不拍葬礼、不拍医生解释。用"空"表达。
- 结尾世界不变成灰色。校园依然好看，只是她不在——这才真的疼。
