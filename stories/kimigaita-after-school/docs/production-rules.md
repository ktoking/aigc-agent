# Production Rules · 君がいた放課後

## 硬规则

1. 全片无完整对白/旁白/歌词/字幕。prompt 里禁止"完整句子对话/台词/字幕/旁白"。但**必须有**：环境人声（老师讲课、操场嘈杂、祭典人群——听不清具体句子，作为氛围）+ 语气词情绪声（女主的笑、"啊~"、"嗯~"、惊呼、娇嗔；男主的"啊？"、鼻音、喘气、闷哼；两人呼吸脚步）。不要把片子拍成哑剧。
2. 16:9，每镜按目录时间边界（8/10/6/12 秒不等）。
3. 男女主跨段脸不换、校服不换、发型不换；浴衣只在 S08，病号服只在 S11。
4. 每个 segment 必给：首帧、尾帧、子节拍（秒级+焦距+运动速度）、环境音、负面词。
5. 色彩弧线：冷灰起 → 盛夏饱和 → 医院苍白 → 结尾复明但空。
6. 每镜至少一个运动镜头（跟拍/推轨/手持/横移），L01/L11/L12 静态为主除外。
7. 用户偏好：干净大形、清晰轮廓、不堆细节、避免过度锐化/鱼鳞网格/满屏微纹理。
