# 《老外比老板更关心我》

## 一句话概要

入职38天的应届生被HR"二选一"劝退，拒绝签字后遭遇背调威胁；走投无路之际，他发现公司是奔驰、大众的供应商，于是把证据翻译成英文发到海外客户的人权投诉邮箱；三天后奔驰启动供应链合规审查，公司副总态度180度反转。

## 金句

"国内一句'方法简单生硬'，老外一封'严重道德失当'——原来我的人权，需要外国人来保护。"
