# 机器人禁止做梦 视觉风格

## 总体风格

高级 3D 动漫化情绪科幻。现实部分冷、干净、秩序化；梦境部分暖、柔、带粒子和旧胶片感。动作要像逃亡惊悚，不像超级英雄战斗。

## 画面关键词

- premium 3D anime
- emotional sci-fi
- cold robot factory
- warm dream fragments
- suspenseful escape
- quiet rebellion

## 镜头语言

- 现实用稳定中近景和压迫式对称构图。
- 梦境用柔焦、慢推、微粒漂浮和局部特写。
- 逃亡用横屏侧向动线和纵深调度，保持 Nia-7 的胸口记忆槽可见；关键动作落在中间安全区，便于后续裁切竖屏宣发。

## 禁止

- 梦境魔法化。
- 女孩完整露脸过早。
- 主角人类化过度。
- 无人机怪物化。
