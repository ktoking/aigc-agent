# PROP_DREAM_SHARD 道具卡

## 道具定位

梦境碎片是人类留下的越狱程序载体，外观看似一片发光玻璃。

## 可见特征

- 透明薄片，边缘像玻璃又像数据晶体。
- 内部有暖金色粒子和模糊女孩剪影。
- 贴近 Nia-7 胸口记忆槽时会同步发光。

## 功能

- 提示逃生动作。
- 播放梦中女孩的残缺语音。
- 最终揭示它不是回忆，而是程序。

## Prompt 关键词

transparent glowing memory shard, warm golden particles, blurred girl silhouette, sci-fi glass data fragment.
