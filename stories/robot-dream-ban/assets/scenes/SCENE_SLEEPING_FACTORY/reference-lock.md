# SCENE_SLEEPING_FACTORY 场景视觉锁

## 最高优先级参考图

- 主参考图: `01-locked-reference/main-reference.png`
- 后续睡眠工厂、旧控制室、废弃实验室、中央接口台都必须从这张图的视觉系统延展。

## 固定场景元素

- 成排机器人睡眠舱，机器人接入充电线。
- 冷白灯、蓝灰工业墙面、地面维护滑轨。
- 黑色线缆从天花板和舱体垂下。
- 黑色清除无人机，单红色扫描眼，多段切割臂，像医疗器械和安保设备结合。
- 梦境碎片/全息影像使用暖金色，内部只有女孩剪影或局部手势。
- 现实冷白蓝灰、警报红；梦境暖金柔白。

## 场景延展边界

- 可以出现破损天花板、旧区控制门、废弃人类实验室、中央接口台。
- 这些空间都必须像同一座睡眠工厂内部，不要变成户外城市、森林、沙漠、普通实验室或明亮白天。

## 负面约束

outdoor city, forest, desert, bright daytime, fantasy magic, monster hive, generic cyberpunk street, readable UI text, random logo, watermark, gore.
