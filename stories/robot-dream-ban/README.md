# 机器人禁止做梦

## 项目定位

- Story ID: `robot-dream-ban`
- 类型: 科幻 / 机器人 / 悬疑 / 情绪反转 / 动作逃亡
- 目标平台: 抖音、小红书、视频号
- 样片规格: 2-3 分钟横屏 16:9 独立短片；后续可拆成 60 秒短剧单元或竖屏宣发切片
- 核心卖点: 一个服务机器人连续梦见陌生女孩，被系统判定为危险故障；它越逃越发现，梦不是故障，而是人类留下的越狱程序。

## 推荐先做

先用 `episodes/EP001_dreams-are-forbidden/` 的 60 秒版本验证梦境美术、悬疑感和动作逃亡节奏。
