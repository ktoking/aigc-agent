# Segment 04 视频提示词

## 旁白
{宇宙真正的主人，我们从未见过。}

## 视频 Prompt
深邃宇宙全景，无数金色和白色的星系如岛屿般散布在无垠的深黑色空间中，半透明的深紫色和暗蓝色暗物质粒子网络如蛛网般交织在星系之间，可见物质与不可见物质同时呈现，尺度感极其宏大。镜头极缓慢拉远，从星系群拉到可观测宇宙全景，随后画面四周逐渐变暗渐入纯黑，中心区域保留微弱的星系光芒和暗物质粒子光晕，营造无尽未知的氛围。AI 科幻大片质感，电影级光影，粒子缓慢流动。无真人、无数字人、无文字。

## 运镜
- 45-53s：极缓慢拉镜（dolly out），从星系群拉到宇宙全景
- 53-60s：缓慢拉镜继续，画面边缘渐暗

## 关键参数
- 时长：15 秒
- 比例：9:16
- 模型：seedance_2.0
- 纯场景，无文字元素
