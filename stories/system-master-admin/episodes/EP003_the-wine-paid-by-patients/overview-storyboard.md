# EP003 60秒概述故事板

## 本集一句话

赵天麟拿妹妹的治疗顺位逼顾沉送酒，顾沉一路受辱按时送到，却发现这箱酒本来就是病人的救命钱。

## 总体节奏

- Segment 01：用治疗顺位强派二十分钟送酒任务，顾沉换到“今晚不动名额”的承诺。
- Segment 02：无系统身份被挡在贵宾电梯外，被迫抱酒爬服务楼梯。
- Segment 03：医疗封签暴露完整资金链，顾沉保存第一条神豪侵吞证据。
- Segment 04：顾沉当众开箱倒酒，小满来电说公共基金又没额度。
