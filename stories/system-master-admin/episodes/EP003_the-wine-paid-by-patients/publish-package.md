# EP003 发布包

## 标题候选

1. 他逼我爬47层送酒，我却查到酒钱来自医疗基金
2. 神豪喝掉一瓶酒，妹妹就少一针救命药
3. 赵少拿妹妹威胁我跑腿，却亲手把犯罪账本送给了我

## 封面

- 画面：前景是赵天麟举起的金色酒杯，酒液倒影里变成一支冷蓝稳定剂；后景顾沉低头锁定暗红资金链。
- 封面大字：`他们喝的酒，是病人的药钱`

## 发布文案

他拿妹妹的治疗顺位逼我二十分钟送酒，还让我抱着酒箱爬四十七层。所有人都把我当成没系统的跑腿穷鬼。可他们不知道，我碰到封签的那一刻，已经看见这箱酒真正的付款人——三百个正在等药的病人。

## 评论引导

顾沉该现在公开账本，还是继续忍到能一口气端掉整条资金链？
