# Segment 01 故事板：天才人手一个系统

## 戏剧任务

用顾沉第一人称和五组高辨识度画面，在开场建立“系统决定整个世界”的背景；结尾骤然落到唯一没有系统的顾沉。

## 镜头表

| 分镜 | 画面 | 第一人称旁白 / 声音 |
| --- | --- | --- |
| 镜头一｜人手一个系统 | 十八岁青年在全民觉醒广场依次亮起不同系统徽记，人群习以为常 | 顾沉旁白：“这个世界，人手一个系统。” |
| 镜头二｜四种系统，四种命运 | 四组快速中景依次亮出完整系统名称：签到系统完成签到，账户立刻入账；战神系统宿主抬手，整支军团列阵听令；气运系统把落榜结果逆转为录取通知；神豪系统宿主展开城市资产权限，豪宅、车队与财富全部归于名下 | 顾沉旁白：“签到系统，签到就给钱。战神系统，统领军团。气运系统，逆天改命。神豪系统，拥有一切。” |
| 镜头三｜皇帝也不例外 | 帝都大殿，皇帝坐在高处，王朝系统把城市、军团和资源连接到王座 | 顾沉旁白：“就连皇帝，也有王朝系统。” |
| 镜头四｜只有我是废物 | 切到觉醒礼堂最下方，顾沉独自站在人群之外；头顶档案连续显示三次“觉醒失败” | 顾沉旁白：“只有我顾沉，觉醒三次，还是个没有系统的废物。” |

## 首帧要求

财富塔顶层，模糊的神豪宿主站在巨幅城市落地窗前，金色腕环开启简洁的资产与医疗权限光环。人物不建立清晰正脸，重点是系统阶级感。

## 尾帧要求

顾沉独自站在觉醒礼堂最下方，灰蓝旧工装与远处白金制服人群形成强烈反差。觉醒终端在高处等待，他尚未上台。

## 优化后视频提示词

9:16 竖屏暗黑华丽都市幻想动漫。开场直接说明这个世界人手一个系统。镜头二必须逐一说出并显示四个完整名称：签到系统签到就给钱，战神系统统领军团，气运系统逆天改命，神豪系统拥有一切；每句话都对应一个现实结果，不能只闪过图标。随后展示皇帝绑定王朝系统，最后切到顾沉三次觉醒失败，旁白明确说自己是没有系统的废物。全程只讲当前世界和当前身份，不出现未来预告。

## 连续性检查

- 五类系统必须全部出现：神豪、签到、战神、气运、王朝。
- 蒙太奇宿主不建立清晰正脸，避免新增角色漂移。
- 顾沉尾帧使用 `SMA_GU_CHEN_OUTFIT_001`，不戴手套，胸前仍有临时证。
- 本段不出现管理员红字，保留 Segment 04 的揭示。
