# Segment 03 故事板：求神豪借我救命钱

## 戏剧任务

正式介绍赵天麟是 SSS 神豪系统宿主。让他用自己随手可得的三十万，逼顾沉承认“没系统的废物”身份并弯腰求人；顾沉为了妹妹主动放下尊严，换到一笔七日翻十倍的救命债。

## 首帧要求

承接 Segment 02 尾帧。赵天麟穿黑金财团礼服从病房门口完整入场，右腕神豪系统金环与“SSS 神豪系统”简洁徽记清楚；顾沉挡在病床前，顾小满仍躺着。

## 尾帧要求

顾沉向赵天麟深深弯腰，右手伸向地面的黑金付款卡；赵天麟的黑金皮靴刚从卡角移开。卡面只显示“到账300,000”“七日应还3,000,000”。顾小满在病床上伸手阻止，眼神愤怒而难过。

## 优化后视频提示词

9:16 竖屏高级暗黑都市幻想动漫。赵天麟以 SSS 神豪系统宿主身份进入病房，直说三十万只是自己一天零花钱，却骂顾沉是“没系统的穷鬼”。顾沉为了妹妹开口借钱，接受利息和做事条件。赵天麟把付款卡扔在地上，逼他承认自己是废物并弯腰去捡。顾沉回头看妹妹，压下尊严说：“我是废物。求你，救我妹妹。”付款卡到账三十万，却形成七日偿还三百万的掠夺契约。

## 连续性检查

- 赵天麟使用黑金财团礼服和黑金皮靴，禁止回到白金学院制服。
- 顾沉是主动为了妹妹求人，不是无原因软弱。
- 顾沉深深弯腰但不下跪、不哭喊。
- 三十万实际到账，七日债务固定为三百万。
- 管理员能力在本段仍未觉醒；仅让系统付款卡进入顾沉触手可及的位置。
