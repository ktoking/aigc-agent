# EP001 连续性表

## 上一集承接

本集为开篇。Segment 01 用顾沉第一人称介绍系统文明，并落到“只有我没有系统”；Segment 02 直接硬切顾小满所在的低权限病房。

## 本集固定状态

- 五类系统必须出现：签到、战神、气运、神豪、王朝。
- 顾沉是天衡唯一登记在册的无系统者。
- 顾小满患系统排异症，今晚十二点前必须注射系统稳定剂。
- 稳定剂治疗费固定为 300,000，顾沉账户余额固定为 37.60。
- 顾沉所有借款申请都因“无系统者，不予授信”被拒绝。
- 赵天麟实际提供 300,000，但付款卡附带“七日应还 3,000,000”的神豪系统契约。
- 顾沉认证为系统最高管理员，当前权限恢复 0.1%。
- 顾沉看见冻结、改任务、没收、合并四项权限，但本集一项也不执行，只秘密锁定赵天麟。

## 人物连续性

### 顾沉

- 全集使用 `SMA_GU_CHEN_OUTFIT_001`：磨损哑黑高领分层长工装、暗金修补线、黑色长裤与黑色工靴。
- Segment 02 坐在病床边照顾妹妹，随后站在缴费屏和病床之间。
- Segment 03 始终保持站立，最后深弯腰捡付款卡，不下跪、不哭喊。
- Segment 04 从同一深弯腰姿势开始，右手指尖触碰付款卡后觉醒管理员权限。
- 觉醒后恢复站直，表情仍然克制，不出现胜利笑或邪魅表情。

### 顾小满

- Segment 02–04 固定穿浅蓝病号内搭与米白针织开衫，黑色中长直发。
- 始终躺在同一张病床上，意识清醒，排异症导致呼吸压抑但不昏迷。
- Segment 03 看到哥哥受辱时撑起上身并出声阻止。
- Segment 04 尾部医护人员才拿稳定剂走向病床，不表现瞬间痊愈。

### 赵天麟

- 使用 `SMA_ZHAO_TIANLIN_OUTFIT_001`：黑色立领财团礼服、细金色包边、黑金皮靴、右腕窄幅哑金系统腕环。
- Segment 02 尾部以病房门口轮廓和金色腕环入画。
- Segment 03 完整出现，先辱骂“没系统的穷鬼”，再把付款卡扔到地上并用皮靴压住卡角。
- Segment 04 仍在病房内；管理员红字只有顾沉能看见，他完全不知道权限已觉醒。

## 场景与道具连续性

- Segment 01 使用 `SCENE_SYSTEM_WORLD_MONTAGE_001`，尾镜可短暂出现觉醒礼堂中的顾沉。
- Segment 02–04 固定使用 `SCENE_LOW_PERMISSION_CLINIC_001` 的同一间病房。
- 床边稳定剂从 Segment 02 开始存在，直到 Segment 04 尾部才由医护人员拿向病床。
- 顾沉手机状态链：余额 37.60 → 多次拒贷 → 不再作为主要前景。
- 黑金付款卡状态链：赵天麟生成 → 扔到地上 → 皮靴压住 → 顾沉触碰 → 管理员觉醒 → 顾沉握在手中。
- 付款卡金额链：到账 300,000；七日应还 3,000,000。
- 管理员文字使用暗红细字，不出现巨大面板或漫天红光。

## 分段桥接

- Segment 01 尾帧：顾沉独自站在觉醒礼堂最下方，说自己是没有系统的废物。
- Segment 02 首帧：硬切顾小满躺在低权限病房，顾沉握住她的手。
- Segment 02 尾帧：缴费与拒贷结果在前，赵天麟黑金轮廓出现在病房门口。
- Segment 03 首帧：赵天麟完整入场，亮明“SSS 神豪系统宿主”身份。
- Segment 03 尾帧：顾沉深弯腰，右手即将捡起地面的黑金付款卡。
- Segment 04 首帧：严格继承弯腰姿势和付款卡位置，指尖接触后才出现管理员红字。

## 禁止偏差

- 不让顾沉在本集没收、冻结、改任务或合并任何系统。
- 不让管理员能力在 Segment 02–03 提前觉醒。
- 不让顾沉下跪、磕头、哭求；他的屈辱动作固定为深弯腰并亲口求人。
- 不让赵天麟无偿施舍；三十万必须形成七日三百万的控制契约。
- 不让管理员红字被顾小满、赵天麟、医护或监控看见。
- 不把顾小满写成昏迷工具人，也不让她在本集瞬间痊愈。
- 不把系统世界做成古装修仙或满屏游戏 UI。
