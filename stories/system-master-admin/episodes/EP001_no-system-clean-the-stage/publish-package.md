# EP001 发布包

## 标题候选

1. 全世界都有系统，只有我没有
2. 当我看见所有系统都显示“非法运行”
3. 天命之子不知道，他们的系统都属于我

## 封面画面建议

9:16 竖屏。穿磨损哑黑暗金长工装的顾沉深弯腰捡起一张黑金付款卡，赵天麟的黑金皮靴停在卡旁；病床上的顾小满位于背景。顾沉抬起的眼睛里映出暗红字：`神豪系统：未经管理员授权，非法运行`。画面保持干净，让“屈辱最低点觉醒管理员”成为视觉焦点。

## 封面大字

所有系统，都是盗版

## 抖音简介

在全民觉醒系统的世界，顾沉是唯一没有系统的人。妹妹躺在病床上急需三十万救命，他却只有三十七元六角。神豪宿主把付款卡扔在脚下，逼他承认自己是废物。就在顾沉弯腰捡钱时，他看见所有系统头顶都写着同一句话：未经管理员授权，非法运行。

## 评论区引导

如果妹妹的救命钱就在仇人脚下，而你刚发现自己能没收他的系统，你会先救人还是先报仇？

## 标签方向

- 全民系统
- 管理员权限
- 隐忍复仇
- 底层逆袭
- AI漫剧

## 适合二次切片的瞬间

- 五类系统快速蒙太奇后骤切“而我什么都没有”。
- 三十万治疗费、三十七元余额与“无系统者拒贷”连续出现。
- 顾沉弯腰说：“我是废物。求你，救我妹妹。”
- 五类系统头顶同时出现“未经管理员授权，非法运行”。
- “我不是没有系统，所有系统都在用我的权限。”
