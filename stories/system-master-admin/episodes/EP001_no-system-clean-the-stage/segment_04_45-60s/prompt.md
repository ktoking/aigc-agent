# Segment 04 视频 Prompt：最高管理员觉醒

## 基础设定

顾沉为了妹妹弯腰捡起赵天麟的神豪系统付款卡。系统授权媒介接触顾沉指尖后，唤醒他沉睡的最高管理员权限。

## 角色锁定

- 顾沉：磨损哑黑暗金长工装，从深弯腰逐渐直起身体；觉醒后仍然克制，不笑、不公开反击。
- 顾小满：继续躺在病床上，等待系统稳定剂，意识清醒。
- 赵天麟：黑金财团礼服与黑金皮靴，神情轻慢；完全看不见管理员红字。
- 五类系统宿主：复用 Segment 01 的系统文明画面，不新增清晰人物脸。

## 分镜

### 镜头一｜弯腰捡救命钱

景别：地面手部近景。
构图：顾沉右手伸向黑金付款卡，赵天麟皮靴停在卡旁；三十万到账与三百万债务同时可见。
运镜手法：沿顾沉手指缓慢靠近卡面，短暂停在接触前一瞬。
画面内容：赵天麟以妹妹停药继续威胁，顾沉为了拿到治疗费忍住。

赵天麟：
“七天后三百万。少一分，我就停她的药。”

### 镜头二｜未经管理员授权

景别：指尖极近景转顾沉主观视角。
构图：指尖碰到付款卡，金色系统纹章被一条暗红细线切开；抬头后赵天麟头顶出现唯一一行红字。
运镜手法：从触卡动作快速上推，模拟顾沉视线对焦赵天麟。
画面内容：文字只显示“神豪系统：未经管理员授权，非法运行”，其他人没有反应。

顾沉旁白：
“就在我捡起那张卡时，我看见了一行红字。”

### 镜头三｜所有系统都在用我的权限

景别：五组快速主观闪回转顾沉眼部近景。
构图：签到、战神、气运、神豪和王朝系统依次出现相同暗红非法标记；最终收进顾沉瞳孔中的简洁认证界面。
运镜手法：复用 Segment 01 动作匹配切换，不用强闪白；最后停在“最高管理员：顾沉”“权限恢复0.1%”。
画面内容：只出现必要认证信息，不展示密集属性。

终端：
“最高管理员认证完成。”

顾沉旁白：
“原来，不是我没有系统。”

### 镜头四｜先救小满

景别：管理员提示特写转顾沉近景。
构图：冻结、改任务、没收、合并四项权限依次亮起，随后显示“是否立即没收神豪系统”；病床上的顾小满位于提示后方。
运镜手法：从权限提示移焦到顾小满，再回到已经直起身体的顾沉。
画面内容：顾沉关闭立即执行，只保留“目标已锁定：赵天麟”；医护人员拿着稳定剂走向病床。

顾沉旁白：
“是他们的系统，都在用我的权限。”

终端：
“是否立即没收？”

顾沉心声：
“否。先救小满。”

## 声音

卡片授权音骤然失真、暗红细线轻响、最高管理员低频认证、四项权限逐个点亮。顾沉选择“否”后所有异常声音消失，只剩输液滴答。

## 负面提示词

真人照片、跪姿、雷电觉醒、红色爆炸、巨大系统面板、密集属性、邪魅笑、公开反杀、没收成功、赵天麟消散、妹妹瞬间治愈、强闪烁、过度锐化、鱼鳞网格。
