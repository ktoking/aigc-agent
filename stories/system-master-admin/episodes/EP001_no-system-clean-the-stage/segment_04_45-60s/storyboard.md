# Segment 04 故事板：最高管理员觉醒

## 戏剧任务

在顾沉弯腰捡起救命债的最低点觉醒管理员权限：先看见赵天麟的神豪系统“未经管理员授权，非法运行”，再确认所有系统都在非法运行，最后给出“是否立即没收”的强钩子。顾沉为了妹妹暂不出手，把目标秘密锁定。

## 首帧要求

直接继承 Segment 03 尾帧：顾沉站立深弯腰，右手即将碰到地面的黑金付款卡；赵天麟的黑金皮靴位于卡旁；顾小满躺在后方病床上伸手阻止。

## 尾帧要求

顾沉已经直起身，将黑金付款卡紧握在右手，挡住所有异常表情。只有他的视野中存在一条克制暗红提示：“目标已锁定：赵天麟”。背景医护人员拿着稳定剂走向顾小满病床，证明三十万确实用于救命；赵天麟仍不知道管理员已经觉醒。

## 优化后视频提示词

9:16 竖屏高级暗黑都市幻想动漫。顾沉弯腰捡起七日翻十倍的黑金付款卡，赵天麟威胁少一分钱就停妹妹的药。指尖触卡瞬间，顾沉第一次看见赵天麟头顶出现暗红字：“神豪系统，未经管理员授权，非法运行。”签到、战神、气运、神豪和王朝系统快速闪回，全部标红。管理员界面认证“最高管理员：顾沉，权限恢复0.1%”，列出冻结、改任务、没收、合并，并询问是否立即没收神豪系统。顾沉看向病床，选择“否，先救小满”，只秘密锁定赵天麟。

## 连续性检查

- 管理员权限必须到本段才觉醒，Segment 02–03 不得提前出现红字。
- 暗红文字只有顾沉能看见，赵天麟与监控完全不知情。
- 本集不执行没收、冻结、改任务或合并，只锁定目标。
- 顾沉暂缓出手的唯一直接原因是先确保顾小满拿到稳定剂。
- 三十万已经到账，七日三百万债务仍然存在。
