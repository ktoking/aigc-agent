# Segment 02 视频 Prompt：妹妹等不起这针药

## 基础设定

顾小满患有系统排异症，必须在今晚十二点前注射一支系统稳定剂。治疗费三十万，而没有系统的顾沉只有三十七元六角，也得不到任何授信。

## 角色锁定

- 顾沉 `SMA_GU_CHEN_001`：黑色碎发、右眉尾浅疤，磨损哑黑高领分层长工装、暗金修补线、黑色工靴。
- 顾小满 `SMA_GU_XIAOMAN_001`：17 岁，黑色中长直发，面色苍白但意识清醒，浅蓝病号内搭、米白针织开衫。
- 赵天麟 `SMA_ZHAO_TIANLIN_001`：仅在尾镜以黑金财团礼服轮廓和右腕金色系统腕环出现。

## 分镜

### 镜头一｜病床上的小满

景别：病床侧面中近景。
构图：顾小满躺在画面右侧病床，顾沉坐在左侧握住她的手，输液管与简洁监测屏形成视觉连接。
运镜手法：从两人交握的手缓慢上移到顾小满苍白但清醒的脸。
画面内容：顾小满呼吸压抑，先看输液袋，再看哥哥。

顾小满：
“哥，我是不是又要停药了？”

顾沉：
“不会。”

### 镜头二｜今晚必须用药

景别：药盒与床边监测屏近景。
构图：透明药盒中的单支系统稳定剂在前，持续升高的排异指数在后。
运镜手法：沿医生放下药盒的手移动到监测屏。
画面内容：医生不渲染病情，只给出明确治疗期限。

医生：
“排异指数还在升。今晚十二点前，必须注射稳定剂。”

### 镜头三｜三十万救命钱

景别：缴费屏与手机交替特写。
构图：缴费屏显示“治疗费 300,000”，顾沉旧手机显示“余额 37.60”；借款页面连续跳出“无系统者，不予授信”。
运镜手法：从三十万费用硬切三十七元余额，再连续切换三次拒贷结果。
画面内容：每项数字保持简洁可读，让观众一眼看懂顾沉无力支付。

医生：
“三十万。先缴费，才能用药。”

### 镜头四｜我没有办法

景别：顾沉近景转病房门口中景。
构图：顾沉挡在缴费屏和病床之间，顾小满伸手想拔输液针；顾沉按住她的手。门外随后亮起克制金光。
运镜手法：推近顾沉无处可点的手指，再快速移焦到打开的病房门。
画面内容：顾沉明确说自己去想办法；赵天麟只在门口形成黑金轮廓。

顾小满：
“哥，别借了，我不治了。”

顾沉：
“不行，我去想办法。”

赵天麟画外音：
“三十万都拿不出来？”

## 声音

输液滴答、压抑呼吸、监测器缓慢加快、连续拒贷提示音。赵天麟开口时，拒贷声骤停，只剩腕环一声清脆金属提示。

## 负面提示词

真人照片、幼童脸、昏迷、血腥抢救、豪华医院、夸张哭喊、顾沉突然有钱、管理员觉醒、金色爆炸、密集 UI、文字乱码、过度锐化、鱼鳞网格。
