# EP003 学院管理员审计版发布包装

## 标题候选

1. 学院管理员要删掉我的觉醒档案
2. 所有人都说我没系统，学院却急着抹掉我的记录
3. 我查到系统管理员的上游，妹妹的药名额却没了

## 封面建议

顾沉站在冷白觉醒终端前，终端红色短条指向“档案待清除”；管理员只露背影和手，暗红审计线从终端裂痕连到顾沉眼睛。

## 封面大字

他们要删掉我的人生

## 抖音简介

上一集我刚封掉赵天麟的神豪系统，学院后台就要删除我的觉醒档案。我找到终端管理员，却发现他也只是替别人下命令。真正的签发人，正在逼我妹妹放弃治疗。

## 评论区引导

如果有人逼你亲手签掉妹妹的治疗资格，你会先签字保命，还是先把签发人找出来？

## 标签方向

- 系统爽文
- 学院审计
- 隐忍复仇
- 底层逆袭
- AI漫剧

## 适合二次切片的瞬间

- 终端显示顾沉档案待清除。
- 管理员把重启权限推给顾沉，顾沉伸手碰上终端。
- 三层签发链亮起：学院管理员、校管接口、天曜财团。
- 医疗候补自愿放弃协议浮出，顾沉停在暗处。
