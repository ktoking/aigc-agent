# Segment 01 视频提示词

## 视频规格

9:16 竖屏，15 秒以内，480p 草稿，高级暗黑都市幻想动漫漫剧，成熟人物比例，生成两句清晰对白和克制环境声，不做真人写实。

## 角色与场景锁

顾沉使用 `SMA_GU_CHEN_001`：黑色碎发、右眉尾浅疤、磨损哑黑暗金长工装。学院管理员不建立正脸资产，只用背影、手部、局部工牌和声音。场景使用 `SCENE_AWAKENING_HALL_001`；终端外形依据 `PROP_AWAKENING_TERMINAL_001/prop-card.md`。

## 动作与运镜

顾沉推清洁车进入闭馆礼堂；管理员站在破损终端前按下确认键；终端出现简洁红色待清除短条；顾沉放下清洁布、抬眼追问。镜头从工靴跟到终端，再切手部和顾沉近景，动作慢而明确。

## 台词与声音

学院管理员清晰说：“顾沉，今晚删档。”
顾沉低声说：“谁签的？”
两句分开，语速稳定；加入清洁车滚轮、终端低鸣、删除确认短鸣和半拍空白，不要长旁白、群众对白或系统属性播报。

## 负面约束

真人、写实照片、清晰新管理员脸、白色学院制服、王座、太空船、电竞馆、巨大水晶、魔法阵、满屏 UI、密集乱码、公开管理员面板、夸张红光、角色漂移、静态拉图、过度锐化、鱼鳞网格、满屏微纹理。
