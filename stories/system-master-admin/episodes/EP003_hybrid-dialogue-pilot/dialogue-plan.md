# EP003 对白试验方案：学院管理员审计

## 连续性修正

EP002 结尾已经给出下一目标：“学院觉醒终端管理员”。本集直接承接这个目标：顾沉利用清洁工通行证进入闭馆后的觉醒礼堂，找到管理员，看到自己的觉醒档案正在被删除。

## 本轮对白硬约束

- 每个 Segment 只解决一个冲突。
- 每段最多两个有声说话者，系统日志只做视觉信息。
- 每段最多两句核心对白；总对白控制在 45 个汉字以内。
- 不用长旁白解释管理员权限；动作、终端状态和短内心声承担信息。
- 学院管理员只用侧影、手部和声音，不新增清晰正脸。

## 最终对白

| 段落 | 说话者 | 台词 | 戏剧功能 |
| --- | --- | --- | --- |
| 01 | 学院管理员 | “顾沉，今晚删档。” | 直接给出本集现实威胁 |
| 01 | 顾沉 | “谁签的？” | 顾沉不争辩，先追源头 |
| 02 | 学院管理员 | “终端坏了，重启。” | 把顾沉推到后台入口 |
| 02 | 顾沉 | “我只看后台。” | 表面服从，实际争取读取机会 |
| 03 | 顾沉内心 | “管理员只是执行人。” | 反转：学院管理员不是源头 |
| 04 | 顾沉内心 | “他们要小满放弃治疗。” | 连接下一集的医疗协议危机 |

## 视觉信息替代对白

- 终端红色短条：`顾沉｜觉醒档案｜待清除`。
- 审计节点：学院管理员 → 校管接口 → 天游财团。
- 下一任务卡：`顾小满｜医疗候补｜自愿放弃协议`。

## 主动删除的内容

- 删除送酒、宴会、公共医疗基金买酒线；这条线后移，不能抢走学院管理员主线。
- 删除管理员长篇解释和群众对白，改成终端状态、手部动作和门禁声。
- 删除公开管理员指令；顾沉只在主观视野里读取并存证。
- 删除“真正的战斗才刚开始”等空泛钩子，结尾改为具体的医疗放弃协议。

## 文本通过标准

1. 观众能听懂顾沉为什么来学院、管理员要删什么。
2. 观众能看懂管理员是执行人，校管接口才是上游。
3. 结尾明确出现顾小满将被逼签放弃医疗资格的问题。
4. 后续视频原生音频只承载短对白，完整配音交给独立 TTS 和字幕层。
