# Segment 02 视频提示词

## 视频规格

9:16 竖屏，15 秒以内，480p 草稿，高级暗黑都市幻想动漫漫剧，成熟人物比例，生成两句清晰对白和克制故障声，不做真人写实。

## 角色与场景锁

顾沉使用 `SMA_GU_CHEN_001`；学院管理员只出现背影、手部、袖口和声音。场景使用 `SCENE_AWAKENING_HALL_001`；终端使用 `PROP_AWAKENING_TERMINAL_001` 文字卡规则。

## 动作与运镜

删除短条停住，终端故障闪烁；管理员把维护通行证推给顾沉并转身看监控；顾沉接证、走到黑色掌纹读取面，右手贴上终端，暗红细线从裂痕短暂亮起。公共镜头只显示设备恢复，不显示管理员面板。

## 台词与声音

学院管理员说：“终端坏了，重启。”
顾沉说：“我只看后台。”
两句分开、慢速；加入故障短鸣、卡片滑动声、指纹接触声和继电器声，不要系统播报和群众对白。

## 负面约束

真人、写实照片、清晰新管理员脸、白色制服、公开管理员指令、巨大 UI、密集乱码、爆炸、攻击、酒箱、金币雨、角色漂移、场景跳变、过度锐化、鱼鳞网格、满屏微纹理、横屏。
