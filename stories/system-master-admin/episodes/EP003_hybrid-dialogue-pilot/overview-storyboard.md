# EP003 文本试验版 60 秒概述故事板

## 本集一句话

顾沉找到学院觉醒终端管理员，却发现对方正在删除自己的档案；他暗中读取后台，查到真正的签发源头是天曜财团校管接口。

## 总体节奏

- Segment 01：目标现身，顾沉的档案进入删除倒计时。
- Segment 02：管理员把重启故障推给顾沉，顾沉获得触碰终端的理由。
- Segment 03：顾沉暗中读取三层签发链，发现管理员只是执行人。
- Segment 04：后台出现顾小满的医疗放弃协议，下一集危机具体化。

## 本集关键画面

1. 顾沉站在最低层，学院管理员站在觉醒终端前；红色短状态落在顾沉档案上。
2. 管理员把维护权限推给顾沉，终端裂痕映出顾沉的手。
3. 顾沉主观视野里出现三枚简洁节点：学院管理员、校管接口、天曜财团。
4. 顾小满的医疗候补协议出现在后台任务列表，顾沉把清洁车推入暗处。
