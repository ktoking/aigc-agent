# EP002 发布包

## 剧名

《无系统者》

## 标题候选

1. 学院觉醒日，神豪系统当场被封
2. 全校都等着看我下跪，神豪少爷却突然失去系统
3. 他逼我认废物，下一秒他的系统没了
4. 无系统者一句话，SSS神豪权限当场归零

## 封面构图

顾沉走入礼堂暗处，赵天麟在后景抬起已经熄灭的金色腕环；身后四类系统正常悬浮，神豪节点变成空白，关闭的直播屏和少量红色监控灯留在高处。主色为冷白、黑金和少量暗红，不出现公开升级面板。

## 发布文案

全世界都在学院觉醒日等待系统分级。财团少爷接到任务，准备当众羞辱我这个“无系统废物”。他不知道，我已经偷偷拿到了管理员权限。等他抬腕启动神豪系统，我让它悄悄失效。全场只当设备坏了，只有我看见权限从 0.1% 升到 0.2%——原来，只要继续使用，权限就能往上升。

## 评论引导

如果你能偷偷让一个系统失效，你会继续藏身份升级，还是立刻公开打脸？
