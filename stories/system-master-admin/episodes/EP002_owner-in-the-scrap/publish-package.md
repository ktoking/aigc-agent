# EP002 发布包

## 标题候选

1. 工资被扣一半后，废系统突然叫我主人
2. 他们把救命系统当垃圾，我却看见它还在运行
3. 妹妹的治疗顺位掉到462，我在焚毁炉前捡到最高权限

## 封面

- 画面：顾沉低头托住裂开的六棱核心，冷蓝钥匙光从掌心亮起；背后焚毁机已经启动。
- 封面大字：`这块废系统，为什么叫我主人？`

## 发布文案

妹妹下一针只剩三天，我的工资却被扣掉一半。所有人都说，空白者连申诉的资格都没有。可当我被逼着清理一块“废系统”时，它却告诉我：检测到原始所有者。

## 评论引导

如果你是顾沉，会立刻带走核心，还是先让它在账上“死”掉？
