# EP002 60秒概述故事板

## 本集一句话

工资被扣到只剩妹妹半针药钱的顾沉，在回收站继续低头干活，却从焚毁线上捡到一块称他为“原始所有者”的废系统。

## 总体节奏

- Segment 01：首针生效，但下一针只剩三天；扣薪让治疗顺位暴跌。
- Segment 02：主管以停医疗绑定威胁顾沉认罚，逼他去清理非法废件。
- Segment 03：顾沉读出废核心仍在运行，报废记录是伪造的。
- Segment 04：废核心认主，权限恢复 0.3%；黎明盘点马上开始。
