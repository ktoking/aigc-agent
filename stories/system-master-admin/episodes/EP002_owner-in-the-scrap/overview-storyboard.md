# EP002 60秒总分镜：学院觉醒日，神豪系统当场被封

## 一句话

全院都在看赵天麟用神豪系统羞辱无系统者，下一秒他的腕环突然熄灭；顾沉当众把自己伪装成无系统旁观者，所有人都以为是设备故障，只有他看见权限从 0.1% 升到 0.2%。

## 叙事原则

- 顾沉第一人称，台词直接，不用未来视角和谜语式旁白。
- 开场先让赵天麟说出神豪任务和五百万元奖励，再用顾沉故意跟随说明他已经看见任务、准备等反派调用系统。
- 赵天麟的压迫落到“无系统废物”的公开羞辱和学院资格清零。
- 反转来自上一集已经觉醒的管理员权限：顾沉等赵天麟调用系统，再执行封禁与剥夺宿主。
- 公开场面只呈现腕环熄灭和赵天麟惊讶，不公开顾沉管理员身份。
- 前期能力只能偷偷使用：顾沉可以让系统失效，但任何人都不能确认“是他剥夺了系统”。
- 每段结尾以动作匹配衔接下一段：付款卡、腕环、空白神豪节点、顾沉眼底暗红升级线。
