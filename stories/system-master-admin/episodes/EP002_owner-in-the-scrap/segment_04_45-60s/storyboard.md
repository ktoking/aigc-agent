# Segment 04 故事板：废系统叫我主人

## 戏剧任务

兑现标题钩子：废核心确认顾沉是原始所有者，权限恢复到 0.3%。顾沉没有沉浸在爽点中，而是立刻面对黎明盘点的新危险。

## 镜头表

| 分镜 | 画面 | 对白 / 声音 |
| --- | --- | --- |
| 镜头一｜硬件验证 | 顾沉掌心钥匙标记闭合成完整圆环，核心短促震动一次 | 终端：“管理员硬件验证完成。” |
| 镜头二｜权限零点三 | 顾沉瞳孔内出现从 0.1% 推进到 0.3% 的细环，`AUDIT_READ` 与 `EVIDENCE_VAULT` 两枚图标稳定亮起 | 终端：“权限恢复百分之零点三。” |
| 镜头三｜把它藏起来 | 顾沉听见脚步，立刻让核心熄光，拉开清洁车底层暗格放入核心，再用脏布覆盖 | 顾沉心声：“还不能让任何人知道。” |
| 镜头四｜黎明盘点 | 整个回收站广播响起，入口红灯一盏盏亮起；主管带人朝焚毁区走来，顾沉推着清洁车停在岔路口 | 广播：“黎明盘点。缺失系统核心一枚。”顾沉心声：“天亮前，我得让它在账上死一次。” |

## 首帧要求

直接复用 Segment 03 尾帧：顾沉掌心托核心，冷蓝钥匙标记刚形成，焚毁区无人注意。

## 尾帧要求

回收站纵深走廊，顾沉推着旧清洁车站在岔路中央，背后焚毁区、前方盘点人员剪影同时逼近。车底暗格处只有一道几乎不可见的冷蓝细光；上方红色盘点灯依次亮起。

## 连续性检查

- 权限固定为 0.3%。
- 核心藏入清洁车底层，不凭空消失。
- 顾沉没有庆祝或邪魅笑。
- 结尾问题明确：如何让缺失核心通过盘点。
