# 《无系统者》故事包

## 剧名

- 主标题：无系统者
- 爆款向标题：天命之子都有系统，而我有后台
- Story ID：`system-master-admin`

## 项目定位

- 类型：全民系统、底层逆袭、隐忍复仇、权限争夺、都市奇幻。
- 形式：9:16 竖屏高级暗黑都市幻想动漫漫剧。
- 默认单集：60 秒。
- 默认结构：4 段，每段 15 秒以内。
- 目标观众：喜欢系统爽文、阶层逆袭、长期复仇和夺权成长的 18-40 岁观众。
- 核心爽点：别人靠系统升级，顾沉靠管理员权限审计、冻结、改写和没收所有系统。
- 情绪卖点：前期压抑和心疼、中期秘密反制、EP010 首次公开清算、后期夺城夺国。

## 一句话卖点

全民系统决定命运的世界里，唯一没有系统的底层清洁工，才是所有系统等待二十年的原始管理员。

## 节奏承诺

顾沉不会第一集立刻公开反杀。EP001-EP009 让他在学院资格、妹妹医疗、工资和尊严上持续受压，同时暗中恢复权限、记录违规宿主、布局证据；EP010 才当着全城观众的面注销赵天麟。
