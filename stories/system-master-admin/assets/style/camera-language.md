# 《无系统者》镜头语言

## 竖屏构图

- 顾沉受压时使用略高机位近景，让赵天麟白鞋、腕环或文件进入前景。
- 顾沉暗中审计时使用眼神、手指、终端编号和医疗卡特写。
- 赵天麟掌控资源时站在画面中心上部，顾沉不必持续跪地，可通过礼台高差表达权力。
- 管理员日志出现时慢推，不用旋转、爆炸或快速拉焦。

## 节奏

- 每 3-5 秒更换信息锚点：结果屏、工牌、医疗卡、清洁布、终端裂缝、腕环状态灯。
- 隐忍场景保留短暂停顿，让观众看见顾沉在判断，而不是呆滞。
- 单段最多四个镜头，动作链简单可生成。

## 常用转场

- 医疗卡状态切换到赵天麟腕环。
- 清洁布擦过礼台，转到终端裂缝。
- 礼堂明亮仪式灯逐盏关闭，进入暗中审计状态。

## 禁止

不要无意义绕拍、360 度旋转、快速闪切、大量大全景、满屏 UI 推拉、角色定格摆拍。
