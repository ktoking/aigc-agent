# 《我是所有系统的主人》全局视觉风格

## 最高优先级参考

- 用户美术参考：`user-anime-style-reference.png`
- 只继承暗黑华丽都市幻想、黑金与银蓝对撞、系统纹章、强层次光效和高级动漫人物设计。
- 不复制参考图的具体人物脸、构图、服装纹样、龙、王座或现成符号。

## 核心风格

- 9:16 竖屏，高级暗黑都市幻想动漫漫剧。
- 人物使用精致二次元五官、成熟比例、锐利线条和可控赛璐璐光影。
- 场景是近未来都市、系统学院、财团高塔、王朝大殿与低权限废墟的幻想化结合。
- 服装允许华丽分层，但必须先保证清楚轮廓和跨镜头可复现。

## 色彩阵营

- 顾沉：哑黑、炭黑、少量磨损暗金。
- 苏见月：银白、午夜蓝、蓝紫晶体。
- 赵天麟：纯黑、暖金、琥珀金。
- 洛星河：黑紫、星光紫、古金。
- 蓝未央：银蓝、钴蓝、黑金。
- 姬玄凰与王朝：深黑、帝国金、暗红。
- 管理员非法标记：暗红细字和裂纹，不使用满屏红光。

## 系统表现

- 神豪：金色钻石、财富环、黑金城市权限。
- 签到/资源：蓝色日历、账本印章、仓储方块。
- 战神：红色剑盾和军团阵列。
- 气运：紫色星盘、概率线和被改写的名额。
- 王朝：金色王冠、双龙轮廓、城市与军团连接图。
- 单镜最多一个主系统纹章，避免多色图标互相争抢。

## 画质要求

- 保留参考图的高级动漫光影与宏大层次，但角色三视图和视频参考图必须减少无效细节。
- 优先清楚人物轮廓、脸、手、服装大形和系统主符号。
- 禁止真人、写实照片、3D 游戏渲染、Q版、过度锐化、鱼鳞网格和满屏微纹理。
