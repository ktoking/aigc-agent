# 医疗基金酒箱道具卡

## 道具 ID

`PROP_MEDICAL_FUND_WINE_CRATE_001`

## 外观锁定

- 单人可抱起的窄长黑金硬质酒箱，四角有低调金属包边。
- 正面是金色王冠酒庄徽记，底部封签却藏着一枚冷蓝医疗基金十字印章。
- 顾沉触碰封签后，只在他的主观视野中出现一条暗红资金流向线。
- 箱内为三瓶深色玻璃酒，瓶口金箔整洁，不做金币堆或夸张奢侈品陈列。

## 剧情职责

- EP003 中赵天麟以顾小满治疗顺位为筹码，逼顾沉二十分钟内送到顶层宴会。
- 酒款与任务奖励实际来自公共医疗救助基金。
- 封签是顾沉读取完整资金链、保存恶意任务证据的媒介。

## 禁止变化

不要木质古董酒箱、现代现实品牌、清晰英文商标、巨型宝箱、金币喷涌、密集 UI 或血迹。
