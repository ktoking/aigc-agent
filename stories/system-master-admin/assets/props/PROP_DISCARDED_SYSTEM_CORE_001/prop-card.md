# 废弃系统核心道具卡

## 道具 ID

`PROP_DISCARDED_SYSTEM_CORE_001`

## 外观锁定

- 巴掌大的六棱黑色金属核心，边角磨损并有一道裂口。
- 原本的金色宿主纹章已熄灭，只在裂缝深处保留极弱冷蓝呼吸光。
- 核心侧面有一枚被刮花的公共医疗分配徽记，不能生成大段可读文字。
- 顾沉触碰后，冷蓝光沿裂缝汇成一枚极简钥匙形管理员标记。

## 剧情职责

- EP002 中被回收站判定为“非法废件”，准备送入焚毁机。
- 实际仍保留 83% 的医疗分配功能，是顾沉找到的第一块管理员硬件。
- 只对顾沉发出“检测到原始所有者”的低声提示。

## 禁止变化

不要水晶球、魔法宝石、巨大机械心脏、漂浮法阵、密集线路、满屏文字或武器化造型。
