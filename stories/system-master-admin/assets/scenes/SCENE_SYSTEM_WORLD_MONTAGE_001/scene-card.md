# 系统文明蒙太奇场景卡

## 场景 ID

`SCENE_SYSTEM_WORLD_MONTAGE_001`

- Canonical 场景图：`canonical-concept.png`

## 戏剧用途

用于 EP001 开场，以五组高辨识度画面在一个 segment 内建立“系统决定世界阶级”的宏大背景。

## 五组画面

1. 神豪系统：财富塔顶层，金色支付环扫过，医疗与资产权限同时打开。
2. 签到系统：城市中央签到台，普通人排长队，宿主随手领取房产钥匙。
3. 战神系统：军团授勋场，黑金军徽与列阵士兵形成权力感。
4. 气运系统：机会榜与录取名额转向宿主，另一人的名字同时暗下。
5. 王朝系统：帝都议政大殿，皇帝坐在高处，城市权限图在身后展开。

## 统一视觉

- 9:16 竖屏，高级暗黑都市幻想动漫漫剧。
- 每组只保留一个人物剪影和一个系统符号，不建立清晰新角色脸。
- 从白金财富、青色签到、黑金军权、紫色气运过渡到深金皇权。
- 最后一帧骤然切回冷白觉醒礼堂下方的顾沉，制造阶级坠落。
