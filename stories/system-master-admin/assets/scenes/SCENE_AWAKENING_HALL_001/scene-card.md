# 系统学院觉醒礼堂场景卡

## 场景 ID

`SCENE_AWAKENING_HALL_001`

- Canonical 场景图：`canonical-concept.png`

## 空间结构

- 高挑黑金都市幻想学院礼堂，中央是圆形觉醒台，维持成熟动漫建筑比例。
- 觉醒台后方有一块纵向结果屏，屏幕内容保持少量、易读。
- 台下前排是学院和财团席位，后排为普通候补者。
- 礼台侧面连接后台门和清洁用品间。
- 场内安装四个明显监控摄像头，后半段清场后仍保持工作。

## 色彩与光线

- 仪式期间：冷白顶灯，黑金装饰，空间明亮但缺少温度。
- 清场之后：只保留礼台工作灯和安全出口绿灯，背景变暗。
- 管理员日志出现时：破损终端反射极细暗红光，不照亮整个房间。

## 核心机位

- 竖屏礼台正面近中景：人物、觉醒终端和结果屏同时可见。
- 顾沉位于最低层、系统精英位于高台的竖向阶级构图。
- 顾沉黑色碎发、磨损哑黑暗金长工装与冷白空间形成轮廓对比。
- 圆形觉醒终端与顾沉眼睛反射的特写。

## 禁止变化

不要变成真人照片、太空船、电竞馆、古代大殿、巨型赛博城市或满屏悬浮 UI。不要自动补大量清晰人脸；远处系统精英只保留模糊剪影。
