# 《我是所有系统的主人》故事包说明

## 故事范围

本目录维护《我是所有系统的主人》的全部专属规则。生成剧情、分镜、首尾帧、视频 prompt、角色资产或连续性文件时，必须优先遵循本目录规则，不得混入其他 story 的末日、抽卡、言灵或异能设定。

## 必读顺序

1. `docs/story-memory.md`
2. `docs/production-rules.md`
3. `docs/audience-strategy.md`
4. `docs/season-arc.md`
5. `docs/workflow.md`
6. `assets/` 下角色、场景、道具与风格资产
7. `episodes/` 下上一集内容

## 默认剧集格式

- 一集 60 秒。
- 一集拆成 4 段，每段 15 秒以内。
- 默认 9:16 竖屏高级暗黑都市幻想动漫漫剧。
- 每段必须包含 `storyboard.md`、`first-frame.md`、`last-frame.md`、`prompt.md`、`director-promt.txt`、`api-request.md`、`frames/`、`output/`。
- `director-promt.txt` 是视频 API 直投提示词，必须按顺序解释参考图用途并写清逐秒动作。

## 本剧本核心锁定

- 主角锁：顾沉，22 岁，无系统者、系统回收站清洁工。外冷内稳，能忍但不软弱；每次忍让都必须换回证据、权限、时间或保护妹妹的机会。
- 妹妹锁：顾小满，17 岁，患系统排异症。她不是等待营救的工具人，知道哥哥受辱后会反对他继续低头。
- 女主锁：苏见月，21 岁，觉醒被嘲笑为废物的“失败预警系统”，能看见行动会在哪一步失败，后续成为顾沉的漏洞审计搭档。
- 第一反派锁：赵天麟，22 岁，系统财团继承人，绑定 SSS 神豪系统。他的恶意来自特权惯性，不写成只会吼叫的纸片恶少。
- 终极反派锁：萧无极，帝国圣皇、王朝系统宿主、临时代理管理员。他用系统秩序筛选阶层并收割宿主成果。
- 世界规则锁：十八岁觉醒系统决定教育、医疗、职业和社会等级；无系统者只能进入最低权限区。
- 管理员能力锁：顾沉可以读取、暂停、改写、注销和合并子系统，但前期公开使用会向系统议会和代理管理员上报位置。
- 隐忍节奏锁：EP001-EP009 不进行公开彻底复仇。顾沉可以私下测试、保护他人、积累证据和进行小范围反制；EP010 才首次公开注销赵天麟。
- 复仇原则锁：隐忍必须有具体收益，不能连续挨打却毫无行动；每集至少让观众看到一项证据、权限进度或反派代价正在累积。
- 视觉风格锁：以 `assets/style/user-anime-style-reference.png` 为美术参考，使用暗黑华丽都市幻想动漫、黑金与银蓝阵营配色、精致成熟人物比例和系统纹章；不复制参考图具体人物或构图，也不做真人写实。
- 禁止偏差：不要重生；不要让顾沉第一集直接无敌公开打脸；不要靠长旁白解释系统；不要写空泛谜语台词；不要让赵天麟在 EP010 前失去全部系统。

## 台词规则

- 对话要像真实人物在利益冲突中说话。
- 顾沉隐忍时少说狠话，优先观察、确认条件、保存证据。
- 反派的羞辱必须对应具体资源：学院资格、医疗名额、工资、住房或家人安全。
- 系统提示只说必要结果，禁止连续播报属性面板。
- 每集结尾必须给出具体下一步问题，不用“真正的战斗才刚开始”。
