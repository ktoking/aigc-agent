# 《我是所有系统的主人》受众与发布策略

## 目标观众

- 年龄/兴趣：18-40 岁，系统爽文、底层逆袭、校园阶层、财团复仇、权力升级题材观众。
- 情绪需求：先替主角憋屈，再看主角暗中掌握证据，最终一次性清算。
- 题材偏好：能力必须一句话听懂，反派必须握有具体资源，复仇必须拿回身份和权力。
- 可能转发/评论的原因：讨论“该不该继续忍”“第几集注销赵天麟”“顾沉到底恢复了多少权限”。

## 情绪卖点

- 爽：管理员对所有外挂拥有最终解释权。
- 急：顾沉妹妹的医疗顺位每天都在下降。
- 虐：顾沉明明有能力苗头，却不能过早暴露。
- 恨：赵天麟把医疗、奖学金和工作当成服从任务奖励。
- 心疼：顾小满知道哥哥受辱，却无法立即离开系统医疗体系。
- 期待：前九集的证据最终会在 EP010 一次性引爆。

## 慢热留存规则

- 不能九集只压不放：每集至少给一个“暗爽”，如反派系统短暂失灵、证据被永久保存、公共资源偷偷归还一部分。
- 顾沉每次忍让前后都要有行动目标和完成状态。
- 观众应比反派更早知道顾沉的权限在恢复，但不能提前知道全部上限。
- 每三集提高一次管理员权限，从读取、保存、三秒暂停升级到十秒暂停和合法注销签名。

## 开头钩子库

| 钩子类型 | 本剧用法 | 示例 |
| --- | --- | --- |
| 世界级反常识 | 五类天命系统全部是未经授权的非法程序 | 这个世界天才人手一个系统，而所有系统都在盗用我的权限 |
| 身份反差 | 无系统清洁工能看见系统隐藏日志 | 所有人都有系统，只有清洁工看见了后台 |
| 现实损失 | 医疗候补、学院资格、工资被夺 | 妹妹的治疗名额，被财团少爷拿去做任务奖励 |
| 关系冲突 | 妹妹拒绝哥哥继续低头 | “我宁可停药，也不要你给他擦鞋。” |
| 信息差 | 反派不知道自己正在被审计 | 顾沉擦掉酒渍，同时记录系统编号 |
| 爽点预告 | 先闪回 EP010 注销画面再回到受辱日 | “九天后，他亲手关掉了SSS系统。” |

## 标题模板

- 所有人都有系统，只有我被安排去擦地
- 他拿妹妹的治疗名额逼我低头，我忍了九天
- SSS系统不知道，它的管理员正在给宿主擦鞋
- 我没有立刻报仇，因为一个系统背后还有七个财团

## 封面策略

- 封面主体：顾沉位于中央，身后排列神豪、签到、战神、气运、皇帝五个宿主剪影；所有人头顶出现同一条暗红非法运行标记。
- 封面大字：所有系统，都是盗版
- 色彩：顾沉灰蓝、赵天麟白金、管理员日志暗红。
- 禁止：满屏系统 UI、多人群像、夸张龙傲天笑容。

## 评论区引导

- 如果你已经能关掉他的系统，会继续忍九天查幕后，还是现在就报仇？
- 顾沉第一次公开注销，放在第几集最解气？
