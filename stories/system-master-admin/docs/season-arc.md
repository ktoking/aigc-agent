# 《无系统者》长线剧情规划

## 总主线

空白者顾沉在反复受辱中发现自己是所有系统的原始管理员。为了保护患病妹妹并查出医疗资源被挪用的真相，他没有立刻暴露，而是用九集时间读取违规任务、恢复权限、锁定财团和系统议会的证据。EP010 首次公开注销赵天麟后，他从个人复仇走向制度争夺：接管医疗、学院、城市、军团和王朝系统，最终面对把全体宿主当作电池的圣皇萧无极。

## 爽点配额

- EP001-EP003：只给读取、证据保存和不公开的微型权限反制；任何人不能确认顾沉就是剥夺者。
- EP004-EP006：每集一次微小系统异常，让观众确认顾沉并非无能。
- EP007：第一次私下能力碾压，保护妹妹。
- EP008-EP009：反派仍以为顾沉服从，观众明确知道局已布好。
- EP010：释放前九集积压的公开清算。

## 长线伏笔

- 赵天麟的神豪系统只是测试版，财团真正目标是筛选可被收割的高服从宿主。
- 顾沉体内管理员密钥来自母亲主动分割，并非天降外挂。
- 顾小满的病不是副作用，而是另一枚密钥无法与王朝系统兼容。
- 苏见月的失败系统保存着初代审计日志。

- EP030 前不揭示顾小满是第二密钥。
