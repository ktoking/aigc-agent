# 《无系统者》故事记忆

## 项目定位

- Story ID：`system-master-admin`
- 类型：全民系统、底层逆袭、隐忍复仇、都市奇幻、权限夺取。
- 目标平台：抖音、快手、红果漫剧、B站合集。
- 目标观众：系统爽文、男频逆袭、阶层反抗与长期清算题材受众。
- 单集规格：60 秒，4 段，每段 15 秒以内，9:16。
- 一句话卖点：人人看不起的无系统清洁工，才是所有天命系统的原始管理员。

## 世界观

故事发生在近未来城邦帝国“天衡”。每个人十八岁参加觉醒仪式，系统等级决定教育、医疗、职业、住房和婚姻匹配权限。系统分为生活级、职业级、战斗级、稀有级、王级五层。无系统者被称为“空白者”，只能居住在低权限区，从事回收、清洁和危险维修。

所有公开系统实际上都是“天衡主系统”的子系统。二十年前，系统议会和七大财团篡夺管理权，把原本服务所有人的公共系统改造成血统特权。圣皇萧无极持有临时代理权限，通过任务和升级悄悄抽取每个宿主的成果。

顾沉体内保存着初代管理员的生物密钥。他不是转世，也没有上一世记忆。管理员权限从 0.1% 开始恢复，理论上能读取、冻结、改写任务、没收、注销和合并全部子系统。前期公开执行高权限操作会向系统议会报告他的精确位置，并可能导致妹妹顾小满的医疗账户被永久冻结。

前期隐秘使用锁：顾沉可以偷偷调用管理员能力，让某个系统短暂失效、封禁或剥夺宿主权限，但不能让世界内任何人确认“无系统者就是系统剥夺者”。公开场面必须保留设备故障、权限冲突或终端异常的解释；管理员指令、能力来源和升级提示只出现在顾沉主观视野，镜头可以让观众短暂理解，但不能让其他角色看见。每次隐秘使用都会积累权限经验，管理员进度可以继续升级。

## 核心故事

顾沉二十二岁，在系统回收站做夜班清洁工。觉醒日他再次申请补测，希望获得最低等级系统，借此为患系统排异症的妹妹顾小满续上医疗权限。结果仪式仍判定他“无系统”，学院取消补录，医院同步暂停妹妹的候补名额。

系统财团少爷赵天麟觉醒 SSS 神豪系统。为了完成连续七日的“服从测试”任务，他以医疗名额为筹码，让顾沉在学院礼堂做清洁、跑腿、当众道歉。顾沉没有立刻反抗，因为他看见只有自己能读到的管理员视野：不只是赵天麟，神豪、签到、战神、气运和王朝系统全部显示“未经管理员授权，非法运行”。

顾沉决定继续低头九天。他暗中恢复权限、保存违规任务链、追查妹妹名额被夺的审批记录，也逐步确认系统议会会监控任何高权限操作。EP010，他在财团举办的全城公益直播上公开证据，先让赵天麟亲口承认任务，再以管理员身份注销其系统，把非法奖励归还受害者。此后冲突从个人复仇升级为学院、城市、军队、皇朝和世界总权限的争夺。

## 管理员权限

### 初始可见权限

- `AUDIT_READ`：读取子系统编号、宿主、任务来源、资金来源和违规记录。
- `PAUSE_3S`：让一个低阶子系统暂停三秒；顾沉前期只在无人处测试。
- `BAN_SYSTEM`：秘密封禁一个非法运行的子系统；前期只能在不暴露操作者的情况下使用。
- `REVOKE_HOST`：秘密剥夺宿主对指定子系统的控制权；公开画面不得出现管理员指令或“顾沉执行”的证据。
- `TASK_DRAFT`：预览任务改写结果，但未获得安全签名之前不能公开提交。
- `EVIDENCE_VAULT`：把违规日志存入主系统隐藏证据库，普通宿主和系统议会无法删除。

### 阶段解锁

- EP002：首次秘密执行 `BAN_SYSTEM` + `REVOKE_HOST`，权限进度从 0.1% 升到 0.2%。
- EP007：可对一个系统执行十秒静默暂停。
- EP010：首次获得合法注销签名，注销赵天麟的神豪系统。
- EP020：任务重写与奖励返还。
- EP030：多系统合并。
- EP060：城市级权限管理。
- EP090：王朝系统注销。
- EP100：主系统所有权恢复。

## 长线伏笔

- 顾沉母亲不是死于事故，而是在拒绝把主系统永久私有化后被删除身份。
- 顾小满的系统排异症其实是第二枚管理员生物密钥自我保护。
- 苏见月的失败预警系统是初代审计模块，被故意降级为“废物系统”。
- 萧无极无法直接使用完整管理员权限，只能依靠全体宿主任务抽成维持统治。

- 角色视觉：顾沉磨损哑黑暗金工装对比赵天麟整洁锋利的黑金财团礼服；女主使用银白蓝紫与二人区分。

- 道具视觉：金色宿主腕环、破损觉醒终端、顾小满医疗候补卡。
- 特效视觉：普通系统为金蓝色半透明光层；管理员日志为极细暗红线框，只在关键时刻出现。

## 禁止改变

- EP001-EP009 不公开注销或承认剥夺赵天麟；允许顾沉在无暴露风险的情况下秘密封禁、暂停或剥夺系统。
- 前期任何能力使用都必须伪装成设备故障、权限冲突或宿主操作失误，不能让角色确认顾沉就是操作者。
- 顾沉的隐忍必须对应调查和布局，不能写成软弱。
- 顾沉不是重生者，不提前知道未来。
- 管理员能力不以大段游戏属性面板展示。
- 顾小满不是只会哭和拖累主角的角色。
