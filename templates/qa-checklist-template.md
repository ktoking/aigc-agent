# EPXXX 质检清单

## 剧本文案：交稿前六项全部通过

依照[剧本文案检查](../skills/story-film-workflow/references/script-language-checklist.md)逐句审读。实例化到story或episode时按实际目录调整链接；记录本次稿件版本与处理证据，任何FAIL或待定先改再交。

- [ ] L01 无反复顿悟报幕。
- [ ] L02 无对照式说教。
- [ ] L03 无刻意金句、抽象升华和强行对仗。
- [ ] L04 无创作约束或反套路说明外露。
- [ ] L05 无硬拗幽默、牵强比喻和频繁抖包袱。
- [ ] L06 无公文口吻、空泛总结和悬念占位句。
- [ ] 已核对连续性、第一人称信息边界并保存逐项检查记录。
- [ ] 另行完成S01—S06叙事检查：开场冲突、目标代价、主角主动选择、反转因果、题材回报及段落推进；逐项记录具体剧情证据，不能用文案合格代替吸引力检查。

## 剧情与留存

- [ ] 前 5 秒有钩子。
- [ ] 本集只有一个核心任务。
- [ ] 本集有冲突。
- [ ] 本集有爽点/揭示/反转。
- [ ] 本集有情绪推进。
- [ ] 最后 3 秒有下一集钩子。
- [ ] 对白短、狠、可演。

## 四段结构

- [ ] Segment 01 有故事板、首帧、尾帧、prompt。
- [ ] Segment 02 有故事板、首帧、尾帧、prompt。
- [ ] Segment 03 有故事板、首帧、尾帧、prompt。
- [ ] Segment 04 有故事板、首帧、尾帧、prompt。
- [ ] 四段均为 15 秒以内。

## 连续性

- [ ] 02 首帧继承 01 尾帧。
- [ ] 03 首帧继承 02 尾帧。
- [ ] 04 首帧继承 03 尾帧。
- [ ] 人脸、发型、服装、站位不漂移。
- [ ] 光线、道具、伤口、场景不漂移。

## 视频 API

- [ ] 每段 prompt 可直接提交。
- [ ] 每段有 `api-request.md` 或任务记录位置。
- [ ] 每段 `api-request.md` 有按 API 输入顺序列出的参考图上传计划。
- [ ] 故事板表格图默认不上传；如上传，已说明原因并显式使用 `--include-storyboard`。
- [ ] 每段有负面提示词。
- [ ] 每段能单独失败、单独重试。
