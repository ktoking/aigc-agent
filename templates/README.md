# 模板目录说明

## 根剧集模板

- `episode-template.md`：单集剧情设计。
- `episode-overview-storyboard-template.md`：60 秒总览故事板。
- `continuity-template.md`：连续性表。
- `segment-storyboard-template.md`：单段故事板。
- `image-manifest-template.md`：图像和视频任务清单。
- `qa-checklist-template.md`：剧集质检清单。
- `publish-package-template.md`：抖音发布包装。

## 单段视频模板

`episode-segment/` 下模板用于每个 15 秒以内的视频段：

- `first-frame-template.md`：首帧提示词。
- `last-frame-template.md`：尾帧提示词。
- `prompt-template.md`：视频 API / 图生视频提示词。
- `api-request-template.md`：视频 API 请求记录。

## Story 初始化模板

`story-package/` 用于新剧本接入：

- story 入口文件：`README.md`、`AGENTS.md`
- story 文档：故事记忆、生产规则、受众策略、长线规划、工作流
- 资产卡：角色、场景、道具、风格

新 story 可以直接复制该目录，再把占位内容替换成具体剧本内容。
