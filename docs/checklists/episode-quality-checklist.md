# 剧集质量检查清单

## 剧本文案：展示与制作前检查

按[剧本文案检查](../../skills/story-film-workflow/references/script-language-checklist.md)逐句及整段审读；六项全部通过、无未处理项才交稿或进入制作。试读片段同样适用。

- [ ] L01 无反复顿悟报幕。
- [ ] L02 无对照式说教。
- [ ] L03 无刻意金句、抽象升华和强行对仗。
- [ ] L04 无创作约束、反套路说明混入旁白。
- [ ] L05 无硬拗幽默、牵强比喻和频繁抖包袱。
- [ ] L06 无公文口吻、空泛总结和悬念占位句。
- [ ] 已记录稿件版本、问题处理、必要保留项的具体用途，并核对连续性与信息边界；改稿后重查。
- [ ] S01—S06叙事检查另行全部通过：开场冲突、目标代价、主角主动选择、反转因果、题材回报及段落推进；记录剧情证据，不把文案通过等同于吸引力通过。

## 结构检查

- [ ] 一集 60 秒。
- [ ] 拆成 4 段。
- [ ] 每段 15 秒以内。
- [ ] 每段都有 `storyboard.md`。
- [ ] 每段都有 `first-frame.md`。
- [ ] 每段都有 `last-frame.md`。
- [ ] 每段都有 `prompt.md`。
- [ ] 每段都有 `director-promt.txt`。
- [ ] 每段都有 `frames/` 和 `output/`。
- [ ] 推荐补齐 `api-request.md`。

## 剧情检查

- [ ] 前 5 秒有可见钩子。
- [ ] 本集只有一个核心戏剧任务。
- [ ] 本集有明确冲突。
- [ ] 本集有爽点、揭示或反转。
- [ ] 本集有情绪推进。
- [ ] 最后 3 秒有下一集钩子。
- [ ] 对白短、狠、可演。
- [ ] 没有用长旁白解释设定。

## 抖音短视频检查

- [ ] 每 3-5 秒有画面或信息变化。
- [ ] 每段结尾都有小悬念或动作延续。
- [ ] 画面中心有明确注意力锚点。
- [ ] 标题、封面、评论引导已准备。
- [ ] 开头画面适合无声自动播放。

## 连续性检查

- [ ] Segment 02 首帧继承 Segment 01 尾帧。
- [ ] Segment 03 首帧继承 Segment 02 尾帧。
- [ ] Segment 04 首帧继承 Segment 03 尾帧。
- [ ] 人物脸、发型、服装不漂移。
- [ ] 伤口、道具、站位、光线不漂移。
- [ ] 场景变化有可见转场。

## 视频 API 检查

- [ ] `prompt.md` 包含画幅、时长、风格、清晰度。
- [ ] `prompt.md` 包含角色锁。
- [ ] `prompt.md` 包含动作链路。
- [ ] `prompt.md` 包含运镜。
- [ ] `prompt.md` 包含台词和音效。
- [ ] `prompt.md` 包含负面提示词。
- [ ] `director-promt.txt` 能直接作为视频 API prompt-file 使用。
- [ ] `director-promt.txt` 包含参考图用途、角色锁、逐秒动作因果、声音和禁止项。
- [ ] `api-request.md` 或 `output/` 中预留任务记录。

## 资产检查

- [ ] 使用 story 内角色 ID。
- [ ] 使用 story 内场景 ID。
- [ ] 使用 story 内道具/特效 ID。
- [ ] 引用参考图路径。
- [ ] 禁止偏差写入 `continuity.md`。

## 发布检查

- [ ] 有 3 个标题候选。
- [ ] 有封面画面建议。
- [ ] 有封面大字。
- [ ] 有评论区引导。
- [ ] 有标签方向。
