# 电影感 3D 动漫 CG

成年动漫角色放在有真实材质、真实光线和镜头景深的空间里。画面像动画电影里截下的一帧，观众看得出角色正在看谁、听什么、准备做什么。

## 人物与材质

- 成年头身比，眼形沿用动漫的概括方式，虹膜略大，鼻梁、嘴唇和下颌用简洁的三维形体。通过眼睑、视线和嘴角表现情绪，保留发型剪影和脸部识别点。
- 头发先做清楚的大束和轮廓，只在逆光处露出细发丝。皮肤采用柔和的哑光明暗，布料、玻璃和金属按各自的反光特性呈现。压低毛孔、锐化、颗粒和密纹理。
- 科幻题材可用颈部、手指或关节上的局部义体。机械结构跟随人体关节和轮廓，细节集中在镜头看得清的位置。

## 光线与镜头

- **日景**以低饱和冷绿或灰绿做底，暖日光从侧后方穿过头发和肩线，脸上留柔和的环境反光。
- **夜景**保留有层次的暗部，用局部琥珀实景灯勾亮脸、手和道具。近景可以用冷侧光与暖轮廓光区分脸的两侧。背景色可随题材调整，维持局部用光和克制的饱和度。
- 半身和近景突出眼神、嘴角和关键道具。中远景留出环境和前景虚化，让人物坐在空间里。按发布画幅保留视线方向和动作空间，竖屏单独构图。
- 每个镜头给演员一个明确动作，例如先侧看再微笑、放下杯子再看向对方。避免全脸均匀打亮、满屏霓虹、皮肤塑料高光和正对镜头摆拍。

## 生成时怎么用

1. 有参考视频时，截取脸部最清楚的一帧和光线、构图最典型的一帧，把图片直接交给生成工具。逐张写明参考脸部、布光还是构图。需要复刻指定镜头时，以该原帧为主参考，优先对齐人物在画面里的大小、姿态和灯位。
2. 新角色先定自己的脸、发型、服装和识别点。确认正面或四分之三脸、表情近景和角色所在环境的中景后，把选定图用作后续镜头的角色参考。跨场景对照眼形、下颌、发型剪影和服装或义体位置。
3. 动态片段先用短镜头检查侧看、微笑或手部交互。回看眼镜、发型、五官、手和道具在动作前后是否稳定。本次样片是静帧参考，动态表现需看试镜成片。
