# 2026-10-13 工作流复盘

## 原问题与根因

- “准备今日3篇”调用固定技术fixture的/demo，只显示提示，没有跳转审核页；固定测试数据被误当成日常内容方向。
- “研究100”“策划50”和生成串行跑多轮Codex，并在长HTTP请求结束后刷新全部页面数据；部分旧任务真实运行几分钟，界面缺少本次任务进度。
- 选题库混入历史技术及Mock内容；没有近期时间窗口和自由方向入口。人工过滤与规则退回共用状态，导致过滤稿仍出现在审核池。

## 当前流程

填写方向（任意领域）与可选素材 → 提交后台任务 → 立即进入审核中心 → 每篇完成显示 → 修改、过滤或批准 → 审批即发布队列。

准备默认1篇，最多3篇；直接一次写作调用/篇，略过旧策划批次。模型仍为本机Codex CLI gpt-6.1-sol/high。任务有持久进度，HTTP不等模型完成，单篇调用上限120秒。生成不自动审批或发布；文章、账号、版本、图片哈希及停止保护保持执行。

热点来自百度公开实时热榜、Google News关键词搜索、中新网与BBC中文公开RSS。并行获取，最多20条，缓存15分钟，单源5秒/总12秒；新闻只收近72小时并区别24/72小时，热榜注明获取时间。不宣称覆盖全部互联网，不将标题链接扩写成未经提供的事件事实。切换方向隔离结果，最多选5个话题，其具体标题带入准备表单。

人工过滤REJECTED退出待审，质检退回QUALITY_REJECTED仍可编辑；过滤稿保留历史，可修改恢复。默认审核聚焦本次草稿，不把旧AI测试稿当成本次产物。诊断和Mock收进高级设置，首页只显示当前热点、准备、发布与复盘进度。
